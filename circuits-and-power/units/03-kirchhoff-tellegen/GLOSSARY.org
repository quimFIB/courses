The terms this unit introduces, in the order the deck meets them. The slides
stay the definition of record; each entry names the slide it comes from, so a
term can be looked up here and read properly there.

Running example: the Wheatstone bridge. Four nodes A, B, C, D; arms
\(R_1 = 100\ \Omega\) (A→B), \(R_2 = 200\ \Omega\) (B→C), \(R_3 = 300\ \Omega\)
(A→D), \(R_4 = 400\ \Omega\) (D→C); a detector \(R_g = 50\ \Omega\) (B→D); an
ideal source holding A 10 V above C, its edge oriented C→A. Its graph is
\(K_4\): cycle and cut spaces of dimension 3 each. Solved, \(\varphi_B =
780/121\) V and \(\varphi_D = 760/121\) V, the detector carries 3.306 mA, and
479.34 mW is delivered and absorbed. As a two-port its transfer resistances
are equal, \(100/29\ \Omega\) both ways. Values chosen for the example.

* A diagram becomes a graph

- graph, directed graph :: A finite set of \(n\) nodes and \(m\) edges, each
  edge joining two distinct nodes and carrying an orientation, from a tail to
  a head. Several edges may join the same two nodes. /Slide: Graphs: the
  words./
- edge :: One element of a circuit, seen as a connection between the two
  nodes its terminals sit on. Ideal wires are not edges; they are what a node
  is.
- orientation :: The choice of which end of an edge is its tail and which its
  head: the direction of its current arrow, with the + of the passive
  convention at the tail. A reference, not a claim about where charge flows;
  reversing it flips the signs of both \(v_e\) and \(i_e\) and leaves
  \(v_ei_e\) alone.
- path :: A sequence of distinct nodes, each joined to the next by an edge,
  traversed with or against the edges' arrows.
- cycle :: A path that returns to its first node, using at least one edge and
  no edge twice.
- connected component :: A largest set of nodes any two of which are joined by
  a path. The graph has \(c\) of them.
- complete graph :: The graph \(K_n\) on \(n\) nodes with one edge between
  every pair, \(n(n-1)/2\) edges in all. The bridge's graph is \(K_4\). /Slide:
  The bridge, drawn and as a graph./
- incidence matrix :: The \(n\times m\) matrix \(A\) with \(A_{ke} = +1\) if
  edge \(e\) leaves node \(k\), \(-1\) if it enters, \(0\) otherwise. \((Ai)_k\)
  is the net current leaving node \(k\); \((A^{\mathsf T}\varphi)_e =
  \varphi_{t(e)} - \varphi_{h(e)}\). Strang writes the transpose with the
  opposite sign. /Slide: The incidence matrix./

* The two laws as subspaces

- signed indicator :: For a cycle traversed in a chosen direction, the vector
  with \(+1\) on each edge it runs along, \(-1\) on each it runs against, \(0\)
  elsewhere. For a cut, \(A^{\mathsf T}\mathbf 1_S\). /Slide: The cycle space./
- cycle space :: \(\ker A\), the currents obeying Kirchhoff's current law in an
  isolated network; spanned by the signed indicators of cycles. Dimension
  \(m - n + c\).
- circulation :: A vector of edge currents in \(\ker A\): flow that balances at
  every node. Every circulation is a sum of multiples of cycle indicators.
- cut :: For a set of nodes \(S\), the edges with one end in \(S\) and one
  outside. Its signed indicator is \(A^{\mathsf T}\mathbf 1_S\): \(+1\) on edges
  leaving \(S\), \(-1\) on edges entering. /Slide: Cuts, and the cut space./
- cut space :: \(\operatorname{im}A^{\mathsf T}\), the voltages obeying
  Kirchhoff's voltage law, \(v = A^{\mathsf T}\varphi\); spanned by the signed
  indicators of cuts. Dimension \(n - c\). The orthogonal complement of the
  cycle space in \(\mathbb R^m\).
- cyclomatic number :: \(m - n + c\), the dimension of the cycle space: the
  number of independent loops. For a connected graph, the number of edges
  beyond a spanning tree. /Slide: The rank of \(A\) is \(n - c\)./

* Bases from a spanning tree

- spanning tree :: A tree containing every node of a connected graph and some
  of its edges. It exists, and has exactly \(n - 1\) edges. /Slide: Trees and
  spanning trees./
- tree :: A connected graph with no cycle.
- chord :: An edge not in a chosen spanning tree; there are \(m - n + 1\).
- fundamental cycle :: The cycle a chord closes with the unique tree path
  between its ends, oriented along the chord. The fundamental cycles of one
  tree are a basis of the cycle space. /Slide: Fundamental cycles./
- fundamental cut :: For a tree edge \(e\), the cut between the two pieces
  the tree falls into when \(e\) is deleted, oriented so that \(e\) has
  \(+1\). The fundamental cuts of one tree are a basis of the cut space.
  /Slide: Fundamental cuts./

* Nodal and mesh analysis

- nodal analysis :: Solving a circuit by writing every voltage as
  \(A^{\mathsf T}\varphi\), grounding one node per component, and imposing the
  current law at the other nodes: \(n - c\) unknowns, fewer where voltage
  sources fix potentials. A parametrisation of the cut space. /Slide: Nodal
  analysis./
- ground :: A node declared to be at potential zero, one per component,
  removing the constant that only differences leave free. Need not be joined
  to the earth.
- balance condition :: A bridge's detector carries no current exactly when
  \(R_1R_4 = R_2R_3\), whatever the detector's resistance and the source.
  /Slide: Balance./
- mesh analysis, loop analysis :: Solving a circuit by writing the currents as
  a combination of a basis of cycles, with unknown loop currents, and imposing
  the voltage law round each basis cycle: \(m - n + c\) unknowns. A
  parametrisation of the cycle space. /Slide: Mesh analysis./
- loop current :: A coefficient in mesh analysis: a current imagined to
  circulate round one basis cycle. An edge's current is the signed sum of the
  loop currents through it.
- Euler's formula :: For a connected graph drawn in the plane without
  crossings, \(n - m + f = 2\), with \(f\) counting faces including the outer
  one. /Slide: Plane drawings and Euler's formula./
- plane graph :: A graph drawn in the plane with no two edges crossing. A graph
  that can be so drawn is planar; \(K_5\) and \(K_{3,3}\) cannot.
- face :: One of the connected regions into which a plane graph divides the
  plane; exactly one, the outer face, is unbounded.
- mesh :: The boundary cycle of a bounded face of a plane graph. The meshes
  are a basis of the cycle space.

* Tellegen's theorem

- Tellegen's theorem :: On one oriented graph, any voltages obeying the
  voltage law and any currents obeying the current law satisfy
  \(v^{\mathsf T}i = 0\). Proof: \((A^{\mathsf T}\varphi)^{\mathsf T}i =
  \varphi^{\mathsf T}Ai = 0\). No element law is used; \(v\) and \(i\) may come
  from different networks on the graph or from different instants. With both
  from one network at one instant it is conservation of power. Tellegen,
  /Philips Research Reports/ 7, 259–269 (1952). /Slide: The theorem./

* Reciprocity, and where linearity stops

- port :: A pair of nodes at which current is fed into a network at one and
  taken out at the other; its voltage is the difference of their potentials.
  With injections \(s\), Tellegen gives \(v^{\mathsf T}i = \varphi^{\mathsf T}s\),
  the sum of port voltage times port current. /Slide: Ports, and the power fed
  in./
- two-port :: A network with two ports marked.
- transfer resistance :: \(z_{21}\): the voltage at port 2 per ampere fed into
  port 1, with port 2 open; \(z_{12}\) the reverse. Units: ohms.
- reciprocity :: In any network of linear resistors, \(z_{21} = z_{12}\).
  Proved from Tellegen's theorem across two experiments and the symmetry of
  \(R_e\hat\imath_e\tilde\imath_e\). For the bridge, \(100/29\ \Omega\) both
  ways. /Slide: Reciprocity, from Tellegen./
- dependent source :: An element whose voltage or current is set by a current
  or voltage elsewhere in the network, such as a current-controlled voltage
  source \(v_e = r\,i_f\). Networks containing one are in general not
  reciprocal. /Slide: Where reciprocity fails./
- superposition :: In a network of linear resistors and ideal sources with a
  unique solution, the response to several sources is the sum of the
  responses to each alone. Can fail once the network contains a nonlinear
  element such as a diode. /Slide: Superposition, and a diode./
- ideal diode :: An element with \(v\le0\), \(i\ge0\), \(vi = 0\) under the
  passive marking: conducting with no voltage, or blocking with no current.
  Defined as an element relation; not linear.

* The kitchen scale

- strain gauge :: A foil resistor bonded to a surface, whose resistance changes
  with the surface's strain: \(\Delta R/R = \mathrm{GF}\cdot\varepsilon\).
  Typically 120 Ω or 350 Ω (Vishay Micro-Measurements TN-505-6). /Slide:
  Strain gauges./
- gauge factor :: The dimensionless constant GF in \(\Delta R/R =
  \mathrm{GF}\cdot\varepsilon\). Taken as 2 in this unit, a representative
  value assumed for the example.
- quarter bridge :: A bridge with one strain gauge and three fixed arms. With
  equal arms and \(x = \Delta R/R\) its output is \(Vx/(2(2 + x))\approx
  Vx/4\), measured against zero. /Slide: One resistor against a bridge./
