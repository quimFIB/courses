The terms this unit introduces, in the order the deck meets them. The slides
stay the definition of record; each entry names the slide it comes from, so a
term can be looked up here and read properly there.

Running example: a load such as an antenna presenting 12.5 Ω (an assumed
value) at the end of unit 08's 50 Ω polyethylene cable, at an assumed 100 MHz,
where \(\lambda = 1.999\) m. Normalised, \(z_L = 0.25\), \(\Gamma_L = -0.6\),
VSWR 4. From a source matched to the line, 64% of the available power reaches
it and 36% returns (with 100 W available, assumed: 64 W, and \(|V|\) between
28.3 V and 113.1 V). Matched two ways: a 25 Ω quarter-wave section, 0.500 m
long (VSWR ≤ 1.5 over 35% of the frequency), or a short-circuited 50 Ω stub
0.4064\(\lambda\) long at 0.0738\(\lambda\) from the load (8.9%).

* The running example

- antenna :: The conductor that turns a guided wave into a radiated one
  (branch 16 says how). In this unit it is only a load impedance of stated
  value at the operating frequency: here 12.5 Ω, assumed. /Slide: Sixty-four
  per cent./
- feed line :: The line, usually a coaxial cable, that carries a
  transmitter's power to its antenna as a guided wave. /Slide: An antenna at
  the end of a feed line./

* The line in the steady state

- phase constant :: \(\beta = \omega/u = 2\pi/\lambda\), in rad/m: the rate at
  which a wave's phase turns with distance along a lossless line. A forward
  wave is \(V_+e^{i(\omega t - \beta z)}\). /Slide: Unit 08's line, in phasors./
- reflection coefficient at d :: \(\Gamma(d) = \Gamma_Le^{-2i\beta d}\): the
  ratio of the reflected to the forward wave at distance \(d\) from the load.
  On a lossless line its size is constant and it turns clockwise, once per
  half wavelength, as \(d\) grows. /Slide: The reflection coefficient turns as
  you walk./
- input impedance :: \(Z_{\mathrm{in}}(d) = V(d)/I(d) = Z_0(Z_L + iZ_0\tan\beta
  d)/(Z_0 + iZ_L\tan\beta d)\): the impedance a terminated length \(d\) of
  line presents at its near end, at one frequency. /Slide: Input impedance./
- normalised impedance :: \(z = Z/Z_0\), dimensionless. In it the reflection
  coefficient is \(\Gamma = (z - 1)/(z + 1)\).

* Standing waves

- standing wave :: The pattern \(|V(d)|\) made by a forward and a reflected
  wave together: fixed in space, periodic with period \(\lambda/2\), between
  \(|V_+|(1 - |\Gamma|)\) and \(|V_+|(1 + |\Gamma|)\). /Slide: The standing
  wave, and its ratio./
- standing-wave ratio, VSWR :: \(S = |V|_{\max}/|V|_{\min}\)
  \(= (1 + |\Gamma|)/(1 - |\Gamma|)\), from 1 (matched) to \(\infty\) (total reflection). The
  impedance is \(Z_0S\) at a voltage maximum and \(Z_0/S\) at a minimum.

* The quarter-wave line

- quarter-wave transformer :: A section of line a quarter wavelength long and
  of impedance \(Z_q = \sqrt{Z_0Z_L}\), which turns a resistive load \(Z_L\)
  into \(Z_q^2/Z_L = Z_0\): a match, at one frequency. /Slide: A quarter
  wavelength inverts impedance./
- half-wave line :: A line half a wavelength long: its input impedance equals
  its load, whatever its own \(Z_0\), at one frequency.

* Möbius maps

- Möbius transformation, Möbius map :: \(T(z) = (az + b)/(cz + d)\)
  with \(ad - bc \ne 0\), on the extended plane. A bijection of it, whose inverse is
  again Möbius. \(\Gamma(z) = (z - 1)/(z + 1)\) is one. /Slide: The reflection
  coefficient is a map./
- extended plane :: \(\mathbb C \cup \{\infty\}\): the complex plane with one
  point at infinity added, where an open circuit's impedance lives.
- translation :: \(z \mapsto z + b\). /Slide: Every Möbius map is built from
  three moves./
- dilation-rotation :: \(z \mapsto kz\), \(k \ne 0\): scales by \(|k|\) and
  turns by \(\arg k\).
- inversion :: \(z \mapsto 1/z\). Every Möbius map is a composition of
  translations, dilation-rotations and at most one inversion.
- generalised circle :: A circle or a line: the set \(A|z|^2 + B\bar z + \bar
  Bz + C = 0\) with \(A, C\) real and \(|B|^2 > AC\); a line is the case \(A =
  0\), a circle through \(\infty\). Möbius maps send generalised circles to
  generalised circles. /Slide: Circles and lines are one family./
- positive-real :: Unit 05's term: an impedance with \(\operatorname{Re}Z(s)
  \ge 0\) for \(\operatorname{Re}s > 0\), true of every network of positive R,
  L, C; on the imaginary axis, \(\operatorname{Re}Z(i\omega) \ge 0\). Here:
  such impedances are exactly those with \(|\Gamma| \le 1\). /Slide: The
  passive half-plane is the disc./

* The Smith chart

- constant-resistance circle :: The image in the \(\Gamma\)-plane of the line
  \(\operatorname{Re}z = r\): the circle of centre \(r/(1 + r)\) and radius
  \(1/(1 + r)\), through \(\Gamma = 1\). /Slide: Constant resistance: circles
  through Γ = 1./
- constant-reactance circle :: The image of the line \(\operatorname{Im}z =
  x\): the circle of centre \(1 + i/x\) and radius \(1/|x|\), of which the arc
  inside the unit disc is used. /Slide: Constant reactance: circles centred at
  1 + i/x./
- Smith chart :: The unit disc in the \(\Gamma\)-plane ruled with the
  constant-resistance and constant-reactance circles: a map of every passive
  impedance, on which a lossless line acts by rotation. Named after P. H.
  Smith (/Electronics/, January 1939). /Slide: The Smith chart./
- toward the generator :: The direction away from the load along the line. On
  the chart, moving that way is a clockwise rotation by \(4\pi d/\lambda\).
  /Slide: Walking along the line turns the chart./
- normalised admittance :: \(y = 1/z = YZ_0 = g + ib\). /Slide: The admittance
  chart./
- admittance chart :: The Smith chart's grid turned through 180°, read as
  \(g + ib\): since \(\Gamma(1/z) = -\Gamma(z)\), the same point \(\Gamma\)
  carries admittance \(y\) on it.

* Matching with a stub

- stub :: A length of line, short-circuited (or open) at its far end,
  connected across a line as a pure susceptance: \(y = -i\cot\beta\ell\) when
  shorted. /Slide: A shunt stub./
- single-stub matching :: Moving from the load to a point where \(y = 1 +
  ib\), and connecting there a stub of susceptance \(-ib\), so that the line
  sees \(y = 1\).

* The antenna, and the band

- matching network :: A lossless two-port between a line and its load that
  makes the line see \(Z_0\) at the operating frequency. /Slide: An antenna at
  the end of a feed line./
- L-network :: A matching network of one series and one shunt reactance,
  built from unit 05's inductors and capacitors.
