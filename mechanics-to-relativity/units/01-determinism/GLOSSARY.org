The terms this unit introduces, in the order the deck meets them. The slides
stay the definition of record; each entry names the slide it comes from, so a
term can be looked up here and read properly there.

Running example: Norton's dome, the frictionless surface \(h(r) = -\frac{2k}{3g}
r^{3/2}\) with \(r\) the arc length from the apex, whose equation of motion is
\(\ddot r = k\sqrt r\) and whose initial value problem \(r(0) = \dot r(0) = 0\)
has the one-parameter family \(r_T(t) = \frac{k^2}{144}(t-T)^4\) (for \(t \ge
T\), zero before) as solutions, one for every \(T \ge 0\).

* The claim, and phase space

- determinism :: The assertion that a law \(\dot y = f(y,t)\) together with a
  state \(y_0\) at time \(t_0\) admits *exactly one* solution. Three separable
  claims: existence, uniqueness, and existence for all time. /Slide: Laplace,
  made precise./
- initial value problem (IVP) :: The pair (equation, initial state) whose
  solutions determinism is a claim about: \(\dot y = f(y,t)\), \(y(t_0) = y_0\).
- state :: The finitely many numbers whose present values, with the law, fix the
  future. For a mechanical system it is the pair \(y = (x, \dot x)\), never the
  position alone. /Slide: The state is a point of phase space./
- phase space :: The space \(\mathbb{R}^{2n}\) of states of a system with
  configuration space \(\mathbb{R}^n\). What a law of motion propagates is a
  point of phase space, not a point of space.
- phase-space reduction :: The theorem that \(m\ddot x = F(x,\dot x,t)\) on
  \(\mathbb{R}^n\) is equivalent to the first-order system \(\dot y = f(y,t)\)
  on \(\mathbb{R}^{2n}\) with \(f((x,v),t) = (v, F(x,v,t)/m)\). Every theorem of
  this unit is therefore about first-order systems only. /Slide: Every Newtonian
  law is a first-order system./
- first-order system :: \(\dot y = f(y,t)\) with \(y\) taking values in
  \(\mathbb{R}^N\) and \(f\) defined on an open \(\Omega \subseteq \mathbb{R}^N
  \times \mathbb{R}\). Autonomous when \(f\) does not depend on \(t\).
- Norton's dome :: The frictionless surface of revolution \(h(r) = -\frac{2k}{3g}
  r^{3/2}\), with \(r\) the arc length from the apex down a meridian. Tangential
  Newton gives \(\ddot r = k \sqrt r\); the surface exists only for \(r \le
  g^2/k^2\), which is 96.17 m when \(k = 1\,\mathrm{m^{1/2}s^{-2}}\). /Slide:
  Norton's dome: the surface, and its equation./

* Existence, and exactly one of them

- Picard integral equation :: \(y(t) = y_0 + \int_{t_0}^t f(y(s),s)\,\mathrm{d}s\),
  equivalent to the initial value problem for continuous \(y\), and the form in
  which the problem is solved. It absorbs the initial condition and asks only
  for continuity of the candidate. /Slide: Step one: turn the ODE into an
  integral equation./
- Lipschitz in \(y\), Lipschitz condition :: \(\|f(y,t) - f(z,t)\| \le L\|y-z\|\)
  for all \((y,t), (z,t)\) in a set, with one constant \(L\). Compared at the
  same instant; no regularity in \(t\) is asked for. The one hypothesis this
  unit is about. /Slide: The Lipschitz condition./
- locally Lipschitz :: Lipschitz in \(y\) on a neighbourhood of every point of
  the domain, with a constant that may vary from place to place but is finite
  everywhere. Enough for Picard–Lindelöf, since a compact set then carries a
  single constant.
- Hölder continuous, Hölder continuity :: \(|g(a)-g(b)| \le C|a-b|^\alpha\) for
  some \(\alpha \in (0,1]\). The square root is Hölder with \(\alpha = 1/2\) and
  Lipschitz with none: \(\alpha = 1\) is the Lipschitz case, and everything below
  it is on the wrong side of Osgood's line.
- contraction :: A map \(P\) of a metric space to itself with \(d(Pu,Pw) \le q\,
  d(u,w)\) for a fixed \(q < 1\). Strict decrease of distances is *not* enough.
  /Slide: The contraction mapping principle./
- Banach fixed-point theorem :: A contraction of a non-empty complete metric
  space has exactly one fixed point, the iterates \(u_{n+1} = Pu_n\) converge to
  it from any start, and \(d(u_n, u^\ast) \le \frac{q^n}{1-q} d(u_1,u_0)\).
  Constructive: it names the sequence and bounds the error.
- sup norm (uniform norm) :: \(\|y\|_\infty = \sup_{t \in J}\|y(t)\|\) on
  \(C(J,\mathbb{R}^N)\), which is complete in it — the reason the problem was
  moved to continuous functions. /Slide: The space the contraction acts on./
- weighted sup norm (Bielecki norm) :: \(\|y\|_\lambda = \sup_{t \in J}
  e^{-\lambda|t-t_0|}\|y(t)\|\). Equivalent to the sup norm on a compact \(J\),
  so completeness transfers, and it makes the Picard operator a contraction with
  factor \(L/\lambda\) for any \(L\) — which is what keeps the existence
  interval from shrinking as the force stiffens.
- compact cylinder :: \(\mathcal{C} = \{(y,t) : \|y-y_0\| \le b,\ |t-t_0| \le
  c\} \subseteq \Omega\), on which \(f\) is bounded by \(M\) and Lipschitz with
  constant \(L\). Its shape alone fixes the guaranteed interval,
  \(a = \min(c, b/M)\). /Slide: Picard–Lindelöf./
- Picard–Lindelöf (the Cauchy–Lipschitz theorem) :: If \(f\) is continuous and
  locally Lipschitz in \(y\) on an open \(\Omega\), every initial value problem
  in \(\Omega\) has exactly one solution on \([t_0-a, t_0+a]\) with \(a =
  \min(c, b/M)\). The course's licence to write /the/ solution.
- Picard operator :: \((Py)(t) = y_0 + \int_{t_0}^t f(y(s),s)\,\mathrm{d}s\),
  acting on the tube \(X = \{y \in C(J,\mathbb{R}^N) : \|y(t)-y_0\| \le b\}\).
  Solutions are exactly its fixed points. /Slide: Proof, part 1: the operator
  maps the tube into itself./
- Picard iteration :: The sequence \(y^{(n+1)} = P y^{(n)}\) from any starting
  curve, usually the constant \(y_0\). For \(\ddot x = -x\) it produces the
  Taylor partial sums of \(\cos\) and \(-\sin\). /Slide: Picard's iteration, run./

* Where the hypothesis fails

- Peano existence theorem :: Continuity of \(f\) alone gives *at least one*
  solution through every point. Cited, not proved here: it needs Arzelà–Ascoli.
  So a continuous force law never lacks a trajectory — it may only have too
  many. /Slide: Continuity alone: Peano, and the sharp line./
- Osgood's criterion :: Uniqueness already follows from \(\|f(y,t)-f(z,t)\| \le
  \omega(\|y-z\|)\) with \(\int_{0^+}\mathrm{d}u/\omega(u) = \infty\). Lipschitz
  is \(\omega(u) = Lu\); the dome has \(\omega(u) \sim k\sqrt u\), whose integral
  converges. The sharp line the dome is on the far side of.

* How far the guarantee reaches

- Grönwall's inequality :: If \(u \ge 0\) is continuous and \(u(t) \le A +
  L\int_{t_0}^t u\), then \(u(t) \le A e^{L(t-t_0)}\). Turns an implicit bound
  into an explicit one; with \(A = 0\) it is a one-line uniqueness proof.
  /Slide: Grönwall's inequality./
- continuous dependence, continuous dependence on initial data :: \(\|y(t)-z(t)\|
  \le \|y(t_0)-z(t_0)\|e^{L(t-t_0)}\) for two solutions of the same
  \(L\)-Lipschitz equation. The third of Hadamard's conditions for a well-posed
  problem, and a worst case over all equations with that \(L\), not a prediction
  for one of them. /Slide: Continuous dependence on the initial state./
- maximal interval of existence :: The open interval \((T_-,T_+)\) on which the
  unique solution through a point lives and which extends every other solution.
  Open, because a solution reaching an interior point of \(\Omega\) could be
  continued. /Slide: The maximal interval of existence./
- leaves every compact subset, escape lemma :: If \(T_+ < \infty\) the solution
  leaves every compact \(K \subseteq \Omega\) before \(T_+\). So a solution can
  end only by going to infinity or by reaching the boundary of \(\Omega\); it
  cannot merely stop.
- blow-up in finite time :: The first mode of the escape lemma, \(\|y(t)\| \to
  \infty\) as \(t \to T_+ < \infty\). Happens for perfectly smooth right-hand
  sides: \(\dot x = x^2\) with \(x(0) = x_0 > 0\) ends at \(t = 1/x_0\). /Slide:
  Two solutions that end./
- global existence :: Every solution lives on all of \(\mathbb{R}\). Guaranteed
  by linear growth, \(\|f(y,t)\| \le C(1+\|y\|)\) on each finite strip of time —
  which the pendulum satisfies, so the pendulum is deterministic as a theorem.
  /Slide: When does a solution live forever?./
