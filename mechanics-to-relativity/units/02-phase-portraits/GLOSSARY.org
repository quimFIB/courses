The terms this unit introduces, in the order the deck meets them. The slides
stay the definition of record; each entry names the slide it comes from, so a
term can be looked up here and read properly there.

Running example: the damped pendulum \(\ddot\theta + \gamma\dot\theta + \sin\theta
= 0\), written as \(\dot\theta = \omega\), \(\dot\omega = -\gamma\omega -
\sin\theta\) on the cylinder \(S^1\times\mathbb{R}\). Equilibria at \((0,0)\)
(hanging, a stable spiral for \(0<\gamma<2\)) and \((\pi,0)\) (upright, a saddle
for every \(\gamma\)). Energy \(V = \tfrac12\omega^2 + (1-\cos\theta)\) with
\(\dot V = -\gamma\omega^2\). At \(\gamma = \tfrac12\) the eigenvalues are
\(-0.25 \pm 0.9682\,i\) below and \(0.7808, -1.2808\) above.

* Vector fields, orbits and flows

- vector field :: A map \(f : U \subseteq \mathbb{R}^n \to \mathbb{R}^n\), read as
  attaching a velocity to each point. An autonomous differential equation and a
  vector field are the same object written two ways. /Slide: An autonomous system
  is a vector field./
- equilibrium (equilibria) :: A point with \(f(\mathbf x^*) = 0\); the constant
  curve there is an orbit, and by uniqueness the only one through it. The first
  thing to compute about any system. /Slide: Linearisation: what it is, and what
  it claims./
- basin of attraction :: The set of initial conditions whose orbits converge to a
  given attracting set. Linearisation never produces one; a Lyapunov function
  with a bounded sublevel set does. /Slide: The damped pendulum stops, and we can
  say where from./
- autonomous system :: \(\dot{\mathbf x} = f(\mathbf x)\), with no explicit \(t\)
  on the right. Autonomy is what makes a phase portrait well defined: the arrow
  at a point never changes. /Slide: An autonomous system is a vector field./
- solution :: A differentiable curve with \(\mathbf x'(t) = f(\mathbf x(t))\),
  defined on its maximal interval (unit 01).
- orbit :: The image of a solution, forgetting the parametrisation. Orbits are
  either disjoint or identical, so they partition the state space.
- phase portrait :: Every orbit drawn at once in the state space. It is the
  equation drawn, not an approximation to it.
- flow :: The family \(\varphi_t\) sending \(\mathbf x_0\) to the solution through
  it at time \(t\). /Slide: The flow is a one-parameter group./
- one-parameter group property :: \(\varphi_{t+s} = \varphi_t \circ \varphi_s\)
  and \(\varphi_0 = \mathrm{id}\), proved from uniqueness alone. When every
  solution is global this makes \(t \mapsto \varphi_t\) a homomorphism
  \((\mathbb{R},+) \to \mathrm{Homeo}(U)\).
- local flow :: What is left of the flow when solutions blow up in finite time:
  \(\varphi_t\) defined only on part of \(U\), and no group.
- first integral :: A non-constant \(E\) that is constant along every solution.
  In the plane its level curves /are/ the phase portrait. /Slide: Two flows with
  extra structure./
- gradient system :: \(\dot x_i = -\partial V/\partial x_i\). Then \(\dot V =
  -\sum_i (\partial_i V)^2 \le 0\), so no periodic orbit can exist. A flow with
  \(\dot V \le 0\) but no such potential is called /gradient-like/, and the
  damped pendulum is one.

* Equilibria and linearisation

- differentiable :: \(f\) is differentiable at \(\mathbf a\) if some linear map
  \(A\) has \(f(\mathbf a + \mathbf h) = f(\mathbf a) + A\mathbf h +
  o(|\mathbf h|)\). The map is the definition; the array of partial derivatives
  is its matrix. /Slide: The derivative of a map, in one slide./
- Jacobian matrix :: The matrix \((\partial f_i/\partial x_j)\) of
  \(Df(\mathbf a)\) in the standard bases — a theorem about the derivative, not
  its definition. Continuous partials imply differentiability; the converse of
  that is proved in unit 03.
- linearisation :: The linear system \(\dot{\boldsymbol\xi} = Df(\mathbf
  x^*)\boldsymbol\xi\) obtained by discarding the \(o(|\boldsymbol\xi|)\)
  remainder at an equilibrium. Discarding it is an assumption, licensed only by
  hyperbolicity. /Slide: Linearisation: what it is, and what it claims./
- hyperbolic :: Of an equilibrium: no eigenvalue of \(Df(\mathbf x^*)\) has zero
  real part. Exactly the hypothesis of Hartman–Grobman, and exactly what fails on
  the two lines \(\Delta = 0\) and \(\tau = 0\). /Slide: Hartman–Grobman, and the
  hole in it./
- trace–determinant plane :: The classification of real \(2\times2\) systems by
  \(\tau = \operatorname{tr}A\) and \(\Delta = \det A\), since \(\lambda^2 -
  \tau\lambda + \Delta = 0\). Stability is \(\tau < 0\) /and/ \(\Delta > 0\).
  /Slide: Planar linear systems: two numbers decide./
- saddle :: \(\Delta < 0\): real eigenvalues of opposite sign, one direction in
  and one out. Index \(-1\).
- node :: \(\Delta > 0\), \(\tau^2 > 4\Delta\): real eigenvalues of the same
  sign, orbits entering or leaving along eigendirections.
- spiral :: \(\tau^2 < 4\Delta\): complex eigenvalues \(\alpha \pm i\beta\), the
  radius going as \(e^{\alpha t}\) and the angle at rate \(\beta\).
- centre :: \(\tau = 0 < \Delta\): purely imaginary eigenvalues, closed orbits in
  the linear system — and no information whatever about the nonlinear one.
- star node :: The case \(A = \lambda I\): every ray is an orbit. /Slide: Solving
  \(\dot\xi = A\xi\), all three cases./
- degenerate node :: A repeated eigenvalue with only one eigendirection; the
  solution picks up a factor \(t\), from the \(2\times2\) Jordan form.
- topological conjugacy :: A homeomorphism carrying orbits of one flow onto
  orbits of another and preserving time. What Hartman–Grobman provides at a
  hyperbolic equilibrium — continuous only, so rates are not preserved. /Slide:
  Hartman–Grobman, and the hole in it./

* Lyapunov's direct method

- stable :: For every \(\varepsilon\) there is \(\delta\) such that orbits
  starting within \(\delta\) stay within \(\varepsilon\), for all \(t \ge 0\).
  /Slide: Stability, defined./
- asymptotically stable :: Stable, /and/ nearby orbits converge to the
  equilibrium. Attraction alone does not imply stability: both halves are needed.
- unstable :: Not stable. Note this is a statement about arbitrarily small
  neighbourhoods, not about how fast anything grows.
- orbital derivative :: \(\dot V(\mathbf x) = \sum_i \partial_i V(\mathbf x)\,
  f_i(\mathbf x)\), the rate of change of \(V\) along whichever orbit passes
  through \(\mathbf x\). It is a function of position alone, so it is computable
  without solving anything — the "direct" in Lyapunov's direct method. /Slide:
  Differentiating along a solution./
- Lyapunov function :: \(V\) positive definite at an equilibrium with \(\dot V
  \le 0\) nearby: proves stability, and asymptotic stability when \(\dot V < 0\)
  off the equilibrium. There is no algorithm for finding one; in mechanics the
  energy is the standing first guess. /Slide: Lyapunov's theorem./
- omega-limit set :: \(\omega(\mathbf x_0)\), the set of limits of
  \(\varphi_{t_n}(\mathbf x_0)\) along sequences \(t_n \to \infty\). For a forward
  orbit with compact closure it is non-empty, compact, connected and invariant,
  and the orbit approaches it. /Slide: Where orbits end up: \(\omega\)-limit
  sets./
- invariant :: \(\varphi_t(S) = S\) for all \(t\). Forward invariance is the
  same with \(\subseteq\) and \(t \ge 0\).
- forward invariant :: \(\varphi_t(S) \subseteq S\) for \(t \ge 0\): once in,
  never out. A bounded sublevel set \(\{V \le c\}\) of a Lyapunov function is the
  standard example.
- LaSalle's invariance principle :: On a compact forward invariant \(\Omega\)
  with \(\dot V \le 0\), every orbit approaches the largest invariant subset of
  \(\{\dot V = 0\}\). It replaces Lyapunov's "\(\dot V < 0\) everywhere", which
  damping never satisfies, by "nothing can stay where \(\dot V = 0\)". /Slide:
  LaSalle's invariance principle./

* Periodic orbits

- periodic orbit :: A non-equilibrium orbit with \(\varphi_T(\mathbf x_0) =
  \mathbf x_0\); the least such \(T\) is the period. Returning once means
  returning forever, by the group property. /Slide: Periodic orbits and limit
  cycles./
- limit cycle :: A periodic orbit that is the \(\omega\)-limit set of some orbit
  off it — isolated, hence attracting or repelling. Its amplitude belongs to the
  equations, not to the initial data. A conservative system has none.
- trapping region :: A compact set whose boundary the field crosses inwards, so
  no orbit leaves. With no equilibrium inside, Poincaré–Bendixson turns it into
  an existence proof for a cycle. /Slide: Poincaré–Bendixson./
- Poincaré–Bendixson theorem :: In the /plane/: a forward orbit confined to a
  compact set free of equilibria has a periodic orbit as its \(\omega\)-limit
  set. Its engine is the Jordan curve theorem, so it is false in three
  dimensions.
- Bendixson–Dulac criterion :: If \(\partial_x f_1 + \partial_y f_2\) has one
  strict sign on a simply connected region, that region holds no periodic orbit.
  Proved by Green's theorem in unit 05. On the cylinder it rules out only the
  contractible cycles. /Slide: Ruling cycles out./

* The index of a vector field

- index :: Of a closed curve on which \(f \ne 0\): the net number of turns the
  field makes along it, \((\vartheta(1)-\vartheta(0))/2\pi \in \mathbb{Z}\).
  Invariant under any homotopy that avoids the zeros of \(f\). /Slide: The index
  of a closed curve./
- index of an equilibrium :: The index of a small circle around it. Equal to
  \(\operatorname{sign}\det Df\) when that is nonzero: \(+1\) for nodes, spirals,
  stars and centres, \(-1\) for saddles. /Slide: Indices of equilibria, and what
  they count./
- Poincaré index theorem :: The index of a curve bounding a disc is the sum of
  the indices of the equilibria inside. With the Umlaufsatz — a periodic orbit
  has index \(+1\) — it gives three non-existence results for cycles at the cost
  of two determinants.

* Bifurcations

- bifurcation :: A parameter value at which the phase portrait stops being
  topologically equivalent to its neighbours. By Hartman–Grobman these can only
  occur where hyperbolicity fails. /Slide: Families, and where the portrait
  breaks./
- saddle-node bifurcation :: Normal form \(\dot x = \mu - x^2\): two equilibria
  for \(\mu > 0\), none for \(\mu < 0\), colliding at \(\mu = 0\). In the plane a
  \(+1\) and a \(-1\) annihilate, conserving the total index.
- transcritical bifurcation :: Normal form \(\dot x = \mu x - x^2\): two branches
  that cross and exchange stability, creating and destroying nothing. Needs a
  branch that persists for all \(\mu\). /Slide: Transcritical and pitchfork./
- pitchfork bifurcation :: Normal form \(\dot x = \mu x \mp x^3\): a symmetric
  pair of branches appears. /Supercritical/ (\(-x^3\)) they are stable and the
  transition is soft; /subcritical/ (\(+x^3\)) they are unstable and the system
  jumps. Needs a symmetry \(f(-x) = -f(x)\).
- Hopf bifurcation :: A pair of eigenvalues crosses the imaginary axis and a
  limit cycle of amplitude \(\propto\sqrt{|\mu|}\) is born. Normal form \(\dot r
  = \mu r - r^3\), \(\dot\theta = \omega_0\). The first genuinely
  two-dimensional bifurcation. /Slide: Hopf: an equilibrium trades stability for
  a cycle./

* Carried in from units 00 and 01

- Picard–Lindelöf :: Local existence and uniqueness for \(\dot{\mathbf y} =
  f(\mathbf y, t)\) with \(f\) locally Lipschitz in \(\mathbf y\). Every "by
  uniqueness" in this unit is this theorem.
- continuous dependence :: The flow map depends continuously on the initial
  point, with Gronwall's bound \(|\varphi_t(x) - \varphi_t(y)| \le
  e^{Lt}|x-y|\). It is what makes \(\omega\)-limit sets invariant.
- quadrature :: Unit 00's reduction of \(\ddot x = F(x)\) to an integral by
  multiplying through by \(\dot x\). It is exactly what damping destroys, which
  is why this unit exists.
