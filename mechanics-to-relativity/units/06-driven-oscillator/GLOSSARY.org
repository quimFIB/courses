The terms this unit introduces, in the order the deck meets them. The slides
stay the definition of record; each entry names the slide it comes from, so a
term can be looked up here and read properly there.

Running example: a moving-coil galvanometer,
\(I\ddot\theta + b\dot\theta + \kappa\theta = \alpha\,i(t)\) with
\(I = 1.0\times10^{-8}\,\mathrm{kg\,m^2}\),
\(\kappa = 6.4\times10^{-7}\,\mathrm{N\,m\,rad^{-1}}\),
\(\alpha = 2.0\times10^{-3}\,\mathrm{N\,m\,A^{-1}}\) and coil resistance
\(r = 5\,\Omega\). Hence \(\omega_0 = 8\,\mathrm{rad\,s^{-1}}\), free period
\(0.7854\) s, and \(\gamma = 400/(R+r)\,\mathrm{s^{-1}}\) with \(R\) the
external resistance: one knob that sweeps every regime. \(R = 995\,\Omega\)
gives \(\gamma = 0.4\) and \(Q = 20\); \(R = 20\,\Omega\) gives
\(\gamma = 16 = 2\omega_0\), critical; \(R = 0\) gives \(\gamma = 80\),
overdamped.

* Why this equation, and the complex numbers

- small oscillations :: The motion near a minimum \(x_*\) of a potential,
  after \(V\) is replaced by its second-order Taylor polynomial:
  \(m\ddot\xi = -V''(x_*)\xi + O(\xi^2)\) with \(\xi = x - x_*\). The
  approximation is quantitative — the dropped term is bounded by
  \(\tfrac12\varepsilon^2\max|V'''|\) on \(|\xi|\le\varepsilon\) — and it is
  why one equation covers so much physics. /Slide: Every minimum is a spring./
- harmonic oscillator :: \(\ddot\xi + \omega_0^2\xi = 0\) with
  \(\omega_0 = \sqrt{V''(x_*)/m}\). The universal local model of a stable
  equilibrium, exact only for a quadratic potential.
- damping :: A force \(-b\dot x\), linear in the velocity, added as a
  phenomenological law exactly as unit 00 admitted force laws as input. In the
  running example it is derived rather than postulated: a coil moving in a
  field induces a current \(-\alpha\dot\theta/(R+r)\) and so a torque
  \(-\alpha^2\dot\theta/(R+r)\), whence \(\gamma = \alpha^2/(I(R+r))\).
  /Slide: The galvanometer, and the knob that is \(\gamma\)./
- complex numbers :: \(\mathbb{C}\) is \(\mathbb{R}^2\) with the
  multiplication \((a,b)(c,d) = (ac-bd,\,ad+bc)\); it is a field, with
  \(z^{-1} = \bar z/|z|^2\). It is introduced here for one purpose: so that
  every quadratic factorises, and one calculation covers all three damping
  regimes instead of three. /Slide: \(\mathbb{C}\), and the one property we
  want./
- complex conjugate :: \(\overline{a+bi} = a-bi\). Conjugation is a field
  automorphism fixing \(\mathbb{R}\), and \(z\bar z = |z|^2\).
- modulus :: \(|z| = \sqrt{z\bar z} = \sqrt{a^2+b^2}\), the Euclidean length
  of \(z\) as a point of the plane. Multiplicative: \(|zw| = |z||w|\).
- argument :: For \(z\ne0\), the angle \(\varphi\) with
  \(z = |z|(\cos\varphi+i\sin\varphi)\), unique modulo \(2\pi\). The unit pins
  a branch whenever it matters: the phase lag is taken in \((0,\pi)\).
- complex exponential :: \(\exp z = \sum_{n\ge0}z^n/n!\), absolutely
  convergent for every \(z\). Its two properties:
  \(\exp(z+w) = \exp z\exp w\), by the Cauchy product and the binomial
  theorem; and
  \(\frac{\mathrm{d}}{\mathrm{d}t} e^{\lambda t} = \lambda e^{\lambda t}\) for
  real \(t\) and complex \(\lambda\), proved by differentiating the real and
  imaginary parts. Used as algebra: no complex analysis until unit 20. /Slide:
  The complex exponential./
- Euler's formula :: \(\exp(i\vartheta) = \cos\vartheta + i\sin\vartheta\),
  obtained by splitting the absolutely convergent series into even and odd
  terms. Hence \(|e^{a+bi}| = e^a\), and every trigonometric identity in this
  unit becomes algebra with exponentials.

* The free equation, and its two-dimensional solution space

- linear differential operator ::
  \(L : C^2(\mathbb{R},\mathbb{R}) \to C^0(\mathbb{R},\mathbb{R})\),
  \(Lx = \ddot x + \gamma\dot x + \omega_0^2x\). Linear because
  differentiation is, so every theorem of linear algebra applies verbatim in
  an infinite-dimensional space. /Slide: \(L\) is a linear map between
  function spaces./
- homogeneous :: The equation \(Lx = 0\); its solution set is the subspace
  \(\ker L\).
- inhomogeneous :: The equation \(Lx = f\) with \(f \ne 0\); its solution set
  is the coset \(x_p + \ker L\) for any one particular solution \(x_p\).
- superposition principle :: The structure theorem
  \(\{x : Lx = f\} = x_p + \ker L\), and its corollary that responses to
  separate drives add. A physical claim as well as an algebraic one: nature
  obeys it only so far as the equation is linear.
- evaluation map :: \(\mathrm{ev} : \ker L \to \mathbb{R}^2\),
  \(x \mapsto (x(t_0),\dot x(t_0))\). It is injective by unit 01's uniqueness
  theorem and surjective by unit 01's global existence theorem for a field of
  linear growth, hence an isomorphism — which is why \(\dim\ker L = 2\).
  "Second order, so two constants" is folklore and is false without linearity:
  unit 01's dome is the counterexample. /Slide: \(\dim \ker L = 2\), and unit
  01 is the reason./
- characteristic polynomial ::
  \(p(\lambda) = \lambda^2 + \gamma\lambda + \omega_0^2\), defined by
  \(Le^{\lambda t} = p(\lambda)e^{\lambda t}\). Its roots
  \(\lambda_\pm = -\gamma/2 \pm \sqrt{\gamma^2/4-\omega_0^2}\) decide
  everything, and both have \(\operatorname{Re}\lambda \le 0\). /Slide: The
  characteristic polynomial./
- repeated root :: The case \(p(\lambda) = p'(\lambda) = 0\), i.e.
  \(\gamma = 2\omega_0\). Then
  \(L(te^{\lambda t}) = p(\lambda)te^{\lambda t} + p'(\lambda)e^{\lambda t} = 0\),
  so \(te^{\lambda t}\) is a second solution. The same identity, used where
  \(p \ne 0\), produces the secular term at undamped resonance.
- Wronskian :: \(W = x_1\dot x_2 - x_2\dot x_1\) for two solutions: the
  determinant of the matrix of their states, hence the signed phase-space area
  they span. /Slide: The Wronskian, and Abel's identity./
- Abel's identity :: \(\dot W = -\gamma W\), so
  \(W(t) = W(t_0)e^{-\gamma(t-t_0)}\): the Wronskian is never zero or
  identically zero. Read physically, the flow contracts phase-space area at
  the rate \(\gamma = -\operatorname{tr}A\), which is unit 14's Liouville
  theorem in miniature.
- fundamental system :: A basis \(\{x_1,x_2\}\) of \(\ker L\). Equivalent to
  \(W \ne 0\) at one instant, and to \(W \ne 0\) at every instant — so
  independence may be checked at whichever \(t\) is convenient.
- variation of parameters :: The construction of a particular solution as
  \(u_1x_1+u_2x_2\) with the imposed constraint
  \(\dot u_1x_1+\dot u_2x_2 = 0\), giving
  \(x_p(t) = \int_{t_0}^{t}K(t,s)f(s)\,\mathrm{d}s\) with
  \(K(t,s) = (x_1(s)x_2(t)-x_2(s)x_1(t))/W(s)\). A closed form for every
  continuous drive, with no ansatz. Lagrange, 1808, for planetary
  perturbations. /Slide: Variation of parameters: any drive at all./

* Damping regimes

- underdamped :: \(\gamma < 2\omega_0\), complex roots, ringing decay. /Slide:
  Worked: the galvanometer's three regimes./
- critically damped :: \(\gamma = 2\omega_0\), a repeated root, basis
  \(\{e^{-\omega_0t}, te^{-\omega_0t}\}\). The unique damping that returns
  fastest without overshoot, which is why pointer instruments are built at it;
  in unit 02's language, a \(2\times2\) Jordan block.
- overdamped :: \(\gamma > 2\omega_0\), two real negative roots. The slow root
  \(\lambda_+ \to -\omega_0^2/\gamma \to 0\), so more damping means a /slower/
  return: the galvanometer takes \(5.7\) s shorted against \(0.83\) s at
  critical.
- damped natural frequency ::
  \(\omega_\mathrm{d} = \sqrt{\omega_0^2-\gamma^2/4} < \omega_0\), the
  frequency of the free ringing. Damping shifts the frequency only at second
  order in \(1/Q\) — \(0.031\%\) at \(Q = 20\) — which is why a lossy
  oscillator can still be a clock. /Slide: Underdamped: ringing, and how fast
  it dies./
- logarithmic decrement ::
  \(\delta = \ln(\theta_n/\theta_{n+1}) = \gamma T_\mathrm{d}/2 = \pi\gamma/\omega_\mathrm{d}\),
  the log of the ratio of successive maxima, constant from swing to swing.
  Measuring it is how \(\gamma\) is measured; that the /ratio/ rather than the
  difference is constant is the test that the damping really is linear in the
  velocity.
- quality factor :: \(Q = \omega_0/\gamma\). Two exact readings — the resonant
  gain over the static deflection, and \(\omega_0\) divided by the half-power
  width — and two approximate ones, good to \(O(1/Q)\): radians of oscillation
  per \(e\)-fold of energy, and \(2\pi\) times stored energy over energy lost
  per cycle. At \(Q = 20\) the last is \(16.5\%\) out. /Slide: \(Q\): one number
  for how good the oscillator is./

* Driving, and resonance

- transient :: The \(\ker L\) part of a driven solution. It carries the
  initial conditions and decays like \(e^{-\gamma t/2}\), so after a few decay
  times the oscillator has forgotten how it started. /Slide: Transient plus
  steady state./
- steady state :: The surviving particular solution, the same for every
  initial condition: the unique solution bounded on all of \(\mathbb{R}\) when
  \(\gamma > 0\). It is what makes a resonance curve a property of the system
  rather than of the experiment.
- frequency response ::
  \(\chi(\omega) = 1/p(i\omega) = 1/(\omega_0^2-\omega^2+i\gamma\omega)\), so
  that the steady state of \(Lx = F_0\cos\omega t\) is
  \(F_0\operatorname{Re}[\chi e^{i\omega t}] = F_0|\chi|\cos(\omega t - \varphi)\).
  Dimensions \(\mathrm{T^2}\); it tends to \(1/\omega_0^2\) as \(\omega\to0\)
  and to \(-1/\omega^2\) as \(\omega\to\infty\). /Slide: The steady state, in
  one line./
- resonance :: The peak of a response curve. \(|\chi|\) peaks at
  \(\omega_{\text{peak}} = \sqrt{\omega_0^2-\gamma^2/2}\), and only if
  \(Q > 1/\sqrt2\); the velocity amplitude and the absorbed power peak exactly
  at \(\omega_0\), for every \(\gamma\). Three distinct frequencies —
  \(\omega_0\), \(\omega_\mathrm{d}\), \(\omega_{\text{peak}}\) — and naming
  which one is meant is compulsory. /Slide: The response curve, and where the
  peak really is./
- phase lag ::
  \(\varphi = \arg(\omega_0^2-\omega^2+i\gamma\omega) \in (0,\pi)\), by which
  the response follows the drive. It is exactly \(\pi/2\) at \(\omega_0\)
  whatever the damping, and sweeps from \(0\) (the drive fights the spring) to
  \(\pi\) (it fights the inertia). Its slope there is \(2Q/\omega_0\), which
  is why phase detection locates a resonance better than amplitude does.
  /Slide: The phase lag, and what it is good for./
- half-power width :: The width of the absorbed-power curve at half its
  maximum: \(\Delta\omega = \gamma\) exactly, the half-power points being
  \(\mp\gamma/2 + \sqrt{\omega_0^2+\gamma^2/4}\), and
  \(\omega_0/\Delta\omega = Q\). They are also the points where the phase lag
  is \(\pi/4\) and \(3\pi/4\). /Slide: Velocity, power, and a width that is
  exactly \(\gamma\)./
- secular term :: A solution growing like \(t\) times an oscillation,
  appearing when the drive lies in \(\ker L\) so that the exponential ansatz
  has nothing to hit: for \(\gamma = 0\) and \(\omega = \omega_0\),
  \(x_p = F_0t\sin(\omega_0 t)/2\omega_0\). Growth is linear, not instant, and
  the oscillator leaves the harmonic regime long before it becomes infinite.
  Unit 21 meets these again as a defect to be cured. /Slide: No damping,
  driven at \(\omega_0\): the ansatz fails./

* The impulse response

- impulse :: \(\int f\,\mathrm{d}t\) over a short interval. Delivered from
  rest it leaves the position unchanged and raises the velocity by its value,
  whatever the pulse's shape — which is why a ballistic galvanometer measures
  charge and nothing else about the current. /Slide: An impulse is a jump in
  the velocity./
- impulse response :: The function \(G\) with \(G(t) = 0\) for \(t \le 0\),
  continuous, solving \(LG = 0\) on \((0,\infty)\) with \(G(0^+) = 0\) and
  \(\dot G(0^+) = 1\). Unique, because \(\mathrm{ev}\) is a bijection, and
  equal to \((e^{\lambda_+t}-e^{\lambda_-t})/(\lambda_+-\lambda_-)\);
  underdamped this is
  \(e^{-\gamma t/2}\sin(\omega_\mathrm{d}t)/\omega_\mathrm{d}\), critically
  damped \(te^{-\omega_0t}\). Also called the Green's function of \(L\); the
  defining jump is in the /derivative/ because \(L\) is second order. /Slide:
  The Green's function, defined and computed./
- convolution ::
  \((G*f)(t) = \int_{-\infty}^{\infty}G(t-s)f(s)\,\mathrm{d}s\), commutative
  by the substitution \(s \mapsto t-s\). For a causal \(G\) the upper limit
  collapses to \(t\). /Slide: Duhamel: convolution solves everything./
- Duhamel's principle :: \(x = G*f\) is the solution of \(Lx = f\) from rest:
  chop the drive into slivers, treat each as an impulse, and superpose. Proved
  here by showing that variation of parameters' kernel \(K(t,s)\) equals
  \(G(t-s)\) when the coefficients are constant.
- linear time-invariant :: A linear operator commuting with time translation,
  which a constant-coefficient \(L\) is. Such an operator acts by convolution
  with a single function, so measuring one ring-down characterises the system
  completely.
- causality :: \(G(t) = 0\) for \(t < 0\) — no response before the kick. Its
  consequence for the frequency response: the transform
  \(\hat G(\omega) = \int_0^\infty G(\tau)e^{-i\omega\tau}\,\mathrm{d}\tau\)
  converges, underdamped, for every complex \(\omega\) with
  \(\operatorname{Im}\omega < \gamma/2\) (in every regime, on the closed
  lower half-plane), so \(\chi\) has no singularity in
  the closed lower half-plane and its poles
  \(\pm\omega_\mathrm{d} + i\gamma/2\) sit above the real axis. That
  analyticity forces a relation between \(\operatorname{Re}\chi\) and
  \(\operatorname{Im}\chi\) — the Kramers–Kronig relations — is /stated and
  not proved here/; it needs unit 20. /Slide: Causality, and the promissory
  note to unit 20./
