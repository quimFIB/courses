The terms this unit introduces, in the order the deck meets them. The slides
stay the definition of record; each entry names the slide it comes from, so a
term can be looked up here and read properly there.

Running example: a bead of mass \(m = 0.12\) kg on a smooth hoop of radius
\(R = 0.35\) m, spun about its vertical diameter at a fixed rate \(\Omega\).
Its Lagrangian is \(L = \tfrac12 mR^2(\dot\theta^2 + \Omega^2\sin^2\theta) +
mgR\cos\theta\); the bottom goes unstable at \(\Omega_c = \sqrt{g/R} = 5.294\
\mathrm{s^{-1}}\), and at \(\Omega = 6\ \mathrm{s^{-1}}\) the bead rests at
\(\theta_* = 38.87^\circ\), pressed by the hoop with \(1.512\) N.

* Overview

- Euler–Lagrange equations :: \(\frac{\mathrm d}{\mathrm dt}\,\partial L/\partial\dot q_a =
  \partial L/\partial q_a\), one for each coordinate: unit 11's equation with the
  independent variable renamed \(t\) and the integrand renamed \(L\). The
  equations of motion, in any coordinates. /Slide: One bead, one hoop, three lines./

* The principle

- holonomic constraint :: An equation \(G(x, t) = 0\) restricting the
  positions of the particles. With \(k\) independent ones among \(3N\)
  Cartesian coordinates, \(3N - k\) coordinates remain free.
  /Slide: Generalised coordinates and constraints./
- scleronomic :: Said of a holonomic constraint with no explicit time
  dependence, like a fixed wire.
- rheonomic :: Said of a holonomic constraint that depends explicitly on time,
  like a wire turned by a motor. Still a constraint on positions, not on
  velocities.
- generalised coordinates :: Coordinates \(q = (q_1, \dots, q_n)\) such that the
  allowed positions are \(x(q, t)\), with \(q \mapsto x(q, t)\) injective and
  \(\partial x/\partial q\) of rank \(n\). The constraints then hold
  automatically.
- degrees of freedom :: The number \(n\) of generalised coordinates needed:
  \(3N\) minus the number of independent holonomic constraints.
- configuration space :: The set of allowed configurations, as a space in its
  own right: a circle for the bead on a hoop, a torus for the double pendulum.
  A manifold, defined properly in unit 31.
- virtual displacement :: A displacement \(\delta\vec x_k = \sum_a(\partial\vec
  x_k/\partial q_a)\,\delta q_a\) tangent to the constraint set with time held
  fixed. /Slide: Virtual displacements and d'Alembert's principle./
- ideal constraint :: One whose forces do no work on any virtual displacement:
  \(\sum_k\vec R_k\cdot\delta\vec x_k = 0\). True of smooth surfaces, rigid rods
  and rolling without slipping; false for sliding friction. A rheonomic ideal
  constraint may still do real work.
- d'Alembert's principle :: \(\sum_k(\vec F_k - m_k\ddot{\vec x}_k)\cdot\delta\vec
  x_k = 0\) for all virtual displacements: Newton's law with the unknown
  constraint forces removed by the assumption that they are ideal.
- Lagrange's equations :: \(\frac{\mathrm d}{\mathrm dt}\,\partial T/\partial\dot q_a -
  \partial T/\partial q_a = Q_a\), or with a potential, the Euler–Lagrange
  equations of \(L = T - V\). Derived from d'Alembert's principle by two
  identities. /Slide: From d'Alembert to Lagrange's equations./
- generalised force :: \(Q_a = \sum_k\vec F_k\cdot\partial\vec x_k/\partial q_a\):
  the applied force paired with the \(a\)-th direction of virtual displacement.
  A torque when \(q_a\) is an angle.
- Lagrangian :: \(L(q, \dot q, t) = T - V\), a function of positions, velocities
  and time whose action is stationary on the motion. Not unique, and not an
  energy. /Slide: Hamilton's principle./
- action :: The functional \(S[q] = \int_{t_0}^{t_1}L(q, \dot q, t)\,\mathrm dt\) on
  paths with fixed ends. Dimension \(\mathrm{J\,s}\).
- Hamilton's principle :: A path is a motion if and only if it makes the
  action stationary among paths with the same endpoints. Stationary, not
  least: past a conjugate point the action is not a minimum.

* Coordinates stop mattering

- form invariance :: The Euler–Lagrange equations keep their form under any
  \(C^2\) point transformation with invertible Jacobian: the equations of
  \(\tilde L\) hold exactly when those of \(L\) do. Componentwise,
  \(\tilde{\mathcal E} = J^{\top}\mathcal E\). /Slide: The theorem the formalism exists for./
- point transformation :: A change of coordinates \(q = \phi(Q, t)\) on
  configuration space, possibly time-dependent, with \(\partial\phi/\partial Q\)
  invertible. It does not mix in velocities.
- general covariance :: The principle that the laws are written the same way
  in every coordinate system. Here, a theorem about the Euler–Lagrange
  equations; at the end of the course, a requirement on the laws of gravity.
- torus :: The product \(S^1 \times S^1\) of two circles: the configuration
  space of the double pendulum, a pair of angles each defined modulo \(2\pi\).
  No single chart covers it. /Slide: Configuration space is a manifold./

* Reading the equations

- generalised momentum (canonical momentum) :: \(p_a = \partial L/\partial\dot
  q_a\). An angular momentum when \(q_a\) is an angle; \(m\dot{\vec x} +
  q\vec A\) for a charge in a magnetic field; not in general \(m\dot q_a\).
  /Slide: Generalised momenta and cyclic coordinates./
- cyclic coordinate (ignorable coordinate) :: A coordinate absent from \(L\),
  only its velocity appearing. Its momentum is conserved, by the Euler–Lagrange
  equation in one line. Whether a coordinate is cyclic depends on the whole
  chart.
- effective potential :: A potential in fewer coordinates that governs the
  remaining motion once a conserved quantity is used: unit 08's \(V(r) +
  p_\theta^2/2\mu r^2\), and the hoop's \(V_{\mathrm{eff}} = -\tfrac12 mR^2\Omega^2\sin^2\theta
  - mgR\cos\theta\). /Slide: Worked: Kepler, with no force drawn./
- energy function :: \(h = \sum_a\dot q_a\,\partial L/\partial\dot q_a - L\), with
  \(\mathrm dh/\mathrm dt = -\partial L/\partial t\) along motions. Equal to \(T +
  V\) when the constraints are scleronomic; different otherwise, as on the
  driven hoop. /Slide: The energy function./
- pitchfork bifurcation :: Unit 02's \(\dot x = \mu x - x^3\): as \(\mu\) passes
  zero, a symmetric equilibrium loses stability and two stable ones branch
  off. On the hoop, \(\mu = \Omega^2 - g/R\). /Slide: The pitchfork, in unit 02's normal form./
- separatrix :: A level set of a conserved quantity passing through a saddle,
  dividing qualitatively different motions: on the fast hoop, the figure of
  eight separating rocking on one side from swinging through the bottom.
  /Slide: Phase portraits on each side./

* Constraint forces, when you want them

- constraint force :: The force \(\vec R_k\) enforcing a constraint. Recovered,
  when wanted, as \(\sum_j\lambda_j\partial G_j/\partial q_a\) by keeping a
  redundant coordinate and adding a multiplier for its constraint.
  /Slide: Multipliers bring the forces back./
- non-holonomic constraint :: A constraint on velocities, \(\sum_aA_a(q)\,\dot
  q_a = 0\), not equivalent to any constraint on positions: the knife edge,
  the rolling disc. /Slide: Non-holonomic constraints, honestly./
- Lagrange–d'Alembert principle :: For constraints linear in the velocities:
  virtual displacements obey the constraint, ideal forces do no work on them,
  hence \(\frac{\mathrm d}{\mathrm dt}\,\partial L/\partial\dot q_a - \partial L/\partial
  q_a = \sum_j\lambda_jA_{ja}\). The correct mechanics for non-holonomic systems.
- vakonomic mechanics :: Making the action stationary among curves that obey a
  non-holonomic constraint. It gives different equations from
  Lagrange–d'Alembert, with an extra free initial datum, and is not the
  mechanics of rolling and sliding bodies.

* What L is allowed to be

- gauge transformation (gauge freedom) :: \(L \to L + \mathrm df(q, t)/\mathrm dt\).
  The equations of motion are unchanged; the canonical momenta shift by
  \(\partial f/\partial q_a\) and the energy function by \(-\partial f/\partial t\).
  /Slide: Gauge freedom./
- generalised potential (velocity-dependent potential) :: A function \(U(q,
  \dot q, t)\) with \(Q_a = \frac{\mathrm d}{\mathrm dt}\,\partial U/\partial\dot q_a -
  \partial U/\partial q_a\), so that \(L = T - U\). For a charge, \(U = q\phi -
  q\dot{\vec x}\cdot\vec A\). /Slide: Velocity-dependent potentials./
- kinetic momentum :: \(m\dot{\vec x}\), as opposed to the canonical momentum
  \(m\dot{\vec x} + q\vec A\). The gauge-invariant one.

* Small oscillations

- mass matrix :: \(M = M(q_0)\), where \(T = \tfrac12\dot q^{\top}M(q)\dot q\):
  symmetric and positive definite. /Slide: Linearising a Lagrangian./
- stiffness matrix :: \(K = \mathrm{Hess}\,V(q_0)\) at an equilibrium:
  symmetric, positive definite at a strict minimum.
- normal frequency :: A root \(\omega\) of \(\det(K - \omega^2M) = 0\); there
  are \(n\) values of \(\omega^2\), all real. /Slide: Modes: \(\det(K - \omega^2M) = 0\)./
- normal mode :: A vector \(v\) with \((K - \omega^2M)v = 0\): a pattern in which
  every coordinate oscillates at the one frequency \(\omega\). Distinct modes
  are orthogonal in the inner product \(u^{\top}Mv\), not in the Euclidean one.
