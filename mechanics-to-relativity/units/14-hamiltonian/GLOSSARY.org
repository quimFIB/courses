The terms this unit introduces, in the order the deck meets them. The slides
stay the definition of record; each entry names the slide it comes from, so a
term can be looked up here and read properly there.

Running example: the Kepler problem in phase space,
\(H = p_r^2/2\mu + p_\theta^2/2\mu r^2 - k/r\), with \(p_\theta = L\) frozen at
Halley's value \(h = L/\mu = 4.78403\times10^{15}\ \mathrm{m^2\,s^{-1}}\) and
energy \(\varepsilon = E/\mu = -2.48740\times10^{7}\ \mathrm{J\,kg^{-1}}\). Its
level curve runs from \(0.586025\) to \(35.0789\) AU, encloses a phase area of
\(8.81646\times10^{16}\ \mathrm{m^2\,s^{-1}}\) per unit mass, and the
derivative of that area in the energy is the period, \(75.3052\) yr.

* Overview

- Hamiltonian :: The Legendre transform \(H(q,p,t)\) of the Lagrangian in the
  velocities. When \(L = T - V\) with \(T\) homogeneous quadratic in \(\dot q\),
  \(H = T + V\) written in terms of momenta; in general it is unit 13's energy
  function. /Slide: Twice the variables, half the order./
- phase space :: The space of states \((q,p)\in\mathbb R^{2n}\), positions and
  momenta together, on which Hamilton's equations are a first-order system.

* The Legendre transform, as convex duality

- Legendre transform (Legendre–Fenchel transform, convex conjugate) ::
  \(f^*(p) = \sup_x\big(p\cdot x - f(x)\big)\), with values in
  \((-\infty,\infty]\). Always convex. For strictly convex smooth \(f\) it
  reduces to the recipe \(f^* = p\cdot x - f\) at \(\nabla f(x) = p\).
  /Slide: The definition, by supremum./
- Fenchel–Young inequality :: \(f(x) + f^*(p)\ge p\cdot x\) for all \(x, p\),
  with equality exactly when \(x\) attains the supremum defining \(f^*(p)\) —
  for differentiable convex \(f\), when \(p = \nabla f(x)\).
- Young's inequality :: For \(x,p\ge0\) and \(1/a + 1/b = 1\),
  \(px\le x^a/a + p^b/b\), with equality iff \(p = x^{a-1}\). It is the
  Fenchel–Young inequality for \(f = |x|^a/a\), whose transform is \(|p|^b/b\).
  /Slide: Young's inequality is a Legendre transform./
- involutivity :: \(f^{**} = f\) for convex \(f\): transforming twice returns
  the function. Proved here for differentiable convex \(f\); in general it is
  the Fenchel–Moreau theorem, for convex lower semicontinuous \(f\).
  /Slide: Involutivity: transforming twice gives \(f\) back./
- supporting line (supporting hyperplane) :: A line (hyperplane) touching the
  graph of \(f\) and lying below it. For differentiable convex \(f\) the tangent
  is one: \(f(y)\ge f(x) + \nabla f(x)\cdot(y-x)\).
- convex envelope :: The largest convex function lying below \(f\); it is
  \(f^{**}\). The Legendre transform cannot see the non-convex parts of \(f\).
- degenerate Lagrangian :: One whose velocity Hessian
  \(\partial^2L/\partial\dot q_i\partial\dot q_j\) is singular, so that
  \(\dot q\mapsto p\) is not invertible: some momenta are fixed functions of
  \(q\) and \(H\) lives only on a constraint set. Linear and degree-one
  homogeneous Lagrangians are the two basic cases.
  /Slide: The degenerate case, flagged now./

* Hamilton's equations, and the picture they draw

- Hamilton's equations (canonical equations) :: \(\dot q = \partial H/\partial p\),
  \(\dot p = -\partial H/\partial q\): equivalent to the Euler–Lagrange
  equations when \(L\) is strictly convex in \(\dot q\). Along solutions
  \(\mathrm dH/\mathrm dt = \partial H/\partial t\).
  /Slide: Hamilton's equations./
- standard symplectic matrix :: \(J = \begin{pmatrix}0&I\\-I&0\end{pmatrix}\)
  on \(\mathbb R^{2n}\), ordered \((q,p)\). \(J^\top = -J = J^{-1}\). Hamilton's
  equations are \(\dot z = J\nabla H\).
  /Slide: One first-order system on \(\mathbb R^{2n}\)./
- Hamiltonian vector field :: \(X_H = J\nabla H\), the vector field whose flow
  is the motion. It is tangent to the level sets of \(H\).
- phase-space action :: \(S[q,p] = \int(p\cdot\dot q - H)\,\mathrm dt\), with
  \(q\) fixed at the ends and \(p\) free. Stationary exactly on solutions of
  Hamilton's equations; linear in the velocities, yet non-degenerate as a
  variational principle. /Slide: The phase-space action principle./
- level set :: \(\{H = E\}\). For one degree of freedom every orbit lies in
  one, and a component with no equilibrium on it is a single orbit, so the
  phase portrait is a contour map.
  /Slide: The pendulum's separatrix, now a level set./
- separatrix :: A level set dividing qualitatively different motions: for the
  pendulum \(H = mgl\), through the saddles, dividing libration from rotation;
  for Kepler \(E = 0\), dividing bound from unbound orbits, with its
  "saddle" at \(r = \infty\).

* Poisson brackets: the algebra of observables

- Poisson bracket :: \(\{f,g\} = \sum_i(\partial_{q_i}f\,\partial_{p_i}g -
  \partial_{p_i}f\,\partial_{q_i}g) = \nabla f^\top J\nabla g\). Bilinear,
  antisymmetric, Leibniz in each slot, and satisfies Jacobi.
  /Slide: The Poisson bracket./
- Jacobi identity :: \(\{f,\{g,h\}\} + \{g,\{h,f\}\} + \{h,\{f,g\}\} = 0\).
  Equivalently \([D_f, D_g] = D_{\{f,g\}}\) with \(D_f = \{f,\cdot\}\).
- fundamental Poisson brackets :: \(\{q_i,q_j\} = 0\), \(\{p_i,p_j\} = 0\),
  \(\{q_i,p_j\} = \delta_{ij}\). A change of coordinates is canonical iff the new
  coordinates satisfy them.
- Lie algebra :: A real vector space with a bilinear, antisymmetric bracket
  satisfying the Jacobi identity. Smooth functions on phase space under the
  Poisson bracket form one; so do \(\mathfrak{so}(3)\), \(\mathfrak{so}(4)\)
  and \(\mathfrak{so}(3,1)\) under the commutator.
  /Slide: The Jacobi identity, and what it makes of observables./
- Poisson's theorem :: If \(f\) and \(g\) are conserved, so is \(\{f,g\}\).
  One line from Jacobi; the conserved quantities form a Lie algebra.
  /Slide: Time evolution is a bracket with \(H\)./
- generator (generates) :: The function \(f\) whose Hamiltonian flow
  \(z' = J\nabla f(z)\) is a given one-parameter family of motions:
  \(\vec a\cdot\vec p\) generates translations, \(\vec a\cdot\vec L\) rotations.
  \(f\) is conserved iff \(H\) is invariant under the flow \(f\) generates.
  /Slide: Noether's converse, now cheap./
- Levi-Civita symbol :: \(\varepsilon_{ijk} = \vec e_i\cdot(\vec e_j\times\vec e_k)\),
  the sign of the permutation \((i,j,k)\) and \(0\) if two indices agree; so
  \(\vec e_i\times\vec e_j = \sum_k\varepsilon_{ijk}\vec e_k\).
  /Slide: Every vector rotates the same way under \(\vec L\)./
- \(\mathfrak{so}(4)\) :: The antisymmetric real \(4\times4\) matrices under the
  commutator: the Lie algebra of rotations of \(\mathbb R^4\). The bracket
  algebra of \(\vec L\) and \(\vec A/\sqrt{-2\mu H}\) for bound Kepler orbits.
  /Slide: The algebra closes: \(\mathfrak{so}(4)\), \(\mathfrak e(3)\), \(\mathfrak{so}(3,1)\)./
- \(\mathfrak{so}(3,1)\) :: The real \(4\times4\) matrices \(X\) with
  \(X^\top\eta + \eta X = 0\), \(\eta = \mathrm{diag}(1,1,1,-1)\): the Lorentz
  algebra. The bracket algebra of \(\vec L\) and \(\vec A/\sqrt{2\mu H}\) for
  unbound Kepler orbits. Not isomorphic to \(\mathfrak{so}(4)\).
- hidden symmetry :: A symmetry of the Hamiltonian whose flow mixes positions
  and momenta, so that it is induced by no transformation of configuration
  space. For Kepler it is generated by the Runge–Lenz vector and carries an
  ellipse to others of the same energy.

* Canonical transformations

- symplectic group :: \(\mathrm{Sp}(2n,\mathbb R) = \{M : M^\top JM = J\}\). In
  the plane it is \(\{\det M = 1\}\); in higher dimensions it is much smaller
  than the volume-preserving matrices.
  /Slide: The symplectic form, and the maps that keep it./
- symplectic form :: The antisymmetric nondegenerate bilinear form
  \(\omega(u,v) = \sum_i(u_{p_i}v_{q_i} - u_{q_i}v_{p_i}) = -u^\top Jv\) on
  \(\mathbb R^{2n}\); written \(\sum\mathrm dp_i\wedge\mathrm dq_i\) in unit 34.
  In the plane it is minus the signed area.
- canonical transformation :: A diffeomorphism of phase space whose Jacobian
  is symplectic at every point. Equivalently it preserves all Poisson
  brackets, or carries Hamilton's equations for every Hamiltonian to Hamilton's
  equations. /Slide: Three tests that are one test./
- generating function :: A function \(F\) with
  \(p\cdot\mathrm dq - P\cdot\mathrm dQ = \mathrm dF\), written in two of the
  four sets of variables: \(F_1(q,Q)\), \(F_2(q,P)\), \(F_3(p,Q)\), \(F_4(p,P)\).
  Exists (locally) iff the map is canonical.
  /Slide: Generating functions: a canonical map from one function./
- point transformation :: A canonical transformation induced by a change of
  configuration coordinates \(Q = f(q)\), with \(p = Df(q)^\top P\); generated
  by \(F_2 = f(q)\cdot P\).
- variational equation :: \(\dot Y = DX(\varphi_t z)\,Y\), satisfied by the
  derivative \(Y = D\varphi_t(z)\) of a flow with respect to its initial point.
  Cited here. /Slide: The motion itself is a canonical transformation./
- symplectic integrator :: A time-stepping method whose one-step map is
  itself canonical, so that it preserves phase-space volume exactly and
  conserves a Hamiltonian close to the true one.

* Liouville: clouds that deform without shrinking

- divergence :: \(\operatorname{div}X = \operatorname{tr}DX = \sum_a\partial X_a/\partial z_a\).
  It is the rate at which the flow of \(X\) changes volume.
  /Slide: Divergence, and how determinants evolve./
- Liouville's formula :: If \(\dot Y = A(t)Y\) then
  \(\frac{\mathrm d}{\mathrm dt}\det Y = \operatorname{tr}A\,\det Y\). Abel's
  identity for the Wronskian is its \(2\times2\) case.
- Liouville's theorem :: The flow of a Hamiltonian vector field preserves
  phase-space volume: \(\operatorname{div}X_H = 0\), so
  \(\det D\varphi_t = 1\). True in \((q,p)\), false in \((q,\dot q)\) in general.
  /Slide: Liouville's theorem, in three lines./
- Liouville equation :: \(\partial_t\rho + \{\rho,H\} = 0\) for a density
  carried by the flow; the density is constant along orbits, and any
  \(\rho = g(H)\) is stationary.
  /Slide: Why statistical mechanics is possible./
- phase area :: \(A(E) = \oint p\,\mathrm dq\), the area enclosed by the orbit
  of energy \(E\) in a one-degree-of-freedom system; an action, in
  \(\mathrm{J\,s}\). Its derivative is the period: \(\mathrm dA/\mathrm dE = T\).
  /Slide: Worked: Halley's phase area, and its period./
