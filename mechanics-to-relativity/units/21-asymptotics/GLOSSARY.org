The terms this unit introduces, in the order the deck meets them. The slides
stay the definition of record; each entry names the slide it comes from, so a
term can be looked up here and read properly there.

Running example, in two parts. The Duffing oscillator \(\ddot x + x +
\varepsilon x^3 = 0\), \(x(0) = A\), \(\dot x(0) = 0\), whose naive expansion
has a secular term that must be removed, giving \(\omega = 1 +
\tfrac38\varepsilon A^2 + O(\varepsilon^2)\). And the relativistic orbit
equation \(w'' + w = 1 + \varepsilon w^2\), \(\varepsilon = 3GM/c^2p\), whose
secular term must be kept: it is the perihelion advance \(2\pi\varepsilon\) per
orbit, \(42.98''\) per century for Mercury.

* Small parameters, and where they come from

- small parameter :: A dimensionless number \(\varepsilon\), built from the
  problem's parameters, that is small compared with 1 and multiplies the
  terms you hope to treat as corrections. It is found, not chosen: by
  nondimensionalising. /Slide: Nondimensionalise first./
- nondimensionalisation :: Rewriting an equation in variables scaled by
  characteristic values built from the parameters, chosen so that the scaled
  variables and their derivatives are of size one. What remains are the
  dimensionless groups of the Buckingham theorem (unit 00); for the cubic
  spring, \(\varepsilon = \beta a^2/k\).
- regular perturbation :: A problem whose \(\varepsilon = 0\) version is of the
  same kind — same degree or order, all conditions imposable — and whose
  solution is the limit of the true one, so that a power series in
  \(\varepsilon\) works. /Slide: Regular or singular: the test./
- singular perturbation :: A problem that is not regular: typically
  \(\varepsilon\) multiplies the highest power or derivative, so setting it to
  zero loses roots or boundary conditions. Also used for problems regular in
  the equation but non-uniform on an unbounded domain.
- dominant balance :: Finding the scaling \(x = \varepsilon^{-\alpha}X\) under
  which two terms are of the same size and all others smaller. Each
  consistent balance gives one family of solutions or one region of a
  boundary-layer problem.

* Asymptotic series

- order notation :: As \(x \to x_0\): \(f = O(g)\) if \(|f/g|\) is bounded near
  \(x_0\); \(f = o(g)\) if \(f/g \to 0\). Statements about a limit, never about a
  particular \(x\). /Slide: Order notation./
- asymptotically equivalent :: \(f \sim g\) as \(x \to x_0\) if \(f/g \to 1\).
  Controls the relative error only.
- asymptotic sequence :: Functions \(\phi_n\) with \(\phi_{n+1} = o(\phi_n)\) as
  \(x \to x_0\), for every \(n\). The powers \(x^n\) as \(x \to 0\) are the
  standard one. /Slide: Poincaré's definition./
- asymptotic expansion :: \(f \sim \sum a_n\phi_n\) if \(f - \sum_{n \le N}
  a_n\phi_n = o(\phi_N)\) for every \(N\) (Poincaré, 1886). A statement about
  fixed \(N\) as \(x \to x_0\); the series need not converge. The coefficients
  are unique; the function is not, since \(e^{-1/x} \sim 0\).
- Stieltjes function :: \(S(x) = \int_0^\infty e^{-t}/(1 + xt)\,\mathrm{d}t\),
  whose asymptotic series \(\sum(-1)^n n!\,x^n\) diverges for every \(x \ne
  0\), with remainder smaller than the first omitted term and of its sign.
  /Slide: The Stieltjes series, and its remainder./
- optimal truncation :: Stopping an asymptotic series at its smallest term,
  where adding more terms starts to make the answer worse. For the Stieltjes
  series, at \(N = \lfloor 1/x \rfloor\), with error at most
  \((e^2/x)e^{-1/x}\). /Slide: Optimal truncation./
- exponentially small :: Smaller than every power of the small parameter, like
  \(e^{-1/x}\) as \(x \to 0^+\). Invisible to any power series; also called
  beyond all orders.
- Borel summation :: Assigning a value to \(\sum a_nx^n\) as \(\int_0^\infty
  e^{-t}B(xt)\,\mathrm{d}t\) with \(B(t) = \sum a_nt^n/n!\). Recovers the
  Stieltjes function exactly from its divergent series. Named, not developed.
  /Slide: Borel summation, named./

* Secular terms

- perturbation hierarchy :: The sequence of equations obtained by substituting
  \(x = x_0 + \varepsilon x_1 + \cdots\) and equating each power of
  \(\varepsilon\) to zero: the same linear operator at every order, forced by
  lower orders. /Slide: Regular perturbation, the naive way./
- secular term :: A term in a perturbation series that grows without bound in
  the independent variable, like \(t\sin t\), produced by forcing a linear
  oscillator at its own frequency. Usually a frequency shift, Taylor-expanded.
  From /saeculum/, the astronomers' century. /Slide: Worked: the naive first
  order./
- uniformly valid :: An approximation whose error is bounded by one function of
  \(\varepsilon\), tending to zero, for all values of the other variable at
  once. The naive Duffing expansion is \(O(\varepsilon^2)\) at each fixed
  \(t\) but not uniformly on \([0, \infty)\). /Slide: Why the naive answer dies
  at t ~ 1/ε./

* Removing secular terms

- solvability condition :: \(u'' + u = f\), \(f\) \(2\pi\)-periodic, has a
  \(2\pi\)-periodic solution iff \(f\) is orthogonal to \(\cos\tau\) and
  \(\sin\tau\) over a period. Imposing it at each order is how secular terms
  are removed. /Slide: The solvability condition./
- Poincaré–Lindstedt method :: For a periodic solution of unknown frequency:
  strain the time, \(\tau = \omega t\), expand \(\omega = 1 + \varepsilon\omega_1
  + \cdots\) along with the solution, and fix each \(\omega_n\) by the
  solvability condition. /Slide: Worked: Poincaré–Lindstedt for Duffing./
- method of multiple scales :: Treating the solution as a function of a fast
  time \(t\) and a slow time \(T = \varepsilon t\) independently, so that
  \(\mathrm{d}/\mathrm{d}t = \partial_t + \varepsilon\partial_T\), and using the
  freedom in the \(T\)-dependence to remove secular terms. Works without
  periodicity. /Slide: Multiple scales./
- amplitude equations :: The equations for the slowly varying amplitude and
  phase that the solvability condition imposes in a multiple-scales
  calculation; for Duffing, \(a' = 0\), \(\phi' = \tfrac38a^2\).

* Boundary layers

- boundary layer :: A thin region, of width set by dominant balance, in which
  the solution changes by \(O(1)\) and the term multiplied by the small
  parameter is not small. Prandtl, 1904. /Slide: A small parameter on the
  highest derivative./
- outer solution :: The expansion valid away from the layer, solving the
  reduced equation with the boundary condition it can keep. /Slide: Inner and
  outer solutions./
- inner solution :: The expansion valid inside the layer, in the stretched
  variable \(X = x/\varepsilon\).
- distinguished limit :: The stretching exponent at which the highest
  derivative balances another term, giving the richest inner equation. For
  \(\varepsilon y'' + (1+x)y' + y = 0\), \(x = \varepsilon X\).
- matching :: Fixing the inner solution's free constants by requiring it to
  agree with the outer solution where both are valid. /Slide: Matching: the
  intermediate variable and Van Dyke's rule./
- intermediate variable :: \(x = \varepsilon^\beta\xi\) with \(0 \lt \beta \lt 1\),
  lying in the overlap \(\varepsilon \ll x \ll 1\) where inner and outer
  expansions must agree.
- Van Dyke's matching rule :: The \(m\)-term inner expansion of the \(n\)-term
  outer solution equals the \(n\)-term outer expansion of the \(m\)-term inner
  solution. A procedure, reliable for power laws, fallible with logarithms.
- composite expansion :: Outer plus inner minus their common part; uniformly
  valid on the whole interval. For the model problem \(2/(1+x) -
  2e^{-x/\varepsilon}\), with error \(O(\varepsilon)\). /Slide: Worked: the
  composite solution, against the exact one./

* WKB

- WKB approximation :: For \(\varepsilon^2y'' + q(x)y = 0\) with \(q \gt 0\): \(y
  \approx q^{-1/4}[C_1\cos(\varepsilon^{-1}\int\sqrt q) + C_2\sin(\varepsilon^{-1}\int\sqrt
  q)]\). Also called the Liouville–Green approximation. /Slide: The WKB
  approximation./
- eikonal equation :: The leading-order WKB equation \(S_0'^2 = -q\), which
  fixes the phase. For a reader who has done unit 15, it is the one-dimensional
  Hamilton–Jacobi equation; nothing here depends on that.
- transport equation :: The next-order WKB equation \(2S_0'S_1' + S_0'' = 0\),
  which fixes the amplitude as \(q^{-1/4}\).
- adiabatic invariant :: A quantity conserved to good accuracy when a parameter
  changes slowly compared with the motion. For \(\ddot x + \omega(\varepsilon
  t)^2x = 0\), \(E/\omega\). /Slide: When WKB is valid, and an adiabatic
  invariant./
- turning point :: A zero of \(q\), where the WKB solution changes from
  oscillatory to exponential and the approximation itself fails; locally an
  Airy equation in a region of width \(\varepsilon^{2/3}\). /Slide: Turning
  points and the connection formulae./
- connection formulae :: The rule, cited from the Airy function's asymptotics,
  that the WKB solution decaying beyond a simple turning point continues on the
  oscillatory side as \(2q^{-1/4}\cos(\varepsilon^{-1}\int_x^a\sqrt q -
  \pi/4)\).
