the slides · the curriculum

Checkpoint. You express Maxwell's four equations as \(\mathrm dF = 0\) and \(\mathrm d\star F = \mu_0\star J\), expand them back into components recovering the originals exactly, compute \(H^1(\mathbb R^2\setminus\{0\})\) — closing unit 04's open question — and reproduce one of unit 33's curvature computations by Cartan's structure equations.

Work each problem on paper first. Twelve problems, about six hours. Work them on paper first. Conventions are the deck's: signature \((-,+,+,+)\); on Minkowski space the orthonormal coframe \(e^0 = c\,\mathrm dt\), \(e^i = \mathrm dx^i\) and \(\mathrm{vol} = e^0\wedge e^1\wedge e^2\wedge e^3\); \(\varepsilon^1 = \mathrm dy\wedge\mathrm dz\), \(\varepsilon^2 = \mathrm dz\wedge\mathrm dx\), \(\varepsilon^3 = \mathrm dx\wedge\mathrm dy\); \(F = B_i\,\varepsilon^i + E_i\,\mathrm dx^i\wedge\mathrm dt\), \(\star F = \tfrac1c E_i\,\varepsilon^i - c\,B_i\,\mathrm dx^i\wedge\mathrm dt\), \(J = -c^2\rho\,\mathrm dt + J_i\,\mathrm dx^i\); for a frame, \(\nabla e_b = \omega^a{}_b\otimes e_a\), \(\mathrm de^a = -\omega^a{}_b\wedge e^b\), \(\Omega^a{}_b = \mathrm d\omega^a{}_b + \omega^a{}_c\wedge\omega^c{}_b\). The algebra and the derivative

P1 Wedges and derivatives by hand routine

exercises: the wedge product, the exterior derivative, the graded Leibniz rule, pullback to a curve

On \(\mathbb R^3\) let \(\alpha = yz\,\mathrm dx + xz\,\mathrm dy + xy\,\mathrm dz\) and \(\beta = x\,\mathrm dy - y\,\mathrm dx\).

  1. Compute \(\alpha\wedge\beta\), in the basis \(\mathrm dy\wedge\mathrm dz\), \(\mathrm dz\wedge\mathrm dx\), \(\mathrm dx\wedge\mathrm dy\).
  2. Compute \(\mathrm d\alpha\) and \(\mathrm d\beta\).
  3. Compute \(\mathrm d(\alpha\wedge\beta)\) directly, and check the Leibniz rule \(\mathrm d(\alpha\wedge\beta) = \mathrm d\alpha\wedge\beta - \alpha\wedge\mathrm d\beta\). Where does the minus sign come from?
  4. Pull both forms back along the helix \(\gamma(t) = (\cos t, \sin t, t)\), \(0\le t\le 2\pi\), and integrate. Say in one line why the answer for \(\alpha\) could have been written down without integrating.
Hints · 3 rungs
Rung 1

Know the degree of every answer before computing it: \(\alpha\wedge\beta\), \(\mathrm d\alpha\) and \(\mathrm d\beta\) are two-forms; \(\mathrm d(\alpha\wedge\beta)\) is a three-form, so on \(\mathbb R^3\) a single function times \(\mathrm dx\wedge\mathrm dy\wedge\mathrm dz\). Part 4 is two numbers.

Rung 2

Expand \(\alpha\wedge\beta\) term by term: six products, of which the two containing \(\mathrm dx\wedge\mathrm dx\) or \(\mathrm dy\wedge\mathrm dy\) die, and every \(\mathrm dy\wedge\mathrm dx\) becomes \(-\mathrm dx\wedge\mathrm dy\). For \(\mathrm d\), use \(\mathrm d(f\,\mathrm dx^I) = \mathrm df\wedge\mathrm dx^I\). Look hard at \(\alpha\) before differentiating it.

Rung 3

The first line: \(\alpha\wedge\beta = yz\cdot x\,\mathrm dx\wedge\mathrm dy + xz\cdot(-y)\,\mathrm dy\wedge\mathrm dx + xy\cdot(-y)\,\mathrm dz\wedge\mathrm dx + xy\cdot x\,\mathrm dz\wedge\mathrm dy\).

Worked solution

Idea. Nothing but the rules: antisymmetry for \(\wedge\), the chart formula for \(\mathrm d\), and the chain rule for pullback. The one thing worth noticing is that \(\alpha = \mathrm d(xyz)\).

1. From rung 3, using \(\mathrm dy\wedge\mathrm dx = -\mathrm dx\wedge\mathrm dy\) and \(\mathrm dz\wedge\mathrm dy = -\mathrm dy\wedge\mathrm dz\), \[ \alpha\wedge\beta = -x^2y\,\mathrm dy\wedge\mathrm dz - xy^2\,\mathrm dz\wedge\mathrm dx + 2xyz\,\mathrm dx\wedge\mathrm dy . \]

2. \(\alpha = \mathrm d(xyz)\), so \(\mathrm d\alpha = \mathrm d\mathrm d(xyz) = 0\). Directly, the \(\mathrm dx\wedge\mathrm dy\) coefficient is \(\partial_x(xz) - \partial_y(yz) = z - z = 0\), and the other two likewise. And \(\mathrm d\beta = \mathrm dx\wedge\mathrm dy - \mathrm dy\wedge\mathrm dx = 2\,\mathrm dx\wedge\mathrm dy\).

3. Only the derivative in the missing direction survives in each term: \[ \mathrm d(\alpha\wedge\beta) = \partial_x(-x^2y)\,\mathrm dx\wedge\mathrm dy\wedge\mathrm dz + \partial_y(-xy^2)\,\mathrm dy\wedge\mathrm dz\wedge\mathrm dx + \partial_z(2xyz)\,\mathrm dz\wedge\mathrm dx\wedge\mathrm dy . \] All three basis three-forms equal \(\mathrm dx\wedge\mathrm dy\wedge\mathrm dz\) (cyclic permutations are even), so \(\mathrm d(\alpha\wedge\beta) = (-2xy - 2xy + 2xy)\,\mathrm dx\wedge\mathrm dy\wedge\mathrm dz = -2xy\,\mathrm dx\wedge\mathrm dy\wedge\mathrm dz\). The right side: \(\mathrm d\alpha\wedge\beta - \alpha\wedge\mathrm d\beta = 0 - 2\alpha\wedge\mathrm dx\wedge\mathrm dy = -2xy\,\mathrm dz\wedge\mathrm dx\wedge\mathrm dy = -2xy\,\mathrm dx\wedge\mathrm dy\wedge\mathrm dz\) ✓. The minus sign is \((-1)^k\) with \(k = \deg\alpha = 1\): \(\mathrm d\) is a one-form-like operator, and reaching \(\beta\) it has to pass \(\alpha\).

4. \(\gamma^*\mathrm dx = -\sin t\,\mathrm dt\), \(\gamma^*\mathrm dy = \cos t\,\mathrm dt\), \(\gamma^*\mathrm dz = \mathrm dt\). So \(\gamma^*\beta = (\cos^2t + \sin^2t)\,\mathrm dt = \mathrm dt\) and \(\int_\gamma\beta = 2\pi\). For \(\alpha\), naturality gives \(\gamma^*\alpha = \mathrm d(\gamma^*(xyz)) = \mathrm d(t\sin t\cos t)\), so \(\int_\gamma\alpha = [t\sin t\cos t]_0^{2\pi} = 0\). Without integrating: \(\alpha\) is exact, so by the gradient theorem (Stokes with \(n = 1\)) its integral is \(xyz\) at the end, \((1)(0)(2\pi) = 0\), minus \(xyz\) at the start, \(0\).

Check. Special case: projected onto the \(xy\)-plane the helix is the unit circle, and \(\tfrac12\oint(x\,\mathrm dy - y\,\mathrm dx)\) is the enclosed area (Green, with \(\mathrm d\beta = 2\,\mathrm dx\wedge\mathrm dy\)), so \(\int_\gamma\beta = 2\times\pi = 2\pi\) ✓. Dimensions: if \(x,y,z\) are lengths, \(\alpha\) is length\(^3\), \(\beta\) length\(^2\), \(\alpha\wedge\beta\) length\(^5\) and \(\mathrm d\) does not change it: \(-2xy\,\mathrm dx\,\mathrm dy\,\mathrm dz\) is length\(^5\) ✓.

P2 d squared in disguise medium

exercises: the exterior derivative in components, Clairaut's theorem, the homogeneous Maxwell pair, charge conservation — a proof

Let \(A = A_x\,\mathrm dx + A_y\,\mathrm dy + A_z\,\mathrm dz - \varphi\,\mathrm dt\) on \(\mathbb R^4\), with arbitrary smooth components, and \(F = \mathrm dA\).

  1. Compute \(\mathrm d(\mathrm dA)\) in components without quoting \(\mathrm d^2 = 0\), and show that each of its four coefficients vanishes by Clairaut's theorem. Name the vector identity each one is.
  2. Deduce that \(\nabla\cdot\vec B = 0\) and \(\nabla\times\vec E + \partial_t\vec B = 0\) hold for any potentials. What, then, is the physical content of the homogeneous pair?
  3. From the preamble's \(\star F\), compute \(\mathrm d(\mathrm d\star F)\) in components and show it vanishes identically. Then apply \(\mathrm d\) to \(\mathrm d\star F = \mu_0\star J\) and read off charge conservation.
  4. Replace Ampère–Maxwell by Ampère's original \(\nabla\times\vec B = \mu_0\vec J\), keeping Gauss's law. Show that this forces \(\nabla\cdot\vec J = 0\), and say why that is incompatible with a charging capacitor.
Hints · 3 rungs
Rung 1

The answer is a proof. \(\mathrm d(\mathrm dA)\) is a three-form on \(\mathbb R^4\): four coefficients, along \(\mathrm dx\wedge\mathrm dy\wedge\mathrm dz\) and the three \(\mathrm dt\wedge\varepsilon^i\). Each must turn out to be a sum of mixed partial derivatives that cancel in pairs.

Rung 2

Example 1 of the deck computed \(\mathrm dA = B_i\varepsilon^i + E_i\,\mathrm dx^i\wedge\mathrm dt\) with \(\vec B = \nabla\times\vec A\) and \(\vec E = -\nabla\varphi - \partial_t\vec A\); example 2 computed \(\mathrm d\) of any two-form of that shape. Use both, with these particular \(\vec B\) and \(\vec E\), and then open the brackets.

Rung 3

The first line: \(\nabla\cdot(\nabla\times\vec A) = \partial_x(\partial_yA_z - \partial_zA_y) + \partial_y(\partial_zA_x - \partial_xA_z) + \partial_z(\partial_xA_y - \partial_yA_x)\).

Worked solution

Idea. \(\mathrm d^2 = 0\) is Clairaut's theorem, and the classical identities "div curl \(= 0\)" and "curl grad \(= 0\)" are its components. Two of Maxwell's equations and charge conservation are those identities, applied to \(A\) and to \(\star F\).

1. Example 2's expansion used nothing about \(F\) but its shape, so \[ \mathrm d(\mathrm dA) = \big(\nabla\cdot(\nabla\times\vec A)\big)\,\mathrm dx\wedge\mathrm dy\wedge\mathrm dz + \big[\partial_t(\nabla\times\vec A) + \nabla\times(-\nabla\varphi - \partial_t\vec A)\big]_i\,\mathrm dt\wedge\varepsilon^i . \] The first coefficient, from rung 3, is \((\partial_x\partial_y - \partial_y\partial_x)A_z + (\partial_y\partial_z - \partial_z\partial_y)A_x + (\partial_z\partial_x - \partial_x\partial_z)A_y = 0\): div curl. The bracket is \(-\nabla\times\nabla\varphi + \big(\partial_t\nabla\times\vec A - \nabla\times\partial_t\vec A\big)\). Its first term has \(x\)-component \((\partial_y\partial_z - \partial_z\partial_y)\varphi = 0\): curl grad. The second vanishes because \(\partial_t\) commutes with \(\partial_y\) and \(\partial_z\) — Clairaut again, now in a time–space pair. Four coefficients, all zero, by Clairaut and nothing else.

2. Since \(F = \mathrm dA\) gives \(\vec B = \nabla\times\vec A\) and \(\vec E = -\nabla\varphi - \partial_t\vec A\), the expansion of \(\mathrm dF\) in example 2 reads \(\nabla\cdot\vec B = 0\) and \(\nabla\times\vec E + \partial_t\vec B = 0\), now as identities. So the homogeneous pair has no content once potentials exist; its content is that they exist. On \(\mathbb R^4\), star-shaped, the Poincaré lemma makes "\(\mathrm dF = 0\)" and "\(F = \mathrm dA\) for some \(A\)" the same statement — no magnetic charge, and Faraday's induction law, are the claim that \(\vec E\) and \(\vec B\) come from one potential.

3. Write \(\mathrm d\star F = \tfrac1c(\nabla\cdot\vec E)\,\mathrm dx\wedge\mathrm dy\wedge\mathrm dz + V_i\,\mathrm dt\wedge\varepsilon^i\) with \(\vec V = \tfrac1c\partial_t\vec E - c\,\nabla\times\vec B\) (example 4). Then \[ \mathrm d(\mathrm d\star F) = \tfrac1c\partial_t(\nabla\cdot\vec E)\,\mathrm dt\wedge\mathrm dx\wedge\mathrm dy\wedge\mathrm dz + \partial_jV_i\,\mathrm dx^j\wedge\mathrm dt\wedge\varepsilon^i . \] Only \(j = i\) survives, and \(\mathrm dx^i\wedge\mathrm dt\wedge\varepsilon^i = -\mathrm dt\wedge\mathrm dx\wedge\mathrm dy\wedge\mathrm dz\), so the coefficient of \(\mathrm dt\wedge\mathrm dx\wedge\mathrm dy\wedge\mathrm dz\) is \[ \tfrac1c\partial_t(\nabla\cdot\vec E) - \nabla\cdot\vec V = \tfrac1c\partial_t\nabla\cdot\vec E - \tfrac1c\nabla\cdot\partial_t\vec E + c\,\nabla\cdot(\nabla\times\vec B) = 0 , \] by Clairaut twice. Applying \(\mathrm d\) to the equation: \(0 = \mu_0\,\mathrm d\star J\), and the deck's computation gives \(\mathrm d\star J = c(\partial_t\rho + \nabla\cdot\vec J)\,\mathrm dt\wedge\mathrm dx\wedge\mathrm dy\wedge\mathrm dz\). So \(\partial_t\rho + \nabla\cdot\vec J = 0\).

4. Take the divergence of \(\nabla\times\vec B = \mu_0\vec J\): the left side is zero identically, so \(\nabla\cdot\vec J = 0\) always. But continuity says \(\nabla\cdot\vec J = -\partial_t\rho\), and on a charging capacitor plate \(\partial_t\rho\ne0\). No field \(\vec B\) satisfies the equation there. With the displacement term, the divergence gives \(\mu_0\nabla\cdot\vec J + \mu_0\varepsilon_0\partial_t\nabla\cdot\vec E = \mu_0(\nabla\cdot\vec J + \partial_t\rho) = 0\), consistent. In forms: the right side of \(\mathrm d\star F = \mu_0\star J\) must be closed, because the left is exact.

Check. Dimensions of part 3: \([\tfrac1c\partial_t\nabla\cdot\vec E] = \mathrm{s\,m^{-1}}\cdot\mathrm{s^{-1}}\cdot\mathrm{V\,m^{-2}} = \mathrm{V\,m^{-3}}\) and \([c\,\nabla\cdot\nabla\times\vec B] = \mathrm{m\,s^{-1}\,T\,m^{-2}} = \mathrm{V\,m^{-3}}\) (as \(\mathrm{T} = \mathrm{V\,s\,m^{-2}}\)) ✓. Special case: statics, \(\partial_t\rho = 0\), requires \(\nabla\cdot\vec J = 0\): steady currents, which is exactly where Ampère's original law is right ✓.

P3 The star, and the signature it does not care about medium

exercises: the Hodge star from its definition, the double-star sign, where the metric enters, sign conventions

Work on Minkowski space with the preamble's coframe and \(\eta = \operatorname{diag}(-1,1,1,1)\).

  1. From \(\alpha\wedge\star\beta = \langle\alpha,\beta\rangle\,\mathrm{vol}\) alone, compute \(\star e^0\), \(\star e^1\), \(\star(e^1\wedge e^2\wedge e^3)\) and \(\star(e^0\wedge e^2\wedge e^3)\). Check \(\star\star = (-1)^{k(n-k)}s\) on one-forms and three-forms.
  2. Now use the opposite signature \(\eta' = -\eta\), the other common convention, with the same orientation. Show \(\mathrm{vol}' = \mathrm{vol}\) and \(\langle\cdot,\cdot\rangle' = (-1)^k\langle\cdot,\cdot\rangle\) on \(k\)-forms, and hence \(\star' = (-1)^k\star\).
  3. The physical current is the vector \(\rho\,\partial_t + J^i\partial_i\); its one-form is obtained by lowering the index, which uses the metric. Show that the one-form changes sign, \(J' = -J\), and conclude that \(\mathrm dF = 0\) and \(\mathrm d\star F = \mu_0\star J\) are word for word the same equations in either signature.
Hints · 3 rungs
Rung 1

One-forms go to three-forms and three-forms to one-forms, and each answer in part 1 is \(\pm\) a single basis element. The whole job is the sign.

Rung 2

For a basis element \(\beta = e^I\), try \(\star\beta = \lambda\,e^{I^c}\) with \(I^c\) the missing indices. \(\langle\beta,\beta\rangle\) is the product of \(\eta^{aa}\) over \(a\in I\), and \(e^I\wedge e^{I^c}\) is \(\pm\mathrm{vol}\) according to the parity of the reordering. For part 2, count how many inverse-metric entries go into a \(k\times k\) determinant.

Rung 3

The first line: \(\langle e^0,e^0\rangle = \eta^{00} = -1\), so we need \(e^0\wedge\star e^0 = -\mathrm{vol}\); with \(\star e^0 = \lambda\,e^1\wedge e^2\wedge e^3\) this is \(\lambda\,\mathrm{vol} = -\mathrm{vol}\).

Worked solution

Idea. The star is fixed by the inner product and the orientation. Flipping the signature changes the inner product by a sign per slot, leaves the volume form alone, and flips the lowering map — and in Maxwell's equations the flips cancel.

1. From rung 3, \(\star e^0 = -e^1\wedge e^2\wedge e^3\). \(\langle e^1,e^1\rangle = +1\); with \(\star e^1 = \lambda\,e^0\wedge e^2\wedge e^3\), \(e^1\wedge e^0\wedge e^2\wedge e^3 = -\mathrm{vol}\) (one transposition), so \(\lambda = -1\): \(\star e^1 = -e^0\wedge e^2\wedge e^3\). \(\langle e^{123},e^{123}\rangle = +1\); with \(\star e^{123} = \lambda e^0\), \(e^1\wedge e^2\wedge e^3\wedge e^0 = -\mathrm{vol}\) (three transpositions), so \(\star(e^1\wedge e^2\wedge e^3) = -e^0\). \(\langle e^{023},e^{023}\rangle = \eta^{00}\eta^{22}\eta^{33} = -1\); with \(\star e^{023} = \lambda e^1\), \(e^0\wedge e^2\wedge e^3\wedge e^1 = +\mathrm{vol}\) (two transpositions), so \(\lambda = -1\): \(\star(e^0\wedge e^2\wedge e^3) = -e^1\).

Double star: \(\star\star e^0 = \star(-e^{123}) = e^0\) and \(\star\star e^1 = \star(-e^{023}) = e^1\); so \(\star\star = +1\) on one-forms, and then on three-forms too (\(\star\star e^{123} = \star(-e^0) = e^{123}\)). The formula: \((-1)^{k(4-k)}s\) with \(s = -1\) is \((-1)^{3}(-1) = +1\) for \(k = 1\) and \(k = 3\) ✓.

2. \(\det\eta' = (-1)^4\det\eta = \det\eta\), so \(\sqrt{|\det\eta'|}\) is unchanged; the orientation is the same, so \(\mathrm{vol}' = \mathrm{vol}\). On one-forms \(\langle\alpha,\beta\rangle' = \eta'^{ab}\alpha_a\beta_b = -\langle\alpha,\beta\rangle\). On decomposable \(k\)-forms the inner product is a \(k\times k\) determinant of one-form inner products, each negated, so it picks up \((-1)^k\); by linearity this holds on all of \(\Lambda^k\). Then for all \(\alpha\), \(\alpha\wedge\star'\beta = (-1)^k\langle\alpha,\beta\rangle\mathrm{vol} = \alpha\wedge\big((-1)^k\star\beta\big)\), and since the pairing \(\Lambda^k\times\Lambda^{n-k}\to\Lambda^n\) is nondegenerate, \(\star'\beta = (-1)^k\star\beta\).

3. Lowering with \(\eta'\) is lowering with \(\eta\) followed by a sign: for the current vector \(j\), \(J' = \eta'(j,\cdot) = -\eta(j,\cdot) = -J\). Check with \(\eta\): lowering \(\rho\,\partial_t\) with \(g_{tt} = -c^2\) gives \(-c^2\rho\,\mathrm dt\), the preamble's \(J\). Now \(\star'J' = (-1)^1\star(-J) = \star J\). And \(A\) is a one-form from the start — the potentials are covector components, not raised from anything — so \(F = \mathrm dA\) and \(\mathrm dF = 0\) involve no metric, while \(\star'F = (-1)^2\star F = \star F\). Hence \(\mathrm d\star'F = \mu_0\star'J'\) is literally \(\mathrm d\star F = \mu_0\star J\).

Check. Special case: in the other signature, a book that forgot to flip \(J\) would find \(\nabla\cdot\vec E = -\rho/\varepsilon_0\), attractive like charges — which is why texts in \((+,-,-,-)\) write \(J_\mu = (c\rho, -\vec J)\) with the minus on the spatial part. The two sign flips in part 3 are exactly that bookkeeping. Dimensions are untouched by a sign ✓.

P4 The two invariants, with numbers routine

exercises: \(F\wedge F\) and \(F\wedge\star F\), frame independence, arithmetic with \(c\)

In a laboratory \(\vec E\) has magnitude \(3.0\times10^6\ \mathrm{V\,m^{-1}}\) — about the breakdown field of air — along \(x\), and \(|\vec B| = 0.020\) T.

  1. Take \(\vec B\) along \(y\). Compute the coefficients of \(\mathrm{vol}\) in \(F\wedge F\) and \(F\wedge\star F\). If some observer measures a purely magnetic field, how large is it? Can any observer measure a purely electric one?
  2. Take \(\vec B\) in the \(xy\)-plane at \(60^\circ\) to \(\vec E\). Compute both coefficients again, and show that no observer measures a purely electric or a purely magnetic field.
  3. Check the units of both coefficients, and say what both are for a plane wave.
Hints · 3 rungs
Rung 1

Each part is a pair of numbers in \(\mathrm T^2\), plus yes-or-no answers argued from their signs.

Rung 2

\(F\wedge F = -\tfrac2c(\vec E\cdot\vec B)\,\mathrm{vol}\) and \(F\wedge\star F = (|\vec B|^2 - |\vec E|^2/c^2)\,\mathrm{vol}\), and both coefficients are the same for every observer. An observer who sees \(\vec E' = 0\) has coefficients \(|\vec B'|^2\) and \(0\).

Rung 3

The first line: \(|\vec E|/c = 3.0\times10^6/2.99792458\times10^8 = 1.0007\times10^{-2}\) T.

Worked solution

Idea. Frame independence turns "what would another observer see" into arithmetic: whatever they see must have the same two coefficients.

1. \((|\vec E|/c)^2 = 1.0014\times10^{-4}\ \mathrm T^2\) and \(|\vec B|^2 = 4.000\times10^{-4}\ \mathrm T^2\), so \[ |\vec B|^2 - |\vec E|^2/c^2 = 2.9986\times10^{-4}\ \mathrm T^2 ,\qquad \vec E\cdot\vec B = 0 . \] The \(F\wedge F\) coefficient is \(0\). An observer seeing only \(\vec B'\) has \(|\vec B'|^2 = 2.9986\times10^{-4}\ \mathrm T^2\), so \(|\vec B'| = 1.7317\times10^{-2}\) T \(= 0.01732\) T. A purely electric field would give \(-|\vec E'|^2/c^2\le0\) for the second invariant, but it is positive in every frame: no.

2. \(\vec E\cdot\vec B = 3.0\times10^6\times0.020\times\cos60^\circ = 3.0\times10^4\ \mathrm{V\,T\,m^{-1}}\), and \[ -\tfrac2c\,\vec E\cdot\vec B = -2.0014\times10^{-4}\ \mathrm T^2 . \] The other coefficient depends only on the magnitudes and is again \(2.9986\times10^{-4}\ \mathrm T^2\). A purely electric or purely magnetic field has \(\vec E'\cdot\vec B' = 0\), so its \(F\wedge F\) coefficient is zero; ours is not, in any frame. No such observer exists.

3. \([\vec E\cdot\vec B/c] = \mathrm{V\,m^{-1}\cdot T\cdot s\,m^{-1}} = (\mathrm{V\,s\,m^{-2}})\,\mathrm T = \mathrm T^2\), and \([|\vec E|^2/c^2] = \mathrm T^2\) likewise ✓; multiplied by \(\mathrm{vol}\), in \(\mathrm m^4\), both give \(\mathrm{T^2\,m^4} = \mathrm{Wb}^2\), the units of \(F\wedge F\) since \([F] = \mathrm{Wb}\) ✓. A plane wave has \(|\vec E| = c|\vec B|\) and \(\vec E\perp\vec B\): both zero.

Check. Limit \(|\vec E|\to0\): the invariants become \(|\vec B|^2\) and \(0\), and the purely magnetic observer of part 1 sees \(|\vec B'| = |\vec B| = 0.020\) T, as she must when she is the laboratory ✓. And the electric contribution here is about a quarter of the magnetic one, \(1.0014/4.000 = 0.2504\), so \(|\vec B'|\) is \(\sqrt{0.7496} = 0.8658\) of \(|\vec B|\): \(0.8658\times0.020 = 0.01732\) ✓.

P5 Stokes, checked twice routine

exercises: integrating forms, pullback to a sphere, the induced orientation, the divergence and curl theorems as one

  1. Let \(B\) be the ball of radius \(R\) in \(\mathbb R^3\) and \(\omega = x\,\mathrm dy\wedge\mathrm dz\). Compute \(\int_B\mathrm d\omega\) and \(\int_{\partial B}\omega\) separately, the second by pulling back to spherical angles \((\theta,\phi)\) with the orientation induced by the outward normal. Evaluate for \(R = 0.10\) m.
  2. Let \(S\) be the upper hemisphere \(r = R\), \(z\ge0\), with the outward normal, and \(\beta = x\,\mathrm dy - y\,\mathrm dx\) (from P1). Compute \(\int_S\mathrm d\beta\) by pulling back, and \(\oint_{\partial S}\beta\) with the induced orientation.
  3. Replace \(S\) by the flat disc \(z = 0\), \(x^2+y^2\le R^2\), oriented by \(+z\). Why must the answer be the same? One line of forms.
Hints · 3 rungs
Rung 1

Each part is a number — a volume or an area up to a factor — computed twice, once on each side of \(\int_M\mathrm d\omega = \int_{\partial M}\omega\).

Rung 2

On \(r = R\): \(x = R\sin\theta\cos\phi\), \(y = R\sin\theta\sin\phi\), \(z = R\cos\theta\). The pair \((\theta,\phi)\) is positively oriented for the outward normal, because \((\partial_r,\partial_\theta,\partial_\phi)\) is positive in \(\mathbb R^3\). For the hemisphere's rim, the outward direction within \(S\) is \(+\partial_\theta\).

Rung 3

The first line: \(\mathrm d\omega = \mathrm dx\wedge\mathrm dy\wedge\mathrm dz\), so \(\int_B\mathrm d\omega = \tfrac43\pi R^3\).

Worked solution

Idea. Stokes is checkable, and checking it is how the orientation convention becomes second nature. Part 1 is unit 05's divergence theorem and part 2 the curl theorem; the computation is the same.

1. \(\int_B\mathrm d\omega = \tfrac43\pi R^3\). On the sphere, \(\mathrm dy = R(\cos\theta\sin\phi\,\mathrm d\theta + \sin\theta\cos\phi\,\mathrm d\phi)\) and \(\mathrm dz = -R\sin\theta\,\mathrm d\theta\), so \(\mathrm dy\wedge\mathrm dz = R\sin\theta\cos\phi\,\mathrm d\phi\wedge(-R\sin\theta\,\mathrm d\theta) = R^2\sin^2\theta\cos\phi\,\mathrm d\theta\wedge\mathrm d\phi\). 3. Both are \(\oint_{\partial}\beta\) over the same oriented circle, by Stokes. Check. Dimensions: with \(z\) a length, \(\oint\bar z\,\mathrm dz\) is an area ✓ and \(\mathrm dz/z\) is dimensionless, as an angle must be ✓. Special case \(f = 1\): \(\mathrm dz = \mathrm d(z)\) is exact and \(\oint\mathrm dz = 0\) ✓.

2. \(\Omega^1{}_2 = \mathrm d\omega^1{}_2 = \mathrm d(-y^{-1})\wedge\mathrm dx = y^{-2}\,\mathrm dy\wedge\mathrm dx = -\tfrac1{y^2}\,\mathrm dx\wedge\mathrm dy = -\tfrac1{a^2}\,e^1\wedge e^2\). So \(K = -1/a^2\).

3. \(g^{xx} = g^{yy} = y^2/a^2\), and only \(\partial_yg_{xx} = \partial_yg_{yy} = -2a^2/y^3\) are nonzero. From \(\Gamma^a{}_{bc} = \tfrac12g^{ad}(\partial_bg_{cd} + \partial_cg_{bd} - \partial_dg_{bc})\): \(\Gamma^x{}_{xy} = -1/y\), \(\Gamma^y{}_{xx} = 1/y\), \(\Gamma^y{}_{yy} = -1/y\), and \(\Gamma^x{}_{xx} = \Gamma^x{}_{yy} = \Gamma^y{}_{xy} = 0\). Then \[ R^x{}_{yxy} = \partial_x\Gamma^x{}_{yy} - \partial_y\Gamma^x{}_{xy} + \Gamma^x{}_{x\lambda}\Gamma^\lambda{}_{yy} - \Gamma^x{}_{y\lambda}\Gamma^\lambda{}_{xy} = 0 - \tfrac1{y^2} + \tfrac1{y^2} - \tfrac1{y^2} = -\tfrac1{y^2} , \] the two products being \(\Gamma^x{}_{xy}\Gamma^y{}_{yy}\) and \(\Gamma^x{}_{yx}\Gamma^x{}_{xy}\). Lower with \(g_{xx}\) and divide by \(g_{xx}g_{yy}\): \(K = R^x{}_{yxy}/g_{yy} = -\tfrac1{y^2}\cdot\tfrac{y^2}{a^2} = -\tfrac1{a^2}\) ✓.

4. Cartan: \(\mathrm de^1\), \(\mathrm de^2\), the inspection, \(\mathrm d\omega^1{}_2\) — 4. Coordinates: 2 inverse-metric entries, 6 symbols of 3 derivative terms each (18), the Riemann formula's 2 derivatives and 4 products (6), then lower and divide (2) — 28. P11 The three-sphere by moving frames hard

exercises: structure equations in three dimensions, the \(\omega\wedge\omega\) term, Ricci from curvature forms, counting

The round three-sphere of radius \(a\): \(g = a^2\big[\mathrm d\chi^2 + \sin^2\!\chi\,(\mathrm d\theta^2 + \sin^2\!\theta\,\mathrm d\phi^2)\big]\), \(0\lt\chi\lt\pi\) — the spatial slice of a closed universe in unit 39.

  1. Take \(e^1 = a\,\mathrm d\chi\), \(e^2 = a\sin\chi\,\mathrm d\theta\), \(e^3 = a\sin\chi\sin\theta\,\mathrm d\phi\) and compute \(\mathrm de^a\).
  2. Find the three connection forms by inspection and verify all three first structure equations.
  3. Compute the three curvature two-forms, including the \(\omega\wedge\omega\) terms, and show \(\Omega^a{}_b = \tfrac1{a^2}\,e^a\wedge e^b\).
  4. Read off \(R^a{}_{bcd}\), the Ricci tensor and the scalar curvature, and show every plane has sectional curvature \(1/a^2\).
  5. How many Christoffel symbols would the coordinate route need, and how many are nonzero?
Hints · 3 rungs
Rung 1

The answer is constant curvature: \(R_{abcd} = (\delta_{ac}\delta_{bd} - \delta_{ad}\delta_{bc})/a^2\), Ricci \(\propto\delta_{ab}\).

Rung 2

\(\mathrm de^1 = 0\), \(\mathrm de^2 = \tfrac{\cot\chi}{a}\,e^1\wedge e^2\), \(\mathrm de^3 = \tfrac{\cot\chi}{a}\,e^1\wedge e^3 + \tfrac{\cot\theta}{a\sin\chi}\,e^2\wedge e^3\). Each coefficient suggests one connection form, proportional to the second coframe element in its term.

Rung 3

The first line: try \(\omega^2{}_1 = \cos\chi\,\mathrm d\theta\), \(\omega^3{}_1 = \cos\chi\sin\theta\,\mathrm d\phi\), \(\omega^3{}_2 = \cos\theta\,\mathrm d\phi\).

Worked solution

Idea. The same three moves as in two dimensions, with the one new feature that \(\omega^a{}_c\wedge\omega^c{}_b\) no longer vanishes — and here it is exactly what makes the answer come out constant.

1. \(\mathrm de^1 = 0\); \(\mathrm de^2 = a\cos\chi\,\mathrm d\chi\wedge\mathrm d\theta\); \(\mathrm de^3 = a\cos\chi\sin\theta\,\mathrm d\chi\wedge\mathrm d\phi + a\sin\chi\cos\theta\,\mathrm d\theta\wedge\mathrm d\phi\), which are rung 2's expressions.

2. With rung 3's guesses and \(\omega^a{}_b = -\omega^b{}_a\): \(-\omega^2{}_1\wedge e^1 - \omega^2{}_3\wedge e^3 = -\cos\chi\,\mathrm d\theta\wedge a\,\mathrm d\chi + \cos\theta\,\mathrm d\phi\wedge a\sin\chi\sin\theta\,\mathrm d\phi = a\cos\chi\,\mathrm d\chi\wedge\mathrm d\theta = \mathrm de^2\) ✓. \(-\omega^3{}_1\wedge e^1 - \omega^3{}_2\wedge e^2 = a\cos\chi\sin\theta\,\mathrm d\chi\wedge\mathrm d\phi + a\sin\chi\cos\theta\,\mathrm d\theta\wedge\mathrm d\phi = \mathrm de^3\) ✓. \(-\omega^1{}_2\wedge e^2 - \omega^1{}_3\wedge e^3 = a\sin\chi\cos\chi\,\mathrm d\theta\wedge\mathrm d\theta + a\sin\chi\cos\chi\sin^2\theta\,\mathrm d\phi\wedge\mathrm d\phi = 0 = \mathrm de^1\) ✓.

3. \(\Omega^2{}_1 = \mathrm d\omega^2{}_1 + \omega^2{}_3\wedge\omega^3{}_1 = -\sin\chi\,\mathrm d\chi\wedge\mathrm d\theta + (-\cos\theta\,\mathrm d\phi)\wedge(\cos\chi\sin\theta\,\mathrm d\phi) = -\sin\chi\,\mathrm d\chi\wedge\mathrm d\theta = \tfrac1{a^2}\,e^2\wedge e^1\). \(\Omega^3{}_1 = -\sin\chi\sin\theta\,\mathrm d\chi\wedge\mathrm d\phi + \cos\chi\cos\theta\,\mathrm d\theta\wedge\mathrm d\phi + \cos\theta\,\mathrm d\phi\wedge\cos\chi\,\mathrm d\theta = -\sin\chi\sin\theta\,\mathrm d\chi\wedge\mathrm d\phi = \tfrac1{a^2}\,e^3\wedge e^1\) — here the wedge term cancels a derivative term. \(\Omega^3{}_2 = -\sin\theta\,\mathrm d\theta\wedge\mathrm d\phi + \cos\chi\sin\theta\,\mathrm d\phi\wedge(-\cos\chi\,\mathrm d\theta) = -\sin^2\!\chi\sin\theta\,\mathrm d\theta\wedge\mathrm d\phi = \tfrac1{a^2}\,e^3\wedge e^2\) — here it turns \(1\) into \(\sin^2\chi\).

4. \(\Omega^a{}_b = \tfrac12R^a{}_{bcd}e^c\wedge e^d = \tfrac1{a^2}e^a\wedge e^b\) gives \(R^a{}_{bcd} = (\delta^a_c\delta_{bd} - \delta^a_d\delta_{bc})/a^2\). Sectional curvature of the plane of orthonormal \(e_a, e_b\) is \(R_{abab} = 1/a^2\); and for any orthonormal pair \(u, v\), \(R(u,v,u,v) = \big(|u|^2|v|^2 - (u\cdot v)^2\big)/a^2 = 1/a^2\), so every plane has \(K = 1/a^2\). Ricci: \(R_{bd} = R^a{}_{bad} = (3-1)\delta_{bd}/a^2 = 2\delta_{bd}/a^2\); scalar \(R = 6/a^2\).

5. \(n^2(n+1)/2 = 18\) symbols; nonzero, up to the lower-index symmetry, six: \(\Gamma^\chi{}_{\theta\theta} = -\sin\chi\cos\chi\), \(\Gamma^\chi{}_{\phi\phi} = -\sin\chi\cos\chi\sin^2\theta\), \(\Gamma^\theta{}_{\chi\theta} = \cot\chi\), \(\Gamma^\theta{}_{\phi\phi} = -\sin\theta\cos\theta\), \(\Gamma^\phi{}_{\chi\phi} = \cot\chi\), \(\Gamma^\phi{}_{\theta\phi} = \cot\theta\). Then six independent Riemann components (\(n^2(n^2-1)/12 = 6\)), each a four-term formula with sums. Cartan used three \(\mathrm de\)'s, three connection forms and three curvature forms.

Check. Special case: freeze \(\chi = \pi/2\); the \((\theta,\phi)\) part is the two-sphere of radius \(a\), and \(\Omega^3{}_2\) there is \(-\sin\theta\,\mathrm d\theta\wedge\mathrm d\phi\), the deck's example 5 ✓. Dimensions: \(R\) in \(\mathrm m^{-2}\) ✓. Limit \(a\to\infty\): flat. And in three dimensions Ricci determines Riemann (unit 33): \(R_{ab} = 2\delta_{ab}/a^2\) is consistent with that.

P12 The symplectic form, used medium

exercises: wedge powers, the interior product, Cartan's magic formula, generating functions as \(\mathrm d^2 = 0\)

  1. On \(\mathbb R^4\) with \(\omega = \mathrm dp_1\wedge\mathrm dq_1 + \mathrm dp_2\wedge\mathrm dq_2\), compute \(\omega\wedge\omega\); show \(\sigma = \mathrm dp_1\wedge\mathrm dq_1\) has \(\sigma\wedge\sigma = 0\). Why is \(\tfrac12\omega\wedge\omega\) a volume form and \(\sigma\) not symplectic?
  2. For the pendulum \(H = p^2/(2ml^2) - mgl\cos q\) on \(\mathbb R^2\) with \(\omega = \mathrm dp\wedge\mathrm dq\), find \(X_H = A\,\partial_q + B\,\partial_p\) from \(i_{X_H}\omega = -\mathrm dH\) and compare with Hamilton's equations. Show \(\mathcal L_{X_H}\omega = 0\) by the magic formula.
  3. The swap \(Q = p\), \(P = -q\): verify \(p\,\mathrm dq - P\,\mathrm dQ = \mathrm dF_1\) with unit 14's \(F_1 = qQ\), and deduce it preserves \(\omega\).
  4. The kick \(Q = q\), \(P = p + k\sin q\): show \(p\,\mathrm dq - P\,\mathrm dQ\) is exact, and hence that the kick is symplectic.
  5. The stretch \(Q = 2q\), \(P = p\): compute \(\mathrm dP\wedge\mathrm dQ\); a blob of phase-space area \(1.0\times10^{-2}\) J s is mapped to what area? Why can no generating function exist?
Hints · 3 rungs
Rung 1

Part 1 is a four-form; part 2 a vector field; parts 3–5 are each a yes-or-no with a one-line reason, and part 5 a number.

Rung 2

\(i_X(\mathrm dp\wedge\mathrm dq) = \mathrm dp(X)\,\mathrm dq - \mathrm dq(X)\,\mathrm dp\). For 3–5, a map preserves \(\omega\) exactly when \(\mathrm dP\wedge\mathrm dQ = \mathrm dp\wedge\mathrm dq\), and applying \(\mathrm d\) to \(p\,\mathrm dq - P\,\mathrm dQ\) gives the difference.

Rung 3

The first line of part 2: \(B\,\mathrm dq - A\,\mathrm dp = -H_q\,\mathrm dq - H_p\,\mathrm dp\).

Worked solution

Idea. Everything unit 14 proved about phase space used only \(\omega\), closedness and \(\mathrm d^2 = 0\). Written in forms, each proof is a line.

1. Two-forms commute, and \(\sigma_i\wedge\sigma_i = 0\) (repeated factors), so \(\omega\wedge\omega = 2\,\mathrm dp_1\wedge\mathrm dq_1\wedge\mathrm dp_2\wedge\mathrm dq_2\ne0\), and \(\tfrac12\omega\wedge\omega\) is a nowhere-zero top form — a volume form. \(\sigma\wedge\sigma = 0\): \(\sigma\) is degenerate, killing \(\partial_{q_2}\) and \(\partial_{p_2}\), so it cannot turn \(\mathrm dH\) into a unique vector field.

2. By rung 3, \(A = H_p = p/(ml^2)\) and \(B = -H_q = -mgl\sin q\): \(\dot q = p/(ml^2)\), \(\dot p = -mgl\sin q\), Hamilton's equations ✓. Then \(\mathcal L_{X_H}\omega = \mathrm d(i_{X_H}\omega) + i_{X_H}\mathrm d\omega = -\mathrm d\mathrm dH + 0 = 0\). Unit 14's divergence check agrees: \(\partial_qA + \partial_pB = 0 + 0 = 0\).

3. \(p\,\mathrm dq - P\,\mathrm dQ = p\,\mathrm dq + q\,\mathrm dp = \mathrm d(qp) = \mathrm d(qQ)\) ✓. Apply \(\mathrm d\): \(\mathrm dp\wedge\mathrm dq - \mathrm dP\wedge\mathrm dQ = \mathrm d\mathrm dF_1 = 0\). Directly: \(\mathrm dP\wedge\mathrm dQ = -\mathrm dq\wedge\mathrm dp = \mathrm dp\wedge\mathrm dq\) ✓.

4. \(p\,\mathrm dq - (p + k\sin q)\,\mathrm dq = -k\sin q\,\mathrm dq = \mathrm d(k\cos q)\), exact, so \(\mathrm dp\wedge\mathrm dq = \mathrm dP\wedge\mathrm dQ\). Directly: \((\mathrm dp + k\cos q\,\mathrm dq)\wedge\mathrm dq = \mathrm dp\wedge\mathrm dq\) ✓. (It has no generating function of type \(F_1(q,Q)\), since \(Q = q\) means \(q, Q\) are not independent coordinates; the one-form statement does not care.) This kick is the building block of unit 17's standard map, for those who take that branch.

5. \(\mathrm dP\wedge\mathrm dQ = 2\,\mathrm dp\wedge\mathrm dq = 2\omega\): areas double, and the blob becomes \(2.0\times10^{-2}\) J s. \(p\,\mathrm dq - P\,\mathrm dQ = -p\,\mathrm dq\), whose \(\mathrm d\) is \(-\mathrm dp\wedge\mathrm dq\ne0\): not closed, so certainly not exact, and no \(F\) exists.

Check. Units: \(\omega\) is momentum times length, \(\mathrm{kg\,m\,s^{-1}\cdot m} = \mathrm{J\,s}\) ✓, the units of the blob's area. Special case \(k = 0\) in part 4: the identity map, \(F = \) const ✓. And part 5 fails Liouville exactly as it must: a map that doubles volume cannot be a Hamiltonian flow.
