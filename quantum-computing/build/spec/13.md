## Why this unit exists, and what it must not become
Gate complexity has no non-trivial lower bounds anyone can prove; query complexity does. So separations between quantum and classical computation are proved in the query model, where an algorithm accesses its input only through an oracle and is charged per access. This unit sets up the model with unit 10's reversible oracle U_f, proves the one trick everything in Part D uses — phase kickback — and runs the first three algorithms, each beating a weaker classical model than the last, and says exactly which. Deutsch–Jozsa's "exponential" speedup evaporates against randomised algorithms, and the unit says so; Bernstein–Vazirani's survives randomisation but is only n versus 1.

It must not oversell. No exponential separation against randomised algorithms appears until unit 14; the unit's last slide says so.

## Mathematical tools
The query model: an input x ∈ {0,1}^N (or a function f: {0,1}^n → {0,1}^m) accessible only through the oracle U_f: |x⟩|y⟩ ↦ |x⟩|y ⊕ f(x)⟩ (unit 10's construction, so any efficiently computable f gives a polynomial-size oracle circuit); a query algorithm as alternating oracle calls and arbitrary oracle-independent unitaries; query complexity counts only oracle calls. Classical counterparts: deterministic decision trees, and randomised ones with bounded error (distributions over decision trees); why query lower bounds are provable (adversary and counting arguments) when circuit lower bounds are not.

Phase kickback, proved: U_f(|x⟩|−⟩) = (−1)^{f(x)}|x⟩|−⟩, so with the target in |−⟩ the oracle writes f into a phase — the phase oracle O_f: |x⟩ ↦ (−1)^{f(x)}|x⟩.

The Hadamard transform H^{⊗n}|x⟩ = 2^{−n/2} Σ_y (−1)^{x·y}|y⟩, proved by induction from H|b⟩ = (|0⟩ + (−1)^b|1⟩)/√2; its interpretation as the Fourier transform over the group ℤ₂ⁿ, the (−1)^{x·y} being the characters — the first appearance of the structure unit 15 generalises, flagged as such.

The algorithms:
- **Deutsch** (1985; the deterministic one-query version from Cleve, Ekert, Macchiavello and Mosca 1998): f: {0,1} → {0,1}, decide f(0) ⊕ f(1) with one query against two.
- **Deutsch–Jozsa** (1992): f on n bits promised constant or balanced; one query; amplitude of |0ⁿ⟩ is 2^{−n} Σ_x (−1)^{f(x)}, which is ±1 or 0. Classically: deterministic needs 2^{n−1} + 1 queries in the worst case, proved by an adversary; but a randomised algorithm with k queries errs with probability at most 2^{1−k}, so with bounded error a constant number suffices — not a separation worth having.
- **Bernstein–Vazirani** (1993/1997): f(x) = s·x mod 2, find s; one query (H^{⊗n} after the phase oracle returns |s⟩ exactly); classically n queries are necessary even with randomisation, proved by an information count (each query reveals at most one bit about s; s has n bits — made rigorous via the uniform distribution on s).

## The running example
**f(x) = s·x on three bits, with s = 101.** Overview: the oracle as a black box, and two questions — is f constant or balanced, and what is s? Section 1 (the model): U_f as a reversible circuit (two CNOTs from qubits 0 and 2 to the target); classical algorithms query it bit by bit. Section 2 (phase kickback): the target in |−⟩. Section 3 (Deutsch–Jozsa): f is balanced, and one query says so — the amplitude of |000⟩ computed as a sum of eight signs cancelling to zero, drawn as amplitudes. Section 4 (Bernstein–Vazirani): the same circuit returns |101⟩ exactly. Close: one query told us everything; a classical algorithm needs three; and the honest scorecard of which classical model each algorithm beats.

## What the problem sheet exercises
Ten to twelve problems; at least one proof and one ending in a number; referee checks where natural (each algorithm on small n via `Circuit.oracle`).
- "The deterministic lower bound": prove 2^{n−1} + 1 queries are needed for Deutsch–Jozsa deterministically (adversary answering "0" until half the inputs are used).
- "Randomised Deutsch–Jozsa": a k-query randomised test errs with probability at most 2^{1−k}; for n = 30, compare 2^{29} + 1 deterministic queries with the 21 randomised queries for error below 10⁻⁶ (2^{1−21} ≈ 9.5 × 10⁻⁷).
- "Bernstein–Vazirani's classical lower bound": prove n queries are necessary even for randomised algorithms with error below ½.
- "Hadamard transform": prove the formula for H^{⊗n} and that it is its own inverse; show the characters (−1)^{x·y} are orthogonal.
- "Phase oracles and bit oracles": show each can be built from the other with one query and an ancilla.
- "Deutsch–Jozsa's amplitude when the promise fails": for an f that is neither constant nor balanced, the probability of 0ⁿ is (1 − 2w/2ⁿ)² for w ones — what does the algorithm then say?
- "Garbage breaks it": rerun Bernstein–Vazirani with an oracle that leaves garbage entangled with the input (unit 10), and show the output is no longer |s⟩.
- "Recursive Fourier sampling", stated: the problem of Bernstein and Vazirani on which they built their superpolynomial separation, defined, the result cited.
