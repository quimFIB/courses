## Why this unit exists, and what it must not become
Quantum error correction looks impossible for three reasons, each apparently fundamental: no-cloning forbids the repetition classical codes rely on; errors are continuous, so there are infinitely many to correct; and measuring a state to find an error destroys it. The three-qubit bit-flip code answers all three at once — encode by entangling rather than copying, measure only parities, correct — and the unit then proves the general theorems that say when *any* code works: the Knill–Laflamme conditions, and the discretisation of errors, by which correcting X, Y and Z on a qubit corrects every single-qubit channel.

It must not become the stabiliser formalism (unit 23) or fault tolerance (unit 24). The codes here are analysed as subspaces and Kraus operators, directly. Classical coding theory goes exactly as far as unit 23 needs: linear codes over 𝔽₂, parity-check matrices, distance, and the Hamming [7, 4, 3] code.

## Mathematical tools
The three obstacles stated precisely; no-cloning reproved (two lines from unitarity). The bit-flip code: |0_L⟩ = |000⟩, |1_L⟩ = |111⟩, encoded by two CNOTs (unit 10) — an entangling isometry, not a copy, so no-cloning is not violated (α|0⟩ + β|1⟩ ↦ α|000⟩ + β|111⟩, never (α|0⟩ + β|1⟩)^{⊗3}). Syndrome measurement of Z₀Z₁ and Z₁Z₂ via ancillas — parities only, which reveal the error and nothing about α, β; correction by the indicated X. Under independent bit flips with probability p, the logical failure probability is 3p² − 2p³, below p exactly when p < ½, proved. The phase-flip code by conjugating with H^{⊗3} (|+++⟩, |−−−⟩). Shor's nine-qubit code (Shor, *PRA* 52, R2493, 1995) as the two composed (concatenation named).

The Knill–Laflamme conditions (Knill and Laflamme, *PRA* 55, 900, 1997), proved necessary and sufficient: a code with projector P corrects a set of errors {E_i} iff P E_i†E_j P = α_ij P for a Hermitian matrix α. Sufficiency by constructing the recovery channel (diagonalise α, the error subspaces become orthogonal, measure which and undo — a channel in unit 21's sense); necessity from the requirement that recovery restore every code state, which forces the environment to learn nothing about which code state it acted on. Corollary: if a code corrects {E_i} it corrects every linear combination of them — the discretisation of errors, proved: since any single-qubit operator is a combination of I, X, Y, Z, a code correcting X, Y, Z on any one qubit corrects every single-qubit channel (each Kraus operator expanded). Distance (the least weight of an error the code cannot detect), t = ⌊(d − 1)/2⌋ errors corrected; degenerate codes (α singular: different errors acting identically on the code, which Shor's code exhibits for Z errors within a block).

Classical linear codes over 𝔽₂: generator and parity-check matrices, syndromes as Hx, distance as the least weight of a non-zero codeword, the Hamming [7, 4, 3] code with its parity-check matrix whose columns are 1 to 7 in binary — so the syndrome of a single error spells its position. Its dual is the [7, 3, 4] simplex code, contained in it — the fact unit 23's CSS construction needs, proved.

## The running example
**The three-qubit bit-flip code, then Shor's code.** Overview: one logical qubit α|0⟩ + β|1⟩ to protect against bit flips, and the three objections. Section 1 (the objections): no-cloning reproved; continuity; measurement. Section 2 (the bit-flip code): encode, syndrome circuit (drawn), correct — the syndrome table for all four outcomes; the logical failure 3p² − 2p³, at p = 10⁻³ about 3.0 × 10⁻⁶. Section 3 (phase flips and Shor): the bit-flip code fails against a single Z (it maps |0_L⟩ ± |1_L⟩ to each other); the phase-flip code; Shor's nine qubits. Section 4 (Knill–Laflamme): the conditions checked on the bit-flip code for {I, X₀, X₁, X₂}. Section 5 (discretisation): an arbitrary single-qubit rotation error on Shor's code, expanded in Paulis, each corrected. Close: the three objections each answered by a theorem.

## Worked examples (three to five, in `box ex`)
1. The bit-flip code's syndrome table, every case, with α, β untouched.
2. Logical failure 3p² − 2p³ derived; at p = 10⁻³, 2.998 × 10⁻⁶; equal to p at p = ½.
3. Knill–Laflamme for the bit-flip code and its error set, the 4×4 matrix α computed (diagonal, α = I).
4. Shor's code against an arbitrary single-qubit error on qubit 4 (e.g. a small rotation e^{−iθY/2}), expanded in I, X, Y, Z and each component's syndrome; recovery to the original state checked.
5. (optional) The Hamming code's syndrome for an error in position 5 reading 101.

## What the problem sheet exercises
Ten to twelve problems; at least one proof and one ending in a number; referee checks where natural (the test file's 3p² − 2p³ via a density-matrix run — but the sheet's snippet is its own; Knill–Laflamme matrices).
- "Logical failure": under independent flips, 3p² − 2p³, below p exactly when p < ½, and 3.0 × 10⁻⁶ at p = 10⁻³.
- "Knill–Laflamme for Shor's code": verify it for all single-qubit Paulis; identify the degeneracy.
- "The bit-flip code fails against a phase flip": show a single Z causes a logical error that goes undetected.
- "Knill–Laflamme, both directions": prove them.
- "Discretisation": prove correcting {X, Y, Z} on each qubit suffices for every single-qubit channel.
- "Syndromes reveal nothing": show the syndrome outcome distribution is independent of the encoded state.
- "Hamming": its parity-check matrix, its distance 3, the simplex code inside its dual — the containment proved.
- "Two errors": the bit-flip code under two flips, and why it then makes things worse.
- "Distance and errors": prove a distance-d code corrects ⌊(d − 1)/2⌋ errors via Knill–Laflamme.
- "Repetition against amplitude damping": does the bit-flip code help against amplitude damping (unit 21) at small γ? Expand the Kraus operators and decide.

## Checkpoint (falsifiable, and the last slide)
You prove Knill–Laflamme in both directions and the discretisation of errors, and verify Shor's code corrects an arbitrary single-qubit error.
