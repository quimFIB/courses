## Why this unit exists, and what it must not become
Unit 22 analysed codes as subspaces by hand. That does not scale; the stabiliser formalism does. A code is the joint +1 eigenspace of an abelian group of Pauli operators, and every question about it — its dimension, its syndromes, its logical operators, its distance — becomes linear algebra over 𝔽₂. The CSS construction turns nested classical codes into quantum ones, and Steane's [[7, 1, 3]] falls out of unit 22's Hamming code. The same formalism proves a theorem that reframes the subject: Clifford circuits on stabiliser states are classically simulable (Gottesman–Knill), so entanglement alone does not make a computation hard, and the non-Clifford T gate is where the power is.

It must not become a catalogue of codes or a course on topological codes. The surface code is unit 24's. Quantum LDPC codes are named in one sentence.

## Mathematical tools
The n-qubit Pauli group P_n (Pauli strings with phases ±1, ±i); commutation of two strings decided by the parity of positions where they differ non-trivially and neither is I. A stabiliser group S: an abelian subgroup of P_n not containing −I; the code V_S = {ψ : gψ = ψ for all g ∈ S}; dim V_S = 2^{n−r} for r independent generators, proved (each generator halves the dimension: the projector (I + g)/2 has trace half, and the product of commuting projectors' traces). Why −I must be excluded, and why the generators must commute.

The binary symplectic representation: a Pauli string up to phase as (x | z) ∈ 𝔽₂^{2n}; multiplication as addition; commutation as the symplectic form x·z′ + z·x′ = 0; generators independent iff their vectors are linearly independent. Syndromes: an error E's syndrome is the vector of commutation bits with the generators, computed as a matrix–vector product over 𝔽₂. Logical operators: the normaliser N(S) (Paulis commuting with all of S) modulo S; there are 2(n − r) independent logical operators, proved by counting dimensions in the symplectic space. Distance: the least weight of an element of N(S) \ S (or of N(S) \ ⟨S, iI⟩). Knill–Laflamme (unit 22) for stabiliser codes reduces to "no product E_i†E_j lies in N(S) \ S", proved.

The CSS construction (Calderbank and Shor 1996; Steane 1996), proved: for classical linear codes C₂ ⊆ C₁ ⊆ 𝔽₂ⁿ with dimensions k₂ < k₁, the span of the coset states |x + C₂⟩ = |C₂|^{−1/2} Σ_{y∈C₂}|x + y⟩ for x ∈ C₁ is an [[n, k₁ − k₂]] code; as a stabiliser code its Z-type generators are the rows of C₁'s parity-check matrix and its X-type generators are a basis of C₂ (the rows of C₂^⊥'s parity-check matrix); X- and Z-type generators commute because C₂ ⊆ C₁ makes every pair of rows orthogonal, proved; it corrects t bit flips if C₁ does and t phase flips if C₂^⊥ does. Steane's [[7, 1, 3]] from the Hamming [7, 4, 3] code (C₁ = Hamming, C₂ = its dual, the simplex code — unit 22): six generators, the three Hamming parity checks as X-type and as Z-type, checked to commute, the code space of dimension 2 (trace of the product of projectors), logical X = X^{⊗7} and logical Z = Z^{⊗7} (or weight-3 representatives), distance 3. The five-qubit code (Laflamme, Miquel, Paz and Zurek 1996; Bennett, DiVincenzo, Smolin and Wootters 1996): generators XZZXI and its cyclic shifts, the smallest code correcting one arbitrary error.

The quantum Hamming bound for non-degenerate codes: 2^k Σ_{j=0}^{t} C(n, j)3^j ≤ 2^n, proved by counting orthogonal error subspaces; the five-qubit code meets it with equality, 2⁵ = (1 + 3·5)·2 — a perfect code.

The Gottesman–Knill theorem (Gottesman 1998), proved: a stabiliser state on n qubits is described by n generators, an n × 2n binary matrix plus signs; a Clifford gate updates the matrix by conjugation in O(n) time per generator; a Pauli measurement's outcome probability and post-measurement generators are computable in polynomial time (deterministic if the measured Pauli commutes with all generators, uniformly random otherwise); so a Clifford circuit on |0ⁿ⟩ with Pauli measurements is simulable classically in polynomial time. Consequences: entanglement alone (GHZ, Bell states — all stabiliser states) does not make a computation hard; the T gate, outside the Clifford group (TXT† = (X + Y)/√2), is where the power is; Aaronson and Gottesman's tableau algorithm (2004) cited for O(n²) per measurement.

## The running example
**Steane's code, built from Hamming.** Overview: Hamming's 3×7 parity-check matrix with columns 1–7 in binary, and the claim that it makes a quantum code. Section 1 (stabiliser groups): the six generators as Pauli strings, their commutation checked. Section 2 (symplectic algebra): the generators as a 6×14 binary matrix; independence; dimension 2^{7−6} = 2. Section 3 (syndromes and logicals): a single Y error on qubit 5 — its X-syndrome and Z-syndrome both read 101 (position 5); logical X and Z found in the normaliser; distance 3. Section 4 (CSS): why it works in general. Section 5 (Gottesman–Knill): encoding |0_L⟩ is a Clifford circuit, so a classical computer tracks it exactly — the tableau updated gate by gate for the first few gates. Close: transversal H implements logical H on Steane's code (because the X and Z stabilisers are the same pattern), the first glimpse of fault tolerance (unit 24).

## Worked examples (three to five, in `box ex`)
1. Dimension of a stabiliser code: each independent generator halves it — proved via projector traces; checked on the bit-flip code (two generators, 2³/2² = 2).
2. Steane's six generators from Hamming's parity checks, their commutation via the symplectic form, the code dimension 2 (trace of the projector product).
3. A Y error on qubit 5 of Steane's code: both syndromes 101; correction.
4. Gottesman–Knill on a three-qubit GHZ preparation (H, CNOT, CNOT): the tableau from Z₀, Z₁, Z₂ to X₀X₁X₂, Z₀Z₁, Z₁Z₂, then a Z₀ measurement's outcome probability ½.
5. (optional) The five-qubit code's generators and the quantum Hamming bound with equality.

## What the problem sheet exercises
Ten to twelve problems; at least one proof and one ending in a number; referee checks where natural (commutation of generators, projector traces, Clifford conjugations).
- "Steane from Hamming": derive the stabilisers from Hamming's parity checks; find logical X and Z; show transversal H implements logical H.
- "The five-qubit code is perfect": check 2⁵ = (1 + 3·5)·2 and that its generators commute.
- "Dimension": prove dim V_S = 2^{n−r}.
- "CSS": prove the construction's stabilisers commute when C₂ ⊆ C₁, and compute its parameters.
- "Gottesman–Knill": prove it; then simulate a given five-gate Clifford circuit on three qubits by tableau, and give a measurement's outcome distribution.
- "Logical operators": prove there are 2(n − r) independent ones.
- "Distance of Shor's code as a stabiliser code": its eight generators, logical operators of weight 3, distance 3, and its degeneracy seen in the formalism.
- "Why −I is excluded": show a group containing −I stabilises only the zero vector.
- "The Hamming bound": evaluate it for n = 7, k = 1, t = 1 (Steane: 2 × 22 = 44 ≤ 128 — not perfect) and n = 5.
- "T is not Clifford": TXT† = (X + Y)/√2, and why that breaks the tableau.

## Checkpoint (falsifiable, and the last slide)
You prove Gottesman–Knill and the CSS construction, and build Steane's code with its logical operators from the Hamming code.
