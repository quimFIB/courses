The terms this unit introduces, in the order the deck meets them. The slides
stay the definition of record; each entry names the slide it comes from, so a
term can be looked up here and read properly there.

Running example: the three Stern–Gerlach bases of \(\mathbb C^2\) — \(z\):
\(\ket0, \ket1\); \(x\): \(\ket\pm = (\ket0 \pm \ket1)/\sqrt2\); \(y\):
\(\ket{\pm i} = (\ket0 \pm i\ket1)/\sqrt2\) — whose twelve cross-overlaps all
have \(|\braket{e|f}|^2 = \frac12\). The real plane holds only two such bases.
A test state \(\frac15(3\ket0 + 4i\ket1)\) gives \(\frac{9}{25}, \frac{16}{25}\)
along \(z\), \(\frac12, \frac12\) along \(x\) and \(\frac{49}{50},
\frac1{50}\) along \(y\). The \(y\) basis reappears as the eigenbasis of the
real quarter-turn \(J\) over \(\mathbb C\), and as the image of the \(z\) basis
under \(e^{-i\theta X/2}\) at \(\theta = \pi/2\).

* An experiment with no theory attached

- Stern–Gerlach experiment :: Silver atoms from an oven, narrowed to a beam,
  cross a magnet whose field is stronger near one pole, and land on a plate.
  Classically the deflections should fill an interval; the beam splits into
  exactly two (Stern and Gerlach, Frankfurt, 1922). Magnets in sequence — the
  textbook idealisation — split a sorted beam 50/50 along any perpendicular
  axis. /Slide: Stern–Gerlach, from nothing./
- minimal model :: The hypotheses of unit 00 only: a state is a unit vector of
  a finite-dimensional inner-product space; a measurement with \(k\) outcomes is
  an orthonormal basis \(e_1, \dots, e_k\); outcome \(i\) has probability
  \(|\braket{e_i|\psi}|^2\); afterwards the state is \(e_i\). A two-outcome
  magnet then forces dimension two. Unit 01 generalises it. /Slide: The least
  model that could describe it./
- mutually unbiased bases :: Orthonormal bases \(\{e_i\}\), \(\{f_j\}\) of a
  \(d\)-dimensional space with \(|\braket{e_i|f_j}|^2 = 1/d\) for all \(i, j\):
  prepared in one, a measurement in the other is uniformly random. Three
  magnets, pairwise 50/50, need three pairwise unbiased bases of a
  two-dimensional space; \(\mathbb R^2\) holds at most two, \(\mathbb C^2\)
  holds three. /Slide: Mutually unbiased bases./

* Complex inner-product spaces

- complex conjugate :: \(\bar z = a - ib\) for \(z = a + ib\). It respects sums
  and products, and \(z\) is real iff \(z = \bar z\). /Slide: Complex numbers:
  the facts this unit uses./
- modulus :: \(|z| = \sqrt{a^2 + b^2}\), so \(|z|^2 = \bar zz\); multiplicative,
  and \(\mathrm{Re}\,z \le |z|\).
- phase :: A complex number of modulus one, \(e^{i\varphi} := \cos\varphi +
  i\sin\varphi\). Phases multiply by adding angles, and
  \(\overline{e^{i\varphi}} = e^{-i\varphi}\). Every \(z \ne 0\) is
  \(|z|e^{i\varphi}\).
- inner product :: On a complex vector space, a map \(\braket{\cdot|\cdot}\)
  linear in the second slot, conjugate symmetric and positive. Course
  convention: conjugate-linear in the *first* slot, the physicists' choice;
  Axler and Mechanics to Relativity unit 19 conjugate the second. On
  \(\mathbb C^d\), \(\braket{u|v} = \sum\bar u_iv_i\). /Slide: The inner
  product, and its convention./
- conjugate symmetry :: \(\braket{v|u} = \overline{\braket{u|v}}\). With
  linearity in the second slot it forces conjugate-linearity in the first, and
  makes \(\braket{v|v}\) real.
- sesquilinear :: Linear in one slot and conjugate-linear in the other. A
  bilinear form over \(\mathbb C\) cannot be positive, since it would give
  \(\braket{iv|iv} = -\braket{v|v}\).
- norm :: \(\lVert v\rVert = \sqrt{\braket{v|v}}\).
- Cauchy–Schwarz inequality :: \(|\braket{u|v}| \le \lVert u\rVert\lVert
  v\rVert\), with equality iff \(u, v\) are dependent. Proved by projecting
  \(v\) onto \(u\); the conjugate enters through \(\lVert cu\rVert = |c|\lVert
  u\rVert\). /Slide: Cauchy–Schwarz, by projection./
- orthonormal basis :: A basis of unit vectors, pairwise orthogonal. Every
  finite-dimensional complex inner-product space has one, by Gram–Schmidt with
  the coefficient \(\braket{e_j|v}\) — basis vector on the left. Then \(v =
  \sum_i\braket{e_i|v}e_i\). /Slide: Orthonormal bases, and Parseval./
- Parseval's identity :: \(\lVert v\rVert^2 = \sum_i|\braket{e_i|v}|^2\) for
  an orthonormal basis; so the minimal model's probabilities sum to one.
- global phase :: A factor \(e^{i\alpha}\) multiplying the whole state. It
  changes no probability in any basis, so the course drops it, but only with
  the words "up to global phase". /Slide: Global phase and relative phase./
- relative phase :: The phase \(e^{i\varphi}\) between two components, as in
  \(\frac1{\sqrt2}(\ket0 + e^{i\varphi}\ket1)\), the general state unbiased to
  \(z\) up to global phase. Its overlap with \(\ket+\) is \(\frac12(1 +
  \cos\varphi)\), so unbiased to \(x\) as well iff \(\varphi = \pm\pi/2\): the
  \(y\) basis. Real amplitudes allow only \(\varphi = 0, \pi\).

* Bras, kets and the adjoint

- dual space :: \(V^*\), the linear maps \(V \to \mathbb C\). /Slide: A bra is
  a dual vector./
- Riesz isomorphism :: The bijection \(V \to V^*\), \(v \mapsto
  \braket{v|\cdot}\), on a finite-dimensional inner-product space. It is
  conjugate-linear: \(cv \mapsto \bar c\braket{v|\cdot}\).
- Dirac notation :: Notation for the Riesz isomorphism: a ket \(\ket v\) is a
  vector, a bra \(\bra v\) its dual vector, and \(\braket{u|v}\) the bra
  \(\bra u\) applied to the ket \(\ket v\).
- ket :: A vector \(\ket v\), written with a label inside. On \(\mathbb C^d\), a
  column.
- bra :: The dual vector \(\bra v = \braket{v|\cdot}\): on \(\mathbb C^d\), the
  conjugate-transposed row. \(\bra{cv} = \bar c\bra v\), so \(\bra{+i} =
  \frac1{\sqrt2}(1, -i)\).
- outer product :: \(\ket u\!\bra v\), the map \(w \mapsto \braket{v|w}u\):
  rank one for nonzero \(u, v\), with matrix \(u\bar v^{\mathsf T}\). Compose
  as \((\ket u\!\bra v)(\ket w\!\bra x) = \braket{v|w}\ket u\!\bra x\); trace
  \(\braket{v|u}\). /Slide: Outer products are rank-one maps./
- orthogonal projector :: An operator with \(P^2 = P = P^\dagger\). For a unit
  vector \(e\), \(\ket e\!\bra e\) projects orthogonally onto
  \(\mathrm{span}(e)\), and the minimal model's probability is
  \(\braket{\psi|P_e\psi}\). /Slide: Orthogonal projectors./
- resolution of the identity :: \(\sum_i\ket{e_i}\!\bra{e_i} = I\) for any
  orthonormal basis. Checked on the three Stern–Gerlach bases with explicit
  \(2\times2\) matrices. /Slide: Resolving the identity./
- adjoint :: \(A^\dagger\), the unique linear map with \(\braket{u|Av} =
  \braket{A^\dagger u|v}\); exists by Riesz. \((AB)^\dagger =
  B^\dagger A^\dagger\), \((cA)^\dagger = \bar cA^\dagger\), \((\ket u\!\bra
  v)^\dagger = \ket v\!\bra u\). /Slide: The adjoint./
- conjugate transpose :: The matrix of \(A^\dagger\) in an orthonormal basis:
  \((A^\dagger)_{ij} = \overline{A_{ji}}\). In a basis that is not orthonormal
  the matrix of the adjoint is something else (problem P6).
- polarisation identity :: \(\braket{u|Av} = \frac14\sum_{k=0}^3
  i^{-k}\braket{u + i^kv|A(u + i^kv)}\) over \(\mathbb C\). So if
  \(\braket{w|Aw} = 0\) for all \(w\), then \(A = 0\) — false over \(\mathbb
  R\), where the quarter-turn has \(\braket{v|Jv} = 0\) for every \(v\).
  /Slide: Polarisation: where the field matters./

* Normal operators and the spectral theorem

- Hermitian operator :: \(A^\dagger = A\); also called self-adjoint. For normal
  \(A\), equivalent to a real spectrum. /Slide: Hermitian, unitary, normal./
- unitary operator :: \(U^\dagger U = I\); equivalently \(U\) preserves inner
  products, equivalently norms (by polarisation). Maps orthonormal bases to
  orthonormal bases and preserves unbiasedness. For normal \(U\), equivalent
  to a spectrum on the unit circle.
- normal operator :: \(A^\dagger A = AA^\dagger\). Exactly the operators with
  an orthonormal basis of eigenvectors. \(\begin{pmatrix}1&1\\0&2\end{pmatrix}\)
  is not normal.
- eigenvalue :: \(\lambda\) with \(Av = \lambda v\) for some \(v \ne 0\). Over
  \(\mathbb C\) every operator has one, by the fundamental theorem of algebra
  (cited); over \(\mathbb R\) the quarter-turn has none. /Slide: Schur: every
  operator is triangular in some orthonormal basis./
- Schur triangularisation :: Every operator on a finite-dimensional complex
  inner-product space is upper triangular in some orthonormal basis: \(A =
  UTU^\dagger\). Proved by induction, taking a unit eigenvector and
  triangularising the compression to its orthogonal complement.
- spectral theorem :: An operator on a finite-dimensional complex
  inner-product space is normal iff it has an orthonormal eigenbasis, \(A =
  UDU^\dagger\). Proved from Schur and the lemma that an upper-triangular
  normal matrix is diagonal. /Slide: The spectral theorem for normal
  operators./
- spectral decomposition :: \(A = \sum_{\lambda\in\sigma(A)}\lambda
  P_\lambda\) for normal \(A\), with \(P_\lambda\) the orthogonal projector
  onto \(\ker(A - \lambda I)\), \(\sum P_\lambda = I\) and \(P_\lambda P_\mu =
  \delta_{\lambda\mu}P_\lambda\). Unique.
- spectrum :: \(\sigma(A)\), the set of eigenvalues of \(A\).
- simultaneous diagonalisation :: Commuting normal operators have a common
  orthonormal eigenbasis, because each preserves the other's eigenspaces.
  \(X\) and \(Y\) do not commute, and their eigenbases are unbiased: they share
  no eigenvector. /Slide: Commuting normal operators diagonalise together./
- commutator :: \([A, B] = AB - BA\). For the running example, \([X, Y] =
  2iZ\).

* Functions of a normal operator

- functional calculus :: \(f(A) := \sum_\lambda f(\lambda)P_\lambda\) for normal
  \(A\) and \(f\) defined on its spectrum. Respects sums, products and
  adjoints, and agrees with polynomials. /Slide: Functional calculus./
- matrix exponential :: \(e^A = \sum_n A^n/n!\), convergent for every \(A\);
  for normal \(A\) it equals \(\sum e^\lambda P_\lambda\). For Hermitian \(H\),
  \(e^{iH}\) is unitary with inverse \(e^{-iH}\). \(e^Ae^B = e^{A+B}\) when \(A,
  B\) commute, and not in general. /Slide: The exponential, and why exp(iH) is
  unitary./
