The terms this unit introduces, in the order the deck meets them. The slides
stay the definition of record; each entry names the slide it comes from, so a
term can be looked up here and read properly there.

Running example: the Mach–Zehnder interferometer. One photon enters path 0;
a beam splitter \(B = \frac1{\sqrt2}\begin{pmatrix}1 & i\\ i & 1\end{pmatrix}\),
a phase shifter \(P(\varphi) = \mathrm{diag}(1, e^{i\varphi})\) on path 1, a
second \(B\), and detectors \(D_0, D_1\). With balanced arms \(B^2 = iX\) and
\(D_0\) never clicks; in general \(P(D_0) = \sin^2\frac\varphi2\),
\(P(D_1) = \cos^2\frac\varphi2\). A which-path detector between the splitters
flattens both to \(\frac12\). The whole apparatus is
\(ie^{i\varphi/2}(\cos\frac\varphi2 X - \sin\frac\varphi2 Z)\), each splitter
is \(e^{i\pi X/4}\), and between the splitters the path \(Z\) and the output
\(W = B^\dagger ZB = -Y\) meet Robertson's bound with equality.

* Two paths, and what a state is

- Mach–Zehnder interferometer :: A light source, a beam splitter dividing the
  light into two arms, two mirrors bringing the arms together at a second beam
  splitter, and two detectors on its outputs (Zehnder 1891, Mach 1892). With
  arms balanced, one output is dark. The unit's running example. /Slide: The
  Mach–Zehnder interferometer, from nothing./
- beam splitter :: A half-silvered mirror: transmits half the light and
  reflects half. On the photon's path qubit it acts as the unitary
  \(B = \frac1{\sqrt2}\begin{pmatrix}1 & i\\ i & 1\end{pmatrix}\); the
  reflected amplitude's phase of \(\pm\pi/2\) relative to the transmitted one
  is forced by unitarity for a splitter that treats both inputs alike; the
  sign is a convention. /Slide: The Mach–Zehnder
  interferometer, from nothing./
- phase shifter :: A thin slab of glass in one arm, delaying the light there
  by \(\varphi = 2\pi(n - 1)d/\lambda\); on the path qubit,
  \(\mathrm{diag}(1, e^{i\varphi})\). /Slide: The Mach–Zehnder interferometer,
  from nothing./
- photon :: In this course, the thing that makes one click at one detector.
  Grangier, Roger and Aspect (1986) showed with a heralded single-photon
  source that one photon is not split between a splitter's outputs, yet
  still interferes. Faint light (Taylor 1909) did not establish this.
  /Slide: One photon at a time./
- state :: Postulate 1: a closed system has a finite-dimensional complex
  inner-product space \(V\), and its state is a unit vector of \(V\) up to a
  global phase — a ray. /Slide: Postulate 1: a state is a ray./
- closed system :: A system interacting with nothing left out of its
  description. Postulates 1 and 3 are about closed systems; a system meeting a
  detector is handled by postulate 2. /Slide: Postulate 1: a state is a ray./
- ray :: The set \([\psi] = \{e^{i\alpha}\psi : \alpha\in\mathbb R\}\) of unit
  vectors differing from \(\psi\) by a phase. The statistics of every
  observable determine the ray and nothing finer. /Slide: Postulate 1: a state
  is a ray./
- qubit :: A system with state space \(\mathbb C^2\) and a named orthonormal
  basis \(\ket0, \ket1\). The photon's path in the interferometer is one.
  /Slide: Postulate 1: a state is a ray./

* Measurement: the Born rule as a probability measure

- observable :: A Hermitian operator \(A = \sum_\lambda\lambda P_\lambda\) on
  \(V\). Its eigenvalues are the possible results and its spectral projectors
  the outcomes. /Slide: Postulate 2, part one: observables./
- projection-valued measure :: On a finite set \(\Lambda\subset\mathbb R\):
  orthogonal projectors \(P_\lambda\) with
  \(P_\lambda P_\mu = \delta_{\lambda\mu}P_\lambda\) and
  \(\sum P_\lambda = I\); \(P_S = \sum_{\lambda\in S}P_\lambda\). The same data
  as an observable. /Slide: Postulate 2, part one: observables./
- Born rule :: Measuring \(A\) on \(\psi\) gives \(\lambda\) with probability
  \(\braket{\psi|P_\lambda|\psi} = \lVert P_\lambda\psi\rVert^2\): a probability
  measure on \(\sigma(A)\), summing to one because \(\sum P_\lambda = I\) (Born
  1926). /Slide: Postulate 2, part two: the Born rule, and the state
  afterwards./
- Lüders rule :: After the result \(\lambda\) the state is
  \(P_\lambda\psi/\lVert P_\lambda\psi\rVert\), which keeps any superposition
  inside a degenerate eigenspace (Lüders 1951; von Neumann 1932 for
  non-degenerate results). /Slide: Postulate 2, part two: the Born rule, and
  the state afterwards./
- repeatability :: Measuring the same observable twice in succession gives the
  same result with probability one; a consequence of Lüders' rule and
  \(P_\lambda^2 = P_\lambda\). /Slide: Repeatability, and the least model
  recovered./
- minimal model :: Unit 00's hypotheses: a measurement is an orthonormal
  basis, probabilities are squared overlaps, the state afterwards is the basis
  vector found. It is postulate 2 for a non-degenerate observable, the
  post-measurement state being correct up to global phase. /Slide:
  Repeatability, and the least model recovered./
- expectation :: The mean of the Born measure,
  \(\langle A\rangle = \sum\lambda\,p_\psi(\lambda)\), which equals
  \(\braket{\psi|A|\psi}\). For a projector it is a probability. /Slide:
  Expectation and variance, from the measure./
- variance :: \((\Delta A)^2 = \sum(\lambda - \langle A\rangle)^2p_\psi(\lambda)
  = \langle A^2\rangle - \langle A\rangle^2 = \lVert(A - \langle A\rangle)\psi\rVert^2\);
  zero exactly when \(\psi\) is an eigenvector of \(A\). /Slide: Expectation
  and variance, from the measure./
- compatible observables :: Commuting observables \(A, B\). Their spectral
  projectors' products \(P_aQ_b\) form a projection-valued measure on
  \(\sigma(A)\times\sigma(B)\), a joint measurement with the right marginals.
  Non-commuting ones have no such thing: for \(X\) and \(Z\) the candidate
  \(\braket{\psi|P_+Q_0|\psi}\) can be negative. /Slide: Compatible
  observables./

* Looking at the path

- which-path detector :: An idealised detector in one arm that records whether
  the photon passed and lets it continue: a measurement of \(Z\) between the
  splitters. It makes \(P(D_0) = P(D_1) = \frac12\) for every \(\varphi\): the
  fringes vanish. /Slide: A which-path detector./

* Evolution: a unitary group, and its generator

- evolution :: Postulate 3: between measurements a closed system evolves as
  \(\psi(t) = U(t)\psi(0)\) with \(t\mapsto U(t)\) a continuous one-parameter
  unitary group. /Slide: Postulate 3: evolution is a unitary group./
- one-parameter unitary group :: A map \(t\mapsto U(t)\) from \(\mathbb R\) to
  the unitaries with \(U(t + s) = U(t)U(s)\) and \(U(0) = I\). A glass slab of
  thickness \(\ell\), \(\mathrm{diag}(1, e^{i\kappa\ell})\), is one in \(\ell\).
  /Slide: Postulate 3: evolution is a unitary group./
- Wigner's theorem :: A bijection of rays preserving every transition
  probability \(|\braket{\chi|\psi}|^2\) comes from a unitary or an antiunitary
  operator (Wigner 1931; proof by Bargmann 1964). Cited, as the motivation for
  unitary evolution. /Slide: Why unitary, and not antiunitary./
- antiunitary :: A conjugate-linear \(K\) with
  \(\braket{K\chi|K\psi} = \overline{\braket{\chi|\psi}}\), such as complex
  conjugation of coordinates. Its square is unitary, so a one-parameter group
  contains none. /Slide: Why unitary, and not antiunitary./
- Stone's theorem :: In finite dimension: every continuous one-parameter
  unitary group is \(e^{-iHt}\) for exactly one Hermitian \(H\), namely
  \(H = iU'(0)\). Proved by averaging, differentiating the group law, and
  showing \(e^{iHt}U(t)\) constant (Stone 1932). /Slide: Stone's theorem./
- generator :: The Hermitian \(H = iU'(0)\) of a one-parameter unitary group
  \(U(t) = e^{-iHt}\). /Slide: Stone's theorem./
- Hamiltonian :: The generator of a system's time evolution. Its eigenvalues
  are energies (divided by \(\hbar\)). /Slide: Stone's theorem./
- Schrödinger equation :: \(i\,d\psi/dt = H\psi\), satisfied by
  \(\psi(t) = e^{-iHt}\psi(0)\), with that the only solution. A consequence of
  postulate 3 through Stone's theorem, not a separate postulate. /Slide: The
  Schrödinger equation is a consequence./
- stationary state :: An eigenvector of \(H\), \(H\psi = E\psi\), which evolves
  only by the global phase \(e^{-iEt}\). Only energy differences are
  observable. /Slide: The Schrödinger equation is a consequence./
- ħ (reduced Planck constant) :: \(\hbar = h/2\pi = 1.054571817\times10^{-34}\)
  J s, converting an energy into an angular frequency. The course sets
  \(\hbar = 1\) and writes \(e^{-iHt}\) with \(H\) in \(\mathrm{s}^{-1}\); units
  02, 25 and 26 restore it. /Slide: The Schrödinger equation is a
  consequence./
- directional coupler :: Two waveguides run side by side for a length \(L\);
  light crosses the gap, and the pair applies \(e^{igLX}\), a one-parameter
  unitary group in \(L\). At \(gL = \pi/4\) it is the beam splitter \(B\).
  /Slide: A beam splitter grown continuously./

* Uncertainty: a statement about preparations

- Robertson uncertainty relation :: For Hermitian \(A, B\):
  \(\Delta A\,\Delta B \ge \frac12|\langle[A, B]\rangle|\), from Cauchy–Schwarz
  (Robertson 1929); equality iff \((B - \langle B\rangle)\psi\) is an imaginary
  multiple of \((A - \langle A\rangle)\psi\), or the latter is zero. A limit on
  preparations, not on disturbance. /Slide: The Robertson uncertainty
  relation./
