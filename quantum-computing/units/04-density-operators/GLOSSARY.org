The terms this unit introduces, in the order the deck meets them. The slides
stay the definition of record; each entry names the slide it comes from, so a
term can be looked up here and read properly there.

Running example: Alice and Bob sharing \(\ket{\Phi^+} = (\ket{00} +
\ket{11})/\sqrt2 = (\ket{++} + \ket{--})/\sqrt2\), Alice holding qubit 0 and
Bob qubit 1. Bob's qubit is in no pure state; its state is \(\rho_B = I/2\),
the same operator as two coin-flip sources (\(\ket0\) or \(\ket1\); \(\ket+\)
or \(\ket-\)) and the trine with weights \(\frac13\). Alice measuring \(z\) or
\(x\) leaves Bob in one ensemble or the other, related by the Hadamard
matrix, and \(\rho_B = I/2\) either way: no signal. A second example, \(\rho =
\frac12(\ket0\!\bra0 + \ket+\!\bra+)\), has Bloch vector \((\frac12, 0,
\frac12)\), purity \(\frac34\) and eigenvalues \(\cos^2\frac\pi8 \approx
0.8536\), \(\sin^2\frac\pi8 \approx 0.1464\).

* Density operators

- positive operator :: An operator \(A\) with \(\braket{v|Av} \ge 0\) for every
  \(v\), written \(A \ge 0\). Over \(\mathbb C\) this forces \(A\) Hermitian,
  and it is equivalent to Hermitian with every eigenvalue \(\ge 0\). Examples:
  \(\ket\psi\!\bra\psi\), projectors, \(B^\dagger B\). /Slide: Positive
  operators./
- density operator :: An operator \(\rho\) with \(\rho \ge 0\) and
  \(\operatorname{tr}\rho = 1\): the state of a quantum system in general. It
  gives every measurement statistic as \(\operatorname{tr}(P_\lambda\rho)\).
  /Slide: Density operators, and the ensembles that make them./
- pure state :: A density operator \(\ket\psi\!\bra\psi\) with \(\psi\) a unit
  vector; it determines \(\psi\) up to a global phase, so pure states are unit
  01's rays. Equivalently: rank one, or \(\operatorname{tr}\rho^2 = 1\).
- mixed state :: A density operator that is not pure: rank at least two,
  \(\operatorname{tr}\rho^2 < 1\).
- maximally mixed state :: \(I/d\) on \(\mathbb C^d\): the unique state of
  least purity, \(1/d\). For a qubit, \(I/2\), the centre of the Bloch ball and
  Bob's state in the running example.
- ensemble :: Probabilities \(p_i\) and unit vectors \(\ket{\psi_i}\), not
  necessarily orthogonal, defining \(\rho = \sum_ip_i\ket{\psi_i}\!\bra{\psi_i}\):
  a preparation story. Every density operator has one (its eigen-ensemble), and
  usually infinitely many, which no measurement can tell apart.
- non-selective measurement :: A measurement whose outcome is not recorded:
  \(\rho \mapsto \sum_\lambda P_\lambda\rho P_\lambda\), the average over
  outcomes of the post-measurement states \(P_\lambda\rho
  P_\lambda/\operatorname{tr}(P_\lambda\rho)\). /Slide: The postulates,
  rewritten for density operators./
- extreme point :: A point of a convex set that is not \(t\sigma + (1 -
  t)\tau\) with \(0 < t < 1\) and \(\sigma \ne \tau\). The extreme points of
  the set of density operators are exactly the pure states. /Slide: A convex
  set whose corners are the pure states./
- purity :: \(\operatorname{tr}\rho^2 = \sum\lambda_k^2\). On \(\mathbb C^d\)
  it lies in \([1/d, 1]\): \(1\) exactly for pure states, \(1/d\) exactly for
  \(I/d\). For a qubit it is \(\frac12(1 + |r|^2)\). /Slide: Purity: how far
  from pure./

* The Bloch ball

- Bloch ball :: The qubit density operators, \(\rho = \frac12(I + r\cdot\sigma)\)
  with \(r_k = \operatorname{tr}(\rho\sigma_k)\) and \(|r| \le 1\). Eigenvalues
  \(\frac12(1 \pm |r|)\); the surface \(|r| = 1\) is unit 02's sphere of pure
  states, the centre is \(I/2\), and mixing averages Bloch vectors, so a
  two-part mixture lies on a chord. /Slide: Every qubit state is a point of the
  ball./

* The partial trace

- partial trace :: The unique linear map \(\operatorname{tr}_A\colon L(H_A
  \otimes H_B) \to L(H_B)\) with \(\operatorname{tr}(M\operatorname{tr}_AX) =
  \operatorname{tr}((I \otimes M)X)\) for all \(M\); likewise
  \(\operatorname{tr}_B\). Formula: \(\operatorname{tr}_BX = \sum_j(I \otimes
  \bra j)X(I \otimes \ket j)\) in any orthonormal basis; on products,
  \(\operatorname{tr}_B(S \otimes T) = (\operatorname{tr}T)S\). /Slide: What
  Bob's state has to be./
- reduced state :: \(\rho_A = \operatorname{tr}_B\rho\) and \(\rho_B =
  \operatorname{tr}_A\rho\): the state of one part, which gives every statistic
  of every measurement on that part and nothing more. For a pure state with
  coefficient matrix \(C\), \(\rho_A = CC^\dagger\), with eigenvalues the
  squared Schmidt coefficients.
- Hilbert–Schmidt inner product :: \(\langle S, T\rangle =
  \operatorname{tr}(S^\dagger T) = \sum\overline{S_{jk}}T_{jk}\) on operators.
  Non-degenerate: if \(\operatorname{tr}(MX) = \operatorname{tr}(MY)\) for all
  \(M\) then \(X = Y\) — which makes the partial trace unique. /Slide: The
  trace pairing, and why there is only one partial trace./
- separable :: A state of \(AB\) of the form \(\sum_kp_k\,\sigma_k \otimes
  \tau_k\); a mixed state is entangled if it is not separable. For pure states
  this is unit 03's notion, decided by whether \(\rho_A\) is mixed; for mixed
  states, deciding it is hard in general and is not in this course. /Slide: A
  pure state is entangled exactly when its halves are mixed./

* Purification and the Schrödinger–HJW theorem

- purification :: A unit vector \(\ket\Psi \in H_A \otimes H_B\) with
  \(\operatorname{tr}_B\ket\Psi\!\bra\Psi = \rho_A\). Exists whenever \(\dim H_B
  \ge \operatorname{rank}\rho_A\) — \(\sum_k\sqrt{\lambda_k}\ket{e_k}\ket{f_k}\)
  — and any two on the same \(H_B\) differ by a unitary \(I \otimes V\).
  \(\ket{\Phi^+}\) purifies \(I/2\). /Slide: Every mixed state is half of a
  pure state./
- Schrödinger–HJW theorem :: Ensembles \(\{p_i, \psi_i\}_{i\le m}\) and
  \(\{q_j, \varphi_j\}_{j\le n}\), \(m \ge n\), give the same density operator
  iff \(\sqrt{p_i}\ket{\psi_i} = \sum_ju_{ij}\sqrt{q_j}\ket{\varphi_j}\) for an
  \(m \times n\) matrix \(u\) with orthonormal columns (unitary after padding).
  Schrödinger 1936; Hughston, Jozsa and Wootters 1993. /Slide: The
  Schrödinger–HJW theorem: all the stories of one state./
- isometry :: A linear map \(u\) with \(u^\dagger u = I\): it preserves inner
  products. As a matrix, one with orthonormal columns; a square isometry is
  unitary.
- steering :: Given a purification of \(\rho_B\) on \(H_A \otimes H_B\), any
  ensemble of \(\rho_B\) with at most \(\dim H_A\) members is produced at Bob's
  end by Alice measuring her part in a suitable basis (Schrödinger 1935). From
  \(\ket{\Phi^+}\), Alice's \(z\) and \(x\) measurements produce the two
  coin-flip ensembles. /Slide: Steering: Alice chooses Bob's ensemble./

* No-signalling

- no-signalling theorem :: Nothing Alice does on her part alone — a unitary
  \(U \otimes I\), or a projective measurement whose outcome Bob is not told —
  changes \(\rho_B\), so no statistic of Bob's changes. Proved in two lines by
  pairing with \(I \otimes M\) and using the uniqueness of the partial trace.
  /Slide: The no-signalling theorem./
- selective measurement :: A measurement whose outcome is recorded and used:
  the state becomes \(P_\lambda\rho P_\lambda/\operatorname{tr}(P_\lambda\rho)\).
  If Alice tells Bob her outcome, his conditional state can differ from
  \(\rho_B\) — but the telling is an ordinary signal. /Slide: The ensemble
  changes, the state does not./
