Conventions, as in the deck: \(\braket{u|v}\) is conjugate-linear in the first slot. \(\ket0 = (1, 0)\), \(\ket1 = (0, 1)\), \(\ket\pm = (\ket0 \pm \ket1)/\sqrt2\), \(\ket{\pm i} = (\ket0 \pm i\ket1)/\sqrt2\); \(X, Y, Z\) are the Pauli matrices and \(H = (X + Z)/\sqrt2\). In \(\ket{ab}\) the first symbol is qubit 0 (Alice, or \(A\)) and is the most significant: the order is \(00, 01, 10, 11\). A two-qubit pure state \(\sum_{i,j}C_{ij}\ket{ij}\) has coefficient matrix \(C\), rows indexed by \(A\). The partial trace is the unique map with \(\operatorname{tr}(A\operatorname{tr}_BX) = \operatorname{tr}((A\otimes I)X)\) for all \(A\), and \(\operatorname{tr}_BX = \sum_j(I\otimes\bra j)X(I\otimes\ket j)\); \(\ket{\Phi^+} = (\ket{00} + \ket{11})/\sqrt2\).

Density operators

P1 A superposition is not a mixture routine

exercises: an ensemble's density operator, the Born rule as a trace, purity, a computed probability

  1. Write the density operators of the pure state \(\ket+\) and of source \(\mathcal Z\) (\(\ket0\) or \(\ket1\) by a fair coin). Give their Bloch vectors and purities.
  2. Show that a measurement in the \(z\) basis gives the same distribution on both, and find a measurement that tells them apart, with its probabilities.
  3. Source \(\mathcal M\) emits \(\ket0\) with probability \(0.9\) and \(\ket1\) with probability \(0.1\). Source \(\mathcal S\) emits the single state \(\sqrt{0.9}\ket0 + \sqrt{0.1}\ket1\) every time. Compute both density operators, and the probability of outcome \(+\) when each output is measured in the \(x\) basis.
Hints · 3 rungs
Rung 1

Every answer here is a \(2\times2\) matrix, or a number \(\operatorname{tr}(P\rho)\) computed from one. A superposition and a mixture with the same \(z\) probabilities differ only in the off-diagonal entries.

Rung 2

For a unit vector \(\psi = (a, b)\), \(\ket\psi\!\bra\psi = \begin{pmatrix}|a|^2&a\bar b\\\bar ab&|b|^2\end{pmatrix}\). For an ensemble, average such matrices with the weights. A measurement along \(n\) gives \(+\) with probability \(\tfrac12(1 + r\cdot n)\).

Rung 3

First line of part 3: "\(\rho_{\mathcal S} = \begin{pmatrix}0.9&\sqrt{0.09}\\\sqrt{0.09}&0.1\end{pmatrix} = \begin{pmatrix}0.9&0.3\\0.3&0.1\end{pmatrix}\), and \(\Pr(+) = \braket{+|\rho|+} = \tfrac12(\rho_{00} + \rho_{01} + \rho_{10} + \rho_{11})\)."

Worked solution

Idea. A mixture averages the projectors and its off-diagonal entries cancel or shrink; a superposition keeps them. Diagonal entries are \(z\) statistics, so \(z\) cannot see the difference; any measurement whose projector has off-diagonal entries can.

1. \(\ket+\!\bra+ = \tfrac12\begin{pmatrix}1&1\\1&1\end{pmatrix}\): Bloch vector \((1, 0, 0)\), purity \(\tfrac14\cdot4 = 1\). \(\rho_{\mathcal Z} = \tfrac12\ket0\!\bra0 + \tfrac12\ket1\!\bra1 = \tfrac12I\): Bloch vector \(0\), purity \(\tfrac14 + \tfrac14 = \tfrac12\).

2. \(\Pr(0) = \operatorname{tr}(\ket0\!\bra0\rho) = \rho_{00}\), which is \(\tfrac12\) for both; then \(\Pr(1) = \tfrac12\) for both. In the \(x\) basis: \(\braket{+|\rho|+}\) is \(1\) for \(\ket+\) and \(\tfrac12\) for \(\mathcal Z\); so outcome \(-\) never happens for \(\ket+\) and happens half the time for \(\mathcal Z\). One \(-\) proves the source is \(\mathcal Z\); many \(+\)'s in a row make \(\ket+\) overwhelmingly likely.

3. \(\rho_{\mathcal M} = 0.9\ket0\!\bra0 + 0.1\ket1\!\bra1 = \mathrm{diag}(0.9, 0.1)\). For \(\mathcal S\), with \(a = \sqrt{0.9}\), \(b = \sqrt{0.1}\), \(ab = \sqrt{0.09} = 0.3\), so \(\rho_{\mathcal S} = \begin{pmatrix}0.9&0.3\\0.3&0.1\end{pmatrix}\). Both have trace \(1\) ✓ and the same diagonal. Then \(\braket{+|\rho|+} = \tfrac12\sum_{j,k}\rho_{jk}\):

\[ \Pr\nolimits_{\mathcal M}(+) = \tfrac12(0.9 + 0.1) = 0.5, \qquad \Pr\nolimits_{\mathcal S}(+) = \tfrac12(0.9 + 0.3 + 0.3 + 0.1) = 0.8 . \]

Check. Bloch vectors: \(\rho_{\mathcal S}\) has \(r = (2\cdot0.3, 0, 0.9 - 0.1) = (0.6, 0, 0.8)\), length \(1\) — pure ✓ — and \(\tfrac12(1 + r_x) = 0.8\) ✓. \(\rho_{\mathcal M}\) has \(r = (0, 0, 0.8)\), \(\tfrac12(1 + 0) = 0.5\) ✓. Purities: \(\rho_{\mathcal M}\): \(0.81 + 0.01 = 0.82\); \(\rho_{\mathcal S}\): \(0.81 + 0.09 + 0.09 + 0.01 = 1\) ✓. Same \(z\) statistics, different everything else.

import numpy as np
from qclib import DensityMatrix, Statevector
mix = DensityMatrix.mixture([0.9, 0.1], [Statevector.from_label("0"), Statevector.from_label("1")])

P2 The post-measurement rule, by Bayes medium

exercises: the postulates rewritten for density operators, Bayes' rule, the non-selective rule, a purity computed

  1. A source emits \(\ket{\psi_i}\) with probability \(p_i\); \(\rho = \sum_ip_i\ket{\psi_i}\!\bra{\psi_i}\). A projective measurement \(\{P_\lambda\}\) gives \(\lambda\). Using only unit 01's rules and Bayes' rule, show that the state afterwards is \(P_\lambda\rho P_\lambda/\operatorname{tr}(P_\lambda\rho)\).
  2. Take \(\rho = \tfrac12(\ket0\!\bra0 + \ket+\!\bra+)\). Measure \(z\): give both probabilities and both post-measurement states, and check one of them against the story "\(\ket0\) or \(\ket+\)" directly. Then give \(\Pr(+)\) for an \(x\) measurement.
  3. The same \(\rho\) is measured in \(z\) and the result is not recorded. Find the new state and its purity.
  4. Prove that a non-selective projective measurement never increases purity: \(\operatorname{tr}\big(\sum_\lambda P_\lambda\rho P_\lambda\big)^2 \le \operatorname{tr}\rho^2\).
Hints · 3 rungs
Rung 1

Part 1 is about a joint distribution over two things — which state the source chose, and which outcome occurred — and the conditional distribution of the first given the second. Part 4 is an inequality between two sums of traces.

Rung 2

Part 1: \(\Pr(i, \lambda) = p_i\lVert P_\lambda\psi_i\rVert^2\). Part 4: expand \(\operatorname{tr}\rho^2 = \operatorname{tr}\big((\sum_\lambda P_\lambda)\rho(\sum_\mu P_\mu)\rho\big)\) and separate the terms \(\lambda = \mu\) from the rest.

Rung 3

First line of part 4: "With \(X_{\lambda\mu} = P_\lambda\rho P_\mu\), \(\operatorname{tr}(P_\lambda\rho P_\mu\rho) = \operatorname{tr}(P_\lambda\rho P_\mu\cdot P_\mu\rho P_\lambda) = \operatorname{tr}(X_{\lambda\mu}X_{\lambda\mu}^\dagger) \ge 0\)."

Worked solution

Idea. A density operator is an average over a story; after an outcome, the story's weights update by Bayes and its states update by unit 01. The answer depends on the story only through \(\rho\). Forgetting the outcome mixes the branches, and mixing can only lower purity.

1. Given that the source chose \(i\), outcome \(\lambda\) has probability \(\lVert P_\lambda\psi_i\rVert^2\) and leaves \(P_\lambda\psi_i/\lVert P_\lambda\psi_i\rVert\) (unit 01). So \(\Pr(i, \lambda) = p_i\lVert P_\lambda\psi_i\rVert^2\), \(\Pr(\lambda) = \sum_ip_i\braket{\psi_i|P_\lambda|\psi_i} = \operatorname{tr}(P_\lambda\rho)\), and by Bayes \(\Pr(i\mid\lambda) = p_i\lVert P_\lambda\psi_i\rVert^2/\Pr(\lambda)\). The post-measurement ensemble has these weights and states; its density operator is

\[ \sum_i\frac{p_i\lVert P_\lambda\psi_i\rVert^2}{\Pr(\lambda)}\cdot\frac{P_\lambda\ket{\psi_i}\!\bra{\psi_i}P_\lambda}{\lVert P_\lambda\psi_i\rVert^2} = \frac{P_\lambda\rho P_\lambda}{\operatorname{tr}(P_\lambda\rho)}, \]

dropping terms with \(P_\lambda\psi_i = 0\), which have weight zero.

2. \(\rho = \begin{pmatrix}3/4&1/4\\1/4&1/4\end{pmatrix}\). \(\Pr(0) = \rho_{00} = \tfrac34\), \(\Pr(1) = \tfrac14\), sum \(1\) ✓. Post-states: \(P_0\rho P_0/\tfrac34 = \ket0\!\bra0\) and \(P_1\rho P_1/\tfrac14 = \ket1\!\bra1\) (\(P_0\rho P_0 = \rho_{00}\ket0\!\bra0\)). From the story: \(\Pr(0) = \tfrac12\cdot1 + \tfrac12\cdot\tfrac12 = \tfrac34\) ✓; given \(0\), the source sent \(\ket0\) with probability \(\tfrac{1/2}{3/4} = \tfrac23\) and \(\ket+\) with \(\tfrac13\), but either way the state is now \(\ket0\) ✓. In \(x\): \(\braket{+|\rho|+} = \tfrac12(\tfrac34 + \tfrac14 + \tfrac14 + \tfrac14) = \tfrac34\).

3. \(P_0\rho P_0 + P_1\rho P_1 = \mathrm{diag}(\tfrac34, \tfrac14)\): the off-diagonal entries are erased. Purity \(\tfrac9{16} + \tfrac1{16} = \tfrac58 = 0.625\), down from \(\tfrac34\).

4. Let \(\rho' = \sum_\lambda P_\lambda\rho P_\lambda\). Using \(\sum_\lambda P_\lambda = I\), \(\operatorname{tr}\rho^2 = \sum_{\lambda,\mu}\operatorname{tr}(P_\lambda\rho P_\mu\rho)\). Each term is \(\operatorname{tr}(X_{\lambda\mu}X_{\lambda\mu}^\dagger) \ge 0\) with \(X_{\lambda\mu} = P_\lambda\rho P_\mu\), by cyclicity and \(P_\mu^2 = P_\mu\), since \(X_{\lambda\mu}^\dagger = P_\mu\rho P_\lambda\) (\(\rho\), \(P\) Hermitian). The diagonal terms are \(\sum_\lambda\operatorname{tr}(P_\lambda\rho P_\lambda\rho) = \sum_\lambda\operatorname{tr}(P_\lambda\rho P_\lambda\cdot P_\lambda\rho P_\lambda) = \operatorname{tr}\rho'^2\), because \(P_\lambda\rho P_\lambda\cdot P_\mu\rho P_\mu = 0\) for \(\lambda \ne \mu\). So \(\operatorname{tr}\rho^2 = \operatorname{tr}\rho'^2 + \sum_{\lambda\ne\mu}\operatorname{tr}(X_{\lambda\mu}X_{\lambda\mu}^\dagger) \ge \operatorname{tr}\rho'^2\). \(\blacksquare\)

Check. Part 3 against part 4: the dropped terms are \(\lambda \ne \mu\), i.e. \(|\rho_{01}|^2 + |\rho_{10}|^2 = \tfrac1{16} + \tfrac1{16} = \tfrac18\), and \(\tfrac34 - \tfrac18 = \tfrac58\) ✓. Pure case: \(\rho = \ket\psi\!\bra\psi\) gives \(\ket{P_\lambda\psi}\!\bra{P_\lambda\psi}/\lVert P_\lambda\psi\rVert^2\), unit 01's rule ✓.

P3 Extreme points medium

exercises: convexity, the kernel of a positive operator, the spectral decomposition, many decompositions of one state

  1. Prove that the density operators on \(H\) form a convex set.
  2. Prove that every pure state \(\ket\psi\!\bra\psi\) is an extreme point: if \(\ket\psi\!\bra\psi = t\sigma + (1 - t)\tau\) with \(0 < t < 1\) and \(\sigma, \tau\) density operators, then \(\sigma = \tau = \ket\psi\!\bra\psi\).
  3. Prove that no mixed state is an extreme point.
  4. For \(\rho = \mathrm{diag}(\tfrac23, \tfrac13)\), find two different ways to write \(\rho = \tfrac12\ket{\psi_1}\!\bra{\psi_1} + \tfrac12\ket{\psi_2}\!\bra{\psi_2}\) with unit vectors \(\psi_1, \psi_2\), and explain on the Bloch ball why there are infinitely many.
Hints · 3 rungs
Rung 1

Part 2 is about what positivity forces when a quadratic form vanishes; part 3 needs one explicit decomposition; part 4 is a centre-of-mass problem on the sphere.

Rung 2

Part 2: test the equation on vectors \(v \perp \psi\). If \(\sigma \ge 0\) and \(\braket{v|\sigma|v} = 0\), then \(\sigma v = 0\) (write \(\sigma\) in its eigenbasis). Part 4: two points of the unit sphere with midpoint \(r = (0, 0, \tfrac13)\).

Rung 3

First line of part 4: "The Bloch vector of \(\rho\) is \((0, 0, \tfrac23 - \tfrac13) = (0, 0, \tfrac13)\), so I need \(r_1 + r_2 = (0, 0, \tfrac23)\) with \(|r_1| = |r_2| = 1\): \(r_{1,2} = (\pm a, \pm b, \tfrac13)\) with \(a^2 + b^2 = \tfrac89\)."

Worked solution

Idea. Mixing is a chord; a pure state's support is one line, and a positive operator that vanishes on the complement of that line is a multiple of its projector. A mixed state has at least two eigenvectors with positive weight, which splits it. Inside the ball, chords through a point are plentiful.

1. For \(v\): \(\braket{v|(t\sigma + (1 - t)\tau)v} = t\braket{v|\sigma v} + (1 - t)\braket{v|\tau v} \ge 0\), and the trace is \(t + (1 - t) = 1\).

2. For \(v \perp \psi\): \(0 = \braket{v|\psi}\braket{\psi|v} = t\braket{v|\sigma|v} + (1 - t)\braket{v|\tau|v}\), a sum of two non-negative terms with positive coefficients, so \(\braket{v|\sigma|v} = 0\). With \(\sigma = \sum_k\mu_k\ket{g_k}\!\bra{g_k}\), \(\mu_k \ge 0\): \(0 = \sum\mu_k|\braket{g_k|v}|^2\) forces \(\braket{g_k|v} = 0\) whenever \(\mu_k > 0\), so \(\sigma v = \sum\mu_k\braket{g_k|v}g_k = 0\). Thus \(\sigma\) kills \(\psi^\perp\). Being Hermitian, it maps \(\mathbb C\psi\) into \((\ker\sigma)^\perp \subseteq (\psi^\perp)^\perp = \mathbb C\psi\), so \(\sigma = c\ket\psi\!\bra\psi\); trace one gives \(c = 1\). Likewise \(\tau\). \(\blacksquare\)

3. A mixed \(\rho\) has rank \(\ge 2\), so eigenvalues \(\lambda_1, \lambda_2 > 0\) with \(\lambda_1 < 1\). Then \(\rho = \lambda_1\ket{e_1}\!\bra{e_1} + (1 - \lambda_1)\sigma\) with \(\sigma = (1 - \lambda_1)^{-1}\sum_{k\ge2}\lambda_k\ket{e_k}\!\bra{e_k}\), a density operator with \(\sigma e_1 = 0\), so \(\sigma \ne \ket{e_1}\!\bra{e_1}\). Not extreme. \(\blacksquare\)

4. Bloch vector \(r = (0, 0, \tfrac13)\). Take \(r_{1,2} = (\pm\tfrac{2\sqrt2}3, 0, \tfrac13)\): lengths \(\tfrac89 + \tfrac19 = 1\) ✓, midpoint \(r\) ✓. The polar angle has \(\cos\theta = \tfrac13\), so \(\cos^2\tfrac\theta2 = \tfrac12(1 + \tfrac13) = \tfrac23\):

\[ \ket{\psi_{1,2}} = \sqrt{\tfrac23}\,\ket0 \pm \sqrt{\tfrac13}\,\ket1 . \]

A second way: rotate the chord about the \(z\) axis by \(90^\circ\), \(r_{1,2} = (0, \pm\tfrac{2\sqrt2}3, \tfrac13)\), giving \(\ket{\psi_{1,2}} = \sqrt{\tfrac23}\ket0 \pm i\sqrt{\tfrac13}\ket1\). Any rotation angle \(\varphi\) works — \(\sqrt{\tfrac23}\ket0 \pm e^{i\varphi}\sqrt{\tfrac13}\ket1\) — one decomposition for each chord through \(r\) whose midpoint is \(r\): infinitely many.

Check. \(\tfrac12\sum_\pm\begin{pmatrix}\tfrac23&\pm\tfrac{\sqrt2}3e^{-i\varphi}\\\pm\tfrac{\sqrt2}3e^{i\varphi}&\tfrac13\end{pmatrix} = \mathrm{diag}(\tfrac23, \tfrac13)\) ✓ — the off-diagonal entries cancel for every \(\varphi\). The eigen-ensemble \(\{\tfrac23, \ket0;\ \tfrac13, \ket1\}\) is a third story, with unequal weights.

P4 Purity bounds medium

exercises: eigenvalue inequalities, purity of a reduced state, determinants of coefficient matrices, a computed number

  1. Prove that every density operator on \(\mathbb C^d\) has \(1/d \le \operatorname{tr}\rho^2 \le 1\), with equality on the right exactly for pure states and on the left exactly for \(I/d\).
  2. For a qubit, show \(\operatorname{tr}\rho^2 = 1 - 2\det\rho\).
  3. For a pure two-qubit state with coefficient matrix \(C\), show \(\det\rho_A = |\det C|^2\), so \(\operatorname{tr}\rho_A^2 = 1 - 2|\det C|^2\).
  4. Compute \(\operatorname{tr}\rho_A^2\) for unit 03's state \(\tfrac1{\sqrt3}(\ket{00} + \ket{01} + \ket{10})\), and check it against unit 03's Schmidt coefficients, whose squares are \(\tfrac{3\pm\sqrt5}6\).
Hints · 3 rungs
Rung 1

Everything is about the eigenvalues \(\lambda_k\): non-negative, summing to one. Purity is \(\sum\lambda_k^2\); the determinant is \(\prod\lambda_k\).

Rung 2

Part 1: compare \(\lambda_k^2\) with \(\lambda_k\), and use Cauchy–Schwarz on the vectors \((\lambda_k)\) and \((1, \dots, 1)\). Part 2: \((\lambda_1 + \lambda_2)^2\). Part 3: \(\rho_A = CC^\dagger\).

Rung 3

First line of part 4: "\(C = \tfrac1{\sqrt3}\begin{pmatrix}1&1\\1&0\end{pmatrix}\), so \(\det C = \tfrac13(0 - 1) = -\tfrac13\) and \(|\det C|^2 = \tfrac19\)."

Worked solution

Idea. Purity is a function of the spectrum, which lives in the probability simplex: largest at the corners, smallest at the centre. For two qubits, the determinant of the coefficient matrix measures entanglement and fixes the purity of either half.

1. \(0 \le \lambda_k \le 1\) gives \(\lambda_k^2 \le \lambda_k\), so \(\sum\lambda_k^2 \le \sum\lambda_k = 1\), with equality iff each \(\lambda_k^2 = \lambda_k\), i.e. \(\lambda_k \in \{0, 1\}\); summing to one, exactly one is \(1\): \(\rho = \ket{e}\!\bra{e}\), pure. Conversely a pure state has eigenvalues \(1, 0, \dots, 0\). Lower bound: Cauchy–Schwarz in \(\mathbb R^d\), \(1 = (\sum_k\lambda_k\cdot1)^2 \le (\sum_k\lambda_k^2)(\sum_k1^2) = d\sum_k\lambda_k^2\), with equality iff \((\lambda_k)\) is parallel to \((1, \dots, 1)\), i.e. all \(\lambda_k = 1/d\), i.e. \(\rho = I/d\) (the spectral decomposition is then \(\tfrac1d\sum\ket{e_k}\!\bra{e_k} = I/d\)). \(\blacksquare\)

2. \(\lambda_1^2 + \lambda_2^2 = (\lambda_1 + \lambda_2)^2 - 2\lambda_1\lambda_2 = 1 - 2\det\rho\).

3. \(\det\rho_A = \det(CC^\dagger) = \det C\cdot\det C^\dagger = \det C\cdot\overline{\det C} = |\det C|^2\), using \(\det C^\dagger = \overline{\det C}\) (transpose does not change a determinant; conjugating every entry conjugates it). With part 2, \(\operatorname{tr}\rho_A^2 = 1 - 2|\det C|^2\).

4. \(|\det C|^2 = \tfrac19\), so \(\operatorname{tr}\rho_A^2 = 1 - \tfrac29 = \tfrac79 \approx 0.7778\).

Check. From the Schmidt coefficients: \(\big(\tfrac{3 + \sqrt5}6\big)^2 + \big(\tfrac{3 - \sqrt5}6\big)^2 = \tfrac{(14 + 6\sqrt5) + (14 - 6\sqrt5)}{36} = \tfrac{28}{36} = \tfrac79\) ✓. From the matrix: \(\rho_A = \tfrac13\begin{pmatrix}2&1\\1&1\end{pmatrix}\), and the sum of squared entries is \(\tfrac{4 + 1 + 1 + 1}9 = \tfrac79\) ✓. Bounds: \(\tfrac12 \le \tfrac79 \le 1\) ✓; the state is entangled but not maximally. Limits: a product has \(\det C = 0\), purity \(1\); \(\ket{\Phi^+}\) has \(\det C = \tfrac12\), purity \(1 - \tfrac12 = \tfrac12\) ✓.

The Bloch ball

P5 The Bloch ball is exactly the qubit density operators medium

exercises: the Pauli basis, positivity through the spectrum, a two-sided set equality, a determinant criterion

Let \(\mathcal B = \{\tfrac12(I + r\cdot\sigma) : r \in \mathbb R^3,\ |r| \le 1\}\) and let \(\mathcal D\) be the set of density operators on \(\mathbb C^2\).

  1. Prove \(\mathcal B \subseteq \mathcal D\).
  2. Prove \(\mathcal D \subseteq \mathcal B\).
  3. Show that \(\det\tfrac12(I + r\cdot\sigma) = \tfrac14(1 - |r|^2)\), and deduce: a Hermitian \(2\times2\) matrix of trace one is a density operator iff its determinant is \(\ge 0\). Why does this test fail for \(3\times3\)?
Hints · 3 rungs
Rung 1

Both inclusions come down to one fact: the eigenvalues of \(\tfrac12(I + r\cdot\sigma)\). For the second inclusion you also need that every trace-one Hermitian matrix has that form.

Rung 2

Compute \((r\cdot\sigma)^2\) using \(\sigma_j\sigma_k + \sigma_k\sigma_j = 2\delta_{jk}I\). And \(\{I, X, Y, Z\}\) is a basis of \(2\times2\) matrices in which the Hermitian ones have real coefficients (unit 02).

Rung 3

First line: "\((r\cdot\sigma)^2 = \sum_{j,k}r_jr_k\sigma_j\sigma_k = \tfrac12\sum_{j,k}r_jr_k(\sigma_j\sigma_k + \sigma_k\sigma_j) = |r|^2I\)."

Worked solution

Idea. \(r\cdot\sigma\) squares to \(|r|^2I\) and is traceless, so its eigenvalues are \(\pm|r|\); everything follows.

Lemma. \((r\cdot\sigma)^2 = |r|^2I\) (rung 3: the symmetric sum, since \(r_jr_k\) is symmetric). So any eigenvalue \(\mu\) of \(r\cdot\sigma\) has \(\mu^2 = |r|^2\). \(r\cdot\sigma\) is Hermitian (real combination of Hermitian matrices) and traceless, so for \(r \ne 0\) its two eigenvalues are \(+|r|\) and \(-|r|\); hence \(\tfrac12(I + r\cdot\sigma)\) has eigenvalues \(\tfrac12(1 \pm |r|)\) (also true at \(r = 0\)).

1. For \(|r| \le 1\): \(\tfrac12(I + r\cdot\sigma)\) is Hermitian with eigenvalues \(\tfrac12(1 \pm |r|) \ge 0\), so positive; its trace is \(\tfrac12\operatorname{tr}I = 1\), the Paulis being traceless. So it is in \(\mathcal D\).

2. Let \(\rho \in \mathcal D\). It is Hermitian, so \(\rho = aI + b\cdot\sigma\) with \(a \in \mathbb R\), \(b \in \mathbb R^3\) (unit 02). Trace one gives \(2a = 1\); put \(r = 2b\), so \(\rho = \tfrac12(I + r\cdot\sigma)\). Positivity: the eigenvalue \(\tfrac12(1 - |r|)\) must be \(\ge 0\), so \(|r| \le 1\). So \(\rho \in \mathcal B\). \(\blacksquare\)

3. \(\tfrac12(I + r\cdot\sigma) = \tfrac12\begin{pmatrix}1 + r_z&r_x - ir_y\\r_x + ir_y&1 - r_z\end{pmatrix}\), with determinant \(\tfrac14\big((1 - r_z^2) - (r_x^2 + r_y^2)\big) = \tfrac14(1 - |r|^2)\) — also the product \(\tfrac12(1 + |r|)\cdot\tfrac12(1 - |r|)\) of the eigenvalues ✓. So for trace-one Hermitian \(2\times2\) matrices, \(\det \ge 0 \iff |r| \le 1 \iff \rho \in \mathcal D\). For \(3\times3\), a determinant \(\ge 0\) allows two negative eigenvalues: \(\mathrm{diag}(2, -\tfrac12, -\tfrac12)\) has trace \(1\) and determinant \(\tfrac12 > 0\), and is not positive. In dimension two, trace one forbids both eigenvalues being negative, which is why the test works there.

Check. \(r = (0, 0, 1)\): \(\tfrac12(I + Z) = \ket0\!\bra0\), eigenvalues \(1, 0\), determinant \(0\) ✓. \(r = 0\): \(I/2\), determinant \(\tfrac14\), the largest possible ✓. \(r = (1, 1, 0)\), outside the ball: \(\tfrac12\begin{pmatrix}1&1 - i\\1 + i&1\end{pmatrix}\) has determinant \(\tfrac14(1 - 2) < 0\) and eigenvalue \(\tfrac12(1 - \sqrt2) < 0\) ✓.

The partial trace

P6 Uniqueness of the partial trace routine

exercises: the trace pairing, the defining property, basis independence by hand, classical marginals

  1. Prove that at most one map \(T\colon L(H_A\otimes H_B) \to L(H_A)\) satisfies \(\operatorname{tr}(A\,TX) = \operatorname{tr}((A\otimes I)X)\) for all \(A\) and \(X\), using that \(\operatorname{tr}(S^\dagger S) > 0\) for \(S \ne 0\).
  2. From the defining property alone, prove \(\operatorname{tr}_B(S\otimes T) = (\operatorname{tr}T)\,S\).
  3. Without appealing to uniqueness, prove that \(\sum_j(I\otimes\bra j)X(I\otimes\ket j)\) is the same for every orthonormal basis \(\{\ket j\}\) of \(H_B\).
  4. If \(\rho = \sum_{i,j}p_{ij}\ket{ij}\!\bra{ij}\) for a joint probability distribution \(p_{ij}\), show that \(\operatorname{tr}_B\rho = \sum_i\big(\sum_jp_{ij}\big)\ket i\!\bra i\): the partial trace of a classical joint distribution is its marginal.
Hints · 3 rungs
Rung 1

Part 1 and part 2 are both "two operators that pair identically with every \(A\) are equal". Part 3 is a change-of-basis computation with a unitary matrix.

Rung 2

Part 1: choose \(A\) cleverly — the adjoint of the difference. Part 2: \(\operatorname{tr}(S\otimes T) = \operatorname{tr}S\,\operatorname{tr}T\) (look at the diagonal of a Kronecker product). Part 3: write \(\ket{j'} = \sum_kU_{kj'}\ket k\) with \(U\) unitary.

Rung 3

First line of part 3: "\(\sum_{j'}(I\otimes\bra{j'})X(I\otimes\ket{j'}) = \sum_{j,k}\Big(\sum_{j'}\overline{U_{jj'}}U_{kj'}\Big)(I\otimes\bra j)X(I\otimes\ket k)\)."

Worked solution

Idea. The trace pairing is an inner product, so pairing with every operator pins an operator down. The formula's basis independence is the unitarity of the change of basis, which also follows for free from uniqueness.

1. If \(T_1, T_2\) both qualify, fix \(X\) and let \(D = T_1X - T_2X\). Then \(\operatorname{tr}(AD) = 0\) for every \(A\); take \(A = D^\dagger\): \(\operatorname{tr}(D^\dagger D) = \sum_{j,k}|D_{jk}|^2 = 0\), so \(D = 0\). As \(X\) was arbitrary, \(T_1 = T_2\). \(\blacksquare\)

2. For every \(A\): \(\operatorname{tr}\big((A\otimes I)(S\otimes T)\big) = \operatorname{tr}(AS\otimes T) = \operatorname{tr}(AS)\operatorname{tr}T = \operatorname{tr}\big(A\cdot(\operatorname{tr}T)S\big)\). (The Kronecker matrix of \(M\otimes N\) has diagonal entries \(M_{ii}N_{jj}\), which sum to \(\operatorname{tr}M\operatorname{tr}N\).) So \((\operatorname{tr}T)S\) satisfies the defining property for the input \(S\otimes T\); by part 1, it is \(\operatorname{tr}_B(S\otimes T)\).

3. A second orthonormal basis is \(\ket{j'} = \sum_kU_{kj'}\ket k\) with \(U\) unitary; then \(\bra{j'} = \sum_j\overline{U_{jj'}}\bra j\). By linearity of \(I\otimes\cdot\) in the \(B\) slot,

\[ \sum_{j'}(I\otimes\bra{j'})X(I\otimes\ket{j'}) = \sum_{j,k}\Big(\sum_{j'}U_{kj'}\overline{U_{jj'}}\Big)(I\otimes\bra j)X(I\otimes\ket k), \]

and \(\sum_{j'}U_{kj'}\overline{U_{jj'}} = (UU^\dagger)_{kj} = \delta_{kj}\). Only \(k = j\) survives: \(\sum_j(I\otimes\bra j)X(I\otimes\ket j)\). \(\blacksquare\)

4. \((I\otimes\bra{j'})\ket{ij} = \delta_{j'j}\ket i\), so \((I\otimes\bra{j'})\ket{ij}\!\bra{ij}(I\otimes\ket{j'}) = \delta_{j'j}\ket i\!\bra i\). Summing over \(j'\) and then over \(i, j\) with weights \(p_{ij}\): \(\operatorname{tr}_B\rho = \sum_{i,j}p_{ij}\ket i\!\bra i\).

Check. Part 4 with \(p_{00} = p_{11} = \tfrac12\) (perfectly correlated coins): marginal \(\tfrac12I\), the same as \(\operatorname{tr}_B\ket{\Phi^+}\!\bra{\Phi^+}\) — which is the warning of the deck's entanglement slide: a mixed half does not certify entanglement unless the whole is pure. Part 2 with \(T = \sigma\) a density operator: \(\operatorname{tr}_B(\rho\otimes\sigma) = \rho\) ✓.

Hints · 3 rungs
Rung 1

The Schmidt decomposition answers all of parts 1–3 at once: it gives both reduced states in diagonal form.

Rung 2

From \(\ket\psi = \sum_ks_k\ket{a_k}\ket{b_k}\): \(\rho_A = \sum_ks_k^2\ket{a_k}\!\bra{a_k}\), \(\rho_B = \sum_ks_k^2\ket{b_k}\!\bra{b_k}\). For part 4, think of two coins that always agree.

Rung 3

First line of part 1: "Let \(\ket\psi = \sum_{k=1}^Rs_k\ket{a_k}\ket{b_k}\) be a Schmidt decomposition, \(s_k > 0\). Then \(\rho_A\) has rank \(R\)."

Worked solution

Idea. In Schmidt form, tracing out either side leaves the other side's Schmidt vectors weighted by \(s_k^2\). The number of terms is the rank of each reduced state, and a product is one term.

1. Schmidt: \(\ket\psi = \sum_{k=1}^Rs_k\ket{a_k}\ket{b_k}\), orthonormal families, \(s_k > 0\). By the deck's formula (with a basis of \(H_B\) containing the \(b_k\)), \(\rho_A = \sum_ks_k^2\ket{a_k}\!\bra{a_k}\), of rank \(R\). Unit 03: \(\psi\) is a product iff \(R = 1\). A density operator is pure iff its rank is \(1\). So product \(\iff R = 1 \iff \rho_A\) pure. \(\blacksquare\)

2. Likewise \(\rho_B = \sum_ks_k^2\ket{b_k}\!\bra{b_k}\). Both are spectral decompositions with the same weights \(s_k^2\), so the non-zero eigenvalues agree with multiplicity (each \(s_k^2\) appears once per \(k\), on either side). \(\blacksquare\)

3. \(\ket\psi = \sqrt{0.9}\ket{00} + \sqrt{0.1}\ket{11}\), already in Schmidt form: \(\rho_A = \rho_B = \mathrm{diag}(0.9, 0.1)\). Norm \(0.9 + 0.1 = 1\) ✓.

4. \(\rho = \tfrac12(\ket{00}\!\bra{00} + \ket{11}\!\bra{11})\) — two coins that always agree — is a mixture of products, so separable (not entangled), and \(\rho_A = \rho_B = \tfrac12I\) (P6, part 4). Even simpler: \(\tfrac I2\otimes\tfrac I2\).

Check. Part 3 via \(CC^\dagger\): \(C = \mathrm{diag}(\sqrt{0.9}, \sqrt{0.1})\), \(CC^\dagger = \mathrm{diag}(0.9, 0.1)\) ✓; \(\det C = 0.3 \ne 0\), entangled ✓, and purity \(0.81 + 0.01 = 0.82 = 1 - 2(0.09)\) ✓ (P4). Part 4: \(\rho\) and \(\ket{\Phi^+}\!\bra{\Phi^+}\) have the same reduced states and the same \(z\) correlations; they differ in \(x\): \(\braket{X\otimes X}\) is \(0\) for \(\rho\) and \(1\) for \(\ket{\Phi^+}\).

exercises: the uniqueness of purifications, the coefficient matrix of (I ⊗ V)ψ, a unitary computed and recognised

\[ \ket\Psi = c^2\ket{00} - s^2\ket{01} + cs\ket{10} + cs\ket{11}, \qquad \ket{\Psi'} = \tfrac1{\sqrt2}\ket{00} + \tfrac12\ket{01} + \tfrac12\ket{11}, \]

with \(c = \cos\tfrac\pi8\), \(s = \sin\tfrac\pi8\).

  1. Show that \((I\otimes V)\sum_{i,j}C_{ij}\ket{ij}\) has coefficient matrix \(CV^{\mathsf T}\).
  2. Find the unitary \(V\) on the second qubit with \(\ket{\Psi'} = (I\otimes V)\ket\Psi\), and recognise it.
  3. Find \(V\) a second way, by following the proof in the deck: compute \((\bra{e_k}\otimes I)\ket{\Psi'}\) for the eigenvectors \(e_1, e_2\) of \(\rho\).
Hints · 3 rungs
Rung 1

The answer is a \(2\times2\) unitary; part 1 turns "find \(V\)" into a matrix equation \(C' = CV^{\mathsf T}\) you can solve because \(C\) is invertible.

Rung 2

\(V^{\mathsf T} = C^{-1}C'\), with \(C = \begin{pmatrix}c^2&-s^2\\cs&cs\end{pmatrix}\), \(\det C = c^3s + cs^3 = cs\). Useful values: \(c^2 + s^2 = 1\), \(c^2 - s^2 = \tfrac1{\sqrt2}\), \(cs = \tfrac1{2\sqrt2}\). For part 3, \(c + s = \sqrt2\,c\) and \(c - s = \sqrt2\,s\).

Rung 3

First line of part 2: "\(C^{-1} = \tfrac1{cs}\begin{pmatrix}cs&s^2\\-cs&c^2\end{pmatrix}\), so \(V^{\mathsf T} = C^{-1}C' = \tfrac1{cs}\begin{pmatrix}cs\cdot\tfrac1{\sqrt2}&\tfrac12(cs + s^2)\\-cs\cdot\tfrac1{\sqrt2}&\tfrac12(c^2 - cs)\end{pmatrix}\)" — and now simplify the right column.

Worked solution

Idea. A unitary on \(B\) acts on the columns of the coefficient matrix; solving for it is a \(2\times2\) inversion. The deck's proof gives the same \(V\) as "send \(\ket k\) to the normalised slice of \(\Psi'\) along \(e_k\)".

1. \((I\otimes V)\ket{ij} = \ket i\otimes V\ket j = \sum_kV_{kj}\ket{ik}\). So the coefficient of \(\ket{ik}\) in \((I\otimes V)\sum C_{ij}\ket{ij}\) is \(\sum_jC_{ij}V_{kj} = (CV^{\mathsf T})_{ik}\).

2. Right column of rung 3: \(\tfrac{cs + s^2}{2cs} = \tfrac{c + s}{2c}\) and \(\tfrac{c^2 - cs}{2cs} = \tfrac{c - s}{2s}\). With \(c + s = \sqrt2c\) and \(c - s = \sqrt2s\) (both from \(\cos x \pm \sin x = \sqrt2\cos(x \mp \tfrac\pi4)\) at \(x = \tfrac\pi8\)), each is \(\tfrac1{\sqrt2}\). So \(V^{\mathsf T} = \tfrac1{\sqrt2}\begin{pmatrix}1&1\\-1&1\end{pmatrix}\) and

\[ V = \tfrac1{\sqrt2}\begin{pmatrix}1&-1\\1&1\end{pmatrix} = \cos\tfrac\pi4\,I - i\sin\tfrac\pi4\,Y = R_y(\tfrac\pi2), \]

a real rotation of the second qubit's plane by \(45^\circ\) — on its Bloch sphere, a quarter-turn about \(y\). Unitary: real with orthonormal columns ✓.

3. The eigenvectors are \(\ket{e_1} = c\ket0 + s\ket1\), \(\ket{e_2} = -s\ket0 + c\ket1\) (real), so \(\braket{e_1|0} = c\), \(\braket{e_1|+} = \tfrac{c + s}{\sqrt2} = c\), \(\braket{e_2|0} = -s\) and \(\braket{e_2|+} = \tfrac{c - s}{\sqrt2} = s\). Since \(\ket{\Psi'} = \tfrac1{\sqrt2}(\ket0\ket0 + \ket+\ket1)\),

\[ (\bra{e_1}\otimes I)\ket{\Psi'} = \tfrac{c}{\sqrt2}(\ket0 + \ket1) = c\ket+, \qquad (\bra{e_2}\otimes I)\ket{\Psi'} = \tfrac{s}{\sqrt2}(-\ket0 + \ket1) = -s\ket- . \]

For \(\Psi\), the same slices are \(c\ket0\) and \(s\ket1\). So the proof's \(f_k\) are \(\ket0, \ket1\) and its \(f'_k\) are \(\ket+, -\ket-\): \(V\ket0 = \ket+\), \(V\ket1 = -\ket- = \tfrac1{\sqrt2}(-\ket0 + \ket1)\). Those are the columns of the \(V\) of part 2 ✓.

Check. \(CV^{\mathsf T}\): row \(0\) is \(\tfrac1{\sqrt2}(c^2 + s^2,\ c^2 - s^2) = (\tfrac1{\sqrt2}, \tfrac12)\); row \(1\) is \(\tfrac1{\sqrt2}(cs - cs,\ cs + cs) = (0, \tfrac12)\): that is \(C'\) ✓. And \(V\) acts only on \(B\), so \(\rho_A\) is untouched, as the deck's converse says.

Show that the conditional states, averaged with their probabilities, give back \(\rho_B\) — for any \(\rho\) and any \(\{P_\lambda\}\).

Rung 1

Every part is an equality of operators on \(H_B\) (or \(H_A\)). The defining property turns such an equality into "both sides give the same \(\operatorname{tr}(M\,\cdot)\) for every \(M\)", which is a trace computation on the joint space.

Rung 2

Pair with \(I\otimes M\), move Alice's operators round the trace by cyclicity, and use \((A\otimes B)(C\otimes D) = AC\otimes BD\). Then \(U^\dagger U = I\), \(P_\lambda^2 = P_\lambda\), \(\sum_\lambda P_\lambda = I\). Rung 3

Worked solution

Idea. Bob's state is defined by what his observables \(I\otimes M\) see, and Alice's operators commute with those observables and, averaged, preserve the identity. The selective update is just conditioning on information Bob has to be sent.

1(a). For every \(M\) on \(H_B\), \(\operatorname{tr}\big((I\otimes M)(U\otimes I)\rho(U^\dagger\otimes I)\big) = \operatorname{tr}\big((U^\dagger\otimes I)(I\otimes M)(U\otimes I)\rho\big) = \operatorname{tr}((U^\dagger U\otimes M)\rho) = \operatorname{tr}((I\otimes M)\rho)\). By the defining property, the left side is \(\operatorname{tr}\big(M\operatorname{tr}_A[(U\otimes I)\rho(U^\dagger\otimes I)]\big)\) and the right side is \(\operatorname{tr}(M\operatorname{tr}_A\rho)\). Equal for every \(M\), so by non-degeneracy (P6) the partial traces are equal.

1(b). Rung 3, then \(\sum_\lambda P_\lambda\otimes M = I\otimes M\) (using \(P_\lambda IP_\lambda = P_\lambda\)), so the pairing with every \(M\) is \(\operatorname{tr}((I\otimes M)\rho)\); conclude as in (a). \(\blacksquare\)

2. The same computation with the factors swapped: pair \((I\otimes V)\rho(I\otimes V^\dagger)\) and \(\sum_\mu(I\otimes Q_\mu)\rho(I\otimes Q_\mu)\) with \(A\otimes I\), and use \(\operatorname{tr}(A\operatorname{tr}_B\cdot) = \operatorname{tr}((A\otimes I)\,\cdot)\). Nothing in the proof cared which side was which.

3. With \(P_k = \ket k\!\bra k\): \((P_k\otimes I)\ket{\Phi^+} = \tfrac1{\sqrt2}\ket{kk}\), so \(\Pr(k) = \tfrac12\) and Bob's conditional state is \(\operatorname{tr}_A\ket{kk}\!\bra{kk} = \ket k\!\bra k\) — pure, and not \(\rho_B = I/2\). In general, writing \(\rho_B^{(\lambda)} = \operatorname{tr}_A\big((P_\lambda\otimes I)\rho(P_\lambda\otimes I)\big)/\Pr(\lambda)\) with \(\Pr(\lambda) = \operatorname{tr}((P_\lambda\otimes I)\rho)\),

\[ \sum_\lambda\Pr(\lambda)\,\rho_B^{(\lambda)} = \operatorname{tr}_A\Big(\sum_\lambda(P_\lambda\otimes I)\rho(P_\lambda\otimes I)\Big) = \rho_B \]

by linearity of \(\operatorname{tr}_A\) and part 1(b). For \(\ket{\Phi^+}\): \(\tfrac12\ket0\!\bra0 + \tfrac12\ket1\!\bra1 = I/2\) ✓.

4. Bob's conditional state is a statement about a sub-collection of his runs that only Alice's message picks out. Until the message arrives he cannot sort his runs, and his unsorted runs are distributed by \(\rho_B\), whatever Alice did. The message is an ordinary signal, limited by the speed of light; the shared pair adds correlation, not communication.

Special case \(\rho = \sigma\otimes\tau\) (no correlation): \(\rho_B^{(\lambda)} = \tau\) for every \(\lambda\), so even told the outcome Bob learns nothing — conditioning helps only when there is correlation to condition on.

P12 Steering in the y basis medium

exercises: slicing a state with a complex vector, the U ⊗ Ū invariance of Φ⁺, steering

Alice and Bob share \(\ket{\Phi^+}\).

  1. For any \(\ket a = \alpha\ket0 + \beta\ket1\), show \((\bra a\otimes I)\ket{\Phi^+} = \tfrac1{\sqrt2}\ket{\bar a}\), where \(\ket{\bar a} = \bar\alpha\ket0 + \bar\beta\ket1\).
  2. Alice measures in the \(y\) basis \(\{\ket{+i}, \ket{-i}\}\). Give her outcome probabilities and Bob's state after each.
  3. Which projective measurement must Alice make for Bob's conditional states to be \(\ket{+i}\) and \(\ket{-i}\)? If both then measure \(y\), with what probability do their labels agree?
  4. Prove \((U\otimes\bar U)\ket{\Phi^+} = \ket{\Phi^+}\) for every unitary \(U\), and use it to rederive part 1 for \(\ket a = U\ket0\).
Hints · 3 rungs
Rung 1

Each part comes down to the vector \((\bra a\otimes I)\ket{\Phi^+}\) in Bob's space. The subtlety is a complex conjugate: the bra conjugates Alice's amplitudes, and Bob's vector inherits the conjugates.

Rung 2

\(\braket{a|0} = \bar\alpha\). For part 4, use P9's rule: \((A\otimes B)\) acts on coefficient matrices as \(C \mapsto ACB^{\mathsf T}\), and \(\ket{\Phi^+}\) has \(C = I/\sqrt2\).

Rung 3

First line of part 2: "\(\ket{+i} = \tfrac1{\sqrt2}(1, i)\), so \(\ket{\overline{+i}} = \tfrac1{\sqrt2}(1, -i) = \ket{-i}\): Alice's outcome \(+i\) leaves Bob in \(\ket{-i}\)."

Worked solution

Idea. \(\ket{\Phi^+}\) correlates Alice's vector with the conjugate of Bob's, because it is invariant under \(U\otimes\bar U\), not \(U\otimes U\). On real vectors conjugation does nothing, so \(z\) and \(x\) correlate perfectly; the \(y\) basis is complex, and there the labels flip.

1. \((\bra a\otimes I)\ket{kk} = \braket{a|k}\ket k\), with \(\braket{a|0} = \bar\alpha\), \(\braket{a|1} = \bar\beta\). So \((\bra a\otimes I)\ket{\Phi^+} = \tfrac1{\sqrt2}(\bar\alpha\ket0 + \bar\beta\ket1) = \tfrac1{\sqrt2}\ket{\bar a}\).

2. \(\ket{\overline{\pm i}} = \ket{\mp i}\). Outcome \(\pm i\) has probability \(\lVert\tfrac1{\sqrt2}\ket{\mp i}\rVert^2 = \tfrac12\), and leaves Bob in \(\ket{\mp i}\): the other member of the \(y\) basis.

3. The \(y\) basis itself: outcome \(+i\) leaves Bob in \(\ket{-i}\), outcome \(-i\) in \(\ket{+i}\) — both of Bob's states occur, with probability \(\tfrac12\) each. (Measuring \(\{\ket{\bar a}\}\) to steer to \(\{\ket a\}\) is the general recipe, and \(\{\ket{\overline{\pm i}}\}\) is again the \(y\) basis.) If both measure \(y\), the labels never agree: probability \(0\). Compare \(z\) or \(x\), where they always agree.

4. P9, part 1, gives \(C \mapsto CB^{\mathsf T}\) for \(I\otimes B\); the same computation on the first factor, \((A\otimes I)\ket{ij} = \sum_kA_{ki}\ket{kj}\), gives \(C \mapsto AC\). As \(A\otimes B = (A\otimes I)(I\otimes B)\), \((U\otimes\bar U)\) sends the coefficient matrix \(C = \tfrac1{\sqrt2}I\) to \(\tfrac1{\sqrt2}U\bar U^{\mathsf T} = \tfrac1{\sqrt2}UU^\dagger = \tfrac1{\sqrt2}I\). So \((U\otimes\bar U)\ket{\Phi^+} = \ket{\Phi^+}\). Now with \(\ket a = U\ket0\): \((\bra a\otimes I) = (\bra0U^\dagger)\otimes I\), and

\[ (\bra a\otimes I)\ket{\Phi^+} = (\bra0U^\dagger\otimes I)(U\otimes\bar U)\ket{\Phi^+} = (\bra0\otimes\bar U)\ket{\Phi^+} = \bar U\tfrac1{\sqrt2}\ket0 = \tfrac1{\sqrt2}\ket{\bar a}, \]

since \(\bar U\ket0\) is the entrywise conjugate of \(U\ket0\). \(\blacksquare\)

Check. Bob, not told: \(\tfrac12\ket{-i}\!\bra{-i} + \tfrac12\ket{+i}\!\bra{+i} = I/2\) ✓ — no-signalling. Real case: \(a = \ket+\) gives \(\ket{\bar a} = \ket+\), the deck's Steering the running example ✓. Bloch picture: conjugation is the reflection \(y \mapsto -y\), which fixes the \(xz\) plane and swaps the poles of \(y\).
