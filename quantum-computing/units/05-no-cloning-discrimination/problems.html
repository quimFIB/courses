Part B · unit 05 · problems

No-cloning, and how well two states can be told apart

the slides · the curriculum

Checkpoint. On paper and without notes, you prove the no-cloning theorem both ways — by linearity, and by inner products, where \(\braket{\psi|\varphi} = \braket{\psi|\varphi}^2\) up to phase forces \(|\braket{\psi|\varphi}|\in\{0, 1\}\) — and you prove the Helstrom bound \(\tfrac12(1 + \sqrt{1 - |\braket{\psi|\varphi}|^2})\) for two equiprobable pure states, producing for \(\ket0\) against \(\ket+\) the value \(\tfrac12(1 + \tfrac1{\sqrt2}) \approx 0.8536\) and the optimal measurement: the basis at angles \(-\pi/8\) and \(3\pi/8\).

Work each problem on paper first. Under it, Hints opens a ladder one rung at a time — each rung appears only once the one before it is open, and the last gives the first line of the working — and Worked solution has the whole thing: the idea, the working, then a check. Read the solution after your attempt, including when you got it right. F folds everything back; D switches dark and light.

Twelve problems, about four hours. Work them on paper first.

Conventions, as in the deck: \(\braket{u|v}\) is conjugate-linear in the first slot. Qubit 0 is the leftmost symbol of a ket. \(\ket\pm = \tfrac1{\sqrt2}(\ket0 \pm \ket1)\), \(\ket{\pm i} = \tfrac1{\sqrt2}(\ket0 \pm i\ket1)\), linear polarisation at angle \(\theta\) is \(\ket\theta = \cos\theta\ket0 + \sin\theta\ket1\), and

\[ X = \begin{pmatrix}0&1\\1&0\end{pmatrix},\quad Z = \begin{pmatrix}1&0\\0&-1\end{pmatrix},\quad \mathrm{CNOT}_{01} = \ket0\!\bra0\otimes I + \ket1\!\bra1\otimes X,\quad \ket{\Phi^+} = \tfrac1{\sqrt2}(\ket{00} + \ket{11}). \]

A cloner for a set \(S\) is a unitary \(U\) on \(H\otimes H\) and a fixed unit vector \(s\) with \(U(\psi\otimes s) = e^{i\gamma_\psi}\psi\otimes\psi\) for all \(\psi\in S\). In two-state discrimination with a projector \(P\) for the answer "\(\psi\)", the success probability is \(p_{\rm succ} = \tfrac12\braket{\psi|P|\psi} + \tfrac12\braket{\varphi|(I - P)|\varphi}\), and its maximum is \(\tfrac12(1 + \sqrt{1 - |c|^2})\) with \(c = \braket{\psi|\varphi}\).

Some solutions end with an optional check by the course's referee, qclib, run from the course directory with uv run python. Every solution is complete without it.

P1 Linearity, by the numbers routine

exercises: linearity of a unitary, the inner product on a tensor product, how badly a classical copier fails on a superposition

Let \(U\) copy \(\ket0\) and \(\ket1\) exactly onto a blank \(s\): \(U(\ket k\otimes s) = \ket k\ket k\) for \(k = 0, 1\) (for example \(\mathrm{CNOT}_{01}\) with \(s = \ket0\)). Let \(\ket\alpha = \cos\alpha\ket0 + \sin\alpha\ket1\) with \(0 \le \alpha \le \pi/2\).

  1. Compute \(U(\ket\alpha\otimes s)\) and check that it is normalised.
  2. Compute its overlap \(f(\alpha)\) with the true copy \(\ket\alpha\ket\alpha\).
  3. For which \(\alpha\) is \(f(\alpha) = 1\)? Where on \([0, \pi/2]\) is \(f\) smallest, and what is its value there? Check against the deck's Worked: CNOT on |+⟩|0⟩.
Hints · 3 rungs
Rung 1

Part 1 is a vector in \(\mathbb C^4\); part 2 is a real function of \(\alpha\), a sum of two cubes; part 3 is a one-variable minimum.

Rung 2

Expand \(\ket\alpha\ket\alpha\) in the basis \(\ket{00}, \ket{01}, \ket{10}, \ket{11}\). Only two of its four coefficients meet a nonzero coefficient of \(U(\ket\alpha\otimes s)\).

Rung 3

First line: "\(U(\ket\alpha\otimes s) = \cos\alpha\,U(\ket0\otimes s) + \sin\alpha\,U(\ket1\otimes s) = \cos\alpha\ket{00} + \sin\alpha\ket{11}\)."

Worked solution

Idea. Linearity fixes the output on every superposition once it is fixed on \(\ket0\) and \(\ket1\); the output keeps only the "both 0" and "both 1" parts of a true copy.

1. \(\ket\alpha\otimes s = \cos\alpha\,(\ket0\otimes s) + \sin\alpha\,(\ket1\otimes s)\), so by linearity \(U(\ket\alpha\otimes s) = \cos\alpha\ket{00} + \sin\alpha\ket{11}\). Norm squared \(\cos^2\alpha + \sin^2\alpha = 1\) ✓.

2. \(\ket\alpha\ket\alpha = \cos^2\alpha\ket{00} + \cos\alpha\sin\alpha(\ket{01} + \ket{10}) + \sin^2\alpha\ket{11}\), norm squared \(\cos^4\alpha + 2\cos^2\alpha\sin^2\alpha + \sin^4\alpha = (\cos^2\alpha + \sin^2\alpha)^2 = 1\) ✓. All coefficients are real, so

\[ f(\alpha) = \braket{\alpha\alpha|U(\alpha\otimes s)} = \cos^2\alpha\cdot\cos\alpha + \sin^2\alpha\cdot\sin\alpha = \cos^3\alpha + \sin^3\alpha . \]

3. On \([0, \pi/2]\), \(\cos\alpha, \sin\alpha \in [0, 1]\), so \(\cos^3\alpha \le \cos^2\alpha\) and \(\sin^3\alpha \le \sin^2\alpha\), and \(f(\alpha) \le 1\) with equality iff each of \(\cos\alpha, \sin\alpha\) is \(0\) or \(1\): \(\alpha = 0\) or \(\pi/2\), the states \(\ket0\) and \(\ket1\) themselves. For the minimum, \(f'(\alpha) = -3\cos^2\alpha\sin\alpha + 3\sin^2\alpha\cos\alpha = 3\sin\alpha\cos\alpha(\sin\alpha - \cos\alpha)\), which vanishes inside \((0, \pi/2)\) only at \(\alpha = \pi/4\). Since \(f(0) = f(\pi/2) = 1\), the minimum is \(f(\pi/4) = 2\cdot(1/\sqrt2)^3 = 1/\sqrt2 \approx 0.7071\).

Check. At \(\alpha = \pi/4\), \(\ket\alpha = \ket+\) and the output is \(\ket{\Phi^+}\): the deck found \(\braket{{+}{+}|\Phi^+} = 1/\sqrt2\) ✓. The probability that the output passes the test "is it \(\ket\alpha\ket\alpha\)?" is \(f^2\), at worst \(\tfrac12\). If \(U\) carried phases, \(U(\ket k\otimes s) = e^{i\gamma_k}\ket{kk}\), the overlap would be \(|e^{i\gamma_0}\cos^3\alpha + e^{i\gamma_1}\sin^3\alpha| \le f(\alpha)\) by the triangle inequality: phases can only make it worse.

P2 A copier for the x basis routine

exercises: change of basis by a unitary, the product rule for tensor operators, that copyability is a property of a set

Let \(H = \tfrac1{\sqrt2}\begin{pmatrix}1&1\\1&-1\end{pmatrix}\) and \(U = (H\otimes H)\,\mathrm{CNOT}_{01}\,(H\otimes H)\).

  1. Check that \(H\) is unitary and that \(H\ket0 = \ket+\), \(H\ket1 = \ket-\), \(H\ket\pm = \ket0, \ket1\).
  2. Show that \(U\) is a cloner for \(\{\ket+, \ket-\}\) with blank \(\ket+\).
  3. Compute \(U(\ket0\ket+)\) and its overlap with \(\ket0\ket0\).
  4. Show that \(U = I\otimes\ket0\!\bra0 + X\otimes\ket1\!\bra1\): the CNOT with control qubit 1 and target qubit 0, which unit 10 will call \(\mathrm{CNOT}_{10}\).
Hints · 3 rungs
Rung 1

Everything follows from "\(H\) swaps the \(z\) and \(x\) bases and \(H^2 = I\)". Part 3's answer is a Bell state; part 4 is an identity between \(4\times4\) matrices, best proved without writing them out.

Rung 2

Follow \(\ket\pm\ket+\) through the three factors of \(U\) one at a time. For part 4, conjugate each term of \(\mathrm{CNOT}_{01}\) by \(H\otimes H\), using \(HXH = Z\), \(\ket\pm\!\bra\pm = \tfrac12(I \pm X)\) and \(\tfrac12(I \pm Z) = \ket0\!\bra0, \ket1\!\bra1\).

Rung 3

First line of part 2: "\((H\otimes H)\ket+\ket+ = \ket0\ket0\), then \(\mathrm{CNOT}_{01}\ket{00} = \ket{00}\), then \((H\otimes H)\ket{00} = \ket{{+}{+}}\)."

Worked solution

Idea. \(H\) carries the \(x\) basis to the \(z\) basis; copy there with CNOT; carry back. A copier for one orthonormal basis is a copier for any other after a change of basis — but only for that basis.

1. \(H\) is real and symmetric, so \(H^\dagger H = H^2 = \tfrac12\begin{pmatrix}2&0\\0&2\end{pmatrix} = I\) ✓. Its columns are \(\tfrac1{\sqrt2}(1, 1) = \ket+\) and \(\tfrac1{\sqrt2}(1, -1) = \ket-\), so \(H\ket0 = \ket+\), \(H\ket1 = \ket-\); applying \(H\) again, \(H\ket+ = H^2\ket0 = \ket0\) and \(H\ket- = \ket1\).

2. By the product rule \((H\otimes H)(a\otimes b) = Ha\otimes Hb\). For \(\ket+\ket+\): \(\ket+\ket+ \mapsto \ket0\ket0 \mapsto \ket0\ket0 \mapsto \ket+\ket+\). For \(\ket-\ket+\): \(\ket-\ket+ \mapsto \ket1\ket0 \mapsto \ket1\ket1 \mapsto \ket-\ket-\). Both copied, no phase. \(U\) is unitary as a product of unitaries.

3. \(\ket0\ket+ \mapsto \ket+\ket0 \mapsto \ket{\Phi^+}\) (the deck's worked example), and then \((H\otimes H)\ket{\Phi^+} = \tfrac1{\sqrt2}(\ket{{+}{+}} + \ket{{-}{-}})\). Expanding, \(\ket{{+}{+}} + \ket{{-}{-}} = \tfrac12[(\ket{00} + \ket{01} + \ket{10} + \ket{11}) + (\ket{00} - \ket{01} - \ket{10} + \ket{11})] = \ket{00} + \ket{11}\), so \(U(\ket0\ket+) = \ket{\Phi^+}\) again. Its overlap with \(\ket0\ket0\) is \(\tfrac1{\sqrt2} \approx 0.7071\): the \(x\)-copier fails on \(\ket0\) exactly as the \(z\)-copier fails on \(\ket+\).

4. Conjugating term by term with \((H\otimes H)(A\otimes B)(H\otimes H) = HAH\otimes HBH\):

\[ U = H\ket0\!\bra0H\otimes HIH + H\ket1\!\bra1H\otimes HXH = \ket+\!\bra+\otimes I + \ket-\!\bra-\otimes Z . \]

Here \(HXH = \tfrac12\begin{pmatrix}1&1\\-1&1\end{pmatrix}\begin{pmatrix}1&1\\1&-1\end{pmatrix} = Z\) (the first product being \(HX\)). With \(\ket\pm\!\bra\pm = \tfrac12(I \pm X)\):

\[ U = \tfrac12(I + X)\otimes I + \tfrac12(I - X)\otimes Z = I\otimes\tfrac12(I + Z) + X\otimes\tfrac12(I - Z) = I\otimes\ket0\!\bra0 + X\otimes\ket1\!\bra1 . \]

That is: flip qubit 0 when qubit 1 is \(1\), i.e. \(\mathrm{CNOT}_{10}\). \(\blacksquare\)

Check. On \(\ket+\ket+\), \(\mathrm{CNOT}_{10}\) gives \(\tfrac12(\ket{00} + \ket{11} + \ket{10} + \ket{01})\) (flipping qubit 0 in the two terms where qubit 1 is \(1\)), which is \(\ket{{+}{+}}\) again ✓. On \(\ket-\ket+ = \tfrac12(\ket{00} + \ket{01} - \ket{10} - \ket{11})\) it gives \(\tfrac12(\ket{00} + \ket{11} - \ket{10} - \ket{01}) = \ket-\ket-\) ✓.

P3 Copying a known set medium

exercises: the inner-product proof with phases, building a unitary from a permutation of a basis, the exact criterion for cloning

  1. Prove: a finite set of states has a cloner if and only if any two of its members are orthogonal or equal as states (equal up to a phase). Allow the phase \(e^{i\gamma_\psi}\) in the definition.
  2. Decide, with reasons, which of these sets has a cloner: (a) \(\{\ket0, \ket1, \ket+\}\) in \(\mathbb C^2\); (b) \(\{\ket{00}, \ket{01}, \ket{11}\}\), as states of one system with \(H = \mathbb C^4\); (c) \(\{\ket+, \ket-, -\ket+\}\) in \(\mathbb C^2\).
Hints · 3 rungs
Rung 1

"Only if" is an identity between inner products; "if" is a construction: a unitary that permutes an orthonormal basis of \(H\otimes H\). Each verdict in part 2 is decided by overlaps alone — and by remembering what "equal as states" means.

Rung 2

For "only if", compare \(\braket{\psi\otimes s|\varphi\otimes s}\) with \(\braket{U(\psi\otimes s)|U(\varphi\otimes s)}\) and take moduli. For "if", extend the distinct members to an orthonormal basis \(e_0, \dots, e_{d-1}\) and send \(e_j\otimes e_k\) to \(e_j\otimes e_{(j + k)\bmod d}\).

Rung 3

First line of "only if": "With \(c = \braket{\psi|\varphi}\), unitarity gives \(c\braket{s|s} = e^{i(\gamma_\varphi - \gamma_\psi)}c^2\), so \(|c| = |c|^2\)."

Worked solution

Idea. A unitary keeps every overlap, and copying squares it; the only overlaps that survive squaring are \(0\) and \(1\). Conversely, orthogonal states are a classical alphabet, and permuting basis pairs copies an alphabet.

Only if. Let \(U\) clone \(\psi\) and \(\varphi\), and \(c = \braket{\psi|\varphi}\). Then \(\braket{\psi\otimes s|\varphi\otimes s} = c\braket{s|s} = c\), and \(\braket{U(\psi\otimes s)|U(\varphi\otimes s)} = \overline{e^{i\gamma_\psi}}e^{i\gamma_\varphi}\braket{\psi|\varphi}^2 = e^{i(\gamma_\varphi - \gamma_\psi)}c^2\). Unitarity makes these equal; taking moduli, \(|c| = |c|^2\), so \(|c|\in\{0, 1\}\). If \(|c| = 1\), Cauchy–Schwarz holds with equality, so \(\varphi = \lambda\psi\) with \(|\lambda| = 1\): the same state.

If. Pick one representative of each distinct state: \(\psi_0, \dots, \psi_{m-1}\), pairwise orthogonal unit vectors. Extend them by Gram–Schmidt to an orthonormal basis \(e_0 = \psi_0, \dots, e_{m-1} = \psi_{m-1}, e_m, \dots, e_{d-1}\) of \(H\). The \(e_j\otimes e_k\) are an orthonormal basis of \(H\otimes H\). Define \(U\) on it by \(U(e_j\otimes e_k) = e_j\otimes e_{(j + k)\bmod d}\) and extend linearly. The index map \((j, k)\mapsto(j, (j + k)\bmod d)\) is a bijection (inverse \((j, k')\mapsto(j, (k' - j)\bmod d)\)), so \(U\) maps an orthonormal basis onto an orthonormal basis and is unitary. With blank \(s = e_0\): \(U(\psi_j\otimes s) = \psi_j\otimes\psi_j\). A member \(e^{i\alpha}\psi_j\) of the set goes to \(e^{i\alpha}\psi_j\otimes\psi_j = e^{-i\alpha}(e^{i\alpha}\psi_j)\otimes(e^{i\alpha}\psi_j)\), a copy up to the phase \(e^{-i\alpha}\). \(\blacksquare\)

2. (a) No: \(|\braket{0|+}| = \tfrac1{\sqrt2}\notin\{0, 1\}\). (b) Yes: distinct computational basis vectors of \(\mathbb C^4\) are orthonormal; the construction with \(d = 4\) copies them. (c) Yes: \(-\ket+\) is the state \(\ket+\) (phase \(-1\)), and \(\ket+\perp\ket-\); P2's \(U\) does it, sending \((-\ket+)\ket+\) to \(-\ket+\ket+ = -(-\ket+)(-\ket+)\), a copy with phase \(-1\).

Check. For \(d = 2\), \((j + k)\bmod2 = j\oplus k\) and the construction is \(\ket j\ket k\mapsto\ket j\ket{k\oplus j}\), which is \(\mathrm{CNOT}_{01}\) ✓. And the criterion is about the set: \(\{\ket+, \ket-\}\) passes, \(\{\ket0, \ket+\}\) fails, though \(\ket+\) is in both.

P4 Ancillas do not help copying medium

exercises: the inner-product method with an environment, Cauchy–Schwarz, isometries

  1. A machine with its own system \(E\), starting in \(e\), applies a unitary \(U\) on \(H\otimes H\otimes E\) with \(U(\psi\otimes s\otimes e) = \psi\otimes\psi\otimes e_\psi\) for \(\psi\in\{\psi_1, \psi_2\}\), where the final machine states \(e_\psi\) are unit vectors that may depend on \(\psi\). Prove \(|\braket{\psi_1|\psi_2}|\in\{0, 1\}\).
  2. Do the same for a machine making \(N \ge 2\) copies: \(U(\psi\otimes s^{\otimes(N-1)}\otimes e) = \psi^{\otimes N}\otimes e_\psi\).
  3. Where exactly is unitarity used? Show the conclusion still holds if \(U\) is only an isometry \(V: H\otimes H\otimes E\to K\) into a larger space, i.e. \(V^\dagger V = I\) — a machine that may bring in further parts as it runs.
Hints · 3 rungs
Rung 1

The answer is the deck's inequality \(|c| \le |c|^2\) or \(|c| \le |c|^N\), and the observation that it needs only "keeps inner products".

Rung 2

Why may the phase be dropped from the definition here? Then take inner products of the two outputs; bound \(|\braket{e_{\psi_1}|e_{\psi_2}}|\) by Cauchy–Schwarz.

Rung 3

First line: "With \(c = \braket{\psi_1|\psi_2}\): \(c = \braket{\psi_1\otimes s\otimes e|\psi_2\otimes s\otimes e} = \braket{U(\cdot)|U(\cdot)} = c^2\braket{e_{\psi_1}|e_{\psi_2}}\)."

Worked solution

Idea. The machine's final state contributes a factor of modulus at most one, which can only make the squared overlap smaller still; so the identity \(|c| = |c|^2\) becomes the inequality \(|c| \le |c|^2\), which forces the same conclusion.

1. Any phase \(e^{i\gamma_\psi}\) on the output can be absorbed into \(e_\psi\), so none is written. Unit 03's product rule and \(U^\dagger U = I\):

\[ c\,\braket{s|s}\braket{e|e} = \braket{U(\psi_1\otimes s\otimes e)|U(\psi_2\otimes s\otimes e)} = c^2\braket{e_{\psi_1}|e_{\psi_2}}, \]

so \(c = c^2\braket{e_{\psi_1}|e_{\psi_2}}\). Taking moduli and using \(|\braket{e_{\psi_1}|e_{\psi_2}}| \le \lVert e_{\psi_1}\rVert\,\lVert e_{\psi_2}\rVert = 1\): \(|c| \le |c|^2\), i.e. \(|c|(1 - |c|) \le 0\). Since \(0 \le |c| \le 1\) (Cauchy–Schwarz again), \(|c|(1 - |c|) \ge 0\), so \(|c|(1 - |c|) = 0\). \(\blacksquare\)

2. Identically, \(c = c^N\braket{e_{\psi_1}|e_{\psi_2}}\), so \(|c| \le |c|^N\). If \(0 \lt |c| \lt 1\), then \(|c|^N \lt |c|\) for \(N \ge 2\), a contradiction. So \(|c|\in\{0, 1\}\).

3. The only property of \(U\) used is \(\braket{Uu|Uv} = \braket{u|v}\), i.e. \(U^\dagger U = I\). An isometry has exactly this: \(\braket{Vu|Vv} = \braket{u|V^\dagger Vv} = \braket{u|v}\), and the outputs \(\psi\otimes\psi\otimes e_\psi\) now live in \(H\otimes H\otimes E'\) with \(K = H\otimes H\otimes E'\). The argument is unchanged.

Check. For orthogonal \(\psi_1, \psi_2\) nothing is violated: \(c = 0\) satisfies \(0 = 0\cdot\braket{e_{\psi_1}|e_{\psi_2}}\) for any machine states, and P3's cloner, with \(E\) idle (\(e_\psi = e\)), is an example. For \(\ket0, \ket+\) the needed inequality reads \(0.7071 \le 0.5\), false.

P5 No-deleting medium

exercises: the inner-product method in reverse, reading a theorem's equality case, Pati and Braunstein's result

A deleter takes two copies of an unknown state and blanks one, using an ancilla: a unitary \(U\) on \(H\otimes H\otimes A\) with \(U(\psi\otimes\psi\otimes a) = \psi\otimes\ket0\otimes a_\psi\), the \(a_\psi\) unit vectors (Pati and Braunstein, Nature 404, 164, 2000).

  1. Show that orthogonal states delete freely: find a unitary on two qubits, no ancilla, with \(\ket k\ket k\mapsto\ket k\ket0\) for \(k = 0, 1\).
  2. Suppose \(U\) deletes \(\psi_1\) and \(\psi_2\). Prove \(c^2 = c\,\braket{a_{\psi_1}|a_{\psi_2}}\), with \(c = \braket{\psi_1|\psi_2}\).
  3. Deduce: if the ancilla's final state does not depend on \(\psi\), then \(|c|\in\{0, 1\}\). And if it does, then whenever \(c \ne 0\), \(\braket{a_{\psi_1}|a_{\psi_2}} = c\). For \(\ket0\) and \(\ket+\), give the overlap of the two final ancilla states, and say in one sentence where the "deleted" copy went.
Hints · 3 rungs
Rung 1

Part 1 is a gate you already know. Parts 2–3 are one line of inner products and one line of algebra; the number in part 3 is the overlap of \(\ket0\) and \(\ket+\).

Rung 2

Take the inner product of the two inputs, then of the two outputs. The blanked slot contributes \(\braket{0|0} = 1\). If \(c \ne 0\), divide by it.

Rung 3

First line of part 2: "\(\braket{\psi_1\otimes\psi_1\otimes a|\psi_2\otimes\psi_2\otimes a} = c^2\), while \(\braket{\psi_1\otimes0\otimes a_{\psi_1}|\psi_2\otimes0\otimes a_{\psi_2}} = c\,\braket{a_{\psi_1}|a_{\psi_2}}\)."

Worked solution

Idea. Deleting is copying run backwards, and the inner-product argument runs backwards too: the overlap that the two copies carried, \(c^2\), cannot vanish into nothing; whatever of it the remaining copy does not hold must be held by the ancilla.

1. \(\mathrm{CNOT}_{01}\): \(\ket0\ket0\mapsto\ket0\ket0\) and \(\ket1\ket1\mapsto\ket1\ket{1\oplus1} = \ket1\ket0\). Unitary (a permutation matrix).

2. Unitarity and the product rule: \(c^2\braket{a|a} = c\,\braket{0|0}\braket{a_{\psi_1}|a_{\psi_2}}\), and \(\braket{a|a} = \braket{0|0} = 1\), so \(c^2 = c\,\braket{a_{\psi_1}|a_{\psi_2}}\). (Any phase on the output is absorbed into \(a_\psi\).) \(\blacksquare\)

3. If \(a_\psi = a'\) for all \(\psi\), then \(\braket{a_{\psi_1}|a_{\psi_2}} = 1\) and \(c^2 = c\), so \(c\in\{0, 1\}\): perfect deletion with an untouched ancilla works only for orthogonal or identical states. In general, if \(c \ne 0\), dividing gives \(\braket{a_{\psi_1}|a_{\psi_2}} = c\): the ancilla's two final states have exactly the overlap the inputs had. For \(\ket0, \ket+\): \(\braket{a_0|a_+} = \tfrac1{\sqrt2} \approx 0.7071\), the overlap of a single copy. The deleted copy was not destroyed; it moved into the ancilla, which now distinguishes the two cases exactly as well as a copy of the state would.

Check. A deleter that works this way exists: swap the second copy into the ancilla (take \(A = H\), \(a = \ket0\), and \(U\) the swap of the last two factors), giving \(\psi\otimes\ket0\otimes\psi\) with \(a_\psi = \psi\) and \(\braket{a_{\psi_1}|a_{\psi_2}} = c\) ✓. Pati and Braunstein's reading: quantum information can be moved, but neither copied nor deleted.

P6 Finish off FLASH medium

exercises: the no-signalling statement of unit 03, building a projector from a record, a proof of no-cloning from no-signalling

Alice and Bob share the singlet \(\ket{\Psi^-}\). Alice measures her photon in \(z\) or in \(x\). Suppose Bob had a unitary \(C\) on his photon, \(2m - 1\) blanks in a fixed state and a machine in a fixed state, with \(C(\chi\otimes\text{blanks}\otimes e) = \chi^{\otimes2m}\otimes e_\chi\) for \(\chi\in\{\ket0, \ket1, \ket+, \ket-\}\). He measures copies \(1, \dots, m\) in \(z\) and copies \(m + 1, \dots, 2m\) in \(x\).

  1. Find the probability that Bob's \(m\) results in \(z\) all agree, when Alice measured \(z\), and when she measured \(x\). Evaluate for \(m = 10\).
  2. Show that "all \(m\) results in \(z\) agree" is an outcome of a projective measurement on Bob's side alone (his photon, blanks and machine).
  3. Use unit 03's no-signalling statement to conclude that no such \(C\) exists. Which tools did this use, and which did it not need?
Hints · 3 rungs
Rung 1

Part 1 is two numbers, one of them \(1\). Part 2 is a projector conjugated by \(C\). Part 3 is a contradiction: two values of a probability that is supposed to have one.

Rung 2

After Alice's \(z\) measurement Bob's photon is \(\ket0\) or \(\ket1\); after \(x\), \(\ket+\) or \(\ket-\) (deck, Alice's choice, and Bob's photon). The projector onto "copies \(1..m\) all agree in \(z\)" is \(R = \big((\ket0\!\bra0)^{\otimes m} + (\ket1\!\bra1)^{\otimes m}\big)\otimes I\). Is \(C^\dagger RC\) a projector?

Rung 3

First line of part 1: "If Alice chose \(x\), each of Bob's \(z\) results on \(\ket\pm\) is a fair coin, independently, so all \(m\) agree with probability \(2\cdot2^{-m}\)."

Worked solution

Idea. A perfect copier would make one of Bob's local statistics depend on Alice's choice; unit 03 proved that no local statistic can. So the copier cannot exist.

1. Alice chose \(z\). Her result (a fair coin) leaves Bob's photon in \(\ket1\) or \(\ket0\), so the copier gives \(\ket1^{\otimes2m}\) or \(\ket0^{\otimes2m}\) (times \(e_\chi\)), and the \(m\) results in \(z\) are all \(1\) or all \(0\): they agree with probability \(1\). Alice chose \(x\). Bob's photon is \(\ket-\) or \(\ket+\); each copy measured in \(z\) gives \(0\) or \(1\) with probability \(|\braket{0|\pm}|^2 = \tfrac12\), independently across copies (the copies are in a product state), so all \(m\) agree with probability \(2^{-m} + 2^{-m} = 2^{1-m}\). For \(m = 10\): \(1\) against \(2^{-9} = \tfrac1{512} \approx 0.001953\).

2. On the \(2m\) copies let \(R = \big((\ket0\!\bra0)^{\otimes m} + (\ket1\!\bra1)^{\otimes m}\big)\otimes I\), the identity on copies \(m + 1, \dots, 2m\) and on the machine: a sum of two orthogonal projectors, hence a projector, whose expectation is the probability that the \(m\) results in \(z\) agree. Bob's whole procedure, "apply \(C\), then test \(R\)", is the test \(Q = C^\dagger RC\) on his side before copying, and \(Q^\dagger = Q\), \(Q^2 = C^\dagger RCC^\dagger RC = C^\dagger R^2C = Q\): a projector. With \(I - Q\) it forms a projective measurement on Bob's side, \(H_B\otimes(\text{blanks})\otimes(\text{machine})\).

3. Regard Bob's side as one system \(H_{B'}\) and the initial state as \(\ket{\Psi^-}\otimes\beta\in H_A\otimes H_{B'}\) with \(\beta\) the fixed blanks and machine. Unit 03's problem P10: for any projective measurement \(\{P_\lambda\}\) by Alice, \(\sum_\lambda\braket{\cdot|(P_\lambda\otimes Q)|\cdot} = \braket{\cdot|(I\otimes Q)|\cdot}\), the same number for every choice of \(\{P_\lambda\}\). But part 1 found it to be \(1\) for Alice's \(z\) and \(2^{1-m}\) for her \(x\), which differ for every \(m \ge 2\). Contradiction: no such \(C\). \(\blacksquare\)

It used: the singlet's form in both bases (unit 03), the Born rule, the product rule for tensor operators, and unit 03's no-signalling for projective measurements. It did not need relativity, unit 04's partial trace, or the inner-product proof — an independent route to no-cloning.

Check. Without a copier (\(m = 1\), no blanks), "all one result agrees" has probability \(1\) in both cases, \(1 = 2^{0}\) ✓: no contradiction, as there must not be. And Bob's single-copy \(z\) statistics are \(\tfrac12, \tfrac12\) whatever Alice did, the deck's Bob alone sees a fair coin ✓.

Hints · 3 rungs
Rung 1

Three numbers between \(\tfrac12\) and \(1\), then two unit vectors written in terms of \(\psi\) and \(\varphi\): the bisector direction \(b\) and the direction \(d\) across it.

Rung 2

Use \(1 + \cos\tfrac\theta2 = 2\cos^2\tfrac\theta4\) and \(1 - \cos\tfrac\theta2 = 2\sin^2\tfrac\theta4\). Then \(\braket{\psi|b} = \cos\tfrac\theta4\) and \(\braket{\psi|d} = \sin\tfrac\theta4\).

Rung 3

First line of part 2: "\(\lVert\psi + \varphi\rVert^2 = 2 + 2\cos\tfrac\theta2 = 4\cos^2\tfrac\theta4\), so \(\lVert b\rVert = 1\); and \(\braket{\psi + \varphi|\psi - \varphi} = 1 - \cos\tfrac\theta2 + \cos\tfrac\theta2 - 1 = 0\)."

Worked solution

Idea. The bisector \(b\) and its perpendicular \(d\) are a basis of the plane; the Helstrom basis is that basis turned through \(45^\circ\), so \(e_\pm = (b \pm d)/\sqrt2\).

1. \(\sqrt{1 - \cos^2\tfrac\theta2} = \sin\tfrac\theta2\) (non-negative on \([0, \pi]\)), so \(p_{\rm succ} = \tfrac12(1 + \sin\tfrac\theta2)\). At \(\pi/3\): \(\tfrac12(1 + \tfrac12) = 0.75\). At \(\pi/2\): \(\tfrac12(1 + \tfrac1{\sqrt2}) \approx 0.8536\). At \(2\pi/3\): \(\tfrac12(1 + \tfrac{\sqrt3}2) \approx 0.9330\).

2. \(\lVert\psi \pm \varphi\rVert^2 = 2 \pm 2\cos\tfrac\theta2\), which is \(4\cos^2\tfrac\theta4\) or \(4\sin^2\tfrac\theta4\), so \(b\) and \(d\) are unit vectors; and \(\braket{\psi + \varphi|\psi - \varphi} = 1 - \cos\tfrac\theta2 + \cos\tfrac\theta2 - 1 = 0\) (the overlap is real), so they are orthogonal. Hence \(e_\pm = (b \pm d)/\sqrt2\) are orthonormal too. Now

\[ \braket{\psi|b} = \frac{1 + \cos\frac\theta2}{2\cos\frac\theta4} = \cos\tfrac\theta4,\quad \braket{\psi|d} = \frac{1 - \cos\frac\theta2}{2\sin\frac\theta4} = \sin\tfrac\theta4,\quad \braket{\varphi|b} = \cos\tfrac\theta4,\quad \braket{\varphi|d} = -\sin\tfrac\theta4 . \]

So \(\braket{e_+|\psi} = \tfrac1{\sqrt2}(\cos\tfrac\theta4 + \sin\tfrac\theta4)\) and \(\braket{e_-|\varphi} = \tfrac1{\sqrt2}(\cos\tfrac\theta4 + \sin\tfrac\theta4)\): equal. Squaring, \(\tfrac12(1 + 2\sin\tfrac\theta4\cos\tfrac\theta4) = \tfrac12(1 + \sin\tfrac\theta2)\) for each, so the average is the bound: this is the Helstrom measurement.

3. \(\theta = \pi/2\): \(\cos\tfrac\pi8 = 0.9239\), \(\sin\tfrac\pi8 = 0.3827\). \(b = (\ket0 + \ket+)/1.8478 = 0.9239\ket0 + 0.3827\ket1\) (the bisector, at \(\pi/8\)), and \(d = (\ket0 - \ket+)/0.7654 = 0.3827\ket0 - 0.9239\ket1\). So \(e_+ = (b + d)/\sqrt2 = (1.3066\ket0 - 0.5412\ket1)/1.4142 = 0.9239\ket0 - 0.3827\ket1\), at angle \(-\pi/8\) ✓, as in the deck's Worked: |0⟩ against |+⟩, the best measurement.

Check. \(\theta = \pi\): \(\varphi \perp \psi\), \(b = (\psi + \varphi)/\sqrt2\), \(d = (\psi - \varphi)/\sqrt2\), and \(e_+ = \psi\), \(e_- = \varphi\): measure in the states' own basis, success \(1\) ✓.

def helstrom(psi, phi, p=0.5):           # p for psi; best success = (1 - p) + top eigenvalue
    G = p * np.outer(psi, psi.conj()) - (1 - p) * np.outer(phi, phi.conj())

Rung 2

In the deck's basis \(u_1 = \psi\), \(u_2 = (\varphi - |c|\psi)/s\), \(\Gamma\) has trace \(2p - 1\) and determinant \(-p(1 - p)s^2\). One eigenvalue is positive and one negative.

Rung 1

Part 1 is a subtraction. Part 2 is about which basis vectors a conclusive outcome can be. Part 3: what should the scheme do when it says "don't know"?

Rung 2

An outcome may be read "\(\ket+\)" only if \(\ket0\) never produces it, so its basis vector is orthogonal to \(\ket0\). On "don't know", guess at random.

Rung 3

First line of part 3: "On a conclusive answer the scheme is right; on 'don't know' a coin is right half the time; so success \(= q + \tfrac12(1 - q) = \tfrac12(1 + q)\)."

The fidelity of a copy is the probability that it passes the test "is it \(\psi\)?". Average over the six states \(\ket0, \ket1, \ket\pm, \ket{\pm i}\), each with probability \(\tfrac16\).

Hints · 3 rungs
Rung 1

Four fractions, all between \(\tfrac12\) and \(1\). The six states fall into three bases, and every overlap between different bases has \(|\braket{e|f}|^2 = \tfrac12\).

Rung 2

Outcome \(k\) has probability \(|\braket{k|\psi}|^2\), and then the copy \(\ket k\) passes the test with probability \(|\braket{\psi|k}|^2\). For an input in the measured basis the sum is \(1\); for one in another basis, \(\tfrac14 + \tfrac14\).

Rung 3

First line of part 1: "Average \(= \tfrac16(1 + 1 + \tfrac12 + \tfrac12 + \tfrac12 + \tfrac12)\), the two \(z\) states giving \(1\) and the four others \(\tfrac12\)."

Worked solution

Idea. Fidelity is a probability of passing a test, so each strategy's fidelity is a short sum over its outcomes; the six states are symmetric enough that every basis does equally well.

1. Outcome \(k\) has probability \(|\braket{k|\psi}|^2\) (Born); the copy is then \(\ket k\), which passes the test \(\{\psi, \psi^\perp\}\) with probability \(|\braket{\psi|k}|^2\). By total probability the fidelity is \(\sum_k|\braket{k|\psi}|^2|\braket{\psi|k}|^2 = \sum_k|\braket{k|\psi}|^4\), the same for both copies. For \(\psi = \ket0\) or \(\ket1\): \(1\). For \(\ket\pm\) or \(\ket{\pm i}\): \(|\braket{0|\psi}|^2 = |\braket{1|\psi}|^2 = \tfrac12\), so \(\tfrac14 + \tfrac14 = \tfrac12\). Average: \(\tfrac16(2\cdot1 + 4\cdot\tfrac12) = \tfrac23\).

2. In basis \(x\) or \(y\) the same count holds — two of the six states give \(1\) and four give \(\tfrac12\), since the three bases are mutually unbiased (unit 00) — so each basis averages \(\tfrac23\), and so does a random choice among them.

3. The original passes with probability \(1\); the padding \(\ket0\) passes with probability \(|\braket{\psi|0}|^2\), which averages \(\tfrac16(1 + 0 + 4\cdot\tfrac12) = \tfrac12\) over the six. Each copy is the original with probability \(\tfrac12\): average fidelity \(\tfrac12\cdot1 + \tfrac12\cdot\tfrac12 = \tfrac34\).

4. \(\mathrm{CNOT}_{01}\): on \(\ket0, \ket1\) a perfect copy; on the other four, the output is \(\tfrac1{\sqrt2}(\ket{00} \pm \ket{11})\) or \(\tfrac1{\sqrt2}(\ket{00} \pm i\ket{11})\), and either copy passes with probability \(\tfrac12\) (as in the deck's worked example); average \(\tfrac23\). Ranking: CNOT \(= \) measure-and-prepare \(= \tfrac23 \lt\) keep-and-pad \(\tfrac34 \lt\) Bužek–Hillery \(\tfrac56 \approx 0.8333 \lt 1\). No strategy reaches \(1\) on all six, by no-cloning.

Check. Each fidelity is a probability in \([0, 1]\), and a strategy that knew \(\psi\) would score \(1\). The measure-and-prepare value \(\tfrac23\) is also its average over all states of a qubit (Massar and Popescu 1995, cited; unit 07 computes such averages over the Bloch sphere).

Describe a device made of an ancilla, a unitary and a projective measurement that discriminates \(\psi\) from \(\varphi\) with success \(\tfrac12(1 + \sqrt{1 - |c|^4})\), and conclude a contradiction.
  2. Evaluate both sides of the contradiction for \(\ket0\), \(\ket+\).
  3. Conversely, show from the deck's theorems that if \(\psi\) and \(\varphi\) can be discriminated with certainty, then they can be cloned. Conclude: "cloneable" and "perfectly distinguishable" are the same condition on a pair of distinct states.
Hints · 3 rungs
Rung 1

The device is "clone, then measure the two copies in the Helstrom basis for \(\psi\otimes\psi\) against \(\varphi\otimes\varphi\)". The contradiction is with the deck's An ancilla does not help.

Rung 2

The ancilla is \(s\otimes e\). The measurement is \(\{P\otimes I_E, (I - P)\otimes I_E\}\) with \(P\) the Helstrom projector for \(\psi\otimes\psi\), \(\varphi\otimes\varphi\), whose overlap is \(c^2\). Compare \(\sqrt{1 - |c|^4}\) with \(\sqrt{1 - |c|^2}\).

Rung 3

First line: "On input \(\psi\), the state before the measurement is \(\psi\otimes\psi\otimes e_\psi\), and \(\braket{\psi\psi e_\psi|(P\otimes I)|\psi\psi e_\psi} = \braket{\psi\psi|P|\psi\psi}\)."

Worked solution

Idea. Two copies are easier to tell apart than one, because the overlap squares. A copier would let one copy behave like two, and so beat the best possible one-copy measurement.

1. The device. Append the ancilla \(s\otimes e\) (fixed); apply \(U\); measure \(\{P\otimes I_E, (I - P)\otimes I_E\}\), where \(P\) is the Helstrom projector on \(H\otimes H\) for \(\psi\otimes\psi\) against \(\varphi\otimes\varphi\); guess \(\psi\) on \(P\). On input \(\psi\) the state before measuring is \(\psi\otimes\psi\otimes e_\psi\), and since \((P\otimes I)(\psi\otimes\psi\otimes e_\psi) = P(\psi\otimes\psi)\otimes e_\psi\) with \(\lVert e_\psi\rVert = 1\), the probability of guessing \(\psi\) is \(\braket{\psi\psi|P|\psi\psi}\). Likewise for \(\varphi\). So the device's success is that of the Helstrom measurement for \(\psi\otimes\psi\), \(\varphi\otimes\varphi\), whose overlap is \(c^2\): \(\tfrac12(1 + \sqrt{1 - |c|^4})\). The contradiction. The device is an ancilla, a unitary and a projective measurement, so An ancilla does not help bounds it by \(\tfrac12(1 + \sqrt{1 - |c|^2})\). But \(0 \lt |c| \lt 1\) gives \(|c|^4 \lt |c|^2\), so \(\sqrt{1 - |c|^4} \gt \sqrt{1 - |c|^2}\) and the device beats the bound. So no such \(U\) exists: a third proof of no-cloning, from discrimination. \(\blacksquare\)

2. \(|c|^2 = \tfrac12\), \(|c|^4 = \tfrac14\): the device would reach \(\tfrac12(1 + \sqrt{0.75}) \approx 0.9330\), against the bound \(\tfrac12(1 + \sqrt{0.5}) \approx 0.8536\).

3. If some measurement discriminates \(\psi, \varphi\) with certainty, Certainty needs orthogonality gives \(\psi\perp\varphi\), and P3's construction (or \(\mathrm{CNOT}_{01}\) in a suitable basis) clones them. Conversely a cloner for two distinct states forces \(|c|\in\{0, 1\}\), and "distinct" excludes \(1\), so \(c = 0\), and then \(P = \ket\psi\!\bra\psi\) discriminates them with certainty. Both conditions are \(\braket{\psi|\varphi} = 0\): one root. \(\blacksquare\)

Check. At \(|c| = 0\) both sides are \(1\), no contradiction, and orthogonal states do clone ✓. At \(|c| = 1\) both are \(\tfrac12\), no contradiction, and identical states trivially "clone" as one state ✓. The argument bites exactly in between, where the theorem says it should.
