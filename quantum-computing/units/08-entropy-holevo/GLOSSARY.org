The terms this unit introduces, in the order the deck meets them. The slides
stay the definition of record; each entry names the slide it comes from, so a
term can be looked up here and read properly there. Logarithms are base 2, so
entropies are in bits.

Running example: Alice sends \(\ket0\) or \(\ket+\) by a fair coin. The
average state \(\rho = \frac12(\ket0\!\bra0 + \ket+\!\bra+)\) has eigenvalues
\(\cos^2\frac\pi8 \approx 0.8536\) and \(\sin^2\frac\pi8 \approx 0.1464\), so
\(S(\rho) = h(0.8536) = 0.601\) bits; both members are pure, so the Holevo
quantity is \(\chi = 0.601\). With a register \(P\) keeping the coin,
\(I(P:Q) = 0.601\). Bob's best single guess, unit 05's Helstrom measurement,
extracts \(I(X:Y) = 1 - h(0.1464) = 0.399\) bits. A long run of the source
compresses to about \(0.601\) qubits per symbol. The orthogonal pair
\(\ket0\), \(\ket1\) has \(\chi = 1\), attained by measuring \(z\).

* Shannon entropy

- Shannon entropy :: \(H(X) = -\sum_xp(x)\log p(x)\) for a random variable
  on a finite set, with \(0\log0 = 0\): the number of bits per symbol a source
  needs, by the source coding theorem. \(0 \le H \le \log d\). /Slide: How many
  bits a source holds./
- binary entropy :: \(h(p) = -p\log p - (1 - p)\log(1 - p)\), the entropy of
  a coin of bias \(p\): \(h(\frac12) = 1\), \(h(0.1464) = 0.601\). /Slide: How
  many bits a source holds./
- Gibbs' inequality :: \(D(p\Vert q) = \sum_xp(x)\log\frac{p(x)}{q(x)} \ge
  0\), with equality iff \(p = q\); \(D\) is the classical relative entropy. Proved
  from \(\ln t \le t - 1\). With \(q\) uniform it gives \(H \le \log d\).
  /Slide: Gibbs' inequality, and the bounds on H./
- typical set :: For \(n\) independent draws from \(p\), the sequences with
  \(|-\frac1n\log p(x^n) - H| \le \delta\). It has probability \(\to 1\) (by
  Chebyshev) and between about \(2^{n(H - \delta)}\) and \(2^{n(H + \delta)}\)
  members, each of probability about \(2^{-nH}\). /Slide: Typical sequences./
- source coding theorem :: Shannon 1948: \(n\) independent symbols can be
  encoded in \(nR\) bits with vanishing error iff \(R > H\); below \(H\) every
  code fails almost surely. /Slide: Compression: H bits per symbol, and no
  fewer./
- joint entropy :: \(H(XY)\), the Shannon entropy of the joint distribution of
  \((X, Y)\). /Slide: Two variables: joint, conditional, mutual./
- conditional entropy :: Classically \(H(Y|X) = H(XY) - H(X) = \sum_xp(x)H(Y|X
  = x) \ge 0\). The quantum \(S(A|B) = S(AB) - S(B)\) can be negative: \(-1\)
  for \(\ket{\Phi^+}\). /Slide: Two variables: joint, conditional, mutual./
- mutual information :: \(I(X:Y) = H(X) + H(Y) - H(XY) = D(p_{XY}\Vert
  p_Xp_Y) \ge 0\), zero iff independent, at most \(\min\{H(X), H(Y)\}\).
  /Slide: Two variables: joint, conditional, mutual./

* Von Neumann entropy

- von Neumann entropy :: \(S(\rho) = -\operatorname{tr}\rho\log\rho\), by the
  functional calculus: the Shannon entropy of the spectrum of \(\rho\). Zero iff
  \(\rho\) is pure, \(\log d\) iff \(\rho = I/d\), unitarily invariant. For a
  qubit, \(h(\frac12(1 + |r|))\). /Slide: The entropy of a density operator./
- concavity (of the entropy) :: \(S(\sum_ip_i\rho_i) \ge \sum_ip_iS(\rho_i)\),
  equality iff the \(\rho_i\) are equal: mixing never lowers entropy. Proved from
  the concavity of \(\eta(t) = -t\log t\) and the fact that a state's diagonal in
  any basis has at least the entropy of its spectrum. /Slide: Concavity: mixing
  never lowers entropy./

* Relative entropy and the inequalities

- relative entropy :: \(D(\rho\Vert\sigma) = \operatorname{tr}\rho\log\rho -
  \operatorname{tr}\rho\log\sigma\), or \(+\infty\) if
  \(\operatorname{supp}\rho \not\subseteq \operatorname{supp}\sigma\). Not
  symmetric. /Slide: Relative entropy, and Klein's inequality./
- Klein's inequality :: \(D(\rho\Vert\sigma) \ge 0\), with equality iff \(\rho
  = \sigma\); proved by expanding in both eigenbases and applying \(a\ln\frac ab
  \ge a - b\). /Slide: Relative entropy, and Klein's inequality./
- quantum mutual information :: \(I(A:B) = S(A) + S(B) - S(AB) =
  D(\rho_{AB}\Vert\rho_A\otimes\rho_B)\). Up to \(2\) bits for a pair of qubits:
  \(\ket{\Phi^+}\) has \(I = 2\). /Slide: Mutual information is a relative
  entropy./
- subadditivity :: \(S(AB) \le S(A) + S(B)\), equality iff \(\rho_{AB} =
  \rho_A\otimes\rho_B\): Klein's inequality applied to \(\rho_{AB}\) and
  \(\rho_A\otimes\rho_B\). /Slide: Mutual information is a relative entropy./
- classical–quantum state :: \(\sum_xp_x\ket x\!\bra x\otimes\rho_x\), a
  classical register holding \(x\) next to a quantum system in \(\rho_x\). Its
  entropy is \(H(p) + \sum_xp_xS(\rho_x)\), and its mutual information is the
  Holevo quantity. /Slide: Register and qubit: the running example as one
  state./
- entanglement entropy :: \(E(\psi) = S(\rho_A) = S(\rho_B)\) for a pure
  bipartite \(\psi\): the Shannon entropy of the squared Schmidt coefficients.
  The unique asymptotic measure of pure-state entanglement under local
  operations and classical communication (Popescu–Rohrlich 1997, cited).
  /Slide: Pure states: the entanglement entropy./
- Araki–Lieb inequality :: \(|S(A) - S(B)| \le S(AB)\), from subadditivity
  applied to a purification. Tight for pure states. /Slide: Araki–Lieb: how much
  less./
- strong subadditivity :: \(S(ABC) + S(B) \le S(AB) + S(BC)\), equivalently
  \(I(A:BC) \ge I(A:B)\): discarding a subsystem never increases mutual
  information. Lieb–Ruskai 1973, cited, not proved in this course.
  /Slide: Strong subadditivity./
- monotonicity of relative entropy :: \(D(\rho_{XY}\Vert\sigma_{XY}) \ge
  D(\rho_X\Vert\sigma_X)\) (Lindblad 1975, Uhlmann 1977, cited). Strong
  subadditivity is its case \(\sigma = \rho_A\otimes\rho_{BC}\); the two are
  equivalent. /Slide: Strong subadditivity./

* The Holevo bound

- accessible information :: \(I_{\mathrm{acc}}\), the largest \(I(X:Y)\) any
  measurement on one system extracts from an ensemble. \(0.399\) bits for the
  running example. /Slide: Alice's message, Bob's measurement./
- Holevo quantity :: \(\chi = S(\sum_xp_x\rho_x) - \sum_xp_xS(\rho_x)\), a
  property of the ensemble alone; equal to \(I(P:Q)\) for the
  classical–quantum state. \(0.601\) for the running example. /Slide: Alice's
  message, Bob's measurement./
- Holevo bound :: \(I(X:Y) \le \chi \le \log d\) for every measurement (Holevo
  1973); proved here from strong subadditivity. So a qubit carries at most one
  bit. /Slide: The Holevo bound./
- HSW theorem :: Holevo 1998, Schumacher–Westmoreland 1997: with long
  codewords and collective measurements, \(\chi\) bits per system can be sent,
  and no more. Named, not taught. /Slide: The gap between 0.399 and 0.601./

* Schumacher compression

- typical subspace :: The span of the eigenvectors of \(\rho^{\otimes n}\)
  whose index sequences are typical for the spectrum of \(\rho\). It holds
  weight \(\to 1\) and has dimension about \(2^{nS(\rho)}\). /Slide: Typical
  subspaces./
- Schumacher compression :: Schumacher 1995: a source of pure states with
  average state \(\rho\) can be compressed to \(R\) qubits per symbol with
  fidelity \(\to 1\) when \(R > S(\rho)\), and not when \(R < S(\rho)\). About \(601\) qubits for \(1000\) of
  the running example's photons. /Slide: Schumacher's theorem./
