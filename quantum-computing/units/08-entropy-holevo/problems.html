Entropy and the Holevo bound: how many bits a qubit holds

the slides · the curriculum

Checkpoint. On paper and without notes, you prove the Holevo bound from strong subadditivity — the register \(P\), the system \(Q\), the pointer \(M\); the measurement as a unitary on \(QM\); each step of the chain named, with the one inequality coming from discarding \(Q\) — and you compute \(\chi = 0.601\) bits for the \(\ket0/\ket+\) ensemble: \(\rho\), its eigenvalues \(\cos^2\frac\pi8\) and \(\sin^2\frac\pi8\), and \(S(\rho)\) to three decimals.

Work each problem on paper first. Under it, Hints opens a ladder one rung at a time — each rung appears only once the one before it is open, and the last gives the first line of the working — and Worked solution has the whole thing: the idea, the working, then a check. Read the solution after your attempt, including when you got it right. F folds everything back; D switches dark and light.

Twelve problems, about five hours. Work them on paper first.

Conventions, as in the deck: logarithms are base 2 unless written \(\ln\), so entropies are in bits; \(0\log0 = 0\); \(h(p) = -p\log p - (1 - p)\log(1 - p)\). \(S(\rho) = -\operatorname{tr}\rho\log\rho\), and \(S(A)\) means \(S(\rho_A)\). \(I(A:B) = S(A) + S(B) - S(AB)\), \(S(A|B) = S(AB) - S(B)\), \(D(\rho\Vert\sigma) = \operatorname{tr}\rho\log\rho - \operatorname{tr}\rho\log\sigma\), and \(\chi = S(\sum_xp_x\rho_x) - \sum_xp_xS(\rho_x)\). \(\braket{u|v}\) is conjugate-linear in the first slot; \(\ket0 = (1, 0)\), \(\ket1 = (0, 1)\), \(\ket\pm = (\ket0 \pm \ket1)/\sqrt2\); in \(\ket{ab}\) the first symbol is qubit 0 (\(A\)). \(\ket{\Phi^+} = (\ket{00} + \ket{11})/\sqrt2\). The running ensemble is \(\ket0\) or \(\ket+\) with probability \(\tfrac12\) each, with average state \(\rho = \begin{pmatrix}3/4&1/4\\1/4&1/4\end{pmatrix}\). Strong subadditivity, \(I(A:BC) \ge I(A:B)\), is cited and may be used freely.

Shannon and von Neumann entropy

P1 Typical sequences routine

exercises: the binary entropy computed, the typical-sequence lemma, the source coding theorem, typical against most probable

A biased coin shows \(1\) with probability \(p = 0.11\) and \(0\) otherwise. It is tossed \(n = 1000\) times.

  1. Compute \(h(0.11)\) to four decimals.
  2. To leading order in the exponent, how many of the \(2^{1000}\) sequences are typical, and what fraction of all sequences is that? What probability does each typical sequence have?
  3. How many bits does Shannon's theorem say are needed to record the 1000 tosses with vanishing error? Show that a code using \(400\) bits fails almost surely as \(n\) grows at that rate.
  4. Find the single most probable sequence and its probability. Is it typical?
Hints · 3 rungs
Rung 1

Every answer is a power of two, or the exponent of one. The exponent per toss is always an entropy or an empirical entropy \(-\tfrac1n\log p(x^n)\).

Rung 2

The typical set has between \(2^{n(H - \delta)}\) and \(2^{n(H + \delta)}\) members, each of probability about \(2^{-nH}\). For part 3 use the converse half of the source coding theorem: a set of \(2^{nR}\) sequences has probability at most \(2^{nR}2^{-n(H - \delta)} + \Pr(T^c)\). For part 4, a sequence with \(k\) ones has probability \(p^k(1 - p)^{n - k}\).

Rung 3

First line of part 1: "\(\log0.11 = -3.1844\) and \(\log0.89 = -0.1681\), so \(h(0.11) = 0.11\cdot3.1844 + 0.89\cdot0.1681\)."

Worked solution

Idea. A biased coin's long runs live on about \(2^{nh(p)}\) sequences, each about equally likely; \(h(0.11)\) happens to be almost exactly half a bit, so 1000 tosses behave like 500 fair ones.

1. \(\log_2 0.11 = \ln0.11/\ln2 = -3.18442\) and \(\log_2 0.89 = -0.16812\). So

\[ h(0.11) = 0.11\times3.18442 + 0.89\times0.16812 = 0.35029 + 0.14963 = 0.49992 \approx 0.4999 . \]

2. To leading order, \(2^{nh} = 2^{499.9} \approx 2^{500}\) typical sequences, a fraction \(2^{500}/2^{1000} = 2^{-500}\) of all of them: about one sequence in \(10^{150}\). Each has probability about \(2^{-500}\), and together they carry almost all the probability. (The \(\pm\delta\) in the exponent is the "leading order" caveat: for \(\delta = 0.05\) the lemma pins the count between \(2^{450}\) and \(2^{550}\), up to a factor \(1 - \varepsilon\).)

3. \(nh = 499.9\), so about \(500\) bits, and any rate \(R > h\) works as \(n \to \infty\). With \(400\) bits, \(R = 0.4 < h\): choose \(\delta = 0.05\), so \(R < h - \delta = 0.4499\). Any code decodes correctly only on its set \(S\) of at most \(2^{nR}\) sequences, and \(\Pr(S) \le 2^{nR}2^{-n(h - \delta)} + \Pr(T^c) = 2^{-0.0499n} + \Pr(T^c) \to 0\). At \(n = 1000\) the first term is already \(2^{-49.9}\).

4. Each toss is more likely \(0\), so the all-zeros sequence is the most probable: \(0.89^{1000} = 2^{1000\log0.89} = 2^{-168.1}\). Its empirical entropy is \(-\tfrac1{1000}\log0.89^{1000} = 0.168\), far from \(0.4999\): not typical for any \(\delta < 0.33\). It is \(2^{332}\) times likelier than a typical sequence, and there is only one of it.

Check. A sequence with \(k\) ones has empirical entropy \(\tfrac1n\big(3.18442k + 0.16812(n - k)\big)\), which equals \(h\) at \(k = 110 = np\) — the expected number of ones, as it must be: \(0.11\times3.18442 + 0.89\times0.16812 = h\). The number of ones has standard deviation \(\sqrt{1000\times0.11\times0.89} = 9.89\); the empirical entropy moves by \(0.003016\) per extra one, so for \(\delta = 0.05\) the typical sequences are those with \(110 \pm 16\) ones.

P2 Entanglement entropy of unit 03's state routine

exercises: the reduced state of a pure state, eigenvalues of a \(2\times2\) matrix, the von Neumann entropy computed, both halves equal

Unit 03's state is \(\ket\psi = \tfrac1{\sqrt3}(\ket{00} + \ket{01} + \ket{10})\).

  1. Check it is normalised, and compute \(\rho_A\) and \(\rho_B\).
  2. Show that both have eigenvalues \(\tfrac16(3 \pm \sqrt5)\).
  3. Compute its entanglement entropy \(E(\psi) = S(\rho_A)\) to four decimals, and compare with the Bell state's.
Hints · 3 rungs
Rung 1

The answer is a number between \(0\) and \(1\), the Shannon entropy of a two-outcome distribution: the squared Schmidt coefficients.

Rung 2

Unit 04: for coefficient matrix \(C\) (rows indexed by \(A\)), \(\rho_A = CC^\dagger\). A \(2\times2\) matrix's eigenvalues come from its trace and determinant.

Rung 3

First line: "\(C = \tfrac1{\sqrt3}\begin{pmatrix}1&1\\1&0\end{pmatrix}\), so \(\rho_A = CC^\dagger = \tfrac13\begin{pmatrix}2&1\\1&1\end{pmatrix}\), with trace \(1\) and determinant \(\tfrac19\)."

Worked solution

Idea. The two halves of a pure state share their non-zero spectrum, the squared Schmidt coefficients; the entanglement entropy is the Shannon entropy of that spectrum.

1. \(\lVert\psi\rVert^2 = \tfrac13(1 + 1 + 1) = 1\) ✓. With \(C = \tfrac1{\sqrt3}\begin{pmatrix}1&1\\1&0\end{pmatrix}\) (rows \(A = 0, 1\); columns \(B = 0, 1\)),

\[ \rho_A = CC^\dagger = \tfrac13\begin{pmatrix}2&1\\1&1\end{pmatrix}, \qquad \rho_B = (C^\dagger C)^{\mathsf T} = \tfrac13\begin{pmatrix}2&1\\1&1\end{pmatrix}, \]

the same matrix, because \(C\) is real and symmetric. Trace \(1\) ✓.

2. \(\det\rho_A = \tfrac19(2 - 1) = \tfrac19\), so the eigenvalues solve \(\lambda^2 - \lambda + \tfrac19 = 0\): \(\lambda = \tfrac12\big(1 \pm \sqrt{1 - \tfrac49}\big) = \tfrac12\big(1 \pm \tfrac{\sqrt5}3\big) = \tfrac16(3 \pm \sqrt5)\), that is \(0.87268\) and \(0.12732\). Sum \(1\) ✓.

3. \(\log0.87268 = -0.19647\) and \(\log0.12732 = -2.97345\), so

\[ E(\psi) = 0.87268\times0.19647 + 0.12732\times2.97345 = 0.17146 + 0.37859 = 0.5500 . \]

About \(0.55\) ebits: a bit more than half a Bell pair's worth, since \(E(\Phi^+) = 1\).

Check. The squared Schmidt coefficients are the squared singular values of \(C\): \(\sqrt3\,C\) has singular values \(\tfrac12(1 \pm \sqrt5)\) in absolute value (it is symmetric with eigenvalues the golden ratio and its negative reciprocal), so \(s^2 = \tfrac13\cdot\tfrac14(1 \pm \sqrt5)^2 = \tfrac1{12}(6 \pm 2\sqrt5) = \tfrac16(3 \pm \sqrt5)\) ✓. And \(0 < 0.55 < 1\), as for any entangled but not maximally entangled pair of qubits.

P3 Concavity, from both sides hard

exercises: subadditivity on a classical–quantum state, purification, the diagonal lemma and its equality case, the chain rule

Let \(\rho = \sum_ip_i\rho_i\) for density operators \(\rho_i\) and a distribution \(p\).

  1. Prove concavity, \(S(\rho) \ge \sum_ip_iS(\rho_i)\), in one line from subadditivity, using the register state \(\sum_ip_i\ket i\!\bra i\otimes\rho_i\). (The deck proved it another way.)
  2. For a pure-state ensemble, \(\rho = \sum_ip_i\ket{\psi_i}\!\bra{\psi_i}\), prove \(S(\rho) \le H(p)\), with equality iff the \(\psi_i\) with \(p_i > 0\) are orthogonal. (Purify \(\rho\).)
  3. Deduce \(S(\sum_ip_i\rho_i) \le \sum_ip_iS(\rho_i) + H(p)\) in general, with equality iff the \(\rho_i\) have mutually orthogonal supports.
  4. Check both bounds on the running ensemble.
Hints · 3 rungs
Rung 1

Three inequalities between entropies of states you can write down. Parts 1 and 3 reduce to one each of the deck's lemmas; part 2 moves the question to the purifying system, where \(p\) appears as a diagonal.

Rung 2

Part 1: the register state has entropy \(H(p) + \sum p_iS(\rho_i)\) and marginals \(H(p)\) and \(S(\rho)\). Part 2: purify by \(\ket\Psi = \sum_i\sqrt{p_i}\ket{\psi_i}\ket i\); then \(S(\rho) = S(\rho_R)\), and look at \(\rho_R\)'s diagonal. Part 3: write each \(\rho_i\) in its eigenbasis and apply part 2 to the combined ensemble.

Rung 3

First line of part 2: "\(\rho_R = \operatorname{tr}_A\ket\Psi\!\bra\Psi = \sum_{i,j}\sqrt{p_ip_j}\braket{\psi_j|\psi_i}\ket i\!\bra j\), whose diagonal is \((p_i)\); by the diagonal lemma \(H(p) \ge S(\rho_R) = S(\rho)\)."

Worked solution

Idea. Mixing adds at least nothing and at most the entropy of the label. The lower bound is subadditivity in disguise; the upper bound says the story's entropy \(H(p)\) exceeds the state's, because the label is a diagonal of the purifier's state and diagonals have more entropy than spectra.

1. Let \(\omega = \sum_ip_i\ket i\!\bra i\otimes\rho_i\). By the deck's classical–quantum lemma \(S(\omega) = H(p) + \sum_ip_iS(\rho_i)\); its marginals are \(\sum_ip_i\ket i\!\bra i\) (entropy \(H(p)\)) and \(\rho\). Subadditivity \(S(\omega) \le H(p) + S(\rho)\) is exactly \(\sum p_iS(\rho_i) \le S(\rho)\). \(\blacksquare\)

2. \(\ket\Psi = \sum_i\sqrt{p_i}\ket{\psi_i}\ket i \in H\otimes\mathbb C^m\) has \(\lVert\Psi\rVert^2 = \sum_{i,j}\sqrt{p_ip_j}\braket{\psi_i|\psi_j}\braket{i|j} = \sum_ip_i = 1\) ✓, and \(\operatorname{tr}_R\ket\Psi\!\bra\Psi = \sum_ip_i\ket{\psi_i}\!\bra{\psi_i} = \rho\) (the cross terms carry \(\braket{j|i} = 0\)). So \(\Psi\) purifies \(\rho\), and the two halves of a pure state have equal entropy: \(S(\rho) = S(\rho_R)\). Tracing out \(H\) instead,

\[ \rho_R = \sum_{i,j}\sqrt{p_ip_j}\,\braket{\psi_j|\psi_i}\,\ket i\!\bra j, \qquad \braket{i|\rho_R|i} = p_i . \]

By the deck's lemma Diagonals have more entropy than the spectrum, \(H(p) \ge S(\rho_R) = S(\rho)\).

Equality. If the \(\psi_i\) are orthogonal, \(\rho_R = \mathrm{diag}(p)\) and \(S = H(p)\). Conversely, in the lemma's proof equality needs, for each \(k\), \(\eta(d_k) = \sum_jB_{kj}\eta(\lambda_j)\); \(\eta\) is strictly concave, so all \(\lambda_j\) with \(B_{kj} > 0\) are equal, so \(\ket k\) lies in one eigenspace of \(\rho_R\): the basis \(\{\ket i\}\) diagonalises \(\rho_R\). The off-diagonal entries \(\sqrt{p_ip_j}\braket{\psi_j|\psi_i}\) vanish, so \(\braket{\psi_j|\psi_i} = 0\) whenever \(p_i, p_j > 0\), \(i \ne j\). \(\blacksquare\)

3. Write \(\rho_i = \sum_k\lambda_{ik}\ket{e_{ik}}\!\bra{e_{ik}}\). Then \(\rho = \sum_{i,k}p_i\lambda_{ik}\ket{e_{ik}}\!\bra{e_{ik}}\) is a pure-state ensemble with weights \(q_{ik} = p_i\lambda_{ik}\), summing to \(1\). Part 2 and the chain rule give

\[ S(\rho) \le H(q) = -\sum_{i,k}p_i\lambda_{ik}\big(\log p_i + \log\lambda_{ik}\big) = H(p) + \sum_ip_iS(\rho_i). \]

Equality iff all \(e_{ik}\) with \(q_{ik} > 0\) are orthogonal. For fixed \(i\) they already are; across different \(i\) this says every eigenvector of \(\rho_i\) in its support is orthogonal to every one of \(\rho_j\): orthogonal supports. \(\blacksquare\)

4. Running ensemble: \(\tfrac12\cdot0 + \tfrac12\cdot0 = 0 \le 0.601 \le 0 + 1 = 1\) ✓, and both are strict — the members are pure but different (lower bound) and not orthogonal (upper bound). For \(\ket0, \ket1\): \(0 \le 1 \le 1\), the upper bound attained, as the orthogonal case must.

Check. A consequence: \(\chi = S(\rho) - \sum p_xS(\rho_x) \le H(p)\), so the Holevo bound never claims more than the information Alice put in.

P4 Klein and subadditivity medium

exercises: Klein's inequality proved, the logarithm of a tensor product, the partial trace's defining property, a relative entropy computed

  1. Prove Klein's inequality: \(D(\rho\Vert\sigma) \ge 0\), with equality iff \(\rho = \sigma\). (Assume \(\operatorname{supp}\rho \subseteq \operatorname{supp}\sigma\).)
  2. Deduce subadditivity, \(S(AB) \le S(A) + S(B)\), with equality iff \(\rho_{AB} = \rho_A\otimes\rho_B\).
  3. For \(\rho_{AB} = \tfrac12(\ket{00}\!\bra{00} + \ket{11}\!\bra{11})\), compute \(D(\rho_{AB}\Vert\rho_A\otimes\rho_B)\) directly from the definition, and check it against \(S(A) + S(B) - S(AB)\).
Hints · 3 rungs
Rung 1

Part 1 is a double sum over two eigenbases with a scalar inequality inside; part 2 is part 1 with \(\sigma = \rho_A\otimes\rho_B\); part 3 is a number of bits.

Rung 2

Part 1: expand \(\operatorname{tr}\rho\log\sigma\) in \(\rho\)'s eigenbasis \(\{r_i\}\) and \(\log\sigma\) in its own \(\{s_j\}\); the weights \(P_{ij} = |\braket{r_i|s_j}|^2\) have all row and column sums \(1\). Then use \(a\ln(a/b) \ge a - b\). Part 2: \(\log(\rho_A\otimes\rho_B) = \log\rho_A\otimes I + I\otimes\log\rho_B\).

Rung 3

First line of part 1: "With \(\rho = \sum_ip_i\ket{r_i}\!\bra{r_i}\) and \(\sigma = \sum_jq_j\ket{s_j}\!\bra{s_j}\), \(\operatorname{tr}\rho\log\sigma = \sum_ip_i\braket{r_i|\log\sigma|r_i} = \sum_{i,j}p_iP_{ij}\log q_j\), and \(\operatorname{tr}\rho\log\rho = \sum_{i,j}p_iP_{ij}\log p_i\) since \(\sum_jP_{ij} = 1\)."

Worked solution

Idea. In two eigenbases the quantum relative entropy is a weighted average of classical terms \(p_i\log(p_i/q_j)\), and each is bounded below by the tangent line of the logarithm. Mutual information is the relative entropy to the product of the marginals.

1. From the rung, \(D(\rho\Vert\sigma) = \sum_{i,j}P_{ij}\,p_i\log(p_i/q_j)\). (A term with \(P_{ij} > 0\), \(p_i > 0\) and \(q_j = 0\) cannot occur: \(r_i\) would have a component outside \(\operatorname{supp}\sigma\).) For \(a \ge 0\), \(b > 0\): \(a\ln(a/b) \ge a - b\), from \(\ln t \le t - 1\) at \(t = b/a\), and trivially at \(a = 0\). So

\[ D(\rho\Vert\sigma)\ln2 \ \ge\ \sum_{i,j}P_{ij}(p_i - q_j) = \sum_ip_i - \sum_jq_j = 1 - 1 = 0, \]

using \(\sum_jP_{ij} = \lVert r_i\rVert^2 = 1\) and \(\sum_iP_{ij} = \lVert s_j\rVert^2 = 1\). Equality needs \(p_i = q_j\) for every pair with \(P_{ij} > 0\); then \(\ket{r_i} = \sum_j\braket{s_j|r_i}\ket{s_j}\) uses only \(s_j\) with \(q_j = p_i\), so \(\sigma\ket{r_i} = p_i\ket{r_i}\) for all \(i\), and \(\sigma = \rho\). \(\blacksquare\)

2. \(\rho_A\otimes\rho_B\) has eigenvectors \(\ket{e_if_j}\) and eigenvalues \(a_ib_j\), so on its support \(\log(\rho_A\otimes\rho_B) = \log\rho_A\otimes I + I\otimes\log\rho_B\). The partial trace satisfies \(\operatorname{tr}((X\otimes I)\rho_{AB}) = \operatorname{tr}(X\rho_A)\), so

\[ -\operatorname{tr}\rho_{AB}\log(\rho_A\otimes\rho_B) = -\operatorname{tr}\rho_A\log\rho_A - \operatorname{tr}\rho_B\log\rho_B = S(A) + S(B), \]

and \(D(\rho_{AB}\Vert\rho_A\otimes\rho_B) = S(A) + S(B) - S(AB)\). The support condition holds (\(\rho_{AB}\) has no weight outside \(\operatorname{supp}\rho_A\otimes\operatorname{supp}\rho_B\), since \(\operatorname{tr}(((I - \Pi_A)\otimes I)\rho_{AB}) = \operatorname{tr}((I - \Pi_A)\rho_A) = 0\)). Part 1 gives \(\ge 0\), and equality iff \(\rho_{AB} = \rho_A\otimes\rho_B\). \(\blacksquare\)

3. \(\rho_A = \rho_B = I/2\), so \(\rho_A\otimes\rho_B = I/4\) and \(\log(I/4) = -2I\). \(\rho_{AB}\) has eigenvalues \(\tfrac12, \tfrac12, 0, 0\), so \(\operatorname{tr}\rho_{AB}\log\rho_{AB} = -1\), and \(-\operatorname{tr}\rho_{AB}\log(I/4) = 2\operatorname{tr}\rho_{AB} = 2\). So \(D = -1 + 2 = 1\) bit.

Check. \(S(A) + S(B) - S(AB) = 1 + 1 - 1 = 1\) ✓. It is the classical answer too: two perfectly correlated fair bits share one bit. Compare \(\ket{\Phi^+}\), which has the same diagonal but \(I = 2\) (P7).

P5 Araki–Lieb medium

exercises: purification, entropies of complementary parts, subadditivity, the equality case

  1. Prove \(|S(A) - S(B)| \le S(AB)\) from subadditivity and purification.
  2. Show it is tight for every pure \(\rho_{AB}\) and for every \(\rho_A\otimes\ket0\!\bra0\).
  3. Show that equality \(S(A) - S(B) = S(AB)\) holds iff, for a purification \(R\) of \(AB\), \(\rho_{BR} = \rho_B\otimes\rho_R\). Give an example that is neither pure nor of the form \(\rho_A\otimes\ket0\!\bra0\): let \(A = A_1A_2\) and \(\rho_{AB} = \tau_{A_1}\otimes\ket{\Phi^+}\!\bra{\Phi^+}_{A_2B}\).
  4. Evaluate both sides for the deck's state \(\rho = \tfrac12\ket{\Phi^+}\!\bra{\Phi^+} + \tfrac12\ket{00}\!\bra{00}\), for which \(S(A) = S(B) = 0.811\) and \(S(AB) = 0.601\).
Hints · 3 rungs
Rung 1

Everything follows from writing the same pure state of three systems \(ABR\) two ways, and applying subadditivity to a pair that does not contain \(B\).

Rung 2

In a pure state \(ABR\), a part and its complement have equal entropies: \(S(R) = S(AB)\), \(S(AR) = S(B)\), \(S(BR) = S(A)\). Apply subadditivity to \(BR\) for the direction \(S(A) - S(B) \le S(AB)\).

Rung 3

First line: "Purify \(\rho_{AB}\) by \(R\). Then \(S(A) = S(BR) \le S(B) + S(R) = S(B) + S(AB)\)."

Worked solution

Idea. Purification turns the unfamiliar inequality on \(AB\) into the familiar one on the complementary pair \(BR\), and its equality case into subadditivity's.

1. Unit 04 gives a purification \(\ket\Psi \in H_A\otimes H_B\otimes H_R\) of \(\rho_{AB}\). For a pure state the reduced states of complementary parts share their non-zero spectrum, so \(S(BR) = S(A)\) and \(S(R) = S(AB)\). Subadditivity on \(BR\): \(S(A) = S(BR) \le S(B) + S(R) = S(B) + S(AB)\). Exchanging the roles of \(A\) and \(B\) (subadditivity on \(AR\)) gives the other sign. \(\blacksquare\)

2. Pure: \(S(AB) = 0\) and \(S(A) = S(B)\), so \(0 \le 0\). Product with a pure \(B\): \(S(B) = 0\), \(S(AB) = S(A) + 0\) by additivity, so \(S(A) - 0 = S(AB)\).

3. The only inequality in the proof is subadditivity on \(BR\), so equality holds iff \(S(BR) = S(B) + S(R)\), iff \(\rho_{BR} = \rho_B\otimes\rho_R\) (the equality case of subadditivity, P4). Example: purify \(\tau\) by \(R\), so the whole state is \(\ket{\tau}_{A_1R}\otimes\ket{\Phi^+}_{A_2B}\), pure. Then \(\rho_{BR} = \tfrac I2\otimes\tau_R\), a product ✓. Directly: \(S(A) = S(\tau) + 1\), \(S(B) = 1\), \(S(AB) = S(\tau) + 0\), and \(S(A) - S(B) = S(\tau) = S(AB)\) ✓. In words: here \(A\) holds a purification of \(B\) — its half \(A_2\) of the Bell pair — and that is what leaves \(B\) uncorrelated with \(R\).

4. \(|0.811 - 0.811| = 0 \le 0.601\): true, and far from tight. Subadditivity on the other side: \(0.601 \le 1.623\).

Check. Combined, \(|S(A) - S(B)| \le S(AB) \le S(A) + S(B)\): the three entropies satisfy the triangle inequalities. For the running register-and-qubit state, \(S(P) = 1\), \(S(Q) = 0.601\), \(S(PQ) = 1\): \(0.399 \le 1 \le 1.601\) ✓.

P6 The whole can be smaller than a part medium

exercises: pure entangled states, concavity of conditional entropy, separable states, an entanglement test with numbers

Recall (unit 04) that a state is separable if it is a mixture \(\sum_ip_i\,\alpha_i\otimes\beta_i\) of product states.

  1. Prove that every entangled pure state has \(S(AB) < S(A)\).
  2. Prove that every separable state has \(S(AB) \ge S(A)\) and \(S(AB) \ge S(B)\). Use the deck's Worked: conditioning, and a separable state: \(S(B|A)\) is concave.
  3. Deduce that \(\tfrac12\ket{\Phi^+}\!\bra{\Phi^+} + \tfrac12\ket{00}\!\bra{00}\) is not separable. Then check that the register-and-qubit state \(\rho_{PQ}\) passes the test, as it must.
Hints · 3 rungs
Rung 1

Each part is a sign: of \(S(B|A) = S(AB) - S(A)\). For a pure entangled state it is negative; for a product it is \(S(B) \ge 0\); concavity carries the sign through mixtures.

Rung 2

Part 1: a pure state has \(S(AB) = 0\), and unit 04 says it is entangled iff \(\rho_A\) is mixed. Part 2: for \(\alpha\otimes\beta\), \(S(AB) = S(\alpha) + S(\beta)\) by additivity.

Rung 3

First line of part 2: "By concavity of conditional entropy, \(S(B|A)_\rho \ge \sum_ip_iS(B|A)_{\alpha_i\otimes\beta_i} = \sum_ip_iS(\beta_i) \ge 0\)."

Worked solution

Idea. Negative conditional entropy is a signature of entanglement: products have non-negative conditional entropy, and mixing (by strong subadditivity) can only raise it.

1. A pure \(\rho_{AB}\) has \(S(AB) = 0\). If it is entangled, its Schmidt rank is at least \(2\) (unit 03), so \(\rho_A\) has at least two non-zero eigenvalues and \(S(A) > 0\) (it is zero only for a pure \(\rho_A\)). Hence \(S(AB) = 0 < S(A)\). \(\blacksquare\)

2. For a product \(\alpha\otimes\beta\): \(S(AB) = S(\alpha) + S(\beta)\) and \(S(A) = S(\alpha)\), so \(S(B|A) = S(\beta) \ge 0\). The deck proved, from strong subadditivity, that \(\rho \mapsto S(B|A)_\rho\) is concave: for \(\rho = \sum_ip_i\rho^{(i)}\), \(S(B|A)_\rho \ge \sum_ip_iS(B|A)_{\rho^{(i)}}\). With \(\rho^{(i)} = \alpha_i\otimes\beta_i\), \(S(B|A)_\rho \ge \sum_ip_iS(\beta_i) \ge 0\), that is \(S(AB) \ge S(A)\). Exchanging the roles of \(A\) and \(B\) (the same argument with \(S(A|B)\)) gives \(S(AB) \ge S(B)\). \(\blacksquare\)

3. For \(\rho = \tfrac12\ket{\Phi^+}\!\bra{\Phi^+} + \tfrac12\ket{00}\!\bra{00}\): \(\rho_A = \mathrm{diag}(\tfrac34, \tfrac14)\), \(S(A) = h(\tfrac14) = 0.811\), and the two members have overlap \(|\braket{00|\Phi^+}| = 1/\sqrt2\), so \(S(AB) = h(\tfrac12(1 + \tfrac1{\sqrt2})) = 0.601\) (P8's formula). So \(S(AB) = 0.601 < 0.811 = S(A)\), and by part 2 the state is not separable. For \(\rho_{PQ} = \tfrac12\ket0\!\bra0\otimes\ket0\!\bra0 + \tfrac12\ket1\!\bra1\otimes\ket+\!\bra+\), already a mixture of products: \(S(PQ) = 1 \ge \max\{S(P), S(Q)\} = \max\{1, 0.601\}\) ✓.

Check. The test is one-sided. The Bell state mixed with white noise, \(\tfrac12\ket{\Phi^+}\!\bra{\Phi^+} + \tfrac12\cdot\tfrac I4\), is entangled — its partial transpose has the eigenvalue \(-\tfrac18\), which no separable state allows (Peres, Phys. Rev. Lett. 77, 1413, 1996, cited) — yet its spectrum is \((\tfrac58, \tfrac18, \tfrac18, \tfrac18)\), so \(S(AB) = 1.549 \ge 1 = S(A)\): the test is silent. Negative conditional entropy certifies entanglement; its absence proves nothing.

Check. Classical maximum for two bits: \(Y = X\) fair, \(I = 1\) (P4's part 3). The quantum pair doubles it, and \(2 = 2\min\{1, 1\}\) is the Araki–Lieb ceiling, attained.

Hints · 3 rungs
Rung 1

Every state here is classical–quantum in \(P\): a block for \(x = 0\) and a block for \(x = 1\). Use the lemma \(S(\sum p_x\ket x\!\bra x\otimes\omega_x) = H(p) + \sum p_xS(\omega_x)\) throughout.

Rung 2

CNOT sends \(\ket0\ket0 \mapsto \ket{00}\) and \(\ket+\ket0 \mapsto \ket{\Phi^+}\). For \(S(QM)\) you need the entropy of an equal mixture of two pure states with overlap \(\braket{00|\Phi^+} = 1/\sqrt2\) — P8.

Rung 3

Idea. The unitary keeps all \(0.601\) bits; they now sit in the correlation between \(Q\) and the pointer, and throwing \(Q\) away loses the part that the pointer alone does not carry.

1. As in the rung. So at \(t_1\):

\[ \rho_{PQM} = \tfrac12\ket0\!\bra0\otimes\ket{00}\!\bra{00} + \tfrac12\ket1\!\bra1\otimes\ket{\Phi^+}\!\bra{\Phi^+}, \qquad \operatorname{tr} = \tfrac12 + \tfrac12 = 1\ ✓. \]

Rung 1

Each encoded state is pure, so \(\chi\) is the entropy of the average. The average over the four Paulis on one qubit erases that qubit completely.

Rung 2

Idea. Alice's random Pauli makes her qubit maximally mixed and leaves Bob's alone, so the average state has entropy \(1 + S(\rho_B)\); every encoded state is pure, so that is \(\chi\). The bound \(\log4 = 2\) is reached exactly when \(\rho_B\) is maximally mixed — an ebit.

The twirl on two qubits. 2. The average is \(\tfrac I2\otimes\rho_B\) with \(\rho_B = \operatorname{tr}_A\ket\psi\!\bra\psi = \mathrm{diag}(s_0^2, s_1^2)\); by additivity its entropy is \(1 + h(s_0^2) = 1 + E(\psi)\). Each \((\sigma\otimes I)\ket\psi\) is pure, so \(\chi = 1 + E(\psi)\). \(\blacksquare\)

P11 Accessible information is less than \(\chi\): the trine hard

exercises: \(\chi\) for a three-state ensemble, mutual information of a measurement optimised over an angle, symmetry, classical data processing

Unit 04's trine: \(\ket{t_k} = \cos\tfrac{\pi k}3\ket0 + \sin\tfrac{\pi k}3\ket1\), \(k = 0, 1, 2\), each sent with probability \(\tfrac13\).

  1. Compute \(\chi\).
  2. Bob uses an analyser at angle \(\alpha\), the basis \(\{\ket\alpha, \ket{\alpha + 90^\circ}\}\).   4. It is known (Sasaki et al., Phys. Rev. A 59, 3325, 1999, cited) that the accessible information of the trine is \(\log3 - 1 \approx 0.585\) bits, attained by a three-outcome generalised measurement — unit 21's. Compare the three numbers.
Hints · 3 rungs
Rung 1

Part 1 is one entropy; part 2 is a \(3\times2\) joint distribution as a function of \(\alpha\); part 3 is a statement about a classical channel that adds noise.

Rung 2

Part 1: the average state is unit 04's. Part 2: Malus's law, \(p(y = 0|k) = \cos^2(\alpha - 60^\circ k)\). Rung 3

Idea. Three pure states with average \(I/2\) hold a full bit in \(\chi\), but no single two-outcome measurement can sort three states well; even the best measurement of all falls short of \(\chi\).

1. \(\tfrac13\sum_k\ket{t_k}\!\bra{t_k} = I/2\) (unit 04: the Bloch vectors \(120^\circ\) apart sum to zero). Each member is pure, so \(\chi = S(I/2) = 1\) bit.

Symmetry. The rotation of the plane by \(60^\circ\) sends \(\ket{t_k}\) to \(\pm\ket{t_{k+1}}\) (indices mod 3; a sign is a global phase) and the analyser at \(\alpha\) to the analyser at \(\alpha + 60^\circ\). Malus's law depends only on angle differences, so the analyser at \(\alpha + 60^\circ\) sees the same statistics with \(x\) relabelled: \(I(\alpha + 60^\circ) = I(\alpha)\). The analyser at \(\alpha + 90^\circ\) is the same basis with outcomes swapped: \(I(\alpha + 90^\circ) = I(\alpha)\). Together, \(I\) has period \(\gcd(60^\circ, 90^\circ) = 30^\circ\). Reflection in the \(z\) axis (\(\ket1 \mapsto -\ket1\)) fixes \(t_0\) and swaps \(t_1, t_2\) up to sign, and sends \(\alpha \mapsto -\alpha\): \(I\) is even. So \(I\) on \([0^\circ, 15^\circ]\) determines it everywhere.

At \(\alpha = 15^\circ\): \(p(y = 0|k) = \cos^2 15^\circ, \cos^2 45^\circ, \cos^2 105^\circ = 0.9330, 0.5, 0.0670\); \(p(y = 0) = \tfrac12\); \(H(Y|X) = \tfrac13(h(0.067) + 1 + h(0.067)) = \tfrac13(0.3546 + 1 + 0.3546) = 0.5697\); \(I(15^\circ) = 0.4303\). In between, the same arithmetic gives \(I(5^\circ) = 0.4482\) and \(I(10^\circ) = 0.4354\): \(I\) falls steadily from \(0.4591\) to \(0.4303\) across \([0^\circ, 15^\circ]\). 3. So no complex basis beats the best real one.

from qclib import DensityMatrix, Statevector, linalg
trine = [Statevector([np.cos(np.pi * k / 3), np.sin(np.pi * k / 3)]) for k in range(3)]
print(round(DensityMatrix.mixture([1 / 3] * 3, trine).entropy(), 4))    # chi = 1.0
def info(a):                                                # analyser at angle a
    b = [np.array([np.cos(a), np.sin(a)]), np.array([-np.sin(a), np.cos(a)])]
    joint = np.array([[abs(v @ t.vector) ** 2 / 3 for v in b] for t in trine])
    H = linalg.shannon_entropy
    return H(joint.sum(1)) + H(joint.sum(0)) - H(joint.ravel())
angles = np.linspace(0, np.pi, 1801)
best = max(angles, key=info)
print(round(info(best), 4), round(np.degrees(best) % 30, 1), round(info(np.pi / 12), 4))   # 0.4591 0.0 0.4303

P12 Schumacher by numbers medium

exercises: the spectrum of \(\rho^{\otimes n}\), additivity, the Chebyshev bound for the typical subspace, a compression rate computed

The running source: \(\rho\) with eigenvalues \(\lambda_1 = \cos^2\tfrac\pi8\), \(\lambda_2 = \sin^2\tfrac\pi8\).

  1. List the eigenvalues of \(\rho^{\otimes3}\) with their multiplicities, check they sum to \(1\), and verify \(S(\rho^{\otimes3}) = 3S(\rho)\).
  2. Let \(L = -\log\lambda_K\), with \(K = 1, 2\) drawn with probabilities \(\lambda_1, \lambda_2\). Show that \(\mathrm{Var}\,L = \tfrac12\big(\log(1 + \sqrt2)\big)^2 \approx 0.808\).
  3. For \(n = 1000\) and \(\delta = 0.05\), what weight and what dimension does the typical-subspace lemma guarantee for \(\Pi\), using Chebyshev? How many qubits, and what fidelity does the deck's encoder then guarantee?
  4. How large must \(n\) be for Chebyshev to guarantee weight \(0.99\) at \(\delta = 0.05\), and how many qubits does the encoder then use?
Hints · 3 rungs
Rung 1

Everything is about the binomial distribution of the number of factors \(e_2\) in an eigenvector of \(\rho^{\otimes n}\), and the Chebyshev bound \(1 - \sigma^2/(n\delta^2)\).

Rung 2

Part 1: eigenvalue \(\lambda_1^{3-k}\lambda_2^k\) with multiplicity \(\binom3k\). Part 2: for a two-valued \(L\), \(\mathrm{Var}\,L = \lambda_1\lambda_2(L_2 - L_1)^2\), and \(\lambda_1\lambda_2 = \tfrac18\), \(\lambda_1/\lambda_2 = \cot^2\tfrac\pi8 = (1 + \sqrt2)^2\). Part 3: the deck's encoder has fidelity \(\ge 2\operatorname{tr}(\Pi\rho^{\otimes n}) - 1\).

Rung 3

First line of part 2: "\(L_2 - L_1 = \log(\lambda_1/\lambda_2) = 2\log(1 + \sqrt2)\), so \(\mathrm{Var}\,L = \tfrac18\cdot4\log^2(1 + \sqrt2) = \tfrac12\log^2(1 + \sqrt2)\)."

Worked solution

Idea. The spectrum of \(n\) copies is a binomial distribution, and Chebyshev bounds its tails with one number, the variance of \(-\log\lambda\). The bound is honest but loose; the exact count, which the deck gives, is much better.

1. With \(\lambda_1 = 0.85355\), \(\lambda_2 = 0.14645\):

1\(\lambda_1^2\lambda_2 = 0.10669\)30.32008
2\(\lambda_1\lambda_2^2 = 0.01831\)30.05492

Sum \(0.62186 + 0.32008 + 0.05492 + 0.00314 = 1.00000\) ✓ — it is \((\lambda_1 + \lambda_2)^3\). Entropy: \(S(\rho^{\otimes3}) = 3S(\rho) = 1.8026\) by additivity; directly, \(-\sum(\text{mult})\lambda\log\lambda = 0.62186\times0.6853 + 3\times0.10669\times3.2284 + 3\times0.01831\times5.7716 + 0.00314\times8.3147\) \(= 0.4262 + 1.0333 + 0.3170 + 0.0261 = 1.8026\) ✓.

2. \(L\) takes \(L_1 = -\log\lambda_1 = 0.2284\) with probability \(\lambda_1\) and \(L_2 = -\log\lambda_2 = 2.7716\) with probability \(\lambda_2\). For a two-valued variable \(\mathrm{Var}\,L = \lambda_1\lambda_2(L_2 - L_1)^2\). Here \(\lambda_1\lambda_2 = \tfrac14\sin^2\tfrac\pi4 = \tfrac18\) and \(\lambda_1/\lambda_2 = \cot^2\tfrac\pi8 = (1 + \sqrt2)^2\), so \(L_2 - L_1 = 2\log(1 + \sqrt2) = 2\times1.27155 = 2.5431\) and \(\mathrm{Var}\,L = \tfrac18\times6.4674 = 0.8084\). (Its mean is \(S(\rho) = 0.601\), as it must be.)

3. Weight \(\operatorname{tr}(\Pi\rho^{\otimes1000}) \ge 1 - \dfrac{0.8084}{1000\times0.05^2} = 1 - 0.3234 = 0.677\). Dimension \(\le 2^{1000(0.6009 + 0.05)} = 2^{650.9}\), so \(651\) qubits. Fidelity \(\ge 2\times0.677 - 1 = 0.353\). (The exact weight of this typical subspace is \(0.927\), which the deck computed: fidelity \(\ge 0.853\). Chebyshev is far from tight.)

4. Need \(0.8084/(n\times0.0025) \le 0.01\), so \(n \ge 0.8084/(0.01\times0.0025) = 32\,337\) (rounding \(32\,336.96\) up). Then \(n(S + \delta) = 32\,337\times0.6509 = 21\,047.4\), so \(21\,048\) qubits for \(32\,337\) symbols, fidelity \(\ge 0.98\): rate \(0.651\).

Check. The rate \(0.651 = S + \delta\) is above \(S = 0.601\) by exactly the \(\delta\) chosen, and smaller \(\delta\) costs larger \(n\): halving \(\delta\) multiplies the required \(n\) by four. Schumacher's theorem is the statement that any rate above \(0.601\) is reachable this way.
