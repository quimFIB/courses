The terms this unit introduces, in the order the deck meets them. The slides
stay the definition of record; each entry names the slide it comes from, so a
term can be looked up here and read properly there.

Running example: one arbitrary rotation \(R_z(\theta)\) inside a circuit of
\(10^9\) gates that must come out within \(10^{-2}\) of the ideal. Errors add,
so each gate gets \(10^{-11}\), an angle accurate to \(2\times10^{-11}\) rad.
\(H\) and \(T\) reach the rotation through \(T\cdot HTH =
e^{i\pi/4}R_{\mathbf n}(\theta)\), \(\cos\frac\theta2 = \cos^2\frac\pi8 =
0.8536\), \(\theta = 0.3489\pi\), an irrational multiple of \(\pi\). It is not
one of the 24 Clifford rotations of the cube, so its cost is counted in \(T\)
gates. Solovay–Kitaev with this deck's constants needs six levels and about
\(4.7\times10^5\) gates; Ross and Selinger's optimal synthesis needs
\(3\log_2(10^{11}) = 109.6\), about 110 \(T\) gates.

* Distance, and errors that add

- finite gate set :: A finite set of unitaries on one or two qubits, from
  which circuits are built by placing gates on chosen wires. Forced by
  error correction, which protects only a finite menu; here \(\{H, S, T,
  \mathrm{CNOT}\}\). /Slide: Why a finite menu./
- operator norm :: \(\lVert A\rVert = \max_{\lVert v\rVert = 1}\lVert
  Av\rVert\). Submultiplicative, unitarily invariant, unchanged by tensoring
  with \(I\), and equal to \(\max|\lambda_i|\) for normal \(A\). \(\lVert
  R_{\mathbf n}(\theta) - I\rVert = 2\sin\frac\theta4\). /Slide: The operator
  norm./
- distance up to phase :: \(d(U, V) = \min_\alpha\lVert U -
  e^{i\alpha}V\rVert\). Outcome probabilities differ by at most \(2d(U, V)\).
  Safe for a gate on its wires; not for a gate that will be controlled, where
  the phase becomes relative: controlled-\(T\) and controlled-\(R_z(\frac\pi4)\)
  are \(0.196\) apart. /Slide: Global phase: when it may be dropped./
- errors add :: \(\lVert U_n\cdots U_1 - V_n\cdots V_1\rVert \le
  \sum_i\lVert U_i - V_i\rVert\) for unitaries, proved by telescoping. Nearly
  tight: \(n = 1000\) rotations by \(\delta = 10^{-3}\) give \(0.4948\) against
  the bound \(0.5000\). /Slide: Errors add along a circuit./
- hybrid argument :: Replacing the gates of one circuit by those of another
  one at a time, so that consecutive hybrids differ in a single gate; the
  triangle inequality then adds the single-gate differences.
- error budget :: The total error allowed for a whole circuit, split among
  its gates because errors add: \(10^9\) gates at \(10^{-2}\) give
  \(10^{-11}\) each. /Slide: Worked: the budget./

* Two gates reach everything

- dense :: \(D\subseteq SU(2)\) is dense if every element of \(SU(2)\) is
  within every \(\varepsilon \gt 0\) of some element of \(D\). The closure of a
  subgroup is a closed subgroup. /Slide: Dense subgroups, and the plan./
- approximately universal :: A finite gate set whose circuits approximate
  every unitary on any number of qubits, up to phase, to any accuracy. \(\{H,
  T, \mathrm{CNOT}\}\) is (Boykin et al. 2000).
- algebraic integer :: A root of a monic polynomial with integer
  coefficients. They form a ring (cited), and a rational one is an integer.
  \(1 + \frac{\sqrt2}2\) is not one, which makes the angle of \(T\cdot HTH\) an
  irrational multiple of \(\pi\). /Slide: Algebraic integers./
- root of unity :: A complex \(\zeta\) with \(\zeta^N = 1\) for some \(N\ge1\);
  a root of \(x^N - 1\), so an algebraic integer. If \(\theta/\pi\) were
  rational, \(e^{i\theta/2}\) would be one.

* The Clifford group

- Pauli group :: \(\mathcal P_n\), all \(i^kP_1\otimes\cdots\otimes P_n\) with
  \(P_j\in\{I, X, Y, Z\}\): \(4\cdot4^n\) elements. /Slide: Paulis, and the
  gates that permute them./
- Clifford group :: The unitaries \(U\) with \(U\mathcal P_nU^\dagger =
  \mathcal P_n\), up to global phase. Generated by \(H\), \(S\), CNOT (Gottesman
  1998, cited). On one qubit, the 24 rotations of a cube, permuting \(\pm x,
  \pm y, \pm z\). \(T\) is not in it: \(TXT^\dagger = (X + Y)/\sqrt2\).
- normaliser :: The normaliser of a subgroup \(K\) of a group \(G\) is
  \(\{g\in G : gKg^{-1} = K\}\). The Clifford group is the normaliser of the
  Pauli group in the unitary group, modulo phases.
- Clifford + T :: The gate set \(\{H, S, \mathrm{CNOT}, T\}\): the Clifford
  generators plus one non-Clifford gate. The standard universal set of
  error-corrected machines. /Slide: Clifford + T: the standard universal
  set./
- T-count :: The number of \(T\) and \(T^\dagger\) gates in a Clifford + \(T\)
  circuit, the figure of merit because each \(T\) is expensive in an
  error-corrected machine (unit 24). Unit 10's Toffoli has T-count 7.

* Solovay–Kitaev

- Solovay–Kitaev theorem :: For a finite, inverse-closed set generating a
  dense subgroup of \(SU(2)\), every element is within \(\varepsilon\) of a word
  of length \(O(\log^c(1/\varepsilon))\), \(c = \log5/\log\frac32 \approx 3.97\),
  found in time \(O(\log^{2.71}(1/\varepsilon))\) (Kitaev 1997; Solovay;
  Dawson–Nielsen 2006; analysis cited). /Slide: How long must the word be?/
- group commutator :: \(VWV^\dagger W^\dagger\), equal to \(I + [A, B] +
  O(\text{cubic})\) for \(V = e^A\), \(W = e^B\). Two rotations by \(\varphi\) about
  \(x\) and \(y\) give a rotation by about \(\varphi^2\) about an axis near
  \(z\). /Slide: Group commutators: a loop that fails to close./
- balanced commutator :: Every \(U\in SU(2)\) with \(\lVert U - I\rVert =
  \varepsilon\le1\) is \(VWV^\dagger W^\dagger\) with \(\lVert V - I\rVert =
  \lVert W - I\rVert \le 0.92\sqrt\varepsilon\). For \(U = R_z(0.02)\):
  \(\varphi = 0.1415\), distance \(0.0708\). /Slide: The balanced-commutator
  lemma./
- error squaring :: Approximating \(V\), \(W\) within \(\delta\) of the
  balanced pair moves their commutator by at most \(4r\delta + 4r^2\delta +
  2\delta^2\le10\varepsilon^{3/2}\) when \(r = \sqrt\varepsilon\), \(\delta =
  \varepsilon\). The engine of the recursion \(\varepsilon_k \le
  10\varepsilon_{k-1}^{3/2}\), \(l_k = 5l_{k-1}\). /Slide: Error squaring./

* Exact synthesis, and the price

- Z[1/√2, i] :: The ring \(\mathbb Z[\frac1{\sqrt2}, i]\) of integer
  combinations of \(2^{-j/2}i^k\); it contains \(\omega = e^{i\pi/4}\). Every
  entry of every Clifford + \(T\) circuit lies in it. Its field of fractions is
  \(\mathbb Q(\sqrt2, i)\). /Slide: Which unitaries Clifford + T makes
  exactly./
- exact synthesis :: Writing a unitary exactly as a Clifford + \(T\) circuit.
  Possible for a single-qubit unitary iff its entries lie in \(\mathbb
  Z[\frac1{\sqrt2}, i]\) (Kliuchnikov, Maslov and Mosca 2013, cited). \(HT\) is
  exactly synthesisable; \(R_z(\frac\pi{16})\) is not, even up to phase. Optimal
  ancilla-free approximation of \(R_z(\theta)\) then costs \(3\log_2(1/\varepsilon) +
  O(\log\log(1/\varepsilon))\) \(T\) gates (Ross and Selinger 2016, cited).
