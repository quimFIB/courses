The terms this unit introduces, in the order the deck meets them. The slides
stay the definition of record; each entry names the slide it comes from, so a
term can be looked up here and read properly there.

Running example: the three-qubit circuit \(C = (H\otimes H\otimes
I)\,\mathrm{Toffoli}_{01\to2}\,(H\otimes H\otimes I)\) on \(\ket{000}\),
accepting when the outcome is \(000\). Its acceptance probability
\(\frac9{16} = 0.5625\) is found three ways: as the state vector, whose
\(\ket{000}\) amplitude is \(\frac34\); as a sum over the \(2^4 = 16\) paths
through its four Hadamards, three of which end at \(000\), each with amplitude
\(+\frac14\), evaluated depth-first in 73 bits; and as \(g/2^h\) with \(g = 9\)
same-sign pairs of paths and \(h = 4\), so that \(2g - 2^h = 2 \gt 0\). Its first
half is a randomised computation (the AND of two coins); its last two Hadamards
make the three routes to \(000\) add as amplitudes, \(\frac9{16}\) where coins
would give \(\frac3{16}\).

* The class

- BQP :: Bounded-error quantum polynomial time: the languages \(L\) decided by
  a uniform family of quantum circuits over a fixed finite universal gate set
  (here \(\{H, T, \mathrm{CNOT}\}\)), run on \(\ket{x, 0\cdots0}\) with qubit 0
  measured, accepting with probability \(\ge\frac23\) when \(x\in L\) and
  \(\le\frac13\) when \(x\notin L\), on every input. Independent of the gate
  set and of the constant \(\frac13\). Contains BPP, contained in PP and in
  PSPACE. /Slide: BQP./
- uniform circuit family :: A sequence \((C_n)\) of circuits, \(C_n\) acting on
  \(n + a(n)\) qubits with gates from a fixed finite set, such that a
  deterministic Turing machine prints a description of \(C_n\) from \(1^n\) in
  time polynomial in \(n\). Uniformity forces polynomial size, and rules out
  families that decide undecidable languages by encoding one uncomputable bit
  per length. /Slide: A circuit family, and who builds it./
- amplification :: Running a bounded-error circuit \(k\) times on independent
  registers and taking the majority, computed reversibly into one output qubit.
  With error \(\le\frac13\) per run, Hoeffding's inequality bounds the
  majority's error by \(e^{-k/18}\); error \(2^{-100}\) needs \(k = 1248\).
  /Slide: The constant does not matter: majority of k runs./
- low for itself :: A class \(\mathsf C\) is low for itself when
  \(\mathsf C^{\mathsf C} = \mathsf C\): machines in \(\mathsf C\) gain nothing
  from an oracle for any language in \(\mathsf C\). BQP is (Bennett, Bernstein,
  Brassard and Vazirani 1997, cited); the key step is compute, copy, uncompute,
  which leaves a subroutine within \(\sqrt{2\varepsilon}\) of a clean oracle when
  its error is \(\varepsilon\). /Slide: Using an answer without measuring it./

* Simulation by keeping every amplitude

- state-vector simulation :: Classical simulation of a circuit on \(m\)
  qubits by storing all \(2^m\) amplitudes and updating them gate by gate; a
  gate on qubit \(q\) mixes the pairs of amplitudes whose indices differ in bit
  \(q\). Time \(O(T\,2^m)\), memory \(2^m\) numbers (18.0 PB at \(m = 50\) in
  double precision). Proves BQP \(\subseteq\) EXP. /Slide: Pushing a vector
  through the gates./
- EXP :: The languages decided by a deterministic Turing machine in time
  \(2^{q(n)}\) for some polynomial \(q\). Contains PSPACE; strictly contains P
  by the time hierarchy theorem (cited). /Slide: Pushing a vector through
  the gates./

* Paths, and polynomial space

- PSPACE :: The languages decided by a deterministic Turing machine using at
  most \(q(n)\) tape cells, \(q\) a polynomial, with no bound on time. Contains
  NP and PP (enumerate certificates, reusing space) and BQP (sum over paths
  depth-first); contained in EXP. Whether P = PSPACE is open. /Slide: PSPACE:
  polynomial memory, any amount of time./
- real-amplitude encoding :: The map \(a + ib \mapsto a\otimes\ket0 +
  b\otimes\ket1\) onto one extra qubit, under which a gate \(U = A + iB\)
  (\(A, B\) real) acts as the real orthogonal \(\tilde U = A\otimes I +
  B\otimes J\), \(J = \begin{pmatrix}0&-1\\1&0\end{pmatrix}\). Outcome
  probabilities are unchanged, so complex amplitudes cost one qubit. /Slide:
  First, make every gate a coin or a permutation./
- path :: For a circuit \(G_T\cdots G_1\) started at \(\ket s\), a sequence of
  basis strings \(s = z_0, z_1, \dots, z_T\), with amplitude
  \(\prod_t\bra{z_t}G_t\ket{z_{t-1}}\). With only \(H\) and permutation gates,
  the non-zero paths are labelled by the \(h\) bits chosen at the Hadamards,
  and each has amplitude \(\pm2^{-h/2}\), its sign and endpoint computable in
  polynomial time. /Slide: A path through a circuit./
- path sum :: \(\bra zC\ket s = \sum_{\text{paths ending at }z}\prod_t
  \bra{z_t}G_t\ket{z_{t-1}}\), from inserting the resolution of the identity
  between the gates: Feynman's sum over histories for a circuit. Evaluated
  depth-first it needs only polynomial memory. /Slide: A path through a
  circuit./

* Counting, with signs

- #P :: The functions \(f(x) = \#\{y\in\{0,1\}^{p(|x|)} : R(x, y)\}\) for a
  polynomial-time predicate \(R\): counting certificates, for example the
  satisfying assignments of a formula (Valiant 1979). /Slide: #P and GapP./
- GapP :: Differences of two #P functions; equivalently, signed sums
  \(\sum_y s(x, y)\) with \(s\) polynomial-time and valued in \(\{-1, 0, 1\}\).
  Closed under negation, sums, products, sums over exponentially many
  arguments, and contains \(2^{q(|x|)}\). The acceptance probability of a
  Hadamard-and-Toffoli circuit is \(g(x)/2^h\) with \(g\in\) GapP. /Slide:
  #P and GapP./
- PP :: Probabilistic polynomial time: \(x\in L\) iff more than half of the
  certificates \(y\in\{0,1\}^{p(|x|)}\) satisfy \(R(x, y)\), with no gap
  required; equivalently, iff \(F(x) \gt 0\) for some \(F\in\) GapP. Contains
  NP and BQP, contained in PSPACE, closed under complement. /Slide: PP: more
  than half, with no gap required./
- PostBQP :: BQP with postselection: a circuit with an extra qubit that must
  read 1 with non-zero probability, correct with probability \(\ge\frac23\)
  conditioned on that event. Aaronson (2005, cited) proved PostBQP = PP; NP
  \(\subseteq\) PostBQP is the first step. /Slide: Why PP is probably far
  larger than BQP./

* The placement

- polynomial hierarchy :: \(\mathsf{PH} = \bigcup_k\Sigma_k^{\mathsf p}\),
  where \(L\in\Sigma_k^{\mathsf p}\) iff \(x\in L \iff \exists y_1\forall
  y_2\cdots Q_ky_k\,R(x, y_1, \dots, y_k)\) with polynomial-length \(y_i\) and
  polynomial-time \(R\). \(\Sigma_1^{\mathsf p} = \) NP. Contained in PSPACE;
  relative to some oracle, BQP is not contained in it (Raz and Tal 2019,
  cited). /Slide: The polynomial hierarchy, and what an oracle is./
- oracle :: A fixed language \(A\) that a machine may query at unit cost; a
  quantum circuit queries it with the gate \(U_A\ket{y, b} = \ket{y, b\oplus
  A(y)}\), possibly on a superposition of \(y\)'s. A proof that works relative
  to every oracle relativises, and cannot prove a statement that fails relative
  to some oracle. /Slide: The polynomial hierarchy, and what an oracle is./
