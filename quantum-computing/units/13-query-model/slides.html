Part D is about algorithms: what interference buys a computation, and where it stops buying anything. It opens here, in the query model, for a reason that is about proof rather than taste. Nobody can prove that a quantum computer outperforms a classical one on any problem measured in gates — such a proof would settle questions in classical complexity theory that have been open for decades. In the query model, where an algorithm pays only for looking at its input, lower bounds can be proved, and so separations can be proved. Every claim of "quantum speed-up" in Part D is, at bottom, a query-model statement.

This unit proves the one trick every Part D algorithm uses — phase kickback — and runs the first three algorithms on it: Deutsch, Deutsch–Jozsa and Bernstein–Vazirani. Each beats some classical model. The unit's discipline is to say exactly which one, because the history of the subject is partly a history of speed-ups that evaporated when the classical side was allowed coins.

What this unit is not: it does not define BQP (unit 12) or prove an exponential separation against randomised algorithms (unit 14, Simon). Its separations are against weaker models, and its last slide says so.

A box that hides one string

the running example: $f(x) = s\cdot x$, $s = 101$

A box computes $f:\{0, 1\}^3\to\{0, 1\}$, $\ f(x) = s\cdot x$, for a string $s$ we are not shown. Here $x\cdot y$ is the dot product mod 2, $x_0y_0\oplus x_1y_1\oplus x_2y_2$; with $s = 101$, $\ f(x) = x_0\oplus x_2$.

We may only ask: give the box $x$, get $f(x)$ back. Two questions:

1. Is $f$ constant, or balanced — $1$ on exactly half the inputs?
2. What is $s$?

How many questions does each cost? Classically, the second takes three. Quantumly, one query answers both.

13 · the query model

Why count queries

A speed-up is a lower bound. To say a quantum algorithm beats every classical one is to prove that no classical algorithm is as fast — a statement about all algorithms at once.

what cannot be proved, yet

For Boolean circuits, the best lower bound known for any explicit function is $3.1n - o(n)$ gates (Li and Yang 2022, cited): linear. A superpolynomial bound for a function in NP would prove $\mathrm P\ne\mathrm{NP}$. Gate-count separations between quantum and classical are out of reach for the same reason.

what can

In the query model the input is reachable only through a box, and an algorithm is charged one unit per call to it. Everything between calls is free.

Then what the algorithm knows after $k$ calls is a function of $k$ answers — and counting what $k$ answers can distinguish gives provable lower bounds. Separations are proved here.

The price. A query bound counts calls, not gates. Upper bounds transfer to gates when the box is efficient — unit 10 makes every polynomial-time $f$ a polynomial-size oracle. Lower bounds do not: an algorithm that may open the box might do better.

The circuit lower bounds, cited. For circuits over the full binary basis (all sixteen two-input gates), Blum proved $3n - o(n)$ for an explicit function in 1984; Find, Golovnev, Hirsch and Kulikov raised it to $(3 + \tfrac1{86})n - o(n)$ in 2016; Li and Yang to $3.1n - o(n)$ (STOC 2022), for affine dispersers, functions computable in polynomial time. Nothing superlinear is known for any function in NP. If some NP function needed superpolynomial circuits, then $\mathrm P\ne\mathrm{NP}$, since polynomial time gives polynomial-size circuits (unit 10, from the background).

Why quantum gate-count separations are harder still. Unit 12 shows that a proof that quantum polynomial time exceeds classical randomised polynomial time would separate P from PSPACE — also open. So an unconditional proof that a quantum computer is faster at some problem, counted in gates, is out of reach. In the query model there is no such barrier.

What a query separation means. It says: an algorithm that treats $f$ as a black box needs this many calls. It is a real statement about the world whenever $f$ is given as a black box — a physical process, a database, a subroutine one cannot inspect. When $f$ comes from an efficient circuit one can inspect, a query separation is evidence, not proof. Units 12 and 14 make that precise with oracle separations of complexity classes.

13 · the query model

The input is a function, the access is an oracle

the input, and one query

The input is $f:\{0, 1\}^n\to\{0, 1\}$ — equivalently its truth table, a string of $N = 2^n$ bits. A quantum algorithm reaches it only through unit 10's oracle

$$U_f\ket x\ket y = \ket x\ket{y\oplus f(x)},$$

one query per application. $U_f$ permutes basis states, so it is unitary; and $U_f^2 = I$, since $(y\oplus f(x))\oplus f(x) = y$.

The running example opened. Two CNOTs, from qubits 0 and 2 to the target, add $x_0\oplus x_2 = f(x)$. Check on basis inputs:

$U_f\ket{100}\ket0 = \ket{100}\ket1$, as $f(100) = 1$; $\ U_f\ket{101}\ket0 = \ket{101}\ket0$, as $f(101) = 1\oplus1 = 0$ ✓.

Inside the box for $s = 101$. The algorithm never sees this: it may only apply the whole box.

Why not $\ket x\mapsto\ket{f(x)}$? It is not injective whenever $f$ is not, so it is not unitary. Keeping $x$ and adding the answer into a fresh register is the reversible version (unit 10, Every polynomial-time function is a polynomial-size oracle). A function with $m$-bit values has the same oracle with an $m$-qubit target; this unit needs only $m = 1$.

Unitarity, in full. On basis vectors $U_f\ket{x, y} = \ket{x, y\oplus f(x)}$. The map $(x, y)\mapsto(x, y\oplus f(x))$ is a bijection of $\{0, 1\}^{n+1}$ — it is its own inverse — so $U_f$ is a permutation matrix, whose columns are orthonormal. It is also real and symmetric (a permutation that is its own inverse), so Hermitian. Its eigenvalues are therefore $\pm1$, a fact the next section turns into an algorithm.

The running example's oracle, checked on all eight inputs with $y = 0$. The first CNOT adds $x_0$, the second adds $x_2$, so the target ends at $x_0\oplus x_2$: $0, 1, 0, 1, 1, 0, 1, 0$ for $x = 000, \dots, 111$, which is $s\cdot x$ for $s = 101$ ✓. In general $U_f$ for $f = s\cdot x$ is one CNOT from each qubit $i$ with $s_i = 1$ — no work qubits, so no garbage.

13 · the query model

Quantum query algorithms

a query algorithm with $T$ queries

Fixed unitaries $U_0, \dots, U_T$, independent of $f$, on input, target and work registers. On $f$ it prepares

$$\ket{\psi_f} = U_T\,\tilde U_f\,U_{T-1}\cdots\tilde U_f\,U_0\ket{0\cdots0},$$

with $\tilde U_f = U_f\otimes I_{\rm work}$, and measures an output register. It computes $F$ with error $\varepsilon$ if, on every allowed $f$, the output is $F(f)$ with probability $\ge 1 - \varepsilon$; exactly if $\varepsilon = 0$.

Query complexity: $Q_E(F)$ and $Q_\varepsilon(F)$, the least $T$ for exact and for error-$\varepsilon$ algorithms. Gates are free; only calls count.

asking every $x$ at once is not the trick

$U_f$ on $2^{-n/2}\sum_x\ket x\ket0$ gives $2^{-n/2}\sum_x\ket x\ket{f(x)}$ — and measuring it yields one random pair $(x, f(x))$, exactly what one random classical query gives. The gain must come from interference.

Measurement at the end only. Unit 10's principle of deferred measurement lets any intermediate measurement be replaced by a controlled gate and a final measurement, so this definition loses nothing. The $U_j$ may use any number of gates, of any kind; that is what "query complexity counts only oracle calls" means.

Promise problems. $F$ need not be defined on every $f$. Deutsch–Jozsa will promise that $f$ is constant or balanced and say nothing about other $f$; an algorithm is then judged only on the allowed $f$. Such an $F$ is a partial function of the truth table, and its classical analogue is a promise problem from the background.

The warning, computed. The state $2^{-n/2}\sum_x\ket x\ket{f(x)}$ has $\Pr(x, b) = 2^{-n}$ when $b = f(x)$ and $0$ otherwise, summing to $2^n\cdot2^{-n} = 1$. So a measurement in the computational basis returns a uniformly random $x$ with its value — "quantum parallelism" alone is a random classical query. Every algorithm in Part D works by arranging for the $2^n$ terms to interfere before anything is measured, so that the amplitudes pile up on an answer that depends on all of $f$.

13 · the query model

Classical query algorithms: decision trees

a decision tree

A rooted binary tree. Each internal node names an $x$ to query; its two children are followed on the answers $f(x) = 0$ and $1$; each leaf names an output. On $f$, walk from the root along the answers; output the leaf.

Its cost is its depth, the most queries on any path. The deterministic query complexity $D(F)$ is the least depth of a tree correct on every allowed $f$.

Every deterministic algorithm is one: with free computation between calls, it is determined by which $x$ it asks next given the answers so far.

The running example. $f(e_i) = s\cdot e_i = s_i$ for the unit strings $e_i$, so asking $100, 010, 001$ reads off $s$: $1, 0, 1$. Depth $3$.

The tree that finds $s$ for $n = 3$. On $s = 101$ the answers $1, 0, 1$ lead to the leaf $101$.

Why trees capture every deterministic algorithm. Fix any deterministic procedure that may compute freely and calls the box. Its first query is fixed (it has seen nothing); its second depends only on the first answer; its $j$-th only on the first $j - 1$ answers; and its output only on all of them. Drawing the possible answer sequences as paths gives a tree whose depth is the worst-case number of calls. Repeated queries can be pruned without increasing depth, so we may assume no path asks the same $x$ twice.

Adaptivity. In general a node's query depends on the path to it. The tree on this slide happens to ask the same three strings on every path: it is non-adaptive. Section 5 proves that for this problem no tree, adaptive or not, does better.

Multi-bit answers. For $f$ with $m$-bit values each node has $2^m$ children. The counting arguments below then give $2^{mk}$ leaves at depth $k$.

13 · the query model

Randomised query algorithms

a randomised decision tree

A probability distribution $\mu$ over decision trees: flip the coins first, then run the chosen tree. It computes $F$ with error $\varepsilon$ if for every allowed $f$,

$$\Pr_{T\sim\mu}\big[T(f)\ne F(f)\big]\le\varepsilon .$$

Its cost is the greatest depth among the trees it may choose. The randomised query complexity $R_\varepsilon(F)$ is the least cost.

Bounded error means $\varepsilon = \tfrac13$; a majority of $r$ independent runs drives the error down exponentially in $r$, as for BPP.

Coins choose a tree; the error is measured over the coins, never over the inputs.

how the models compare

$Q_\varepsilon(F)\le R_\varepsilon(F)\le D(F)$ and $Q_E(F)\le D(F)$. A separation is a family $F_n$ on which one of these is far below another.

Coins in advance. An algorithm that flips coins as it goes can flip them all at the start — it uses at most finitely many — and then behaves deterministically. Each coin string fixes a tree, so the algorithm is a distribution over trees.

Full proof of the comparisons. $R_\varepsilon\le D$: a deterministic tree is a distribution on one tree, with error $0$. $Q_E\le D$: run the tree reversibly. To ask $x$, write $x$ into the input register (a classical reversible circuit, unit 10), apply $U_f$ to $\ket x\ket0$, and read the answer from the target; the choice of the next $x$ from the answers so far is a classical function, so unit 10 computes it reversibly too. On a basis state everything stays a basis state, the answers are exact, and the number of oracle calls is the depth. $Q_\varepsilon\le R_\varepsilon$: put a coin register in $\ket+^{\otimes r}$ — each coin string with probability $2^{-r}$, when $\mu$ is uniform on $2^r$ coin strings — and run, controlled on the coins, the tree they choose. Branches with different coin strings carry orthogonal records, so their probabilities add (unit 10's garbage principle, here used on purpose), and the output distribution is the classical one. Coins with probabilities that are not dyadic are never a problem: $U_0$ may be any unitary, so it can prepare $\sum_T\sqrt{\mu(T)}\ket T$ on the coin register directly.

Why only bounded error matters. If one run errs with probability $\varepsilon\lt\tfrac12$, the majority of $r$ independent runs errs with probability at most $e^{-2r(1/2 - \varepsilon)^2}$ (Hoeffding, from the background). So $R_{1/3}$ and $R_{0.001}$ differ by a constant factor, and "bounded error" names one class of algorithms whatever constant is chosen. Exact algorithms ($\varepsilon = 0$) are a different matter, as section 4 will show.

Why lower bounds can be proved here

three tools

1. A fooling pair. If $f, f'$ agree at every $x$ a tree asks on $f$'s path, they reach the same leaf; so if $F(f)\ne F(f')$ the tree is wrong on one. An adversary argument answers queries so as to keep such a pair alive.

2. Counting leaves. A depth-$k$ tree has at most $2^k$ leaves, so it outputs at most $2^k$ different values.

3. Averaging. If every depth-$k$ tree is right with probability at most $p$ on an $f$ drawn from a distribution $\nu$, then every randomised algorithm of depth $k$ is right with probability at most $p$ on some $f$.

A fooling pair: the tree asks three positions; elsewhere the inputs may differ unseen.

proof of 3

$\mathbb E_{f\sim\nu}\Pr_{T\sim\mu}[\text{right}] = \mathbb E_{T\sim\mu}\Pr_{f\sim\nu}[\text{right}]\le p$, and an average is at least its smallest term. $\blacksquare$

Proofs of 1 and 2. (1) The walk on $f$ is determined by the answers on its path; $f'$ gives the same answers there, so it takes the same walk, and the leaf has one label. (2) Induction on depth: a tree of depth $0$ is one leaf; a tree of depth $k$ is a root and two subtrees of depth at most $k - 1$, so at most $2\cdot2^{k-1}$ leaves.

Why these work and circuit lower bounds do not. A query algorithm's knowledge of its input is bottlenecked through the answers it has received — a channel of one bit per query — and both tools count what can pass through that channel. A circuit has the whole input from the start; there is no channel to count, and the only known lower-bound techniques for general circuits stall at small linear bounds.

Tool 3 is the easy half of Yao's minimax principle (A. C. Yao, 1977): the best randomised algorithm's worst-case success is at most the best deterministic algorithm's average success under any input distribution. The swap of expectations is legitimate because both distributions are finite. The hard half — that some $\nu$ makes this tight — is not used in this course.

Quantum lower bounds need different tools, because a quantum algorithm's state after $k$ queries is not a function of $k$ classical answers. Unit 18 builds them: the polynomial method and the adversary method.

Phase kickback

$\ket- = \tfrac1{\sqrt2}(\ket0 - \ket1)$ is an eigenvector of $X$: $\ X\ket- = \tfrac1{\sqrt2}(\ket1 - \ket0) = -\ket-$. And adding $f(x)$ into the target is $X^{f(x)}$ on it.

lemma: phase kickback $$U_f\big(\ket x\ket-\big) = (-1)^{f(x)}\ket x\ket- .$$
proof

$U_f(\ket x\ket b) = \ket x\,X^{f(x)}\ket b$, so $U_f(\ket x\ket-) = \ket x\,X^{f(x)}\ket- = (-1)^{f(x)}\ket x\ket-$. $\blacksquare$

By linearity, on any input state:

$$U_f\big(\textstyle\sum_x a_x\ket x\big)\ket- = \big(\textstyle\sum_x(-1)^{f(x)}a_x\ket x\big)\ket- .$$

Check: the norm is $\sum_x|a_x|^2$ before and after ✓.

The gate acts on the target, yet the target is unchanged and the input picks up the sign.

why it matters

The value $f(x)$ is now a relative phase between the terms of a superposition — invisible to a direct measurement, but able to interfere.

The name. One expects the oracle to act on its target and leave its input alone, as it does on basis states. On $\ket-$ the roles reverse: the target is an eigenvector, so it is untouched, and the eigenvalue $(-1)^{f(x)}$ is "kicked back" onto the input. The term and the one-query form of the algorithms below are from R. Cleve, A. Ekert, C. Macchiavello and M. Mosca, "Quantum algorithms revisited", Proc. R. Soc. Lond. A 454, 339 (1998).

The general pattern. If $\ket u$ is an eigenvector of a unitary $V$ with $V\ket u = e^{i\theta}\ket u$, then the controlled gate $C(V)$ sends $(\alpha\ket0 + \beta\ket1)\ket u$ to $(\alpha\ket0 + \beta e^{i\theta}\ket1)\ket u$: the eigenvalue moves to the control as a relative phase. Here $V = X$, $\ket u = \ket-$, $e^{i\theta} = -1$, and the oracle is a CNOT controlled by "$f(x) = 1$". Unit 15's phase estimation is the same move with a general $V$.

Unit 10 saw this coming. Its slide The Toffoli gate, as a matrix noted that the Toffoli multiplies $\ket{ab}\ket-$ by $(-1)^{ab}$: phase kickback for $f(a, b) = ab$.

Preparing $\ket-$. Start the target in $\ket1$ and apply $H$: $H\ket1 = \tfrac1{\sqrt2}(\ket0 - \ket1) = \ket-$. Every circuit below does this.

Worked: phase kickback, every line

$U_f = \mathrm{CNOT}_{03}\,\mathrm{CNOT}_{23}$, target in $\ket-$

(a) $x = 100$. Expand the target:

$$\ket{100}\ket- = \tfrac1{\sqrt2}\big(\ket{100}\ket0 - \ket{100}\ket1\big).$$

$\mathrm{CNOT}_{03}$ fires ($x_0 = 1$) and flips the target in both terms:

$$\tfrac1{\sqrt2}\big(\ket{100}\ket1 - \ket{100}\ket0\big) = -\ket{100}\ket- .$$

$\mathrm{CNOT}_{23}$ does nothing ($x_2 = 0$). Result $-\ket{100}\ket-$, and $(-1)^{f(100)} = (-1)^1$ ✓.

(b) $x = 101$. Both CNOTs fire; each gives a factor $-1$: $\ (-1)(-1)\ket{101}\ket- = +\ket{101}\ket-$, and $f(101) = 0$ ✓.

(c) A superposition. By linearity, from (a) and (b):

$$\tfrac1{\sqrt2}\big(\ket{100} + \ket{101}\big)\ket-\ \mapsto$$ $$\tfrac1{\sqrt2}\big(-\ket{100} + \ket{101}\big)\ket- .$$

Norm $\tfrac12 + \tfrac12 = 1$ ✓. The input is $\ket{10}\otimes\tfrac1{\sqrt2}(-\ket0 + \ket1) = -\ket{10}\ket-$ on qubits $0, 1, 2$.

(d) The sign is visible. $H$ on qubit 2 now gives $-\ket{10}\ket1$: it reads $1$ with certainty. Without the oracle the input was $\ket{10}\ket+$, and $H$ gives $\ket{10}\ket0$: it reads $0$.

In (a) and (b) the sign is a global phase, invisible; in (c) it is relative, and one Hadamard reads it.

Every CNOT kicks its own sign. With the target in $\ket-$, $\mathrm{CNOT}_{i3}$ multiplies $\ket x\ket-$ by $(-1)^{x_i}$. The oracle is a product of such CNOTs, one for each $i$ with $s_i = 1$, so it multiplies by $\prod_{i:\,s_i = 1}(-1)^{x_i} = (-1)^{s\cdot x}$. Phase kickback for a linear $f$ is therefore a product of one-qubit phases $Z^{s_i}$ on the input qubits — which is why section 5's algorithm never entangles anything.

The bookkeeping in (c). $\tfrac1{\sqrt2}(-\ket{100} + \ket{101}) = \ket1\otimes\ket0\otimes\tfrac1{\sqrt2}(-\ket0 + \ket1)$ and $\tfrac1{\sqrt2}(-\ket0 + \ket1) = -\ket-$. Then $H\ket- = \ket1$, so $H$ on qubit 2 gives $-\ket{101}$, a basis state up to the global phase $-1$, and qubit 2 reads 1 with probability $1$. The probability distribution of qubit 2 went from $(1, 0)$ to $(0, 1)$, both summing to one, because of one sign.

A warning about global phase. In (a) the state $-\ket{100}\ket-$ is the same physical state as $\ket{100}\ket-$ (unit 01). One query on a single basis state therefore learns nothing in phase-kickback form — the classical way of asking (target $\ket0$) is the right one there. The sign only means something next to another term with a different sign.

13 · phase kickback

The phase oracle

the phase oracle $$O_f\ket x = (-1)^{f(x)}\ket x .$$

Kickback builds it from one query to $U_f$ and an ancilla in $\ket-$, which leaves unentangled.

Checks. $O_f$ is diagonal with entries $\pm1$: real, so Hermitian; of modulus one, so unitary; and $O_f^2 = I$ ✓.

two cautions

A lost bit. $O_{1\oplus f} = -O_f$, a global phase: $O_f$ alone cannot tell $f$ from its complement. No problem here asks it to; problem P2 restores the bit with a control qubit.

Clean oracles only. If $U_f$ leaves garbage $\ket{g(x)}$, the sign sits on $\ket x\ket{g(x)}$, and terms with orthogonal garbage no longer interfere — unit 10's Garbage destroys interference. Problem P10.

The running example's phase oracle: its diagonal is eight signs, four of each.

The running example. $O_f = \mathrm{diag}(1, -1, 1, -1, -1, 1, -1, 1)$, and as the last example showed, it equals $Z\otimes I\otimes Z$: a phase $(-1)^{x_0}$ times a phase $(-1)^{x_2}$.

Kickback as an identity of operators. Kickback says $U_f(I\otimes\ket-) = O_f\otimes\ket-$ as maps from the input space: on the subspace where the target is $\ket-$, the bit oracle acts as the phase oracle. So any algorithm written with $O_f$ can be run with $U_f$ at the same number of queries, plus one ancilla.

The complement. $O_{1\oplus f}\ket x = (-1)^{1\oplus f(x)}\ket x = -(-1)^{f(x)}\ket x$, so $O_{1\oplus f} = -O_f$. A global phase cannot be observed (unit 01), so no algorithm using $O_f$ alone can distinguish $f$ from $1\oplus f$. But $U_f$ can: one classical query with target $\ket0$ returns $f(x)$, which differs from $1\oplus f(x)$. The fix (problem P2) is the controlled phase oracle $\ket b\ket x\mapsto(-1)^{b\,f(x)}\ket b\ket x$, which turns the global sign into a relative one on the control.

The garbage, quantitatively. Suppose $U_f\ket x\ket y\ket0 = \ket x\ket{y\oplus f(x)}\ket{g(x)}$. Then kickback gives $\sum_x a_x(-1)^{f(x)}\ket x\ket{g(x)}\ket-$, and measuring the input register in any basis weights each cross term between $x$ and $x'$ by $\braket{g(x)|g(x')}$. With orthogonal garbage every cross term dies, and the input behaves as if each $x$ had been measured — the which-path detector of unit 01. Bennett's uncomputation (unit 10) is exactly what prevents this.

13 · Deutsch

Deutsch's problem in an interferometer

The experiment, recalled from unit 01. One photon at a time meets a half-silvered mirror, travels one of two paths, meets a second half-silvered mirror, and is caught by detector $D_0$ or $D_1$. A glass slab in path 1 delays it there by a phase $\varphi$, and the clicks follow the fringes $P(D_0) = \sin^2\tfrac\varphi2$, $\ P(D_1) = \cos^2\tfrac\varphi2$.

Now hide a bit in each path. Someone places in path $b$ either nothing or a slab of phase $\pi$ — that is, phase $\pi f(b)$ — for an unknown $f:\{0, 1\}\to\{0, 1\}$.

Up to a global phase the paths differ by $\varphi = \pi\big(f(1) - f(0)\big)$, so

$$P(D_0) = \sin^2\tfrac{\pi(f(1) - f(0))}{2} = f(0)\oplus f(1).$$

One photon, through both slabs, says whether they are equal. Looking at one slab says nothing about it.

Unit 01's Mach–Zehnder interferometer with a slab that may or may not be there in each path.

Check the four cases: slabs $(0,0)$ and $(\pi,\pi)$ send the photon to $D_1$; $(0,\pi)$ and $(\pi,0)$ to $D_0$. Each distribution sums to one ✓.

The computation. The photon enters path 0. With unit 01's beam splitter $B = \tfrac1{\sqrt2}\begin{pmatrix}1 & i\\ i & 1\end{pmatrix}$ and slabs $\mathrm{diag}(e^{i\pi f(0)}, e^{i\pi f(1)}) = e^{i\pi f(0)}\,\mathrm{diag}(1, e^{i\varphi})$, $\varphi = \pi(f(1) - f(0))$, the output is $e^{i\pi f(0)}$ times unit 01's state $\tfrac12\big[(1 - e^{i\varphi})\ket0 + i(1 + e^{i\varphi})\ket1\big]$, whose probabilities are $\sin^2\tfrac\varphi2$ and $\cos^2\tfrac\varphi2$. For $\varphi = 0$ that is $(0, 1)$; for $\varphi = \pm\pi$ it is $(1, 0)$. The global factor $e^{i\pi f(0)} = \pm1$ changes nothing.

Why this is the right picture. A slab of phase $\pi f(b)$ in path $b$ is exactly the phase oracle $O_f$ acting on the photon's path qubit. The first beam splitter puts the photon into both paths, so it "consults" both slabs; the second recombines the paths so that the relative sign decides the detector. What comes out is one bit, the parity — never both values of $f$. That is the shape of every algorithm in Part D: a single global property of $f$, extracted by interference, and nothing more.

Classically. A slab is a physical object; to learn whether two unknown slabs are equal by examining them one at a time, one must examine both. The photon examines neither separately.

History. D. Deutsch, "Quantum theory, the Church–Turing principle and the universal quantum computer", Proc. R. Soc. Lond. A 400, 97 (1985), posed the problem and gave the first algorithm that beat classical query counting on it — though, in that version, only with probability $\tfrac12$.

Deutsch's algorithm

theorem: Deutsch's algorithm

For $f:\{0, 1\}\to\{0, 1\}$, the circuit below outputs $f(0)\oplus f(1)$ with probability $1$, using one query.

proof

$\psi_1 = H\ket0\otimes H\ket1 = \ket+\ket-$. By kickback,

$$\psi_2 = \tfrac1{\sqrt2}\big((-1)^{f(0)}\ket0 + (-1)^{f(1)}\ket1\big)\ket-$$ $$= (-1)^{f(0)}\,\tfrac1{\sqrt2}\big(\ket0 + (-1)^{f(0)\oplus f(1)}\ket1\big)\ket-,$$

which is $\pm\ket+\ket-$ if $f(0) = f(1)$ and $\pm\ket-\ket-$ if not. Since $H\ket+ = \ket0$ and $H\ket- = \ket1$,

$$\psi_3 = (-1)^{f(0)}\ket{f(0)\oplus f(1)}\ket- .\qquad\blacksquare$$

The interferometer as a circuit: $H$ is the splitter, the oracle is the slabs, the meter is the detectors.

Check: $\psi_3$ is a basis state up to the global phase $\pm1$, so the outcome distribution is $(1, 0)$ or $(0, 1)$, summing to one ✓.

The Deutsch problem: decide $f(0)\oplus f(1)$ — whether $f$ is constant — with as few queries as possible.

The middle step in full. $\psi_1 = \tfrac1{\sqrt2}(\ket0 + \ket1)\ket-$. Kickback on each term: $\ket0\ket-\mapsto(-1)^{f(0)}\ket0\ket-$ and $\ket1\ket-\mapsto(-1)^{f(1)}\ket1\ket-$. Factor out $(-1)^{f(0)}$: the coefficient of $\ket1$ becomes $(-1)^{f(1) - f(0)} = (-1)^{f(0)\oplus f(1)}$, since $f(1) - f(0)$ and $f(0)\oplus f(1)$ have the same parity.

Interferometer and circuit, compared. Unit 01's beam splitter $B$ and the Hadamard differ by phases on the paths: $B = R_x(-\tfrac\pi2)$, a quarter-turn about $x$, while $H$ is a reflection; both map a path to an equal-weight superposition of both paths. Any such pair works, and changes only which detector means "equal": in the interferometer $D_1$ fires on equal slabs, in the circuit the meter reads $0$. The circuit's choice is the one that generalises to $n$ qubits.

The four functions, as circuits. $f\equiv0$: no gate. $f\equiv1$: $X$ on the target. $f = \mathrm{id}$: a CNOT. $f = \mathrm{not}$: a CNOT then $X$ on the target. The next slide runs all four.

Classically, two queries

theorem

Every deterministic algorithm for Deutsch's problem makes $2$ queries. Every one-query randomised algorithm is right with probability at most $\tfrac12$ on some $f$.

proof

Deterministic: one query sees $f(b)$ for one $b$. Flipping $f(1 - b)$ changes the parity and not the answer: a fooling pair.

Randomised: take $f$ uniform over the four. Whatever $b$ a tree asks, $f(1 - b)$ is a fair coin independent of $f(b)$, so each one-query tree is right on exactly $2$ of the $4$ functions. Averaging gives an $f$ with success $\le\tfrac12$. $\blacksquare$

So $D = 2$, $\ R_\varepsilon = 2$ for every $\varepsilon\lt\tfrac12$, $\ Q_E = 1$. A factor of two, against every classical model.

After one classical query, two functions remain on each branch, with opposite parities.

The randomised bound in full. A one-query tree asks some $b$ and outputs a bit $g(f(b))$. Under the uniform distribution on the four functions, $f(b)$ and $f(1 - b)$ are independent fair bits, so the parity $f(0)\oplus f(1)$ is a fair bit independent of $f(b)$, and $\Pr[g(f(b)) = f(0)\oplus f(1)] = \tfrac12$ exactly. Every tree in the support of $\mu$ has success $\tfrac12$ on average over $f$, so $\mu$ does too, and the averaging tool gives an $f$ on which $\mu$'s success is at most $\tfrac12$ — no better than guessing without a query. Two queries suffice deterministically, so $R_\varepsilon = 2$ for $\varepsilon\lt\tfrac12$.

History. Deutsch's 1985 algorithm was not this one: it answered correctly with probability $\tfrac12$ and otherwise reported failure. The exact one-query version on the previous slides is from Cleve, Ekert, Macchiavello and Mosca (1998), and is the one now taught.

A factor of two is not nothing. It is the smallest possible separation, and it holds against every classical model, deterministic or randomised. The next two sections scale it up — and find that scaling up the separation and keeping it against randomised algorithms pull in different directions.

and $(x\,b)\cdot(y\,c) = x\cdot y\oplus bc$; a sign depends only on parity. $\blacksquare$

Full proof, the step written out. By the induction hypothesis and the case $n = 1$, $H^{\otimes n}\ket x\otimes H\ket b = \big(2^{-n/2}\sum_y(-1)^{x\cdot y}\ket y\big)\otimes\big(2^{-1/2}\sum_c(-1)^{bc}\ket c\big)$. Concatenation matches the qubit order: $\ket y\otimes\ket c = \ket{y\,c}$, with $c$ the new last qubit. The characters of ℤ₂ⁿ

$\mathbb Z_2^n$: bit strings under $\oplus$ — a group with identity $0^n$, each element its own inverse.

a character

A homomorphism $\chi:\mathbb Z_2^n\to\mathbb C^\times$ (nonzero complex numbers under multiplication): $\chi(x\oplus x') = \chi(x)\chi(x')$.

theorem

The characters are exactly $\chi_y(x) = (-1)^{x\cdot y}$, one for each $y$, and they are orthogonal:

$$\sum_x\chi_y(x)\chi_z(x) = 2^n\,\delta_{yz}.$$
proof

$\chi_y$ is a homomorphism because $(x\oplus x')\cdot y = x\cdot y\oplus x'\cdot y$. Conversely $\chi(e_i)^2 = \chi(e_i\oplus e_i) = \chi(0) = 1$, so $\chi(e_i) = (-1)^{y_i}$ for some bit $y_i$, and $\chi(x) = \prod_i\chi(e_i)^{x_i} = (-1)^{x\cdot y}$. Orthogonality: $\chi_y\chi_z = \chi_{y\oplus z}$, and

$$\sum_x(-1)^{x\cdot w} = \prod_i\big(1 + (-1)^{w_i}\big),$$

which is $2^n$ if $w = 0$ and $0$ otherwise. $\blacksquare$

Characters multiply as their labels add: $\chi_{101}\chi_{011} = \chi_{110}$.

Full proof of the product formula. $\sum_{x\in\{0, 1\}^n}(-1)^{x\cdot w} = \sum_{x_0}\cdots\sum_{x_{n-1}}\prod_i(-1)^{x_iw_i} = \prod_i\sum_{x_i\in\{0, 1\}}(-1)^{x_iw_i}$, and the factor for $i$ is $1 + 1 = 2$ if $w_i = 0$ and $1 - 1 = 0$ if $w_i = 1$. One zero factor kills the product.

What this says about $H^{\otimes n}$. Its rows are $2^{-n/2}\chi_y$, so orthogonality of the characters is exactly $H^{\otimes n}(H^{\otimes n})^\dagger = I$: the transform is unitary, now proved without the tensor product.

The first appearance of a pattern. For any finite abelian group $G$, the characters $G\to\mathbb C^\times$ form a group of the same size, they are orthogonal, and the unitary whose rows are the normalised characters is the Fourier transform on $G$. For $G = \mathbb Z_2^n$ it is $H^{\otimes n}$. For $G = \mathbb Z_N$ the characters are $j\mapsto e^{2\pi ijk/N}$ and the transform is the quantum Fourier transform of unit 15, which builds the general theory. At $N = 2$, $e^{2\pi ijk/2} = (-1)^{jk}$, so $H$ is the QFT on $\mathbb Z_2$, and the course's sign convention for the QFT makes no difference there.

The running example. $(-1)^{f(x)} = \chi_{101}(x)$: the function in the box, written as signs, is a character. Characters of $\mathbb Z_2^n$ are exactly the functions $x\mapsto(-1)^{s\cdot x}$, i.e. the sign patterns of the linear functions — which is why Bernstein–Vazirani's promise is "$f$ is linear".

Fourier sampling

the Fourier transform over ℤ₂ⁿ

For $F:\{0, 1\}^n\to\mathbb C$, $\ \hat F(y) = 2^{-n}\sum_xF(x)(-1)^{x\cdot y}$. By orthogonality $F = \sum_y\hat F(y)\chi_y$, and if $F = \pm1$ everywhere, $\sum_y\hat F(y)^2 = 1$ (Parseval).

theorem: Fourier sampling

With $F = (-1)^f$, one query gives

$$H^{\otimes n}O_fH^{\otimes n}\ket{0^n} = \sum_y\hat F(y)\ket y,$$

so measuring returns $y$ with probability $\hat F(y)^2$.

proof

$H^{\otimes n}\ket{0^n} = 2^{-n/2}\sum_x\ket x$; $\ O_f$ multiplies by $F(x)$; then $H^{\otimes n}$ by the theorem, and swap the sums. $\blacksquare$

One query, Hadamards on both sides: the outcome is a sample from $\hat F^{\,2}$.

Check: probabilities sum to $\sum_y\hat F(y)^2 = 1$ by Parseval ✓. For the running example, $F = \chi_{101}$, so $\hat F(y) = \delta_{y,101}$ by orthogonality: the outcome is $101$, certainly.

Sections 4 and 5 are two readings of this one circuit: $\hat F(0^n)$, and $\hat F$ of a character.

Full proof. $H^{\otimes n}O_fH^{\otimes n}\ket{0^n} = H^{\otimes n}\,2^{-n/2}\sum_xF(x)\ket x = 2^{-n/2}\sum_xF(x)\,2^{-n/2}\sum_y(-1)^{x\cdot y}\ket y = \sum_y\big(2^{-n}\sum_xF(x)(-1)^{x\cdot y}\big)\ket y$. In circuits, $O_f$ is one query to $U_f$ with the target in $\ket-$, as drawn.

Inversion and Parseval, in full. $\sum_y\hat F(y)\chi_y(x') = 2^{-n}\sum_xF(x)\sum_y(-1)^{(x\oplus x')\cdot y} = 2^{-n}\sum_xF(x)\,2^n\delta_{xx'} = F(x')$, using orthogonality with the roles of $x$ and $y$ exchanged (the formula is symmetric). The name. Bernstein and Vazirani called this primitive Fourier sampling. It does not compute the Fourier transform of $f$ — that is $2^n$ numbers — it draws one $y$ with probability $\hat F(y)^2$. Whether a single sample is useful depends entirely on the promise: for a character it is the whole answer.

A second example. For majority on three bits ($1$ when at least two bits are $1$) the coefficients are $\hat F = \tfrac12$ at $001, 010, 100$ and $-\tfrac12$ at $111$, and $0$ elsewhere, so the outcome is one of those four strings, each with probability $\tfrac14$. Problem P4 computes it.

Constant or balanced

the Deutsch–Jozsa problem

$f:\{0, 1\}^n\to\{0, 1\}$ is promised to be constant (one value on all $2^n$ inputs) or balanced ($1$ on exactly $2^{n-1}$ inputs). Decide which.

theorem: the Deutsch–Jozsa algorithm

Fourier sampling outputs $0^n$ with probability $1$ if $f$ is constant and $0$ if balanced. So "constant iff $0^n$" is exact, with one query.

proof

With $w$ the number of $x$ with $f(x) = 1$,

$$\hat F(0^n) = 2^{-n}\big((2^n - w) - w\big) = 1 - \frac{2w}{2^n}.$$

$w = 0$ or $2^n$: $\pm1$, squared $1$. $\ w = 2^{n-1}$: $0$. $\blacksquare$

The same circuit as Fourier sampling; read only whether the outcome is $0^n$.

The running example is balanced: $f = x_0\oplus x_2$ is $1$ on $001, 011, 100, 110$ — four of eight. So the outcome is never $000$.

Unit 15 will meet the same structure on a different group; here the group is $\mathbb Z_2^n$ and $\hat F(0^n)$ is just the average sign.

The circuit in qubits. $n$ input qubits in $\ket0$ and a target in $\ket1$; $H$ on all $n + 1$; one call to $U_f$; $H$ on the $n$ input qubits; measure them. By kickback the target factors out as $\ket-$ throughout, and the input register follows the Fourier-sampling calculation exactly.

Where the probability goes when $f$ is balanced. Not to $0^n$ — and otherwise wherever $\hat F^{\,2}$ puts it. For the running example all of it lands on $101$ (section 5). For majority on three bits it spreads over $001, 010, 100, 111$. The algorithm ignores everything but whether the outcome is $0^n$.

History. D. Deutsch and R. Jozsa, "Rapid solution of problems by quantum computation", Proc. R. Soc. Lond. A 439, 553 (1992). Their version used two queries; the one-query version with the target in $\ket-$ is from Cleve, Ekert, Macchiavello and Mosca (1998).

The promise is load-bearing. For an $f$ with $w$ ones that is neither constant nor balanced, the probability of $0^n$ is $(1 - 2w/2^n)^2$, strictly between $0$ and $1$, and the algorithm decides nothing. Problem P7.

Deterministically: 2ⁿ⁻¹ + 1 queries

theorem

$D(\mathrm{DJ}_n) = 2^{n-1} + 1$.

proof

Enough: ask any $2^{n-1} + 1$ distinct inputs. A balanced $f$ has only $2^{n-1}$ of each value, so if all answers agree, $f$ is constant; otherwise balanced.

Needed (an adversary): answer $0$ to every query. After $k\le2^{n-1}$ distinct queries, at least $2^n - k\ge2^{n-1}$ inputs are unasked. Both $f\equiv0$ and the balanced $f$ that is $1$ on $2^{n-1}$ of the unasked inputs fit every answer: a fooling pair, so the tree is wrong on one. $\blacksquare$

The running example's size: $n = 3$ needs $5$ queries against one. At $n = 30$, $536{,}870{,}913$ against one.

$n = 3$: the adversary has said $0$ four times. Constant and balanced both remain possible, so a fifth query is needed.

Full proof of the lower bound. Fix a deterministic tree of depth $k\le2^{n-1}$. Follow the path on which every answer is $0$; it asks at most $k$ distinct inputs, forming a set $A$ with $|A|\le2^{n-1}$. Let $f_0\equiv0$, and let $f_1$ be $0$ on $A$ and $1$ on some $2^{n-1}$ inputs outside $A$ — possible since $2^n - |A|\ge2^{n-1}$ — and $0$ on the rest. Then $f_1$ has exactly $2^{n-1}$ ones, so it is balanced. Both $f_0$ and $f_1$ answer $0$ on $A$, so both follow the all-zeros path to the same leaf (tool 1), while the right outputs differ. The tree is wrong on one of them.

The adversary's strategy. It answers $0$ — the answer that commits it to least. Any algorithm can be forced down this path, so the worst case is at least as bad as this path. The argument does not depend on the order or adaptivity of the queries.

The numbers. $2^{3-1} + 1 = 5$; $2^{29} + 1 = 536{,}870{,}913$; $2^{9} + 1 = 513$ at $n = 10$. The quantum algorithm uses one query at every $n$, and is exact: this is an exponential separation between $Q_E$ and $D$.

With coins: a constant number

theorem

Query $k$ inputs chosen independently and uniformly. Say "constant" if all answers agree, "balanced" otherwise. This errs only on balanced $f$, with probability

$$2\cdot2^{-k} = 2^{1-k}.$$
proof

Constant $f$: the answers always agree, and the verdict is right. Balanced $f$: each answer is an independent fair bit, since half the inputs give each value; all $k$ agree with probability $2\cdot(\tfrac12)^k$. $\blacksquare$

So $R_{1/3}(\mathrm{DJ}_n)\le3$ for every $n$: $k = 3$ gives error $\tfrac14$. This is one-sided error: a "balanced" verdict is always right.

The running example with $k = 2$: two random answers from four $0$s and four $1$s agree with probability $\tfrac12$.

The error bound $2^{1-k}$ falls by half per query, whatever $n$ is.

Why independent and uniform. For a balanced $f$, a uniform $x$ has $\Pr[f(x) = 1] = 2^{-n}\cdot2^{n-1} = \tfrac12$. Independent draws give independent answers, so the $k$ answers are $k$ fair coin flips, and the chance they agree is $\Pr[\text{all }0] + \Pr[\text{all }1] = 2^{-k} + 2^{-k}$. Drawing without replacement does slightly better, since after some $0$s a $1$ becomes more likely; the bound $2^{1-k}$ is enough.

The randomised lower bound is tiny too. One query is not enough for any $\varepsilon\lt\tfrac12$. A one-query algorithm asks $x$ with some probability $\pi(x)$, sees the bit $b = f(x)$, and says "constant" with some probability $c(x, b)$. Let $c_b = \sum_x\pi(x)c(x, b)$. On $f\equiv0$ every answer is $0$, so it says "constant" with probability $c_0$; on $f\equiv1$, with probability $c_1$; being right on both needs $c_0, c_1\ge1 - \varepsilon$. Now average over a uniformly random balanced $f$: for each fixed $x$, $f(x)$ is a fair bit, so the average probability of "constant" is $\sum_x\pi(x)\tfrac12\big(c(x, 0) + c(x, 1)\big) = \tfrac12(c_0 + c_1)\ge1 - \varepsilon$. Some balanced $f$ is at least the average, and on it the algorithm errs with probability at least $1 - \varepsilon\gt\tfrac12\gt\varepsilon$. So $R_\varepsilon(\mathrm{DJ}_n)$ lies between $2$ and $\lceil\log_2(1/\varepsilon)\rceil + 1$ for every $n\ge1$: a constant.

The numbers on the plot. $2^{1-3} = 0.25\lt\tfrac13$, while $2^{1-2} = 0.5$ is not, so $3$ queries are the least this test needs for bounded error. $2^{1-21} = 9.54\times10^{-7}\lt10^{-6}$, while $2^{1-20} = 1.91\times10^{-6}$ is not: $21$ queries for error below one in a million. Problem P6 puts that beside the deterministic $536{,}870{,}913$ at $n = 30$.

Not yet a separation worth having

what it does show

An exponential separation between exact quantum and exact classical computation: $Q_E = 1$, $D = 2^{n-1} + 1$. And the pattern — kickback, Hadamards, one global property — that the rest of Part D reuses.

what it does not

Against coins the gap is $1$ against at most $3$. Allow a classical algorithm the error a real quantum computer has anyway, and Deutsch–Jozsa's exponential speed-up evaporates.

A quantum machine is never exact: every gate has some error. So the comparison that matters for a physical device is bounded-error quantum against bounded-error classical — and here it is constant against constant.

The question for the rest of the unit, and for unit 14: is there a problem where quantum beats randomised algorithms, and by how much?

The history of the claim. Deutsch and Jozsa's 1992 paper was careful: it compared with deterministic computation and said so. The claim is still often repeated as "Deutsch–Jozsa gives an exponential speed-up", without the word "deterministic". It is the standard example of why a separation must name its classical model.

Exactness is fragile. If each gate errs with probability $p$, a circuit of $g$ gates errs with probability at most $gp$ (a union bound over the gates), and the algorithm is then a bounded-error one. Its competitor is $R_\varepsilon$, not $D$. Units 22–24 show how error correction makes the error as small as one likes — small, never zero.

Where the exponential lives, precisely. A family of promise problems on which $Q_E(F_n) = 1$ and $D(F_n) = 2^{n-1} + 1$. As a statement about exact computation with a black box it is true and proved. It is just not a statement about the computers anyone will build.

Bernstein–Vazirani

The same circuit, a stronger promise, and a separation that survives coins — but only n against 1.

13 · Bernstein–Vazirani

Find the hidden string

the Bernstein–Vazirani problem

$f(x) = s\cdot x$ for an unknown $s\in\{0, 1\}^n$. Find $s$.

theorem

The Deutsch–Jozsa circuit outputs $s$ with probability $1$, after one query.

proof

After the oracle the input register holds $2^{-n/2}\sum_x(-1)^{s\cdot x}\ket x$, which is $H^{\otimes n}\ket s$ by the Hadamard transform. $H^{\otimes n}$ is its own inverse, so the last layer returns $\ket s$. $\blacksquare$

In Fourier terms: $F = \chi_s$, so $\hat F = \delta_s$. The promise says $F$ is a character, and Fourier sampling names it.

The circuit of section 4 again. Deutsch–Jozsa asked whether the output is $0^n$; now the output is the answer.

Classically, $f(e_i) = s_i$, so $n$ queries suffice: section 1's tree. For $s\ne0^n$, $f$ is balanced, so this is a special case of Deutsch–Jozsa's promise.

The proof, without the Fourier words. By kickback, one query on $2^{-n/2}\sum_x\ket x\ket-$ gives $2^{-n/2}\sum_x(-1)^{s\cdot x}\ket x\ket-$. The Hadamard-transform formula with $x$ and $s$ in place of $x$ and $y$ reads $H^{\otimes n}\ket s = 2^{-n/2}\sum_x(-1)^{s\cdot x}\ket x$, the same vector, because $s\cdot x = x\cdot s$. Applying $H^{\otimes n}$, with $(H^{\otimes n})^2 = I$, gives $\ket s$.

Why $f$ is balanced for $s\ne0^n$. $\sum_x(-1)^{s\cdot x} = 0$ by the character sum, so $f$ takes the values $0$ and $1$ equally often. For $s = 0^n$, $f\equiv0$, constant. So every instance of Bernstein–Vazirani is an instance of Deutsch–Jozsa, and the Deutsch–Jozsa verdict is read off the Bernstein–Vazirani answer: constant iff $s = 0^n$.

History. E. Bernstein and U. Vazirani, "Quantum complexity theory", STOC 1993, pp. 11–20; journal version SIAM J. Comput. 26, 1411 (1997). The paper's main subject was the quantum Turing machine and the complexity class it defines (unit 12); the hidden-string problem was a step towards a separation, recursive Fourier sampling, which closes this section.

Why it works, drawn

Conjugating the oracle by Hadamards turns each CNOT round: the target becomes the control.

lemma

$(H\otimes H)\,\mathrm{CNOT}_{01}\,(H\otimes H) = \mathrm{CNOT}_{10}$.

Proof. $\mathrm{CNOT}_{01} = (I\otimes H)\,CZ\,(I\otimes H)$ with $CZ = \mathrm{diag}(1, 1, 1, -1)$, since $HXH = Z$. So the left side is $(H\otimes I)\,CZ\,(H\otimes I)$, and $CZ$ is symmetric in its qubits. $\blacksquare$

Read off the answer. Add an $H$ on the target at the end (it is unentangled, so the input register is unaffected). Then the whole circuit is the right-hand picture: the target, holding $1$, flips exactly the qubits $i$ with $s_i = 1$, writing $s$ into a register of zeros.

In the computational basis each query reveals one bit of $s$; in the Hadamard basis, all of them.

Full proof of the lemma. $CZ = \ket0\!\bra0\otimes I + \ket1\!\bra1\otimes Z$ (unit 10's controlled-$U$ with $U = Z$). Since $HZH = X$, $(I\otimes H)CZ(I\otimes H) = \ket0\!\bra0\otimes I + \ket1\!\bra1\otimes X = \mathrm{CNOT}_{01}$. Then $(H\otimes H)\mathrm{CNOT}_{01}(H\otimes H) = (H\otimes H)(I\otimes H)CZ(I\otimes H)(H\otimes H) = (H\otimes I)CZ(H\otimes I)$, using $H^2 = I$ on the second qubit. Now $CZ$ is diagonal with $-1$ only on $\ket{11}$, which is symmetric under swapping the qubits, so $CZ = I\otimes\ket0\!\bra0 + Z\otimes\ket1\!\bra1$ as well, and $(H\otimes I)CZ(H\otimes I) = I\otimes\ket0\!\bra0 + X\otimes\ket1\!\bra1 = \mathrm{CNOT}_{10}$. Check on one basis state: the left side sends $\ket{01}$ through $H\otimes H$ to $\tfrac12(\ket{00} - \ket{01} + \ket{10} - \ket{11})$, the CNOT to $\tfrac12(\ket{00} - \ket{01} + \ket{11} - \ket{10}) = \ket-\ket-$, and $H\otimes H$ to $\ket{11}$; $\mathrm{CNOT}_{10}\ket{01} = \ket{11}$ ✓.

Applying it to the oracle. The oracle is $\mathrm{CNOT}_{03}\mathrm{CNOT}_{23}$. Conjugating the product by $H^{\otimes4}$ conjugates each factor (insert $H^{\otimes4}H^{\otimes4} = I$ between them), and on the qubits a CNOT does not touch, $HH = I$. So $H^{\otimes4}\,U_f\,H^{\otimes4} = \mathrm{CNOT}_{30}\mathrm{CNOT}_{32}$. The circuit with a final $H$ on the target is exactly $H^{\otimes4}U_fH^{\otimes4}$ on $\ket{000}\ket1$, which gives $\ket{101}\ket1$.

The moral, stated carefully. "Information flows from target to control in the Hadamard basis." It is a change of basis, not a change of physics: the same unitary looks like a copy in one basis and a phase in the other. Unit 23's stabiliser formalism turns this into a calculus.

Classically, n queries — even with coins

theorem

A randomised algorithm that finds $s$ with error below $\tfrac12$ on every $s$ makes at least $n$ queries. So $D = R_\varepsilon = n$ for $\varepsilon\lt\tfrac12$.

proof

Draw $s$ uniformly from the $2^n$ strings. A depth-$k$ tree has at most $2^k$ leaves, each with one output, and on $s$ it is right only if $s$'s leaf is labelled $s$. So it is right on at most $2^k$ strings: probability $\le2^{k-n}$.

By averaging, a randomised algorithm of depth $k$ is right on some $s$ with probability $\le2^{k-n}$. If $k\le n - 1$ that is $\le\tfrac12$: error $\ge\tfrac12$. $\blacksquare$

$n = 3$, $k = 2$: four leaves, eight candidates. Two queries cannot beat a coin flip on some $s$.

Each query reveals at most one bit about $s$, and $s$ has $n$ bits — the leaf count is that sentence made exact. For $s = 101$: three queries classically, and no fewer, against one.

Full proof, the counting step. Fix a tree $T$ of depth $k$. On input $s$ the walk ends at a leaf $\ell(s)$ with label $L(\ell(s))$, and $T$ is right on $s$ iff $L(\ell(s)) = s$. The map $s\mapsto\ell(s)$ sends the set of strings on which $T$ is right injectively into the leaves, because two such strings with the same leaf would both equal its label. So $T$ is right on at most (number of leaves) $\le2^k$ strings (tool 2), and $\Pr_{s}[T\text{ right}]\le2^k/2^n$.

The averaging step. For a distribution $\mu$ over trees of depth at most $k$, $\mathbb E_s\Pr_\mu[\text{right}] = \mathbb E_\mu\Pr_s[\text{right}]\le2^{k-n}$, so some $s$ has $\Pr_\mu[\text{right on }s]\le2^{k-n}$ (tool 3). The uniform distribution on $s$ is what makes "one bit per query" rigorous: the information argument is just this count.

Tightness. With $n - 1$ queries, ask $e_0, \dots, e_{n-2}$ and guess the last bit with a fair coin: right with probability exactly $\tfrac12$ on every $s$. So the bound $\tfrac12$ is attained, and $n - 1$ queries really are not enough for any error below $\tfrac12$. For $n = 3$, $k = 2$: success at most $4/8 = \tfrac12$, as drawn.

One against n is only polynomial

the size of the gap

Bernstein–Vazirani beats randomised algorithms — the first separation in this unit that survives coins. But the gap is $1$ against $n$: polynomial. A computer $n$ times slower is not a different kind of computer.

Recursive Fourier sampling (Bernstein and Vazirani 1993): nest the problem $h$ levels deep. At each node, the answer of each child is one query's worth of $s\cdot x$ for the node's hidden $s$.

Quantumly, run Bernstein–Vazirani on each child, kick back its answer, and uncompute — possible because the algorithm is exact and leaves no garbage: $2^{h-1}$ queries. Classically, superpolynomially many at $h = \log_2 n$ (cited).

Height two: each child is a hidden-string problem whose answer is one bit of the parent's.

Next, unit 14: Simon's problem, an exponential separation against randomised algorithms, with a proof that fits on a slide.

The quantum count, in outline (problem P11 does it). Let $C(h)$ be the number of queries needed to prepare $\ket{s}$ cleanly for a height-$h$ instance. $C(1) = 1$: Bernstein–Vazirani. At height $h$, the "oracle" $x\mapsto s\cdot x$ is not given; its value at $x$ is the answer $g(s_x)$ of the child instance at $x$. To apply its phase oracle, prepare $\ket{s_x}$ with $C(h - 1)$ queries, multiply by $(-1)^{g(s_x)}$ (no query: $g$ is a known function), and run the preparation backwards with another $C(h - 1)$. So one virtual query costs $2C(h - 1)$, Bernstein–Vazirani needs one virtual query, and $C(h) = 2C(h - 1) = 2^{h-1}$. At $h = \log_2 n$ that is $n/2$. Exactness and the absence of garbage are essential: anything left behind would act as a which-path record and spoil the next level's interference.

The classical side, cited. Bernstein and Vazirani proved that bounded-error classical algorithms need superpolynomially many queries at $h = \log_2 n$ (classically $n^h$ always suffice), and concluded that relative to an oracle, quantum polynomial time is not contained in classical randomised polynomial time — the first such oracle separation (SIAM J. Comput. 26, 1411, 1997; the classes are unit 12's). S. Aaronson, "Quantum lower bound for recursive Fourier sampling", Quantum Inf. Comput. 3, 165 (2003), showed that this quantum algorithm is essentially optimal (cited), despite its apparently wasteful uncomputation.

Why Simon is better. Recursive Fourier sampling's separation is superpolynomial but not exponential, and its proof is long. Simon's (1994) is exponential — $O(n)$ quantum against $\Omega(2^{n/2})$ randomised — and short. It is also the algorithm Shor read.
