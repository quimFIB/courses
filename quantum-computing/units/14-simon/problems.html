Simon's problem: the first exponential separation, and the algorithm Shor read

the slides · the curriculum

Checkpoint. On paper and without notes, you prove the quantum upper bound — one run returns \(y\) uniform on \(s^\perp\), \(n - 1\) independent samples determine \(s\), and the expected number of runs is below \(n + 1\), so \(O(n)\) queries — and the classical randomised lower bound \(\Omega(2^{n/2})\) by averaging, lazy sampling and the collision bound \(\binom q2/(2^n - 1)\); and you compute \(\prod_{k\ge1}(1 - 2^{-k}) = 0.2888\) to four places, with a tail bound that proves the digits.

Work each problem on paper first. Under it, Hints opens a ladder one rung at a time — each rung appears only once the one before it is open, and the last gives the first line of the working — and Worked solution has the whole thing: the idea, the working, then a check. Read the solution after your attempt, including when you got it right. F folds everything back; D switches dark and light.

Twelve problems, about four and a half hours. Work them on paper first.

Conventions as in the deck: strings \(x = x_0x_1\cdots x_{n-1}\) with \(x_0\) on qubit 0, the top wire; \(x\cdot y = x_0y_0\oplus\cdots\oplus x_{n-1}y_{n-1}\); \(s^\perp = \{y : y\cdot s = 0\}\); \(U_f\ket x\ket w = \ket x\ket{w\oplus f(x)}\); \(H^{\otimes n}\ket x = 2^{-n/2}\sum_y(-1)^{x\cdot y}\ket y\) (unit 13). One run of Simon's circuit is: \(H^{\otimes n}\) on register 1 of \(\ket{0^n}\ket{0^n}\), one query, \(H^{\otimes n}\) on register 1, measure register 1. \(P_m = \prod_{k=1}^m(1 - 2^{-k})\). P1 Simon by hand routine

exercises: the state after each layer, the amplitude formula, the coset state, solving for \(s\)

Take \(n = 3\) and

\(x\)000001010011100101110111
\(f(x)\)110001001110111010010111
  1. Find \(s\) from the table, and check that \(f\) satisfies Simon's promise with it.
  2. Write the state of the six qubits after each of the three layers of one run.
  3. Compute every nonzero amplitude \(a(y, v)\) of the final state, the distribution of \(y\), and check that it sums to 1.
  4. Suppose register 2 is measured straight after the query and reads \(001\). Write the state of register 1, then its state after \(H^{\otimes3}\).
  5. Two runs return \(100\) and \(111\). Solve for \(s\).
Hints · 3 rungs
Rung 1

Part 1 is a string; parts 2–3 are vectors in \((\mathbb C^2)^{\otimes6}\) with sixteen or fewer nonzero coefficients, part 4 two vectors in \((\mathbb C^2)^{\otimes3}\); part 5 is a string again. Everything follows the deck's running example with a different \(s\).

Rung 2

The pairs are the inputs sharing a value: XOR the two members of any pair to get \(s\). For part 3, the amplitude is \(2^{1-n}(-1)^{x_v\cdot y}\) when \(y\cdot s = 0\) and \(0\) otherwise, with \(x_v\) either member of the pair mapping to \(v\).

Rung 3

First line: \(000\oplus011 = 011\), so try \(s = 011\); then \(y\cdot s = y_1\oplus y_2\), and \(s^\perp = \{000, 011, 100, 111\}\). Pick representatives \(x_{110} = 000\), \(x_{001} = 001\), \(x_{111} = 100\), \(x_{010} = 101\).

Worked solution

Idea. Every amplitude is a sum of two signs, one from each member of a pair; the pair's two members agree in sign exactly when \(y\cdot s = 0\).

1. The pairs are \(\{000, 011\}\mapsto110\), \(\{001, 010\}\mapsto001\), \(\{100, 111\}\mapsto111\), \(\{101, 110\}\mapsto010\), and in each the XOR of the members is \(011\). So \(s = 011\). The four values \(110, 001, 111, 010\) are distinct, so \(f(x) = f(x')\) exactly when \(x' \in\{x, x\oplus011\}\) ✓.

2. After \(H^{\otimes3}\) on register 1: \(2^{-3/2}\sum_x\ket x\ket{000}\). After the query: \(2^{-3/2}\sum_x\ket x\ket{f(x)}\), that is,

\[ \tfrac1{2\sqrt2}\Big[(\ket{000} + \ket{011})\ket{110} + (\ket{001} + \ket{010})\ket{001} + (\ket{100} + \ket{111})\ket{111} + (\ket{101} + \ket{110})\ket{010}\Big]. \]

Norm: eight orthonormal terms of squared size \(\tfrac18\) ✓. After the second \(H^{\otimes3}\): \(\tfrac18\sum_y\sum_x(-1)^{x\cdot y}\ket y\ket{f(x)}\), worked out in part 3.

3. \(y\cdot s = y_1\oplus y_2\), so \(a(y, v) = 0\) unless \(y\in\{000, 011, 100, 111\}\), and then \(a(y, v) = \tfrac14(-1)^{x_v\cdot y}\). With the representatives \(000, 001, 100, 101\) for \(v = 110, 001, 111, 010\):

\(y\)\(x\cdot y\)\(v = 110\)\(001\)\(111\)\(010\)
000\(0\)\(+\tfrac14\)\(+\tfrac14\)\(+\tfrac14\)\(+\tfrac14\)
011\(x_1\oplus x_2\)\(+\tfrac14\)\(-\tfrac14\)\(+\tfrac14\)\(-\tfrac14\)
100\(x_0\)\(+\tfrac14\)\(+\tfrac14\)\(-\tfrac14\)\(-\tfrac14\)
111\(x_0\oplus x_1\oplus x_2\)\(+\tfrac14\)\(-\tfrac14\)\(-\tfrac14\)\(+\tfrac14\)

So \(P(000) = P(011) = P(100) = P(111) = 4\cdot\tfrac1{16} = \tfrac14\), the other four are \(0\), and the sum is \(1\) ✓. One cancelling entry by hand, as a check: \(y = 001\), \(v = 110\): \(\tfrac18[(-1)^{000\cdot001} + (-1)^{011\cdot001}] = \tfrac18[1 - 1] = 0\) ✓.

4. Outcome \(001\) has probability \(2\cdot\tfrac18 = \tfrac14\) and leaves the pair in equal superposition: \(\tfrac1{\sqrt2}(\ket{001} + \ket{010})\). Then

\[ H^{\otimes3}\tfrac1{\sqrt2}(\ket{001} + \ket{010}) = \tfrac12\big(\ket{000} - \ket{011} + \ket{100} - \ket{111}\big), \]

the signs being \((-1)^{001\cdot y} = (-1)^{y_2}\) on \(s^\perp\). Norm \(4\cdot\tfrac14 = 1\) ✓; the distribution is again uniform on \(s^\perp\), as the deck's coset-state slide says it must be.

5. \(100\cdot t = 0\) gives \(t_0 = 0\); \(111\cdot t = 0\) gives \(t_0\oplus t_1\oplus t_2 = 0\), so \(t_1 = t_2\). Solutions \(\{000, 011\}\); the nonzero one is \(s = 011\) ✓. The samples are independent (distinct and nonzero), and \(2 = n - 1\), so this was guaranteed.

Check. Both samples are orthogonal to the answer: \(100\cdot011 = 0\), \(111\cdot011 = 1\oplus1 = 0\) ✓. And \(s = 011\) has two 1s, so it lies in its own \(s^\perp\) — it appears in the table as an outcome, as \(110\) did in the deck.

With the referee

from qclib import Circuit
table = {0b000: 0b110, 0b001: 0b001, 0b010: 0b001, 0b011: 0b110,
         0b100: 0b111, 0b101: 0b010, 0b110: 0b010, 0b111: 0b111}
c = Circuit(6).h(0).h(1).h(2).oracle(lambda x: table[x], [0, 1, 2], [3, 4, 5])

P2 Linear algebra over \(\mathbb F_2\) routine

exercises: orthogonal complements, self-orthogonal vectors, rank–nullity over \(\mathbb F_2\)

  1. For \(s = 1011\), list \(s^\perp\) and give a basis of it. Is \(s\in s^\perp\)?
  2. Find every nonzero \(y\in\mathbb F_2^3\) with \(y\cdot y = 0\), and prove: \(s\in s^\perp\) if and only if \(s\) has an even number of 1s.
  3. Show that \(W = \operatorname{span}\{1100, 0011\}\subseteq\mathbb F_2^4\) satisfies \(W^\perp = W\). Explain why no nonzero subspace of \(\mathbb R^4\) equals its own orthogonal complement.
  4. Prove, with rank–nullity, that \(|s^\perp| = 2^{n-1}\) for every \(s\ne0\) in \(\mathbb F_2^n\).
Hints · 3 rungs
Rung 1

Part 1 is a list of eight strings; part 2 a list of three and a one-line proof; part 3 four dot products and a dimension count; part 4 a statement about the kernel of a linear map \(\mathbb F_2^n\to\mathbb F_2\).

Rung 2

Over \(\mathbb F_2\), \(y\cdot y = y_0^2\oplus\cdots = y_0\oplus\cdots\oplus y_{n-1}\), since \(b^2 = b\) for a bit. Over \(\mathbb R\), what is \(w\cdot w\) for \(w\in W\cap W^\perp\)?

Rung 3

First line of part 1: \(y\cdot1011 = y_0\oplus y_2\oplus y_3\), so \(y_1\) is free and \((y_0, y_2, y_3)\) must have an even number of 1s. First line of part 4: the map \(\lambda(y) = y\cdot s\) is linear, and \(\lambda(e_i) = s_i\) for the standard basis vector \(e_i\).

Worked solution

Idea. The dot product over \(\mathbb F_2\) is still bilinear, so all of linear algebra's counting works; what changes is that \(y\cdot y\) is a parity, not a positive number.

1. \(y\cdot1011 = y_0\oplus y_2\oplus y_3 = 0\): the even-parity triples \((y_0, y_2, y_3)\in\{000, 011, 101, 110\}\), with \(y_1\) free. So

\[ s^\perp = \{0000, 0011, 1001, 1010, 0100, 0111, 1101, 1110\}, \]

eight elements \(= 2^{4-1}\) ✓. A basis: \(0100, 0011, 1001\) — independent, since in echelon order \(1001, 0100, 0011\) each has its leading 1 in a new column — and \(2^3 = 8\) ✓. And \(s\cdot s = 1\oplus0\oplus1\oplus1 = 1\), so \(s\notin s^\perp\).

2. \(y\cdot y = \bigoplus_iy_i^2 = \bigoplus_iy_i\), the parity of the number of 1s, because \(b^2 = b\) for \(b\in\{0, 1\}\). So \(y\cdot y = 0\) iff \(y\) has even weight; in \(\mathbb F_2^3\) the nonzero ones are \(011, 101, 110\). And \(s\in s^\perp\) means \(s\cdot s = 0\), which is the same statement.

3. \(1100\cdot1100 = 1\oplus1 = 0\), \(0011\cdot0011 = 0\), \(1100\cdot0011 = 0\); so every element of \(W\) is orthogonal to every element of \(W\), and \(W\subseteq W^\perp\). By the deck's theorem \(\dim W^\perp = 4 - 2 = 2 = \dim W\), so \(W^\perp = W\). Over \(\mathbb R\), if \(w\in W\cap W^\perp\) then \(w\cdot w = 0\), which forces \(w = 0\) because \(w\cdot w = \sum w_i^2\); so \(W\cap W^\perp = \{0\}\), and \(W = W^\perp\) would give \(W = \{0\}\), whose complement is all of \(\mathbb R^4\).

4. \(\lambda(y) = y\cdot s\) is linear from \(\mathbb F_2^n\) to \(\mathbb F_2\). Pick \(i\) with \(s_i = 1\); then \(\lambda(e_i) = 1\), so \(\lambda\) is onto and has rank 1. Rank–nullity: \(\dim\ker\lambda = n - 1\), and \(\ker\lambda = s^\perp\) has \(2^{n-1}\) elements.

Check. Part 4 at \(n = 4\), \(s = 1011\): \(2^3 = 8\), the count in part 1 ✓. And part 3's \(W\) is the kind of subspace unit 23 builds codes from: self-orthogonal, here even self-dual.

P3 Elimination on six bits routine

exercises: Gaussian elimination over \(\mathbb F_2\) as samples arrive, spotting a dependent sample, back-substitution

Six runs of Simon's algorithm on some \(f\) with \(n = 6\) return, in order,

\[ 101000,\quad 010010,\quad 110001,\quad 011001,\quad 110100,\quad 101111 . \]
  1. Reduce each sample against the rows held so far, as in the deck. Which sample is dependent, and on which earlier ones?
  2. Show that the rank after six runs is \(5 = n - 1\), and back-substitute to find \(s\).
  3. Check your \(s\) against all six samples.
Hints · 3 rungs
Rung 1

The answer is one nonzero 6-bit string, and the intermediate object is a \(5\times6\) bit matrix in echelon form with one pivot-free column.

Rung 2

Keep the rows sorted by pivot. For each new sample, XOR in the row with pivot \(p\) whenever the sample has a 1 in column \(p\), for \(p\) in increasing order. A sample that reaches \(000000\) is dependent.

Rung 3

First lines: \(101000\) is kept with pivot 0; \(010010\) is kept with pivot 1; \(110001\oplus101000 = 011001\), then \(\oplus\,010010 = 001011\), kept with pivot 2.

Worked solution

Idea. Elimination keeps an echelon basis of the span; a sample that reduces to zero was already in it. At rank \(n - 1\) there is one free column, set to 1.

1. Step by step:

  • \(101000\): kept, pivot 0.
  • \(010010\): column 0 is 0; kept, pivot 1.
  • \(110001\): \(\oplus\,101000\to011001\); \(\oplus\,010010\to001011\); kept, pivot 2.
  • \(011001\): column 0 is 0; \(\oplus\,010010\to001011\); \(\oplus\,001011\to000000\). Dependent. Indeed \(011001 = 101000\oplus110001\), the sum of the first and third samples.
  • \(110100\): \(\oplus\,101000\to011100\); \(\oplus\,010010\to001110\); \(\oplus\,001011\to000101\); kept, pivot 3.
  • \(101111\): \(\oplus\,101000\to000111\); columns 1 and 2 are 0; \(\oplus\,000101\to000010\); kept, pivot 4.

2. Five rows, pivots in columns 0–4, column 5 free:

\[ \begin{array}{cccccc|c} t_0&t_1&t_2&t_3&t_4&t_5&\\\hline \mathbf1&0&1&0&0&0&0\\ 0&\mathbf1&0&0&1&0&0\\ 0&0&\mathbf1&0&1&1&0\\ 0&0&0&\mathbf1&0&1&0\\ 0&0&0&0&\mathbf1&0&0\end{array} \]

Set \(t_5 = 1\). Row 5: \(t_4 = 0\). Row 4: \(t_3\oplus t_5 = 0\), so \(t_3 = 1\). Row 3: \(t_2\oplus t_4\oplus t_5 = 0\), so \(t_2 = 1\). Row 2: \(t_1\oplus t_4 = 0\), so \(t_1 = 0\). Row 1: \(t_0\oplus t_2 = 0\), so \(t_0 = 1\). Hence \(s = 101101\).

3. Check. \(s\) has 1s in positions 0, 2, 3, 5, so \(y\cdot s = y_0\oplus y_2\oplus y_3\oplus y_5\): \(101000\to1\oplus1 = 0\); \(010010\to0\); \(110001\to1\oplus1 = 0\); \(011001\to1\oplus1 = 0\); \(110100\to1\oplus1 = 0\); \(101111\to1\oplus1\oplus1\oplus1 = 0\) ✓. Setting \(t_5 = 0\) instead forces every \(t_i = 0\): the solution set is \(\{000000, 101101\}\), as the theorem requires at rank \(n - 1\).

P4 A hidden subspace medium

exercises: the amplitude computation in general, character sums over a subspace, recovering a subspace from its complement

Let \(S\subseteq\mathbb F_2^n\) be a subspace of dimension \(k\), and suppose \(f:\{0,1\}^n\to\{0,1\}^n\) satisfies \(f(x) = f(x')\iff x\oplus x'\in S\). (Simon's problem is \(k = 1\), \(S = \{0, s\}\).)

  1. Prove that for every \(y\), \(\sum_{t\in S}(-1)^{t\cdot y}\) equals \(|S| = 2^k\) if \(y\in S^\perp\) and \(0\) otherwise.
  2. Prove that one run of Simon's circuit returns \(y\) uniform on \(S^\perp\), and check normalisation.
  3. Show that \(n - k\) linearly independent samples determine \(S\), and say how.
  4. Check the cases \(k = 0\) and \(k = 1\).
Hints · 3 rungs
Rung 1

Part 1 is a lemma about a sum of \(\pm1\)s; part 2 a probability distribution; part 3 a construction using \((W^\perp)^\perp = W\).

Rung 2

For part 1 with \(y\notin S^\perp\), there is some \(t_0\in S\) with \(t_0\cdot y = 1\); the map \(t\mapsto t\oplus t_0\) is a bijection of \(S\) to itself. For part 2, the preimage of each value is a coset \(x_v\oplus S\).

Rung 3

First line of part 2: \(a(y, v) = 2^{-n}\sum_{t\in S}(-1)^{(x_v\oplus t)\cdot y} = 2^{-n}(-1)^{x_v\cdot y}\sum_{t\in S}(-1)^{t\cdot y}\).

Worked solution

Idea. Exactly the deck's computation, with a pair replaced by a coset of \(S\): the coset's members agree in sign for every \(y\in S^\perp\) and cancel perfectly otherwise.

1. If \(y\in S^\perp\), every term is \((-1)^0 = 1\) and the sum is \(|S| = 2^k\). Otherwise pick \(t_0\in S\) with \(t_0\cdot y = 1\). Since \(S\) is a subspace, \(t\mapsto t\oplus t_0\) maps \(S\) bijectively to itself, so

\[ \Sigma := \sum_{t\in S}(-1)^{t\cdot y} = \sum_{t\in S}(-1)^{(t\oplus t_0)\cdot y} = (-1)^{t_0\cdot y}\,\Sigma = -\Sigma, \]

and \(\Sigma = 0\).

2. After the query the state is \(2^{-n/2}\sum_x\ket x\ket{f(x)}\); the values \(v\) number \(2^n/2^k = 2^{n-k}\), and the preimage of \(v\) is the coset \(x_v\oplus S\). After the second \(H^{\otimes n}\),

\[ a(y, v) = 2^{-n}\sum_{t\in S}(-1)^{(x_v\oplus t)\cdot y} = 2^{-n}(-1)^{x_v\cdot y}\sum_{t\in S}(-1)^{t\cdot y} = \begin{cases}2^{k-n}(-1)^{x_v\cdot y} & y\in S^\perp,\\ 0 & \text{otherwise,}\end{cases} \]

using bilinearity and part 1. So \(P(y) = \sum_v|a(y, v)|^2 = 2^{n-k}\cdot2^{2k-2n} = 2^{k-n}\) on \(S^\perp\) and \(0\) elsewhere. \(|S^\perp| = 2^{n-k}\) (dimension \(n - k\) by the deck's theorem), so the total is \(2^{n-k}\cdot2^{k-n} = 1\) ✓: uniform on \(S^\perp\).

3. \(n - k\) independent samples lie in the \((n-k)\)-dimensional \(S^\perp\), so they span it. The solutions \(t\) of \(y_j\cdot t = 0\) for all \(j\) form \((S^\perp)^\perp = S\). So solve the system by elimination: at rank \(n - k\) there are \(k\) free columns, and setting each free variable to 1 in turn (the others 0) and back-substituting gives \(k\) vectors forming a basis of \(S\).

4. Check. \(k = 1\): \(S = \{0, s\}\), \(P(y) = 2^{1-n}\) on \(s^\perp\) — the deck's theorem ✓. \(k = 0\): \(S = \{0\}\), \(f\) one-to-one, \(S^\perp = \mathbb F_2^n\), and \(P(y) = 2^{-n}\) for every \(y\) — the samples are uniform on everything and \(n\) independent ones give \(S = \{0\}\), which is problem P10's test ✓. The expected number of runs to rank \(n - k\) is, by the deck's argument with \(n - 1\) replaced by \(n - k\), \(\sum_{j=1}^{n-k}\frac1{1 - 2^{-j}} < n - k + 2\).

P5 0.2888 medium

exercises: convergence of an infinite product, the Weierstrass inequality, a tail bound that certifies digits

  1. Prove that \(P_m = \prod_{k=1}^m(1 - 2^{-k})\) converges as \(m\to\infty\) to a limit \(P_\infty > 0\).
  2. Prove \(P_m(1 - 2^{-m})\le P_\infty\le P_m\) for every \(m\ge1\).
  3. Show that \(P_\infty > \tfrac14\) using only \(P_2\).
  4. Find the smallest \(m\) for which the bounds of part 2 determine \(P_\infty\) to four decimal places, and give those places.
Hints · 3 rungs
Rung 1

Part 1 is a monotone-convergence argument plus a positive lower bound; part 2 an inequality between products and sums; part 4 a number with four decimals and the \(m\) that certifies it.

Rung 2

Prove \(\prod_{k=1}^r(1 - a_k)\ge1 - \sum_{k=1}^ra_k\) for \(a_k\in[0,1]\) by induction, and apply it to the tail \(\prod_{k=m+1}^R(1 - 2^{-k})\), then let \(R\to\infty\). Part 2 then gives part 1's positivity for free.

Rung 3

First line of part 2: \(P_R = P_m\prod_{k=m+1}^R(1 - 2^{-k})\ge P_m\big(1 - \sum_{k=m+1}^R2^{-k}\big)\ge P_m(1 - 2^{-m})\). For part 4, the interval has width \(P_m2^{-m}\); compute \(P_m\) for \(m = 10, 12, 13\).

Worked solution

Idea. A decreasing positive sequence converges; the Weierstrass inequality, which is the union bound in disguise, keeps the limit away from 0 and gives a computable error bar.

Lemma. For \(a_1, \dots, a_r\in[0,1]\), \(\prod_{k=1}^r(1 - a_k)\ge1 - \sum_{k=1}^ra_k\). For \(r = 1\) it is equality. If it holds for \(r\), multiply both sides by \(1 - a_{r+1}\ge0\) (which preserves \(\ge\) whatever the signs):

\[ \prod_{k=1}^{r+1}(1 - a_k)\ge\Big(1 - \sum_{k=1}^ra_k\Big)(1 - a_{r+1}) = 1 - \sum_{k=1}^{r+1}a_k + a_{r+1}\sum_{k=1}^ra_k\ge1 - \sum_{k=1}^{r+1}a_k. \]

1. Each factor \(1 - 2^{-k}\) lies in \([\tfrac12, 1)\), so \(P_m\) is positive and strictly decreasing; a bounded monotone sequence converges, to some \(P_\infty\ge0\). Positivity comes from part 2: \(P_\infty\ge P_1(1 - \tfrac12) = \tfrac14 > 0\).

2. For \(R > m\), \(P_R = P_m\prod_{k=m+1}^R(1 - 2^{-k})\). The tail product is \(\le1\), so \(P_R\le P_m\); by the lemma it is \(\ge1 - \sum_{k=m+1}^R2^{-k}\ge1 - \sum_{k>m}2^{-k} = 1 - 2^{-m}\), so \(P_R\ge P_m(1 - 2^{-m})\). Both bounds hold for every \(R\); let \(R\to\infty\).

3. \(P_2 = \tfrac12\cdot\tfrac34 = \tfrac38\), so \(P_\infty\ge\tfrac38\cdot\tfrac34 = \tfrac9{32} = 0.28125 > \tfrac14\).

4. The bounds, computed:

\(m\)\(P_m(1 - 2^{-m})\)\(P_m\)rounded to 4 places
100.2887880.2890700.2888 / 0.2891
120.2887880.2888590.2888 / 0.2889
130.2887880.2888230.2888 / 0.2888

At \(m = 13\) both ends round to the same four places, so \(P_\infty = 0.2888\) to four places; at \(m = 12\) they do not. (The limit is \(0.2887880951\ldots\); at \(m = 20\) the interval is \([0.2887881, 0.2887884]\).)

Check. \(P_3 = \tfrac{21}{64} = 0.328\): the chance that three samples are independent at \(n = 4\), by the deck's theorem; and \(0.288788 < 0.328\), consistent with the sequence decreasing ✓. Note the lower bound column barely moves: \(P_m(1 - 2^{-m})\) increases to \(P_\infty\) as \(P_m\) decreases to it, which is why one good \(m\) pins the number from both sides.

P6 Expected runs medium

exercises: geometric waiting times, linearity of expectation, Markov's inequality

Run Simon's circuit until the samples have rank \(n - 1\); let \(T\) be the number of runs.

  1. Prove \(\mathbb E[T] = \sum_{k=1}^{n-1}\frac1{1 - 2^{-k}}\), and that \(\mathbb E[T] < n + 1\).
  2. Compute \(\mathbb E[T]\) exactly for \(n = 3\) and \(n = 4\), and to two decimals for \(n = 100\).
  3. Give a fixed budget of runs, linear in \(n\), after which the algorithm has failed with probability below \(\tfrac13\).
Hints · 3 rungs
Rung 1

\(T\) is a sum of \(n - 1\) random variables, one per stage, each of a standard kind. Part 3 is a tail bound from the mean alone.

Rung 2

At rank \(j\) the span has \(2^j\) of the \(2^{n-1}\) elements of \(s^\perp\). A run raises the rank with probability \(q_j = 1 - 2^{j-(n-1)}\), independently of the past. A waiting time for a success of probability \(q\) has mean \(1/q\).

Rung 3

First line of the bound: \(\frac1{1 - 2^{-k}} = 1 + \frac1{2^k - 1}\le1 + 2^{1-k}\), because \(2^k - 1\ge2^{k-1}\) for \(k\ge1\).

Worked solution

Idea. Split the waiting into stages; each stage is geometric; expectations add; most of the cost is the last stage, where every run is a coin flip.

1. Let \(T_j\) be the number of runs made while the rank is \(j\), \(j = 0, \dots, n - 2\). A run is independent of all previous runs, and it raises the rank iff it lands outside the current span, which happens with probability \(q_j = 1 - 2^j/2^{n-1}\) whatever the previous samples were. So \(P(T_j = t) = (1 - q_j)^{t-1}q_j\) and

\[ \mathbb E[T_j] = \sum_{t\ge1}t(1 - q_j)^{t-1}q_j = \frac{q_j}{(1 - (1 - q_j))^2} = \frac1{q_j}, \]

using \(\sum_tt\,r^{t-1} = (1 - r)^{-2}\) for \(|r| < 1\), the derivative of the geometric series. By linearity, \(\mathbb E[T] = \sum_{j=0}^{n-2}1/q_j\); with \(k = n - 1 - j\), \(q_j = 1 - 2^{-k}\) and \(k\) runs over \(1, \dots, n - 1\). For the bound,

\[ \mathbb E[T] = \sum_{k=1}^{n-1}\Big(1 + \frac1{2^k - 1}\Big)\le(n - 1) + \sum_{k=1}^{n-1}2^{1-k} = (n - 1) + 2 - 2^{2-n} < n + 1. \]

2. \(n = 3\): \(\frac1{1/2} + \frac1{3/4} = 2 + \tfrac43 = \tfrac{10}3 = 3.33\). \(n = 4\): \(2 + \tfrac43 + \tfrac87 = \tfrac{94}{21} = 4.48\). \(n = 100\): \(99 + \sum_{k=1}^{99}\frac1{2^k - 1} = 99 + 1.6067 = 100.61\), the sum having converged to \(\sum_{k\ge1}\frac1{2^k - 1} = 1.60670\) long before \(k = 99\).

3. Markov's inequality, \(P(T\ge a)\le\mathbb E[T]/a\) for \(T\ge0\), with \(a = 3(n + 1)\): \(P(T\ge3(n + 1)) < \tfrac{n + 1}{3(n + 1)} = \tfrac13\). So a budget of \(3(n + 1)\) runs fails with probability below \(\tfrac13\) — at \(n = 100\), 303 runs.

Check. \(n = 2\): \(s^\perp = \{0, s\}\), each run gives \(s\) with probability \(\tfrac12\), so \(T\) is geometric with mean 2; the formula gives \(\frac1{1/2} = 2 < 3\) ✓. And all three values of part 2 lie between \(n - 1\) and \(n + 1\) ✓.

P7 Las Vegas medium

exercises: checking a candidate with classical queries, turning bounded error into zero error, expected cost of repetition

A block is: run Simon's circuit \(n - 1\) times, solve the equations \(y_j\cdot t = 0\), and output a nonzero solution \(t\) chosen uniformly at random (there is always one: \(s\)).

  1. Show that a block outputs \(s\) with probability at least \(0.2888\).
  2. Show that two classical queries decide, with certainty, whether a candidate \(t\ne0\) equals \(s\).
  3. Build an algorithm that never outputs a wrong answer and makes at most \(3.47(n + 1)\) queries on average.
  4. The deck's rule — run until rank \(n - 1\) — needs no check. Why does this problem's algorithm still earn its keep?
Hints · 3 rungs
Rung 1

Part 1 is a probability bound you already have; part 2 a test using the promise; part 3 a loop and an expected count of its iterations.

Rung 2

Under the promise, \(f(0^n) = f(t)\) holds for exactly two strings \(t\). Repeating a block until a test passes is a geometric number of blocks.

Rung 3

First line: if the \(n - 1\) samples are independent, the only nonzero solution is \(s\), so \(P(\text{block outputs } s)\ge P(\text{independent}) = P_{n-1}\ge P_\infty = 0.2888\).

Worked solution

Idea. A wrong candidate is cheap to detect, so guess-and-check converts any algorithm that is right with constant probability into one that is never wrong, at a constant factor in expected cost.

1. With probability \(P_{n-1} = \prod_{k=1}^{n-1}(1 - 2^{-k})\ge P_\infty = 0.2888\) (deck, section 4) the samples are independent; then the solutions are exactly \(\{0, s\}\) and the block outputs \(s\). (When they are dependent it may still output \(s\) by luck, which only helps.)

2. Query \(f(0^n)\) and \(f(t)\). By the promise \(f(0^n) = f(t)\iff t\in\{0^n, s\}\); since \(t\ne0^n\), equality holds iff \(t = s\). Deterministic, so never wrong.

3. Repeat: run a block, test its candidate; stop and output \(t\) at the first pass. Zero error: a candidate is output only after passing a test that only \(s\) passes. Cost: blocks are independent and each passes with probability \(p\ge0.2888\), so the number of blocks is geometric with mean \(1/p\le1/0.2888 = 3.463\). Each block costs \(n - 1\) quantum queries plus 2 classical ones, \(n + 1\) in all, so the expected total is at most \(3.463(n + 1) < 3.47(n + 1)\). (Query \(f(0^n)\) once and remember it, and a block costs \(n\).)

4. Under the promise the deck's rule is already zero-error, and cheaper (below \(n + 1\) on average). The check matters when the promise cannot be trusted: if \(f\) is in fact one-to-one, or two-to-one with no common \(s\), the deck's rule may stop at rank \(n - 1\) and output a "solution" that means nothing, while the checked algorithm never outputs an unverified string — it can be told to give up after a budget and report that no candidate passed. Problem P10 makes the one-to-one case precise.

Check. \(n = 2\): a block is one run, returning \(00\) or the nonzero element of \(s^\perp\), with probability \(\tfrac12\) each. In the second case the only nonzero solution is \(s\); in the first, every \(t\) solves \(00\cdot t = 0\), and a random one of \(01, 10, 11\) is \(s\) with probability \(\tfrac13\). So \(p = \tfrac12 + \tfrac12\cdot\tfrac13 = \tfrac23\ge0.2888\) ✓.

P8 Proof: the collision lower bound hard

exercises: Yao's averaging, lazy sampling, coupling an adaptive algorithm to an oracle that ignores \(s\)

Prove: every randomised algorithm that makes \(q\) queries and outputs \(s\) with probability at least \(\tfrac23\) on every \(f\) satisfying Simon's promise has

\[ q(q - 1)\ \ge\ \tfrac43(2^n - 1) - 2, \]

so its query complexity is \(\Omega(2^{n/2})\). Then show that the same method bounds by \(\binom q2/(2^n - 1)\) how much better than a coin flip \(q\) queries can tell a random two-to-one \(f\) from a random one-to-one \(f\).

Hints · 4 rungs
Rung 1

The answer is a chain of three reductions: randomised to deterministic; a real oracle to one that does not know \(s\); and an event about an adaptive algorithm to an event about a set chosen independently of \(s\).

Rung 2

Hard distribution: \(s\) uniform on the \(2^n - 1\) nonzero strings, then \(f\) uniform with period \(s\). By averaging, it suffices to bound every deterministic algorithm's success on it.

Rung 3

A uniform function with period \(s\) can be sampled lazily: a new query gets the old value if it is an earlier query \(\oplus\,s\), and otherwise a fresh uniform unused value. Drive it and the free oracle (fresh values always) with the same fresh values.

Rung 4

First line of the key step: the free run's queries \(X_1, \dots, X_q\) and output \(\hat s\) are functions of the fresh values only, hence independent of \(s\); the real run collides iff \(s\in D = \{X_i\oplus X_j : i < j\}\).

Worked solution

Idea. Until a collision, a Simon function looks exactly like a random one-to-one function, which carries no information about \(s\). A collision needs \(s\) to be one of the \(\binom q2\) differences of the queries, and \(s\) is uniform over \(2^n - 1\) strings.

Step 1 (averaging). A randomised algorithm is a distribution \((p_D)\) over deterministic trees of depth \(\le q\). Let \(\mu\) be the hard distribution of rung 2 and \(c(D, f)\in\{0, 1\}\) record success. Correctness gives \(\sum_Dp_Dc(D, f)\ge\tfrac23\) for every valid \(f\); averaging over \(f\sim\mu\) and exchanging the two finite sums, \(\sum_Dp_D\,\mathbb E_\mu[c(D, f)]\ge\tfrac23\), so some deterministic \(D\) with at most \(q\) queries has \(\Pr_\mu[D\text{ outputs }s]\ge\tfrac23\). Fix it. Without loss of generality it never repeats a query (a repeat can be answered from memory).

Step 2 (lazy sampling). Fix \(s\). A function with period \(s\) is an injective map \(g\) from the \(2^{n-1}\) pairs \(\{x, x\oplus s\}\) to \(\{0,1\}^n\), uniform over the \((2^n)!/(2^n - 2^{n-1})!\) such maps. Given \(g\)'s values on \(c\) pairs, each of the \(2^n - c\) unused values is equally likely on a further pair: each extends to exactly \((2^n - c - 1)!/(2^n - 2^{n-1})!\) injections. \(D\)'s next query is a function of the answers so far, so conditioning on the transcript is conditioning on \(g\) at the pairs queried. Hence the real answers can be generated as: draw \(u_1, u_2, \dots\), each \(u_t\) uniform among values not yet returned; answer query \(t\) by repeating \(x_i\)'s answer if \(x_t = x_i\oplus s\) for some \(i < t\), and by \(u_t\) otherwise. The free oracle answers query \(t\) by \(u_t\) always. (Until the real oracle first repeats an answer, both have returned the same values, so "not yet returned" is the same set for both; after that the real run draws its own fresh values, and the argument never looks past that point.)

Step 3 (coupling). Run \(D\) against the free oracle; call its queries \(X_1, \dots, X_q\) and its output \(\hat s\). These depend only on the \(u\)'s, so they are independent of \(s\). The real run makes the same queries and gets the same answers up to the first \(t\) with \(X_t = X_i\oplus s\) for some \(i < t\) — each query being determined by the earlier answers. So

\[ \{\text{real run collides}\} = \{s\in D\},\qquad D = \{X_i\oplus X_j : i < j\le q\},\ |D|\le\tbinom q2 . \]

The \(X_i\) are distinct, so \(D\) consists of nonzero strings, and since \(s\) is uniform on the \(2^n - 1\) nonzero strings independently of \(D\), \(P(\text{collision}) = \mathbb E\big[|D|/(2^n - 1)\big]\le\binom q2/(2^n - 1)\).

Step 4 (no collision, no information). Without a collision the real output equals \(\hat s\). So \(\{\text{output} = s\}\subseteq\{\text{collision}\}\cup\{\hat s = s\}\), and by independence \(P(\hat s = s)\le\frac1{2^n - 1}\). Therefore

\[ \tfrac23\le P(\text{output} = s)\le\frac{\binom q2 + 1}{2^n - 1}, \]

which rearranges to \(q(q - 1)\ge\tfrac43(2^n - 1) - 2\), and so \(q > \sqrt{\tfrac43(2^n - 1) - 2}\approx1.15\cdot2^{n/2}\).

Distinguishing. Let \(\mu_1\) be the hard distribution and \(\mu_0\) a uniform one-to-one \(f\). Against \(\mu_0\) a non-repeating algorithm's answers are exactly the free oracle's \(u_t\); against \(\mu_1\) they agree with them unless a collision occurs. So for any event \(E\) about the transcript, \(|\Pr_{\mu_1}[E] - \Pr_{\mu_0}[E]|\le P(\text{collision})\le\binom q2/(2^n - 1)\); averaging (Step 1) transfers this to randomised algorithms.

Check. \(n = 3\): the bound \((\binom q2 + 1)/7\) is \(\tfrac47 < \tfrac23\) at \(q = 3\) and \(1\) at \(q = 4\), so success \(\tfrac23\) needs \(q\ge4\) — and P9 shows four queries suffice. \(q = 1\): the bound is \(\tfrac1{2^n - 1}\), a blind guess ✓. The adaptive case is the whole difficulty: a union bound over a list of pairs fixed in advance would not apply to an algorithm that chooses its queries after seeing answers; Step 3 is what makes the list independent of \(s\).

P9 Deterministic Simon medium

exercises: an adversary argument, an explicit deterministic algorithm, exact counts at small \(n\)

  1. Prove that a deterministic algorithm that always finds \(s\) must make \(q\) queries with \(\binom q2\ge2^n - 2\).
  2. At \(n = 3\), show that the queries \(000, 001, 010, 100\) always find \(s\), so exactly 4 queries are needed and suffice.
  3. For even \(n\), give a deterministic algorithm with \(2^{n/2+1} - 1\) queries.
  4. Evaluate both bounds at \(n = 100\).
Hints · 3 rungs
Rung 1

Part 1 is an adversary that answers so as to keep two candidates alive; parts 2 and 3 are query sets whose pairwise XORs cover all nonzero strings, or all but one.

Rung 2

The adversary answers every new query with a value never used before. After \(q\) queries the strings ruled out are the \(\binom q2\) differences \(x_i\oplus x_j\). For part 3, split a string into halves \((a, b)\) of length \(n/2\).

Rung 3

First line of part 1: if \(\binom q2 < 2^n - 2\), then at least two nonzero strings \(s\ne s'\) are not of the form \(x_i\oplus x_j\); show each is consistent with the transcript.

Worked solution

Idea. A deterministic algorithm must distinguish every candidate; an adversary that never lets two queries collide keeps all but \(\binom q2\) candidates possible.

1. The adversary answers each new query with a value not used before (a repeated query gets its old answer). Let \(x_1, \dots, x_q\) be the distinct queries and \(D = \{x_i\oplus x_j\}\). Suppose \(\binom q2 < 2^n - 2\); then at least two nonzero strings \(s\ne s'\) lie outside \(D\). For \(s\notin D\), the queries lie in distinct pairs \(\{x, x\oplus s\}\), so the transcript's distinct answers can be assigned to those pairs and the remaining \(2^{n-1} - q\) pairs given distinct unused values — possible because there are \(2^n\ge2^{n-1}\) values. That is a valid \(f\) with period \(s\) consistent with every answer; likewise for \(s'\). The algorithm's output is a function of the transcript, so it is wrong on one of the two. Hence \(\binom q2\ge2^n - 2\), i.e. \(q(q - 1)\ge2^{n+1} - 4\), so \(q > \sqrt2\cdot2^{n/2}\) roughly.

2. At \(n = 3\), \(\binom q2\ge6\) forces \(q\ge4\). The four queries \(000, 001, 010, 100\) have six pairwise XORs, \(001, 010, 100, 011, 101, 110\) — every nonzero string except \(111\). If two answers coincide, their XOR is \(s\); if none do, \(s\) is not among the six, so \(s = 111\). Either way \(s\) is found with 4 queries, and part 1 says 3 cannot suffice ✓. (On the deck's running example, \(s = 110\), the answers to \(010\) and \(100\) collide.)

3. Write strings as \((a, b)\) with \(a, b\in\{0,1\}^{n/2}\) and query every \((a, 0)\) and every \((0, b)\): \(2\cdot2^{n/2} - 1\) distinct strings, \((0, 0)\) counted once. For \(s = (s_L, s_R)\), the queries \((s_L, 0)\) and \((0, s_R)\) are both in the set and differ by \(s\) (when \(s_L = 0\) they are \((0, 0)\) and \((0, s_R)\), still distinct since \(s\ne0\); similarly for \(s_R = 0\)). So some pair collides, and its XOR is \(s\).

4. \(n = 100\): part 1 needs \(q(q - 1)\ge2^{101} - 4\), so \(q\ge1.59\times10^{15}\); part 3 uses \(2^{51} - 1 = 2.25\times10^{15}\). The deterministic complexity is pinned within a factor \(\sqrt2\).

Check. Part 3 at \(n = 2\): queries \(00, 10, 01\), three of them; the bound of part 1 needs \(\binom q2\ge2\), so \(q\ge3\) ✓ — tight at \(n = 2\). A quantum remark, cited: the quantum algorithm can be made exact as well — zero error in the worst case with \(O(n)\) queries — by modifying each run so that it never returns a sample already in the span (G. Brassard and P. Høyer, "An exact quantum polynomial-time algorithm for Simon's problem", Proc. 5th Israeli Symposium on Theory of Computing and Systems, 1997, 12–23). So the separation survives even with the deterministic classical model on one side and the exact quantum model on the other.

P10 What if \(s = 0\) is allowed medium

exercises: Simon's decision problem, one-sided error, a union bound over hyperplanes

Simon's original problem: \(f\) is promised to be either one-to-one, or two-to-one with some \(s\ne0\); decide which.

  1. Show that for one-to-one \(f\), one run returns \(y\) uniform on all of \(\mathbb F_2^n\).
  2. Decide "one-to-one" iff \(m\) runs give samples of rank \(n\). Show this is never wrong on a two-to-one \(f\), and wrong on a one-to-one \(f\) with probability at most \((2^n - 1)2^{-m}\).
  3. How large must \(m\) be for error below \(\tfrac14\)? Evaluate the bound and the exact error at \(n = 3\), \(m = 5\).
Hints · 3 rungs
Rung 1

Part 1 is the hidden-subspace computation with \(S = \{0\}\); part 2 a one-sided error bound; part 3 a number of runs and two probabilities.

Rung 2

Samples of rank below \(n\) all lie in some hyperplane \(t^\perp\), \(t\ne0\). For a fixed \(t\), what is the probability that \(m\) uniform samples all lie in \(t^\perp\)?

Rung 3

First line of part 2: in the two-to-one case every sample lies in the \((n-1)\)-dimensional \(s^\perp\), so the rank is at most \(n - 1\) and the answer is always "two-to-one", correctly.

Worked solution

Idea. Two-to-one functions confine the samples to a hyperplane; one-to-one functions spray them over everything, and a full-rank set of samples is a certificate.

1. For one-to-one \(f\) each value has one preimage, so \(a(y, f(x)) = 2^{-n}(-1)^{x\cdot y}\) and \(P(y) = \sum_x2^{-2n} = 2^{-n}\) for every \(y\): uniform, summing to \(1\) ✓. (This is P4 with \(k = 0\).)

2. Two-to-one: all samples lie in \(s^\perp\), of dimension \(n - 1\), so the rank never reaches \(n\): the test says "two-to-one", always right. One-to-one: the rank is below \(n\) iff the samples span a proper subspace, iff they all lie in \(t^\perp\) for some \(t\ne0\) (a proper subspace \(Y\) has \(Y^\perp\ne\{0\}\)). For fixed \(t\ne0\), each uniform sample lies in \(t^\perp\) with probability \(\tfrac12\), so all \(m\) do with probability \(2^{-m}\). Union bound over the \(2^n - 1\) choices of \(t\): \(P(\text{error})\le(2^n - 1)2^{-m}\).

3. \((2^n - 1)2^{-m} < 2^{n-m}\le\tfrac14\) once \(m\ge n + 2\). At \(n = 3\), \(m = 5\): the bound is \(\tfrac7{32} = 0.219\). Exactly: put the \(m\) samples as the columns of an \(n\times m\) bit matrix \(M\). Its entries are independent uniform bits, so its \(n\) rows are independent uniform vectors of \(\mathbb F_2^m\); the samples span \(\mathbb F_2^n\) iff \(\operatorname{rank}M = n\) iff the rows are independent (row rank equals column rank), which by the deck's stage argument has probability \(\prod_{i=0}^{n-1}(1 - 2^{i-m})\). Here that is \(\tfrac{31}{32}\cdot\tfrac{30}{32}\cdot\tfrac{28}{32} = \tfrac{26040}{32768}\), so the error is \(1 - 0.795 = 0.205\).

Check. Bound \(0.219\ge\) exact \(0.205\) ✓, and the union bound is nearly tight because the \(2^n - 1\) bad events rarely overlap. With \(m = n + 2\) at \(n = 100\): bound \(0.25\), exact \(0.230\).

P11 Over \(\mathbb Z_2^n\) the characters are \(\pm1\) hard

exercises: why the Hadamard transform belongs to \(\mathbb Z_2^n\), cosets under \(+\) against cosets under \(\oplus\), a first Fourier transform with complex characters

Let \(G = \mathbb Z_4\times\mathbb Z_4\), with \((a, b)\) stored on four qubits as the binary digits of \(a\) (qubits 0, 1, most significant first) then of \(b\) (qubits 2, 3). Let \(K = \{(t, t) : t\in\mathbb Z_4\}\) and \(f(a, b) = (b - a)\bmod4\), on a two-qubit output register.

  1. Check that \(f\) is constant on each coset \((a, b) + K\) (addition mod 4) and distinct on distinct cosets.
  2. Run Simon's circuit unchanged, with \(H^{\otimes4}\) on the input register. Find the distribution of the outcome. (Write each coset as a set of 4-bit strings first.)
  3. If you feed these samples to Simon's post-processing — the strings orthogonal to all of them — what subgroup do you find?
  4. Replace each \(H^{\otimes2}\) after the query by \(F_4\), the \(4\times4\) matrix with entries \(\tfrac12i^{jk}\) (\(j, k = 0, \dots, 3\)). Check \(F_4\) is unitary, and show the outcome \((k, l)\) is then uniform on \(K^\perp = \{(k, l) : k + l\equiv0\pmod4\}\). Recover \(K\).
Hints · 4 rungs
Rung 1

Part 2's answer is a distribution on 16 outcomes, of which six have nonzero probability; part 4's is uniform on four outcomes. The point of the problem is that they differ.

Rung 2

Each \(\mathbb Z_4\)-coset of \(K\), written in binary, happens to be an XOR-coset — but not always of the same XOR-subgroup. Measure the output register first (deferred measurement) and use P4 on each coset state.

Rung 3

The coset with \(f = 0\) is \(\{0000, 0101, 1010, 1111\}\); the coset with \(f = 1\) is \(\{(0,1), (1,2), (2,3), (3,0)\} = \{0001, 0110, 1011, 1100\} = 0001\oplus\{0000, 0111, 1010, 1101\}\).

Rung 4

First line of part 4: on the coset state \(\tfrac12\sum_t\ket{t, u + t}\), the amplitude of \((k, l)\) is \(\tfrac12\cdot\tfrac14\sum_ti^{tk + (u+t)l} = \tfrac18i^{ul}\sum_{t=0}^3i^{t(k+l)}\).

Worked solution

Idea. The cancellation in Simon's algorithm used \((-1)^{(x\oplus s)\cdot y} = (-1)^{x\cdot y}(-1)^{s\cdot y}\): the characters of \(\mathbb Z_2^n\) turn \(\oplus\) into multiplication. A structure hidden under \(+\) needs the characters of \(\mathbb Z_4\), the powers of \(i\), which \(H^{\otimes n}\) does not have.

1. \(f((a, b) + (t, t)) = (b + t) - (a + t) = b - a\), so \(f\) is constant on cosets; and if \(b - a = b' - a'\) then \((a', b') - (a, b) = (t, t)\) with \(t = a' - a\), so equal values mean the same coset. Four cosets, values \(u = 0, 1, 2, 3\).

2. The coset with value \(u\) is \(\{(t, u + t)\}\). In binary:

\(u\)cosetas an XOR-coset
00000, 0101, 1010, 1111\(0000\oplus K_0\)
10001, 0110, 1011, 1100\(0001\oplus K_1\)
20010, 0111, 1000, 1101\(0010\oplus K_0\)
30011, 0100, 1001, 1110\(0011\oplus K_1\)

with \(K_0 = \{0000, 0101, 1010, 1111\}\) and \(K_1 = \{0000, 0111, 1010, 1101\}\), both XOR-subspaces (check: \(0101\oplus1010 = 1111\), \(0111\oplus1010 = 1101\)). Measure the output first (it changes nothing: deferred measurement). Each \(u\) has probability \(\tfrac14\) and leaves a uniform superposition over \(x_u\oplus K_{u\bmod2}\); by P4, \(H^{\otimes4}\) then gives \(y\) uniform on \(K_0^\perp\) or \(K_1^\perp\):

\[ K_0^\perp = \{y : y_1\oplus y_3 = 0,\ y_0\oplus y_2 = 0\} = \{0000, 0101, 1010, 1111\}, \] \[ K_1^\perp = \{y : y_1\oplus y_2\oplus y_3 = 0,\ y_0\oplus y_2 = 0\} = \{0000, 0101, 1011, 1110\}. \]

Averaging over \(u\): \(P(0000) = P(0101) = \tfrac14\) and \(P(1010) = P(1111) = P(1011) = P(1110) = \tfrac18\). Sum \(\tfrac12 + \tfrac48 = 1\) ✓. In \((k, l)\) notation the outcomes are \((0,0), (1,1)\) with \(\tfrac14\) and \((2,2), (3,3), (2,3), (3,2)\) with \(\tfrac18\).

3. The samples span \(\{0101, 1010, 1011\}\) — dimension 3, containing \(0001 = 1010\oplus1011\). The strings orthogonal to all of them satisfy \(t_1\oplus t_3 = 0\), \(t_0\oplus t_2 = 0\), \(t_3 = 0\): so \(\{0000, 1010\}\) — the subgroup \(\{(0,0), (2,2)\}\), half of \(K\). The element \((1,1)\) that generates \(K\) is lost: the post-processing finds the largest XOR-structure common to all cosets, not the hidden subgroup.

4. \(F_4\) is unitary: \((F_4^\dagger F_4)_{jk} = \tfrac14\sum_mi^{-mj}i^{mk} = \tfrac14\sum_{m=0}^3i^{m(k-j)}\), and \(\sum_{m=0}^3\omega^m = 4\) if \(\omega = 1\), and \(\frac{\omega^4 - 1}{\omega - 1} = 0\) if \(\omega = i^{k-j}\ne1\) (since \(\omega^4 = 1\)). So \(F_4^\dagger F_4 = I\). On the coset state \(\tfrac12\sum_t\ket{t, u + t}\), the amplitude of \((k, l)\) under \(F_4\otimes F_4\) is

\[ \tfrac12\cdot\tfrac14\sum_{t=0}^3i^{tk}i^{(u+t)l} = \tfrac18\,i^{ul}\sum_{t=0}^3i^{t(k+l)} = \begin{cases}\tfrac12\,i^{ul} & k + l\equiv0\pmod 4,\\ 0 & \text{otherwise,}\end{cases} \]

by the same root-of-unity sum. So for every \(u\), the outcome is uniform on \(K^\perp = \{(0,0), (1,3), (2,2), (3,1)\}\), each with probability \(\tfrac14\), sum \(1\) ✓; the unknown \(u\) survives only as the phase \(i^{ul}\). One sample \((1,3)\) or \((3,1)\) recovers \(K\): \((a, b)\) with \(a + 3b\equiv0\), i.e. \(a\equiv b\pmod4\), which is \(K\). (A sample \((2,2)\) only gives \(a + b\) even; a generating sample arrives with probability \(\tfrac12\) per run.)

Check, and the accident. For a cyclic group of order \(2^r\) the trouble never shows: every subgroup of \(\mathbb Z_{2^r}\) is \(2^j\mathbb Z_{2^r}\), whose cosets are "the low \(j\) bits are fixed" — an XOR-coset of one fixed XOR-subgroup — so \(H^{\otimes r}\) happens to work. Here, as \(\mathbb Z_4\times\mathbb Z_4\) with the diagonal \(K\), it does not. Unit 15 builds \(F_N\) for every \(N\) and an efficient circuit for \(N = 2^r\); \(F_4\) is its smallest non-trivial case, \(\tfrac12[i^{jk}]\) in the course's sign convention.

P12 Numbers at \(n = 100\) routine

exercises: putting the two bounds side by side, orders of magnitude

Take \(n = 100\).

  1. Quantum: the expected number of runs, a budget with failure below \(\tfrac13\), and the bit operations of elimination.
  2. Classical: the fewest queries a randomised algorithm needs for success \(\tfrac23\), by the collision bound; compare with \(2^{50}\).
  3. At \(10^9\) classical queries a second, how long is that? And at \(n = 200\)?
  4. What does one extra bit of \(n\) cost each side?
Hints · 3 rungs
Rung 1

Four groups of numbers: three quantum counts, one classical count, two times, two growth factors.

Rung 2

Use P6 for the expected runs and the Markov budget; elimination is at most \(n - 1\) row XORs of \(n\) bits per sample. For the classical side solve \(\big(\binom q2 + 1\big)/(2^n - 1)\ge\tfrac23\) for \(q\).

Rung 3

First line: \(\mathbb E[T] = 99 + \sum_{k=1}^{99}\frac1{2^k - 1} = 99 + 1.607 = 100.61\).

Worked solution

Idea. The quantum cost is linear in \(n\), the classical one is a square root of \(2^n\); the numbers make the asymptotics concrete.

1. \(\mathbb E[T] = 100.61\) runs, one query each (P6). Budget: \(3(n + 1) = 303\) runs fail with probability below \(\tfrac13\). Elimination: at most \((n - 1)\cdot n\) bit operations per sample, and about \(n\) samples, so about \(99\cdot99\cdot100 = 9.8\times10^5\approx10^6\) — under a millisecond on any computer.

2. \(q(q - 1)\ge\tfrac43(2^{100} - 1) - 2\) gives \(q\ge1\,300\,077\,228\,592\,328\approx1.30\times10^{15}\). And \(2^{50} = 1\,125\,899\,906\,842\,624\approx1.13\times10^{15}\); the ratio is \(\sqrt{4/3} = 1.155\).

3. \(1.30\times10^{15}/10^9 = 1.30\times10^6\) s \(= 15.0\) days. At \(n = 200\) the bound is \(1.46\times10^{30}\) queries, \(1.46\times10^{21}\) s \(= 4.6\times10^{13}\) years, about 3400 times the age of the universe (\(1.38\times10^{10}\) years).

4. Quantum: one more run on average (\(\mathbb E[T]\approx n + 0.607\)) and slightly more elimination. Classical: the bound grows by \(\sqrt2\) per bit, so doubling \(n\) squares it (up to the constant), as \(n = 100\to200\) shows: \(1.3\times10^{15}\to1.5\times10^{30}\).

Check. \(\sqrt{4/3}\cdot2^{50} = 1.1547\times1.1259\times10^{15} = 1.300\times10^{15}\) ✓, agreeing with part 2's exact solution. And at \(n = 3\) the same formula gives \(q\ge4\), which P9 showed is exactly enough: the constant in front is right even where the asymptotics are not.
