The terms this unit introduces, in the order the deck meets them. The slides
stay the definition of record; each entry names the slide it comes from, so a
term can be looked up here and read properly there.

Running example: a million-item search — \(N = 2^{20}\) items, twenty qubits,
exactly one marked item behind a phase oracle. Classically about \(N/2 =
524{,}288\) queries on average. The Grover angle is \(\theta = \arcsin 2^{-10} =
9.7656\times10^{-4}\) rad, so each iteration turns the state by \(2\theta\); the
optimal count is \(k^* = \lfloor\pi/4\theta\rfloor = 804\), where the state lands
\(4.93\times10^{-4}\) rad past \(\pi/2\) and the success probability is
\(\sin^2(1609\theta) = 0.99999976\). Iterating twice as long, 1608 times, gives
\(8.9\times10^{-11}\); with four marked items, 804 iterations give
\(9.8\times10^{-7}\). Without knowing \(M\), exponential search takes about 1489
queries on average.

* The running example

- marked item :: An input \(x\) with \(f(x) = 1\), one of the \(M\) that a
  search must find among \(N = 2^n\). The running example has \(M = 1\) among
  \(N = 2^{20}\). /Slide: A million items, one marked./

* The problem, and its plane

- unstructured search :: Given query access to \(f:\{0, 1\}^n\to\{0, 1\}\) with
  \(M\ge1\) marked items among \(N = 2^n\), find one, knowing nothing about \(f\)
  beyond its answers. Queries go through the phase oracle \(O_f = I -
  2\sum_{f(x)=1}\ket x\!\bra x\). Any NP verifier with its instance fixed gives
  such an \(f\). /Slide: Unstructured search./
- Grover's algorithm :: Prepare \(\ket s = H^{\otimes n}\ket{0^n}\), apply the
  Grover iteration \(k\) times, measure, and check the outcome with one more
  query. Grover (1996). /Slide: The algorithm, before the explanation./
- uniform superposition :: \(\ket s = H^{\otimes n}\ket{0^n} =
  N^{-1/2}\sum_x\ket x\): every item with amplitude \(N^{-1/2}\), so a
  measurement returns a uniformly random item.
- Grover iteration :: \(G = D\,O_f\): the phase oracle, then the diffusion
  operator. One query per iteration. On the Grover plane it is the rotation by
  \(2\theta\).
- diffusion operator :: \(D = 2\ket s\!\bra s - I\), Hermitian and unitary with
  \(D^2 = I\); the reflection about \(\ket s\). As a circuit,
  \(H^{\otimes n}(2\ket{0^n}\!\bra{0^n} - I)H^{\otimes n}\), with the middle
  factor equal to \(-X^{\otimes n}C^{n-1}(Z)X^{\otimes n}\): \(O(n)\) gates and
  no queries.
- Grover angle :: The \(\theta\in(0, \frac\pi2)\) with \(\sin\theta =
  \sqrt{M/N} = \braket{m|s}\), where \(\ket m\) and \(\ket{m^\perp}\) are the
  normalised superpositions of the marked and unmarked items and \(\ket s =
  \sin\theta\ket m + \cos\theta\ket{m^\perp}\). For the running example
  \(\theta = \arcsin2^{-10}\). /Slide: The two vectors that matter./
- Grover plane :: \(P = \mathrm{span}\{\ket m, \ket{m^\perp}\}\), which contains
  \(\ket s\) and is mapped into itself by \(O_f\) and \(D\): every state of the
  algorithm lies in it. In the basis \((\ket{m^\perp}, \ket m)\) everything is
  real, so it is a copy of \(\mathbb R^2\). /Slide: The plane is invariant./
- inversion about the mean :: \(D\sum_xa_x\ket x = \sum_x(2\bar a - a_x)\ket x\),
  with \(\bar a\) the mean amplitude: every amplitude is reflected through the
  mean. Grover's own picture of the diffusion step. /Slide: Inversion about the
  mean./

* Two reflections make a rotation

- reflection about a vector :: For a unit vector \(\ket u\) in a subspace \(V\),
  \(R_u = 2\ket u\!\bra u - I_V\): keeps the component along \(\ket u\) and
  negates the rest. Hermitian, unitary, \(R_u^2 = I\). Two reflections about
  axes at angle \(\gamma\) compose to a rotation by \(2\gamma\). On the Grover
  plane \(O_f = R_{m^\perp}\) and \(D = R_s\). /Slide: Reflections./

* How many iterations

- quadratic speedup :: A quantum cost that is the square root of the classical
  one: for search, order \(\sqrt N\) queries against order \(N\). Grover's
  speedup is quadratic and, by unit 18, no more. /Slide: \(\sqrt N\) against
  \(N\)./

* Overshoot

- overshoot :: The success probability \(P_k = \sin^2((2k + 1)\theta)\) is a
  sinusoid in \(k\) with period \(\pi/2\theta\): iterating past
  \(k^*\approx\pi/4\theta\) lowers it, to near zero at about \(2k^*\). For the
  running example, \(P_{1608} = 8.9\times10^{-11}\). Brassard's soufflé.
  /Slide: The success probability is periodic./

* Unknown M, and amplitude amplification

- quarter lemma :: For \(k\) uniform in \(\{0, \dots, m - 1\}\), the average
  success is \(\frac12 - \sin(4m\theta)/(4m\sin2\theta)\), at least \(\frac14\)
  once \(m\ge1/\sin2\theta\). Boyer, Brassard, Høyer and Tapp (1998). /Slide:
  The quarter lemma./
- exponential search :: Search with \(M\) unknown: choose the iteration count
  uniformly below \(m\), and multiply \(m\) by \(\frac65\) after each failure, up
  to \(\sqrt N\). Expected cost below \(9\sqrt{N/M}\) iterations plus one check
  per stage, for \(M\le\frac34N\). /Slide: Exponential search./
- amplitude amplification :: For a reversible algorithm \(A\) whose output is good
  with probability \(p = \sin^2\theta\), the round \(Q = -AS_0A^{-1}S_\chi\)
  rotates by \(2\theta\), so about \(\pi/4\sqrt p\) rounds — each running \(A\)
  and \(A^{-1}\) once — give success at least \(1 - p\). Grover is the case
  \(A = H^{\otimes n}\). Brassard, Høyer, Mosca and Tapp (2002). /Slide:
  Amplitude amplification./
- good subspace :: The subspace, with projection \(\Pi\), of outputs counted as
  success in amplitude amplification; \(S_\chi = I - 2\Pi\) negates it.
- quantum counting :: Estimating \(M\) by phase estimation on controlled powers of
  \(G\), whose eigenvalues on the Grover plane are \(e^{\pm2i\theta}\): relative
  error \(\varepsilon\) with \(O(\sqrt{N/M}/\varepsilon)\) queries (Brassard,
  Høyer and Tapp 1998, cited; phase estimation is unit 15's). /Slide: Quantum
  counting, stated./

* What a quadratic speedup buys

- exhaustive key search :: Trying every key of a cipher against known
  plaintext–ciphertext pairs: an unstructured search with \(N = 2^{128}\) for
  AES-128. Grover needs \(\frac\pi4 2^{64} = 1.45\times10^{19}\) sequential
  iterations, and \(P\) parallel machines buy only a factor \(\sqrt P\) (Zalka
  1999, cited). /Slide: Key search: AES-128./
- post-quantum cryptography :: Cryptography meant to resist quantum attacks. For
  symmetric ciphers, Grover's square root is answered by doubling the key
  length; public-key schemes broken by Shor's algorithm must be replaced.
  /Slide: The response: longer keys, not new ciphers./
