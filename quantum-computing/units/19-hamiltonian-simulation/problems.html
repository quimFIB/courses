Part D · unit 19 · problems

Hamiltonian simulation: Feynman's reason, made into an algorithm

the slides · the curriculum

Checkpoint. You prove the first-order Trotter bound and size a Trotterised Ising simulation for a target accuracy. Concretely, on paper and without notes: you prove \(\lVert e^{-i(A+B)\delta} - e^{-iA\delta}e^{-iB\delta}\rVert\le\tfrac12\lVert[A, B]\rVert\delta^2\) for Hermitian \(A, B\) with no unbounded remainder, telescope it to \(\lVert[A, B]\rVert t^2/2r\) for \(r\) steps, bound the transverse-field Ising chain's \(\lVert[A, B]\rVert\le4(n - 1)\) by counting the pairs of terms that fail to commute, and find that a 50-spin chain at \(t = 10\), \(\varepsilon = 10^{-3}\) needs \(r = 9.8\times10^6\) first-order steps.

Work each problem on paper first. Under it, Hints opens a ladder one rung at a time — each rung appears only once the one before it is open, and the last gives the first line of the working — and Worked solution has the whole thing: the idea, the working, then a check. Read the solution after your attempt, including when you got it right. F folds everything back; D switches dark and light.

Thirteen problems, the last optional, about four and a half hours. P4 is the checkpoint's proof and P7 its computation.

Conventions, as in the deck. The chain is \(H = -J\sum_{i=0}^{n-2}Z_iZ_{i+1} - h\sum_{i=0}^{n-1}X_i\), split as \(H = A + B\) with \(A\) the \(ZZ\) part and \(B\) the \(X\) part; \(J = h = 1\) unless a problem says otherwise. \(n\) is the number of spins, \(t\) the time, \(r\) the number of Trotter steps and \(\delta = t/r\). \(U(\delta) = e^{-i(A+B)\delta}\), \(V(\delta) = e^{-iA\delta}e^{-iB\delta}\), \(S(\delta) = e^{-iA\delta/2}e^{-iB\delta}e^{-iA\delta/2}\). \(\lVert\cdot\rVert\) is the operator norm (unit 11). \(R_P(\theta) = e^{-i\theta P/2}\); qubit 0 is the leftmost symbol of a ket and the top wire. An eigenphase \(\varphi\) means \(U\ket u = e^{2\pi i\varphi}\ket u\), and phase estimation uses \(m\) counting qubits (unit 15's \(t\)). Logarithms are base 2.

Some solutions end with an optional check by the course's referee, qclib, run from the course directory with uv run python. Every solution is complete without it.

Feynman's reason

P1 Feynman's count routine

exercises: the dimension of a tensor product, orders of magnitude, what one more spin costs

Store a state of \(n\) spins as \(2^n\) complex amplitudes in double precision, 16 bytes each.

  1. How many bytes does a 50-spin state take? Give it in petabytes (\(10^{15}\) bytes).
  2. How many bytes would the matrix \(e^{-iHt}\) of a 50-spin Hamiltonian take, stored densely?
  3. What is the largest \(n\) whose state fits in 16 GiB \(= 2^{34}\) bytes? In one exabyte, \(10^{18}\) bytes?
  4. How many qubits does a quantum computer need to hold the 50-spin state, and how many more for a 51st spin? How much more classical memory does the 51st spin cost?
Hints · 3 rungs
Rung 1

Four numbers, each a power of 2 times 16, then converted. Nothing here is subtle; the point is the size of the exponents.

Rung 2

\((\mathbb C^2)^{\otimes n}\) has dimension \(2^n\) (unit 03). An operator on it is a \(2^n\times2^n\) matrix: \(4^n\) entries. For part 3, solve \(16\cdot2^n\le M\) for the largest integer \(n\).

Rung 3

First line: \(16\times2^{50} = 2^4\times2^{50} = 2^{54}\) bytes.

Worked solution

Idea. A state is a vector in a space of dimension \(2^n\); an operator is a square matrix of that size. Exponents add.

1. \(2^{50} = 1.126\times10^{15}\) amplitudes, so \(16\times2^{50} = 2^{54} = 1.80\times10^{16}\) bytes \(= 18\) PB.

2. \(4^{50} = 2^{100}\) entries, so \(16\times2^{100} = 2^{104} = 2.03\times10^{31}\) bytes — \(10^{15}\) times the state vector. The matrix is out of the question at any \(n\) of interest, which is why classical simulation works on the vector.

3. \(16\cdot2^n\le2^{34}\) iff \(n\le30\): a 16 GiB laptop holds exactly 30 spins. \(16\cdot2^n\le10^{18}\) iff \(n\le\log(6.25\times10^{16}) = 55.8\), so \(n = 55\).

4. 50 qubits, and one more for the 51st spin. Classically the 51st spin doubles the memory, from 18 PB to 36 PB.

Check. Going from 16 GiB to an exabyte multiplies the memory by \(10^{18}/2^{34} = 5.8\times10^7\) and buys 25 spins, from 30 to 55: \(\log(5.8\times10^7) = 25.8\). Each factor of two buys one ✓.

P2 Commuting terms routine

exercises: the derivative trick of worked example 1, commutators of Pauli products, exponentials of commuting sums

Let \(A\) and \(B\) be Hermitian.

  1. Prove, without power series, that \(e^{-i(A+B)t} = e^{-iAt}e^{-iBt}\) for all \(t\) when \([A, B] = 0\). Use \(F(s) = e^{i(A+B)s}e^{-iAs}e^{-iBs}\).
  2. Prove the converse: if the identity holds for all real \(t\), then \([A, B] = 0\).
  3. Show that the chain's \(A = -J\sum_iZ_iZ_{i+1}\) is a sum of pairwise commuting terms, and so is \(B = -h\sum_iX_i\). Deduce \(e^{-iA\delta} = \prod_ie^{iJ\delta Z_iZ_{i+1}}\).
  4. Show that \(Z_0Z_1\) anticommutes with \(X_1\) and commutes with \(X_2\).
Hints · 3 rungs
Rung 1

Part 1 is "a function with zero derivative is constant"; part 2 compares two second derivatives at \(t = 0\); parts 3 and 4 are statements about which tensor factors two operators share.

Rung 2

Worked example 1 computed \(F'(s) = ie^{i(A+B)s}\big[Be^{-iAs} - e^{-iAs}B\big]e^{-iBs}\) for any Hermitian \(A, B\). If \(B\) commutes with \(A\), does it commute with \(e^{-iAs}\)? The spectral projectors of \(A\) are polynomials in \(A\).

Rung 3

First line of part 2: \(\tfrac{d^2}{dt^2}e^{-i(A+B)t}\big|_0 = -(A + B)^2\), while \(\tfrac{d^2}{dt^2}\big(e^{-iAt}e^{-iBt}\big)\big|_0 = -A^2 - 2AB - B^2\).

Worked solution

Idea. The Trotter error's velocity is a commutator; if the commutator vanishes the error never starts. Conversely the error's second derivative at 0 is the commutator, so it cannot vanish identically unless the commutator does.

1. If \(AB = BA\) then \(B\) commutes with every polynomial in \(A\). Each spectral projector of the Hermitian \(A = \sum\lambda P_\lambda\) is one: \(P_\lambda = \prod_{\mu\ne\lambda}(A - \mu)/(\lambda - \mu)\), since the right side acts as 1 on the \(\lambda\)-eigenspace and 0 on the others. So \(B\) commutes with \(e^{-iAs} = \sum e^{-i\lambda s}P_\lambda\). By worked example 1's step 2, \(F'(s) = ie^{i(A+B)s}\big[Be^{-iAs} - e^{-iAs}B\big]e^{-iBs} = 0\). A matrix function with zero derivative is constant (unit 01), so \(F(s) = F(0) = I\), i.e. \(e^{-iAs}e^{-iBs} = e^{-i(A+B)s}\) for every \(s\).

2. Differentiate both sides twice (unit 01's product rule) and set \(t = 0\). Left: \((-i)^2(A + B)^2 = -(A^2 + AB + BA + B^2)\). Right: \(\tfrac{d^2}{dt^2}(e^{-iAt}e^{-iBt}) = (-iA)^2e^{-iAt}e^{-iBt} + 2(-iA)e^{-iAt}(-iB)e^{-iBt} + e^{-iAt}(-iB)^2e^{-iBt}\), which at 0 is \(-(A^2 + 2AB + B^2)\). Equality gives \(AB + BA = 2AB\), so \(BA = AB\).

3. Each \(Z_iZ_{i+1}\) is diagonal in the computational basis (\(Z\) is diagonal, and tensor products of diagonal matrices are diagonal), and diagonal matrices commute. For \(i\ne j\), \(X_i\) and \(X_j\) act on different factors: \((\cdots X\cdots I\cdots)(\cdots I\cdots X\cdots) = (\cdots X\cdots X\cdots) = (\cdots I\cdots X\cdots)(\cdots X\cdots I\cdots)\) by unit 03's rule \((P\otimes Q)(R\otimes T) = PR\otimes QT\). For the product formula, induct on the number of terms: \(H_1\) commutes with \(H_2 + \cdots + H_L\), so part 1 gives \(e^{-i(H_1 + \cdots + H_L)\delta} = e^{-iH_1\delta}e^{-i(H_2 + \cdots + H_L)\delta}\), and the hypothesis splits the second factor. With \(H_i = -JZ_iZ_{i+1}\), \(e^{-iH_i\delta} = e^{iJ\delta Z_iZ_{i+1}}\).

4. \(Z_0Z_1X_1 = Z_0\otimes ZX\otimes I\cdots\) and \(X_1Z_0Z_1 = Z_0\otimes XZ\otimes I\cdots\); since \(ZX = iY = -XZ\), \(Z_0Z_1X_1 = -X_1Z_0Z_1\). \(X_2\) shares no qubit with \(Z_0Z_1\), so they commute as in part 3.

Check. Part 2 is the deck's leading-order slide in other clothes: the two second derivatives differ by \(-(A^2 + 2AB + B^2) + (A^2 + AB + BA + B^2) = BA - AB\), and \(\tfrac{t^2}2\) times that is \(-\tfrac12[A, B]t^2\), the deck's second-order gap ✓.

P3 One qubit routine

exercises: a Trotter error computed by hand, the distance between two \(SU(2)\) elements, the \(1/r\) and \(1/r^2\) laws

Take \(H = X + Z\), \(A = X\), \(B = Z\), \(t = 1\).

  1. Evaluate the first-order bound \(\lVert[X, Z]\rVert t^2/2r\) at \(r = 10\) and \(r = 20\).
  2. Compute the actual first-order error \(\lVert U(1) - V(\delta)^r\rVert\) at \(r = 10\) and at \(r = 20\), using the distance lemma of worked example 2: \(\lVert(a_0 - b_0)I - i(\mathbf a - \mathbf b)\cdot\boldsymbol\sigma\rVert = |(a_0, \mathbf a) - (b_0, \mathbf b)|\).
  3. Worked example 4 found \(S(\delta) = \cos^2\delta\,I - i(\sin\delta\cos\delta\,X + \sin\delta\,Z)\) and a Strang error of \(0.0027\) at \(r = 10\). Predict the Strang error at \(r = 20\) from the \(1/r^2\) law, then compute it.
Hints · 3 rungs
Rung 1

Every object here is a \(2\times2\) unitary of the form \(c_0I - i\mathbf c\cdot\boldsymbol\sigma\), so it is a unit 4-vector, and every error is the length of a difference of 4-vectors. The work is finding the 4-vector of a power.

Rung 2

Write one step as \(\cos\tfrac\alpha2I - i\sin\tfrac\alpha2\,\mathbf m\cdot\boldsymbol\sigma\) with \(\mathbf m\) a unit vector. Then its \(r\)-th power is \(\cos\tfrac{r\alpha}2I - i\sin\tfrac{r\alpha}2\,\mathbf m\cdot\boldsymbol\sigma\): powers of a rotation about a fixed axis add angles.

Rung 3

First line at \(r = 20\): \(\delta = 0.05\), \(\cos\tfrac\alpha2 = \cos^20.05 = 0.997502\), so \(\tfrac\alpha2 = 0.070696\) and \(20\cdot\tfrac\alpha2 = 1.413919\).

Worked solution

Idea. Everything lives in \(SU(2)\), where the operator-norm distance is a Euclidean distance in \(\mathbb R^4\) and powers of one element only advance an angle.

1. \([X, Z] = XZ - ZX = -iY - iY = -2iY\), of norm 2. Bounds: \(2/20 = 0.1\) at \(r = 10\), \(2/40 = 0.05\) at \(r = 20\).

2. The exact evolution: \(((X + Z)/\sqrt2)^2 = I\), so \(U(1) = \cos\sqrt2\,I - i\sin\sqrt2\,\frac{X + Z}{\sqrt2}\), with 4-vector \(u = (0.155944, 0.698456, 0, 0.698456)\). One Trotter step, multiplied out with \(XZ = -iY\):

\[ V(\delta) = \cos^2\delta\,I - i\big[\sin\delta\cos\delta\,X - \sin^2\delta\,Y + \sin\delta\cos\delta\,Z\big], \]

a unit 4-vector since \(\cos^4\delta + 2\sin^2\delta\cos^2\delta + \sin^4\delta = 1\). So \(\cos\tfrac\alpha2 = \cos^2\delta\) and \(\mathbf m = (\sin\delta\cos\delta, -\sin^2\delta, \sin\delta\cos\delta)/\sin\tfrac\alpha2\).

At \(r = 10\) (worked example 2): \(\tfrac\alpha2 = 0.141303\), \(\mathbf m = (0.705334, -0.070769, 0.705334)\), \(10\cdot\tfrac\alpha2 = 1.413033\), so \(V^{10}\leftrightarrow(0.157110, 0.696574, -0.069891, 0.696574)\) and the distance to \(u\) is \(\sqrt{0.001166^2 + 2\times0.001882^2 + 0.069891^2} = 0.0700\).

At \(r = 20\): \(\tfrac\alpha2 = 0.070696\), \(\mathbf m = (0.706665, -0.035363, 0.706665)\), \(20\cdot\tfrac\alpha2 = 1.413919\), \(\cos = 0.156235\), \(\sin = 0.987720\). So \(V^{20}\leftrightarrow(0.156235, 0.697987, -0.034928, 0.697987)\), and the distance is \(\sqrt{0.000291^2 + 2\times0.000469^2 + 0.034928^2} = 0.0349\).

3. Prediction: \(0.0027/4 = 0.00069\). Computation: the Strang step has the same \(\cos\tfrac\alpha2 = \cos^2\delta\), so the same angle, and axis \((\cos\delta, 0, 1)/\sqrt{1 + \cos^2\delta} = (0.706665, 0, 0.707549)\) at \(\delta = 0.05\). Then \(S^{20}\leftrightarrow(0.156235, 0.697987, 0, 0.698860)\), and the distance to \(u\) is \(\sqrt{0.000291^2 + 0.000469^2 + 0.000404^2} = 0.00068\).

Check. First order: \(0.0700\to0.0349\), a factor \(2.00\) for twice the steps, and each below its bound (\(0.1\), \(0.05\)) ✓. Strang: \(0.00274\to0.00068\), a factor \(4.0\) ✓. In both first-order errors almost everything is the \(Y\) component, \(-\sin^2\delta/\sin\tfrac\alpha2\approx-\delta/\sqrt2\) in the axis, multiplied by \(\sin\tfrac{r\alpha}{2}\approx0.988\): \(0.0699\) and \(0.0349\).

import numpy as np
from qclib import gates, linalg
X, Z = gates.X, gates.Z
E = lambda h, s: linalg.exp_hermitian(h, -1j * s)       # e^{-ihs}
U = E(X + Z, 1)
for r in (1, 10, 20):
    d = 1 / r
    V = E(X, d) @ E(Z, d)                                # first-order step
    S = E(X, d / 2) @ E(Z, d) @ E(X, d / 2)              # Strang step
    first = linalg.op_norm(U - np.linalg.matrix_power(V, r))
    strang = linalg.op_norm(U - np.linalg.matrix_power(S, r))
    print(r, f"{first:.4f} {strang:.5f}")                # 1 0.7992 0.31367 · 10 0.0700 0.00274 · 20 0.0349 0.00068

P4 Proof: the one-step bound, from the other end medium

exercises: the checkpoint's proof, re-derived by variation of parameters; why the constant ½ is the right one

Let \(A\), \(B\) be Hermitian and \(\delta \gt 0\).

  1. Let \(W(s) = e^{-i(A+B)(\delta - s)}e^{-iAs}e^{-iBs}\) for \(0\le s\le\delta\). Show \(W(0) = U(\delta)\) and \(W(\delta) = V(\delta)\), compute \(W'(s)\), and prove \(\lVert V(\delta) - U(\delta)\rVert\le\tfrac12\lVert[A, B]\rVert\delta^2\) from \(V(\delta) - U(\delta) = \int_0^\delta W'(s)\,ds\). You may use the deck's two lemmas.
  2. Show the constant cannot be lowered: \(\lim_{\delta\to0}\lVert V(\delta) - U(\delta)\rVert/\delta^2 = \tfrac12\lVert[A, B]\rVert\).
  3. For \(A = X\), \(B = Z\), the computed ratio \(\lVert V(\delta) - U(\delta)\rVert/\delta^2\) is \(0.99778\) at \(\delta = 0.1\) and \(0.99998\) at \(\delta = 0.01\). Is that what part 2 predicts?
Hints · 3 rungs
Rung 1

Part 1 is the proof of worked example 1 with the exact evolution moved to the other side: an interpolation from \(U(\delta)\) to \(V(\delta)\) whose velocity is a unitary sandwich around \(G(s) - B\). Part 2 needs a lower bound to match the upper one: an expansion with a remainder you control.

Rung 2

\(\tfrac{d}{ds}e^{-i(A+B)(\delta - s)} = e^{-i(A+B)(\delta - s)}\,i(A + B)\) — the chain rule with inner derivative \(-1\). For part 2, write \(V - U = -\tfrac12[A, B]\delta^2 + R(\delta)\) and bound \(R\) by the multinomial argument of the deck's Strang notes, with \(\alpha = \lVert A\rVert + \lVert B\rVert\).

Rung 3

First line of part 1: \(W'(s) = e^{-i(A+B)(\delta - s)}\big[i(A + B)e^{-iAs} - iAe^{-iAs} - ie^{-iAs}B\big]e^{-iBs}\).

Worked solution

Idea. Interpolate between the exact and the split evolutions; the interpolation's velocity is, up to unitaries, the drift \(G(s) - B\) of lemma 2, which grows at most linearly. For sharpness, the second-order Taylor term is exactly \(-\tfrac12[A, B]\delta^2\), and everything else is smaller.

1. \(W(0) = e^{-i(A+B)\delta}\cdot I\cdot I = U(\delta)\) and \(W(\delta) = I\cdot e^{-iA\delta}e^{-iB\delta} = V(\delta)\). By the product rule (unit 01), the three factors differentiate to \(e^{-i(A+B)(\delta - s)}\,i(A + B)\), \(-iAe^{-iAs}\) and \(-iBe^{-iBs}\); writing \(-iBe^{-iBs}\) as \(e^{-iBs}(-iB)\) and keeping the factors in place,

\[ W'(s) = e^{-i(A+B)(\delta - s)}\Big[i(A + B)e^{-iAs} - iAe^{-iAs} - ie^{-iAs}B\Big]e^{-iBs} = ie^{-i(A+B)(\delta - s)}\Big[Be^{-iAs} - e^{-iAs}B\Big]e^{-iBs}, \]

using that \(A\) commutes with \(e^{-iAs}\). As in worked example 1, \(Be^{-iAs} - e^{-iAs}B = e^{-iAs}(G(s) - B)\) with \(G(s) = e^{iAs}Be^{-iAs}\), so

\[ W'(s) = i\,e^{-i(A+B)(\delta - s)}\,e^{-iAs}\,\big(G(s) - B\big)\,e^{-iBs},\qquad\lVert W'(s)\rVert = \lVert G(s) - B\rVert\le s\lVert[A, B]\rVert \]

by unitary invariance and lemma 2. By the fundamental theorem and lemma 1, \(\lVert V(\delta) - U(\delta)\rVert = \big\lVert\int_0^\delta W'\big\rVert\le\int_0^\delta s\lVert[A, B]\rVert\,ds = \tfrac12\lVert[A, B]\rVert\delta^2\). ∎ (Note \(W(s) = U(\delta)F(s)\) with worked example 1's \(F\): the same proof, multiplied on the left by a constant unitary.)

2. Write \(a = -iA\), \(b = -iB\). The products \(V(\delta) = \sum_{p,q}\frac{(a\delta)^p(b\delta)^q}{p!\,q!}\) and \(U(\delta) = \sum_m\frac{((a + b)\delta)^m}{m!}\) agree in degrees 0 and 1, and in degree 2 differ by \(\tfrac12(ab - ba)\delta^2 = -\tfrac12[A, B]\delta^2\) (the deck's leading-order slide). The terms of degree \(\ge3\) have total norm at most \(\sum_{m\ge3}(\alpha\delta)^m/m!\) in each series, by the multinomial (here binomial) theorem with \(\lVert A\rVert + \lVert B\rVert = \alpha\) and \(\lVert A + B\rVert\le\alpha\). So \(V - U = -\tfrac12[A, B]\delta^2 + R(\delta)\) with \(\lVert R(\delta)\rVert\le2\sum_{m\ge3}\frac{(\alpha\delta)^m}{m!}\le\tfrac13(\alpha\delta)^3e^{\alpha\delta}\). By the triangle inequality in both directions,

\[ \Big|\,\frac{\lVert V - U\rVert}{\delta^2} - \tfrac12\lVert[A, B]\rVert\,\Big|\le\frac{\lVert R(\delta)\rVert}{\delta^2}\le\tfrac13\alpha^3\delta\,e^{\alpha\delta}\to0 . \]

So no constant \(c \lt \tfrac12\) can satisfy \(\lVert V - U\rVert\le c\lVert[A, B]\rVert\delta^2\) for all small \(\delta\) unless \([A, B] = 0\).

3. \(\tfrac12\lVert[X, Z]\rVert = 1\), and the ratios \(0.99778\), \(0.99998\) approach it ✓. Part 2's remainder bound with \(\alpha = 2\) allows deviations up to \(\tfrac83\delta e^{2\delta}\): \(0.33\) at \(\delta = 0.1\) and \(0.027\) at \(\delta = 0.01\). The true deviations, \(0.0022\) and \(0.00002\), are far smaller — here they shrink like \(\delta^2\), the bound only like \(\delta\). That is all an upper bound promises.

Check. Dimensions: \(\lVert[A, B]\rVert\delta^2\) is dimensionless when \(A\), \(B\) are angular frequencies ✓. Special case \(B = 0\): \(W\) is constant, \(W' = 0\), bound 0 ✓.

P5 Many terms medium

exercises: induction on the one-step bound, counting the pairs that clash, what the bound cannot see

  1. Prove that for Hermitian \(H_1, \dots, H_L\) with sum \(H\), \(\big\lVert e^{-iH\delta} - e^{-iH_1\delta}\cdots e^{-iH_L\delta}\big\rVert\le\frac{\delta^2}2\sum_{j \lt k}\lVert[H_j, H_k]\rVert\).
  2. Write the chain as its \(2n - 1\) terms in the interleaved order \(-X_0, -Z_0Z_1, -X_1, -Z_1Z_2, \dots, -X_{n-1}\). Evaluate \(\sum_{j \lt k}\lVert[H_j, H_k]\rVert\), and the resulting \(r\)-step bound at \(n = 8\), \(t = 5\), \(r = 1000\).
  3. The grouped order (all bonds, then all sites) is the deck's \(V = e^{-iA\delta}e^{-iB\delta}\), with actual error \(0.0144\) at these values. The interleaved order's actual error, computed, is \(0.155\). Is either inconsistent with part 2? What does the comparison say about the bound?
Hints · 3 rungs
Rung 1

Part 1 is an induction on \(L\) whose step is the two-term bound; part 2 is a count; part 3 is a comparison of three numbers with one bound.

Rung 2

Peel off the first term: \(H = H_1 + R\), \(R = H_2 + \cdots + H_L\). Two errors: replacing \(e^{-iH\delta}\) by \(e^{-iH_1\delta}e^{-iR\delta}\), then replacing \(e^{-iR\delta}\) by the product of the rest. For part 2, which pairs fail to commute does not depend on the order in which they are listed.

Rung 3

First line of part 1: \(\lVert e^{-iH\delta} - e^{-iH_1\delta}W\rVert\le\lVert e^{-iH\delta} - e^{-iH_1\delta}e^{-iR\delta}\rVert + \lVert e^{-iH_1\delta}(e^{-iR\delta} - W)\rVert\) with \(W = e^{-iH_2\delta}\cdots e^{-iH_L\delta}\).

Worked solution

Idea. One term at a time: each peel costs that term's commutators with everything after it, and the rest is the same problem with one term fewer.

1. \(L = 1\) is trivial and \(L = 2\) is the one-step bound. Assume the claim for \(L - 1\) terms. With \(R\) and \(W\) as in rung 3, the first term on the right is at most \(\tfrac{\delta^2}2\lVert[H_1, R]\rVert\le\tfrac{\delta^2}2\sum_{k\ge2}\lVert[H_1, H_k]\rVert\) (one-step bound; then linearity of the commutator and the triangle inequality). The second equals \(\lVert e^{-iR\delta} - W\rVert\) by unitary invariance, at most \(\tfrac{\delta^2}2\sum_{2\le j \lt k}\lVert[H_j, H_k]\rVert\) by hypothesis. The two sums together run over all pairs \(j \lt k\). ∎ Over \(r\) steps, the hybrid argument multiplies by \(r\) with \(\delta = t/r\): \(\frac{t^2}{2r}\sum_{j \lt k}\lVert[H_j, H_k]\rVert\).

2. A bond \(-Z_iZ_{i+1}\) and a site \(-X_j\) clash exactly when \(j\in\{i, i + 1\}\) (P2, part 4), with \(\lVert[Z_iZ_{i+1}, X_j]\rVert = \lVert2iY_iZ_{i+1}\rVert = 2\) (or \(2iZ_iY_{i+1}\)). Two bonds commute; two sites commute. So the sum is \(2(n - 1)\times2 = 4(n - 1)\), whatever the order: \(28\) at \(n = 8\). The bound is \(28\times25/2000 = 0.35\).

3. Neither is inconsistent: \(0.0144\le0.35\) and \(0.155\le0.35\) ✓. But the two orders differ by a factor of \(10.7\), and the bound — which depends only on which pairs clash — gives both the same number. So the ordering of terms is a free parameter the bound is blind to; at \(n = 8\) one can compute which order is better, and at \(n = 50\) one cannot. (The grouped order also satisfies the sharper two-term bound with the exact \(\lVert[A, B]\rVert = 19.0\), namely \(0.238\); the interleaved order has no such two-term form.)

Check. \(L = 2\) recovers the one-step bound ✓. For terms that all commute the sum is 0 and the product is exact, as P2 proved ✓.

sites = [-word({i: 'X'}) for i in range(n)]
U = linalg.exp_hermitian(sum(bonds) + sum(sites), -1j * t)

def error(order):
    step = np.eye(2**n, dtype=complex)

Hints · 3 rungs
Rung 1

Parts 1 and 2 multiply three power series and sort by degree. Part 3 is one line for \(S\) and a second-derivative argument, as in P2, for \(V\).

Rung 2

In degree 2 there are six contributions to \(S\): one \(\delta^2\) term from each factor, and one product of \(\delta\) terms from each pair of factors, in order. For part 2, bound every term of degree \(m\) of \(S\) by the corresponding term of \(\big(\tfrac{\lVert A\rVert\delta}2 + \lVert B\rVert\delta + \tfrac{\lVert A\rVert\delta}2\big)^m/m!\).

Rung 3

First line of part 1, with \(a = -iA\), \(b = -iB\): the \(\delta^2\) coefficient of \(S\) is \(\tfrac{a^2}8 + \tfrac{b^2}2 + \tfrac{a^2}8 + \tfrac a2b + \tfrac a2\tfrac a2 + b\tfrac a2\).

Worked solution

Idea. A palindrome of exponentials agrees with the true evolution one order further than a non-palindrome, because the asymmetric \(ab\) has been split evenly into \(\tfrac12ab + \tfrac12ba\).

1. Degree 1: \(\tfrac a2 + b + \tfrac a2 = a + b\) ✓. Degree 2: from rung 3, \(\tfrac{a^2}4 + \tfrac{a^2}4 + \tfrac{b^2}2 + \tfrac12ab + \tfrac12ba = \tfrac12(a^2 + ab + ba + b^2) = \tfrac12(a + b)^2\), which is the \(\delta^2\) coefficient of \(e^{(a+b)\delta}\) ✓.

2. Multiply out: \(S(\delta) = \sum_{p,q,s\ge0}\frac{(a\delta/2)^p(b\delta)^q(a\delta/2)^s}{p!\,q!\,s!}\), an absolutely convergent triple series. The part of degree \(m = p + q + s\) has norm at most \(\sum_{p+q+s = m}\frac{x^py^qx^s}{p!\,q!\,s!} = \frac{(2x + y)^m}{m!}\) with \(x = \lVert A\rVert\delta/2\), \(y = \lVert B\rVert\delta\) (multinomial theorem), and \(2x + y = \alpha\delta\). Likewise the degree-\(m\) part of \(e^{(a+b)\delta}\) has norm at most \((\alpha\delta)^m/m!\). Degrees 0, 1 and 2 cancel by part 1, so

\[ \lVert S(\delta) - e^{-i(A+B)\delta}\rVert\le2\sum_{m\ge3}\frac{(\alpha\delta)^m}{m!} = 2(\alpha\delta)^3\sum_{k\ge0}\frac{(\alpha\delta)^k}{(k + 3)!}\le\frac{(\alpha\delta)^3}{3}e^{\alpha\delta}, \]

since \((k + 3)!\ge6\cdot k!\). Over \(r\) steps, the hybrid argument gives at most \(\frac{\alpha^3t^3}{3r^2}e^{\alpha t/r}\), which is \(O(t^3/r^2)\) once \(r\ge\alpha t\).

3. \(S(-\delta) = e^{iA\delta/2}e^{iB\delta}e^{iA\delta/2}\), and \(S(\delta)^{-1} = (e^{-iA\delta/2})^{-1}(e^{-iB\delta})^{-1}(e^{-iA\delta/2})^{-1}\) in reversed order, which is the same product because the palindrome reads the same backwards ✓. For \(V\): \(V(-\delta) = e^{iA\delta}e^{iB\delta}\) while \(V(\delta)^{-1} = e^{iB\delta}e^{iA\delta}\). If these agree for all \(\delta\), differentiate twice at \(\delta = 0\) as in P2: \(-(A^2 + 2AB + B^2) = -(B^2 + 2BA + A^2)\), so \(AB = BA\).

4. \(\alpha = \lVert X\rVert + \lVert Z\rVert = 2\), so one step: \(\tfrac13(0.2)^3e^{0.2} = 0.00326\); ten steps: \(0.0326\). The actual \(0.0027\) is twelve times smaller, and the cited nested-commutator constant (\(0.005\)) is six times sharper than this crude bound. All three are \(O(t^3/r^2)\); only the constants differ.

Check. Part 1 for commuting \(A, B\): \(S(\delta) = e^{-i(A+B)\delta}\) exactly, consistent ✓. A remark only, since it uses the logarithm of a matrix near \(I\), which this course has not developed: writing \(S(\delta) = e^{-i(A + B)\delta + E(\delta)}\) for small \(\delta\), part 3 forces \(E(-\delta) = -E(\delta)\). P12 The flip symmetry, and a bad input hard

exercises: a symmetry commuting with \(H\), simultaneous eigenvectors, bounding an overlap, the cat state

The chain with \(J = h = 1\), and \(F = X_0X_1\cdots X_{n-1}\), which flips every spin.

  1. Show \(F^2 = I\) and \([F, H] = 0\).
  2. Suppose the ground energy \(E_0\) is non-degenerate (true at \(n = 8\), by computation). Show \(\ket{E_0}\) is an eigenvector of \(F\), with eigenvalue \(\pm1\).
  3. Show that \(\ket{0^n}\) has weight exactly \(\tfrac12\) on each eigenspace of \(F\), so \(|\braket{E_0|0^n}|^2\le\tfrac12\). If \(F\ket{E_0} = \ket{E_0}\), show the cat state \(\ket{\mathrm{cat}} = (\ket{0^n} + \ket{1^n})/\sqrt2\) has \(|\braket{E_0|\mathrm{cat}}|^2 = 2|\braket{E_0|0^n}|^2\).
  4. At \(n = 8\), \(\ket{0^8}\) has weights \(0.116\) on \(E_0\) and \(0.211\) on \(E_1\), and computation gives \(F = +1\) on \(\ket{E_0}\), \(F = -1\) on \(\ket{E_1}\). Predict the cat state's weights on \(E_0\) and \(E_1\).
Hints · 3 rungs
Rung 1

A unitary that commutes with \(H\) maps each eigenspace of \(H\) into itself; a one-dimensional eigenspace is then spanned by an eigenvector of the unitary. The weights in part 3 come from the projectors onto the eigenspaces of \(F\).

Rung 2

\(F\) and \(Z_iZ_{i+1}\) disagree (\(X\) against \(Z\)) in exactly two positions. The projectors of \(F\) are \(P_\pm = \tfrac12(I \pm F)\), and \(F\ket{0^n} = \ket{1^n}\).

Rung 3

First line of part 3: \(P_\pm\ket{0^n} = \tfrac12(\ket{0^n}\pm\ket{1^n})\), whose squared norm is \(\tfrac14(1 + 1) = \tfrac12\).

Worked solution

Idea. The chain cannot tell "all up" from "all down", so its eigenvectors are symmetric or antisymmetric under the flip; a basis state is half of each, and so can never have more than half its weight on the ground state.

1. \(F^2 = \prod_iX_i^2 = I\), the factors acting on different qubits. \(F\) commutes with each \(X_j\) (same reason). Against \(Z_iZ_{i+1}\) it has \(X\) where the bond has \(Z\) at two positions, and each swap of an anticommuting pair gives a sign: \((-1)^2 = 1\). So \(F\) commutes with every term, hence with \(H\).

2. \(HF\ket{E_0} = FH\ket{E_0} = E_0F\ket{E_0}\), so \(F\ket{E_0}\) lies in the \(E_0\)-eigenspace, which is spanned by \(\ket{E_0}\): \(F\ket{E_0} = \lambda\ket{E_0}\). Then \(\ket{E_0} = F^2\ket{E_0} = \lambda^2\ket{E_0}\), so \(\lambda = \pm1\).

3. \(F\) is Hermitian and unitary with \(F^2 = I\), so \(P_\pm = \tfrac12(I\pm F)\) are the projectors onto its \(\pm1\) eigenspaces (they are Hermitian, \(P_\pm^2 = \tfrac14(I \pm 2F + I) = P_\pm\), and \(P_+ + P_- = I\)). By rung 3 each has weight \(\tfrac12\) on \(\ket{0^n}\) — the weights sum to 1 ✓. If \(F\ket{E_0} = \pm\ket{E_0}\) then \(\braket{E_0|0^n} = \braket{E_0|P_\pm|0^n}\), so \(|\braket{E_0|0^n}|^2\le\lVert P_\pm\ket{0^n}\rVert^2 = \tfrac12\) by Cauchy–Schwarz. If \(F\ket{E_0} = \ket{E_0}\): \(\braket{E_0|0^n} = \braket{E_0|P_+0^n} = \tfrac12\braket{E_0|0^n + 1^n} = \tfrac1{\sqrt2}\braket{E_0|\mathrm{cat}}\), and squaring gives the factor 2.

4. \(\ket{\mathrm{cat}}\) is in the \(+1\) eigenspace, so it has weight 0 on \(\ket{E_1}\) (orthogonal eigenspaces of \(F\)) and \(2\times0.116 = 0.232\) on \(\ket{E_0}\).

Check. \(0.116\le\tfrac12\) ✓. The cat state is not hard to prepare — one \(H\) and \(n - 1\) CNOTs — so this symmetry argument doubles the success rate of phase estimation for free. It does not reach the \(0.565\) of \(\ket{+}^{\otimes8}\), which is itself flip-symmetric (\(F\ket{+}^{\otimes n} = \ket{+}^{\otimes n}\)) and closer to the ground state at \(J = h\).

exercises: the same splitting for real matrices, second order from symmetry, area preservation in place of unitarity

Optional, and a cross-reference only: Mechanics to Relativity's unit 14 treats a Hamiltonian as generating a flow on phase space. Nothing here needs that course. The linear differential equation \((q, p)' = (p, -q)\) has flow \(R(t) = e^{tN} = \begin{pmatrix}\cos t&\sin t\\ -\sin t&\cos t\end{pmatrix}\) with \(N = N_D + N_K\), \(N_D = \begin{pmatrix}0&1\\0&0\end{pmatrix}\) (the "drift" \(q' = p\)) and \(N_K = \begin{pmatrix}0&0\\-1&0\end{pmatrix}\) (the "kick" \(p' = -q\)).

  1. Compute \(D(\delta) = e^{\delta N_D}\) and \(K(\delta) = e^{\delta N_K}\).
  2. Compute the first-order step \(D(\delta)K(\delta)\) and the symmetric step \(K(\tfrac\delta2)D(\delta)K(\tfrac\delta2)\), and show both have determinant 1.
  3. Show the symmetric step agrees with \(R(\delta)\) through \(\delta^2\), the first-order step only through \(\delta\).
  4. At \(t = 1\) the errors (operator norm) are \(0.0435\) and \(0.00147\) with 10 steps, \(0.0214\) and \(0.00037\) with 20. Which laws are these?
Hints · 3 rungs
Rung 1

The exponentials are of nilpotent matrices — unit 00's Exponentials do not add slide had exactly this kind — so the series stop after two terms. Everything else is \(2\times2\) multiplication.

Rung 2

\(N_D^2 = N_K^2 = 0\), so \(D(\delta) = I + \delta N_D\) and \(K(\delta) = I + \delta N_K\): shears. Expand \(\cos\delta = 1 - \tfrac{\delta^2}2 + \cdots\), \(\sin\delta = \delta - \tfrac{\delta^3}6 + \cdots\) for part 3.

Rung 3

First line of part 2: \(K(\tfrac\delta2)D(\delta) = \begin{pmatrix}1&0\\-\delta/2&1\end{pmatrix}\begin{pmatrix}1&\delta\\0&1\end{pmatrix} = \begin{pmatrix}1&\delta\\-\delta/2&1 - \delta^2/2\end{pmatrix}\).

Worked solution

Idea. The same algebra as the unit, with real matrices: splitting a flow into exactly solvable pieces, and symmetrising for second order. Unitarity is replaced by determinant 1 — area preservation.

1. \(D(\delta) = \begin{pmatrix}1&\delta\\0&1\end{pmatrix}\), \(K(\delta) = \begin{pmatrix}1&0\\-\delta&1\end{pmatrix}\).

2. \(D(\delta)K(\delta) = \begin{pmatrix}1 - \delta^2&\delta\\-\delta&1\end{pmatrix}\), determinant \(1 - \delta^2 + \delta^2 = 1\). Continuing rung 3,

\[ K(\tfrac\delta2)D(\delta)K(\tfrac\delta2) = \begin{pmatrix}1 - \delta^2/2&\delta\\-\delta + \delta^3/4&1 - \delta^2/2\end{pmatrix}, \]

determinant \((1 - \tfrac{\delta^2}2)^2 + \delta(\delta - \tfrac{\delta^3}4) = 1 - \delta^2 + \tfrac{\delta^4}4 + \delta^2 - \tfrac{\delta^4}4 = 1\) ✓. (Each factor is a shear of determinant 1.)

3. \(R(\delta) = \begin{pmatrix}1 - \delta^2/2 + O(\delta^4)&\delta - \delta^3/6\\-\delta + \delta^3/6&1 - \delta^2/2 + O(\delta^4)\end{pmatrix}\) up to \(O(\delta^4)\) off the diagonal. The symmetric step matches every entry through \(\delta^2\) and first differs at \(\delta^3\) (\(\delta^3/4\) against \(\delta^3/6\) in the lower left; \(0\) against \(-\delta^3/6\) in the upper right). The first-order step already differs at \(\delta^2\) in the upper left: \(1 - \delta^2\) against \(1 - \delta^2/2\).

4. Doubling the steps divides the first-order error by \(0.0435/0.0214 = 2.03\) and the symmetric one by \(0.00147/0.00037 = 4.0\): \(1/r\) and \(1/r^2\), the same laws as the quantum case.

Check.
