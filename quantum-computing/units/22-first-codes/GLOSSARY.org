The terms this unit introduces, in the order the deck meets them. The slides
stay the definition of record; each entry names the slide it comes from, so a
term can be looked up here and read properly there.

Running example: the three-qubit bit-flip code, \(\alpha\ket0 + \beta\ket1
\mapsto \alpha\ket{000} + \beta\ket{111}\) by two CNOTs, with parity checks
\(Z_0Z_1\) and \(Z_1Z_2\) whose four syndromes identify no error or a flip on
one of the three qubits. Under independent flips of probability \(p\) it fails
with probability \(3p^2 - 2p^3\) — \(2.998\times10^{-6}\) at \(p = 10^{-3}\),
below \(p\) exactly when \(p < \frac12\) — and a single phase flip defeats it.
Then Shor's nine-qubit code, the phase-flip code with each qubit replaced by a
bit-flip code: it satisfies the Knill–Laflamme conditions for every
single-qubit Pauli, with a degenerate matrix of rank 22, and corrects a
rotation \(R_Y(0.2)\) on qubit 4 exactly, in both of the branches the syndrome
measurement produces (probabilities 0.990 and 0.010).

* Why it looks impossible

- repetition code :: The classical code \(0\mapsto000\), \(1\mapsto111\),
  decoded by majority vote. Against independent flips of probability \(p\) it
  fails with probability \(3p^2 - 2p^3\). /Slide: Repetition protects a bit./
- no-cloning theorem :: No unitary \(U\) and fixed state \(\ket e\) satisfy
  \(U\ket\psi\ket e = \ket\psi\ket\psi\) for every \(\ket\psi\): copying two
  states forces \(\braket{\varphi|\psi} = \braket{\varphi|\psi}^2\), so they
  must be equal or orthogonal. An orthonormal basis can be copied, by CNOT.
  /Slide: Objection one: there is no copier./

* The bit-flip code

- bit-flip code :: The three-qubit code with \(\ket{0_L} = \ket{000}\) and
  \(\ket{1_L} = \ket{111}\), encoded by the isometry \(\alpha\ket0 +
  \beta\ket1\mapsto\alpha\ket{000} + \beta\ket{111}\), which two CNOTs
  implement. It corrects any single \(X\) and no single \(Z\). /Slide: Encode
  by entangling, not by copying./
- logical qubit :: The two-dimensional system a code protects, with basis
  \(\ket{0_L}, \ket{1_L}\) inside a larger space of physical qubits. Operators
  acting on it within the code, such as \(X_L\) and \(Z_L\), are logical
  operators.
- code space :: The subspace \(C\) spanned by the codewords; for the bit-flip
  code \(\mathrm{span}\{\ket{000}, \ket{111}\}\), with projector \(P =
  \ket{000}\!\bra{000} + \ket{111}\!\bra{111}\).
- parity check :: An observable that reads the parity of some qubits rather
  than their values, such as \(Z_0Z_1\), with \(Z_0Z_1\ket x =
  (-1)^{x_0\oplus x_1}\ket x\). The bit-flip code is the joint \(+1\)
  eigenspace of \(Z_0Z_1\) and \(Z_1Z_2\); each single flip moves it to a
  different joint eigenspace. /Slide: Parities, not values./
- ancilla :: An extra qubit prepared in a known state, used during a
  computation and then measured or discarded. In the syndrome circuit each
  ancilla collects one parity by CNOTs from the data. /Slide: The syndrome
  circuit./
- syndrome :: The outcomes of the parity checks. For the bit-flip code
  \(s_1 = x_0\oplus x_1\), \(s_2 = x_1\oplus x_2\): \(00\) no error, \(10\)
  \(X_0\), \(11\) \(X_1\), \(01\) \(X_2\). It depends on the error, not on the
  encoded state, so measuring it disturbs nothing.
- recovery :: The procedure that undoes an identified error: for the bit-flip
  code, apply \(X_k\) on the syndrome naming qubit \(k\). As a channel it has
  Kraus operators \(P\) and \(PX_k\); it can also be done coherently with
  Toffoli gates and no measurement. /Slide: Correcting, by measurement or by
  gates./

* Phase flips, and Shor's nine qubits

- phase-flip code :: \(\ket{0_L} = \ket{+++}\), \(\ket{1_L} = \ket{---}\): the
  bit-flip code conjugated by \(H^{\otimes3}\), with checks \(X_0X_1\),
  \(X_1X_2\). It corrects any single \(Z\) and no single \(X\). /Slide: The
  phase-flip code: the same code, seen through H./
- Shor's nine-qubit code :: \(\ket{0_L} = (\ket{000} +
  \ket{111})^{\otimes3}/2\sqrt2\), \(\ket{1_L} = (\ket{000} -
  \ket{111})^{\otimes3}/2\sqrt2\) (Shor, 1995). Six \(ZZ\) checks inside the
  blocks catch bit flips, two six-qubit \(X\) checks between them catch phase
  flips. A \([[9, 1, 3]]\) code, and degenerate. /Slide: Shor's code: one code
  inside the other./
- concatenation :: Encoding the qubits of one code with another code. Shor's
  code is the phase-flip code concatenated with the bit-flip code; repeated
  concatenation drives unit 24's threshold theorem.

* The Knill–Laflamme conditions

- quantum code :: A subspace \(C\) of a Hilbert space, with projector \(P\).
  It corrects an error set if some channel undoes the errors on every state in
  \(C\). /Slide: What it means for a code to correct a set of errors./
- error set :: A finite list of operators \(E_i\), typically the Kraus
  operators of the noise, defining \(\mathcal E(\rho) = \sum_iE_i\rho
  E_i^\dagger\).
- recovery channel :: A channel \(\mathcal R\) with \(\mathcal R(\mathcal
  E(\rho)) = c\rho\) for every density operator \(\rho\) on the code, \(c > 0\)
  a constant. It may depend on the code and the error set, never on \(\rho\) or
  on which error occurred.
- Knill–Laflamme conditions :: \(C\) corrects \(\{E_i\}\) if and only if
  \(PE_i^\dagger E_jP = \alpha_{ij}P\) for some matrix \(\alpha\), which is
  then Hermitian and positive semidefinite (Knill and Laflamme, 1997). Proved
  sufficient by diagonalising \(\alpha\) and measuring which orthogonal image
  of the code the state is in, and necessary because any recovery makes each
  \(R_kE_i\) a scalar on the code. Read physically: a recoverable error leaves
  the environment in a state, \(\alpha^{\mathsf T}\), independent of the code
  state. /Slide: The conditions./
- degenerate code :: A code whose Knill–Laflamme matrix \(\alpha\) is
  singular: some non-trivial combination of correctable errors acts on the code
  as zero, so distinct errors act identically. Shor's code is degenerate:
  \(Z_0, Z_1, Z_2\) act alike, and its 28 by 28 \(\alpha\) has rank 22.
  /Slide: Shor's code passes, and is degenerate./

* Discretisation, and distance

- discretisation of errors :: A code that corrects \(I\) and \(X, Y, Z\) on
  each qubit corrects every noise whose Kraus operators each act on one qubit,
  because \(I, X, Y, Z\) span the \(2\times2\) matrices and correctable errors
  form a linear space, corrected by the same recovery. The syndrome measurement
  projects a continuous error onto finitely many Pauli branches. /Slide: The
  discretisation of errors./
- weight :: Of a Pauli operator on \(n\) qubits, the number of tensor factors
  that are not \(I\). /Slide: Distance, and how many errors a code corrects./
- distance :: Of a quantum code, the least weight of a Pauli \(E\) it does not
  detect, i.e. with \(PEP\) not a multiple of \(P\). A code of distance \(d\)
  corrects every error on \(\lfloor(d - 1)/2\rfloor\) qubits; an \(n\)-qubit
  code of dimension \(2^k\) and distance \(d\) is an \([[n, k, d]]\) code. Of a
  classical linear code, the least weight of a non-zero codeword.

* Classical linear codes

- linear code :: A \(k\)-dimensional subspace \(C\) of \(\mathbb F_2^n\), an
  \([n, k]\) code; with distance \(d\), an \([n, k, d]\) code. /Slide: Linear
  codes over F2./
- generator matrix :: A \(k\times n\) matrix \(G\) whose rows are a basis of
  the linear code \(C\), so \(C = \{uG\}\).
- parity-check matrix :: An \((n - k)\times n\) matrix \(H\) of rank \(n - k\)
  with \(C = \ker H\). The syndrome of a received word \(y = c + e\) is \(Hy =
  He\), a function of the error alone.
- Hamming weight :: The number of 1s in a binary word. The Hamming distance of
  two words is the weight of their sum.
- Hamming code :: The \([7, 4, 3]\) code \(\ker H\) whose parity-check matrix
  has column \(j\) equal to \(j\) in binary (Hamming, 1950), so the syndrome of
  a single error spells its position. /Slide: The Hamming [7, 4, 3] code./
- dual code :: \(C^\perp = \{y : y\cdot c = 0\ \text{for all}\ c\in C\}\) with
  the dot product mod 2; it has dimension \(n - k\) and, for \(C = \ker H\), is
  the row space of \(H\). A non-zero word can be orthogonal to itself. /Slide:
  The dual code, and a code inside its dual./
- simplex code :: The \([7, 3, 4]\) dual of the Hamming code, spanned by the
  rows of its parity-check matrix; its seven non-zero words all have weight 4.
  It is contained in the Hamming code, which is what unit 23's CSS construction
  needs for Steane's code.
