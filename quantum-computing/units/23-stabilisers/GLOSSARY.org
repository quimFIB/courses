The terms this unit introduces, in the order the deck meets them. The slides
stay the definition of record; each entry names the slide it comes from, so a
term can be looked up here and read properly there.

Running example: Steane's code, built from Hamming's parity-check matrix \(M\),
whose columns are \(1, \dots, 7\) in binary (rows \(0001111\), \(0110011\),
\(1010101\)). Each row \(h\) is read twice, as \(X^h\) and as \(Z^h\): six
commuting generators \(IIIXXXX, IXXIIXX, XIXIXIX, IIIZZZZ, IZZIIZZ, ZIZIZIZ\)
on qubits \(1, \dots, 7\), a check matrix of rank 6, and a code of dimension
\(2^{7-6} = 2\). A \(Y\) error on qubit 5 has both syndromes \(101\). The
logical operators are \(\bar X = X^{\otimes7}\), \(\bar Z = Z^{\otimes7}\),
with weight-3 representatives such as \(X_1X_2X_3\); the distance is 3, so
the code is \([[7, 1, 3]]\), the CSS code of Hamming \(\supseteq\) simplex.
Twelve Clifford gates prepare \(\ket{0_L}\), and a tableau follows them
exactly; seven transversal Hadamards perform the logical Hadamard.

* Stabiliser groups

- ancilla :: An extra qubit, prepared in a known state, used to extract
  information from other qubits and then measured. To measure a Pauli product
  \(g\) on data qubits: ancilla in \(\ket0\), \(H\), controlled-\(g\), \(H\),
  measure; the outcome is \(\pm1\) with probability \(\bra\psi\tfrac{I\pm
  g}2\ket\psi\) and the data are projected, never read. /Slide: The
  experiment: measuring a product of Paulis./
- Pauli group :: \(\mathcal P_n\), all \(i^cP_0\otimes\cdots\otimes P_{n-1}\) with
  \(c\in\{0,1,2,3\}\) and \(P_j\in\{I, X, Y, Z\}\); \(4\cdot4^n\) elements,
  written as strings like \(XZYIZ\). Any two elements commute or anticommute,
  anticommuting exactly when the number of positions with two different
  non-\(I\) letters is odd. /Slide: The Pauli group, and when two strings
  commute./
- weight :: The number of non-identity letters in a Pauli string. Subadditive:
  \(\mathrm{wt}(PQ)\le\mathrm{wt}P + \mathrm{wt}Q\).
- stabiliser group :: An abelian subgroup \(S\subseteq\mathcal P_n\) not
  containing \(-I\). Its elements are then all \(\pm\) Pauli strings, hence
  Hermitian with eigenvalues \(\pm1\). Both conditions are forced if \(S\) is
  to fix any nonzero vector. /Slide: A stabiliser group, and the code it fixes./
- stabiliser code :: \(V_S = \{\psi : g\psi = \psi\ \forall g\in S\}\), the
  joint \(+1\) eigenspace of a stabiliser group. With \(r\) independent
  generators on \(n\) qubits it has dimension \(2^{n-r}\): an \([[n, n -
  r]]\) code.
- generator :: One of a list \(g_1, \dots, g_r\) whose products give all of
  \(S\). A vector is in \(V_S\) iff every generator fixes it.
- independent :: Generators none of which is a product of the others.
  Equivalent to linear independence of their binary vectors \(v(g_j)\); then
  \(|S| = 2^r\).

* Paulis as bit strings

- non-degenerate :: A bilinear form \(\beta\) on \(\mathbb F_2^m\) with
  \(\beta(u, \cdot) = 0\Rightarrow u = 0\), i.e. an invertible Gram matrix.
  For such a symmetric form, \(\dim W^\beta = m - \dim W\) and \((W^\beta)^\beta =
  W\), even though \(W\cap W^\beta\) may be nonzero. /Slide: Linear algebra
  over the field with two elements./
- symplectic form :: On \(\mathbb F_2^{2n}\), \(\omega((x|z), (x'|z')) = x\cdot
  z' + z\cdot x'\), with Gram matrix \(J = \begin{pmatrix}0 & I\\I &
  0\end{pmatrix}\). With the map \(v(P) = (x|z)\) coding \(I, X, Z, Y\) as
  \(00, 10, 01, 11\): \(v(PQ) = v(P) + v(Q)\) and \(PQ = (-1)^{\omega(v(P),
  v(Q))}QP\). /Slide: The binary symplectic representation./
- isotropic :: A subspace on which \(\omega\) vanishes identically. The image
  \(v(S)\) of a stabiliser group is isotropic, so has dimension at most \(n\).
  /Slide: A stabiliser group is an isotropic subspace./
- check matrix :: The \(r\times2n\) binary matrix \(G\) with rows \(v(g_1),
  \dots, v(g_r)\). The generators commute iff \(GJG^{\mathsf T} = 0\) and are
  independent iff \(\mathrm{rank}\,G = r\). For Steane's code,
  \(G = \begin{pmatrix}M & 0\\0 & M\end{pmatrix}\).

* Syndromes, logical operators, distance

- syndrome :: For a Pauli error \(E\), \(s(E) = GJ\,v(E)^{\mathsf T}\in\mathbb
  F_2^r\): bit \(j\) is 1 iff \(E\) anticommutes with \(g_j\). Measuring the
  generators on \(E\psi\), \(\psi\in V_S\), returns \((-1)^{s_j}\) with
  certainty, independent of \(\psi\). /Slide: The syndrome is a matrix–vector
  product./
- decoder :: A rule assigning to each syndrome a Pauli correction \(R\) with
  that syndrome. Correction succeeds when \(RE\in\langle S, iI\rangle\), not
  only when \(RE = I\).
- normaliser :: \(N(S)\), the Paulis commuting with every element of \(S\);
  in symplectic terms \(v(N(S)) = v(S)^\omega\), of dimension \(2n - r\). Its
  elements preserve \(V_S\) and have syndrome 0. /Slide: The normaliser, and
  \(2k\) logical operators./
- logical operators :: Elements of \(N(S)\setminus\langle S, iI\rangle\): they
  act on the code as non-scalar operators. Modulo \(S\) there are \(2k\)
  independent ones, choosable as \(\bar X_1, \bar Z_1, \dots, \bar X_k, \bar
  Z_k\) with the commutation relations of \(k\) qubits. Steane: \(\bar X =
  X^{\otimes7}\), \(\bar Z = Z^{\otimes7}\).
- distance :: The least weight of a logical operator, an element of
  \(N(S)\setminus\langle S, iI\rangle\); written \([[n, k, d]]\). A code of
  distance \(d\ge2t + 1\) corrects every error on at most \(t\) qubits.
  Steane's code has \(d = 3\). /Slide: Logical means nontrivial, and distance
  means lightest./
- degenerate :: Of a code and a set of Pauli errors: two distinct errors
  differ by an element of \(\langle S, iI\rangle\), so they act identically on
  the code and need no distinguishing. Shor's code is degenerate: \(Z_0Z_1\in
  S\). Equivalent to unit 22's singular \(\alpha\). /Slide: Knill–Laflamme for
  stabiliser codes./

* CSS: quantum codes from classical ones

- CSS code :: For classical linear codes \(C_2\subseteq C_1\subseteq\mathbb
  F_2^n\) of dimensions \(k_2\lt k_1\), the span of the coset states \(\ket{x +
  C_2}\), \(x\in C_1\): an \([[n, k_1 - k_2]]\) code. /Slide: Coset states./
- coset state :: \(\ket{x + C_2} = |C_2|^{-1/2}\sum_{y\in C_2}\ket{x + y}\),
  the uniform superposition over one coset; distinct cosets give orthogonal
  states. Steane's \(\ket{0_L}\) is the simplex code's, \(\ket{1_L}\) its
  complement's.
- CSS construction :: Calderbank–Shor and Steane (1996): \(\mathrm{CSS}(C_1,
  C_2)\) is the stabiliser code with \(Z\)-type generators from the rows of a
  parity-check matrix of \(C_1\) and \(X\)-type generators from a basis of
  \(C_2\); they commute because \(C_2\subseteq C_1\). It corrects \(t\) bit
  flips if \(C_1\) does and \(t\) phase flips if \(C_2^\perp\) does. /Slide:
  CSS codes are stabiliser codes./
- five-qubit code :: The \([[5, 1, 3]]\) code with generators \(XZZXI\) and
  its cyclic shifts (Laflamme, Miquel, Paz, Zurek; Bennett, DiVincenzo,
  Smolin, Wootters; 1996). Not CSS; the smallest code correcting one arbitrary
  error. /Slide: The five-qubit code: not CSS, and smaller./
- quantum Hamming bound :: For a non-degenerate \([[n, k]]\) code correcting
  all errors of weight \(\le t\): \(2^k\sum_{j\le t}\binom nj3^j\le2^n\),
  because the error images \(E_aV_S\) are mutually orthogonal. Steane: \(44\le
  128\). /Slide: The quantum Hamming bound./
- perfect code :: One meeting the quantum Hamming bound with equality, so that
  every syndrome is used exactly once. The five-qubit code: \(2\cdot(1 + 15) =
  32 = 2^5\).

* Gottesman–Knill

- Clifford group :: The unitaries mapping \(\mathcal P_n\) to itself under
  conjugation, up to global phase; generated by \(H\), \(S\) and CNOT
  (Gottesman 1998, cited). \(H\colon X\leftrightarrow Z\); \(S\colon X\mapsto
  Y\), \(Z\mapsto Z\); CNOT copies \(X\) forward and \(Z\) backward. \(T\) is
  not in it. /Slide: The Clifford group./
- stabiliser state :: The unique state, up to phase, fixed by a stabiliser
  group with \(n\) independent generators on \(n\) qubits. Examples:
  \(\ket{0^n}\), Bell states, the GHZ state, Steane's \(\ket{0_L}\). /Slide:
  Follow the stabiliser, not the state./
- tableau :: The \(n\times2n\) check matrix of a stabiliser state's generators
  plus \(n\) sign bits: \(2n^2 + n\) bits. A Clifford gate on one or two qubits
  updates it in \(O(n)\) time by fixed bit rules.
- Gottesman–Knill theorem :: A circuit of \(m\) gates from \(\{H, S,
  \mathrm{CNOT}\}\) on \(\ket{0^n}\) with \(q\) Pauli measurements is simulated
  exactly by a classical computer in time \(O(nm + qn^3)\). Each measurement
  outcome is certain or a fair coin. Consequence: entanglement alone does not
  make a computation hard. /Slide: The Gottesman–Knill theorem./
- GHZ state :: \(\tfrac1{\sqrt2}(\ket{000} + \ket{111})\), stabilised by
  \(XXX, ZZI, IZZ\); made by \(H_0\), \(\mathrm{CNOT}_{01}\),
  \(\mathrm{CNOT}_{12}\). Measuring \(Z_0\) gives \(\pm1\) with probability
  \(\tfrac12\), after which \(Z_2\) is certain. After Greenberger, Horne and
  Zeilinger (1989). /Slide: Worked: three qubits into a GHZ state./
- transversal :: Of a gate on a code block: a tensor product of gates acting
  on the block's qubits one at a time, so that a fault spreads to no other
  qubit of the block. \(H^{\otimes7}\) is a transversal logical Hadamard on
  Steane's code. /Slide: Close: seven Hadamards make one./
