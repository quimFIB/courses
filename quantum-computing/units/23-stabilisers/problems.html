Stabiliser groups

P1 Which groups fix something routine

exercises: the two conditions on a stabiliser group, products of Pauli strings, the dimension count, dependent generators

  1. Prove that a subgroup \(S\subseteq\mathcal P_n\) fixes only the zero vector if it contains \(-I\), or if it contains two anticommuting elements. Prove that if it fixes a nonzero vector, every element of \(S\) is \(\pm\) a Pauli string.
  2. For each list, decide whether it generates a stabiliser group. If it does, give the number \(r\) of independent generators, \(\dim V_S\), and a basis of \(V_S\).
    1. \(\langle XX, ZZ\rangle\) on two qubits;
    2. \(\langle XX, ZI\rangle\);
    3. \(\langle ZZI, IZZ, ZIZ\rangle\);
    4. \(\langle XX, ZZ, YY\rangle\);
    5. \(\langle XX, ZZ, -YY\rangle\).
Hints · 3 rungs
Rung 1

Part 1 is three short proofs, each by taking a nonzero fixed vector and deriving a contradiction or a constraint. Part 2 is five verdicts; for the yes cases the answer is a number and one or two vectors.

Rung 2

For each list, check every pair for commutation by counting positions where the letters are different and neither is \(I\). Then look for products: a generator that is a product of the others adds nothing, and a product that equals \(-I\) kills everything. Remember \(XZ = -iY\).

Rung 3

First line of (d): \(XX\cdot ZZ = (XZ)\otimes(XZ) = (-iY)\otimes(-iY) = -YY\), so \(XX\cdot ZZ\cdot YY = -YY\cdot YY\).

Worked solution

Idea. A nonzero fixed vector forces \(-I\notin S\) and commutativity; conversely, once those hold the dimension is \(2^{n-r}\), so the work is in finding \(r\) honestly — dependent generators and hidden \(-I\)'s are the traps.

1. Let \(\psi\ne0\) be fixed by all of \(S\). If \(-I\in S\), then \(\psi = -I\psi = -\psi\), so \(\psi = 0\): contradiction. If \(g, h\in S\) with \(gh = -hg\), then \(\psi = gh\psi = -hg\psi = -\psi\): contradiction. Every element of \(\mathcal P_n\) is \(i^cP\) for a string \(P\); if \(c\) is odd then \((i^cP)^2 = i^{2c}P^2 = -I\in S\), excluded. So \(c\) is even and the element is \(\pm P\), Hermitian.

2.

  1. \(XX\) and \(ZZ\): two positions with \(X\) against \(Z\), so they commute. Neither is \(\pm I\) or the other, so \(r = 2\) and \(\dim V_S = 2^{2-2} = 1\). \(ZZ\) fixes \(\ket{00}, \ket{11}\); \(XX\) swaps them; so \(V_S\) is spanned by \(\tfrac1{\sqrt2}(\ket{00} + \ket{11})\), the Bell state, normalised \(\tfrac12 + \tfrac12 = 1\).
  2. \(XX\) against \(ZI\): one position, so they anticommute. Not a stabiliser group; \(V_S = \{0\}\).
  3. All three are \(Z\)-type, so commute; but \(ZZI\cdot IZZ = ZIZ\), so the third is dependent. \(r = 2\), \(\dim = 2^{3-2} = 2\), basis \(\ket{000}, \ket{111}\). Writing three generators would wrongly suggest \(2^{3-3} = 1\).
  4. Pairs: \(XX, YY\) differ in two positions, commute; \(ZZ, YY\) likewise. But \(XX\cdot ZZ = (-iY)\otimes(-iY) = -YY\), so \(XX\cdot ZZ\cdot YY = -YY^2 = -I\in S\). Not a stabiliser group; \(V_S = \{0\}\). Directly: \(YY\ket{00} = (i)(i)\ket{11} = -\ket{11}\) and \(YY\ket{11} = (-i)(-i)\ket{00} = -\ket{00}\), so the Bell state has \(YY = -1\), and nothing has \(XX = ZZ = YY = +1\).
  5. \(-YY = XX\cdot ZZ\) is already in \(\langle XX, ZZ\rangle\): the same group as (a). \(r = 2\), \(\dim = 1\), the same Bell state; and indeed \(-YY\) fixes it, by the computation in (d).

Check. (a) and (e) agree, as they must, since they are the same group. In (d) and (e) the only difference is one sign — signs of generators matter, which is why the tableau of section 5 keeps them.

P2 Proof: the dimension, two ways medium

exercises: the projector expansion, traces of Pauli strings, non-degeneracy of \(\omega\), an induction on generators

Let \(S = \langle g_1, \dots, g_r\rangle\subseteq\mathcal P_n\) be a stabiliser group with independent generators.

  1. Prove \(\dim V_S = 2^{n-r}\) by showing \(P_S = \prod_j\tfrac{I + g_j}2 = 2^{-r}\sum_{g\in S}g\) and taking traces.
  2. Give a second proof. Show that there is a Pauli \(E\) that anticommutes with \(g_r\) and commutes with \(g_1, \dots, g_{r-1}\). Use it to show that, inside \(V_{S'}\) for \(S' = \langle g_1, \dots, g_{r-1}\rangle\), the \(+1\) and \(-1\) eigenspaces of \(g_r\) have equal dimension, and conclude by induction.
  3. Check on \(S = \langle XXXX, ZZZZ\rangle\): give \(\dim V_S\) and an orthonormal basis.
Hints · 3 rungs
Rung 1

Parts 1 and 2 are proofs ending in the same formula; part 3 is a number and four vectors. The first proof is in the deck — reproduce it with every step justified. The second is new: it trades traces for a unitary map between two subspaces.

Rung 2

For the existence of \(E\): you want a vector \(u\in\mathbb F_2^{2n}\) with \(\omega(v(g_j), u) = 0\) for \(j\lt r\) and \(\omega(v(g_r), u) = 1\). That is a linear system \(GJu = e_r\). Why does it have a solution?

Rung 3

First line of part 2: the map \(u\mapsto GJu\) from \(\mathbb F_2^{2n}\) to \(\mathbb F_2^r\) has rank \(r\), because \(G\) has rank \(r\) (independence) and \(J\) is invertible; so it is onto, and some \(u\) maps to \((0, \dots, 0, 1)\).

Worked solution

Idea. Either count with traces — only the identity has nonzero trace — or find a symmetry that swaps the two halves of the space a new generator splits.

1. Each \(Q_j = \tfrac{I + g_j}2\) is an orthogonal projector (\(g_j\) Hermitian, \(g_j^2 = I\), so \(Q_j^2 = Q_j = Q_j^\dagger\)) onto the \(+1\) eigenspace of \(g_j\). They commute, so their product is an orthogonal projector onto the intersection of their ranges, which is \(V_S\). Expanding, \(P_S = 2^{-r}\sum_{T\subseteq\{1..r\}}\prod_{j\in T}g_j\). If two subsets \(T\ne T'\) gave the same product, then \(\prod_{j\in T\triangle T'}g_j = I\) (commute, and \(g_j^2 = I\)), making some \(g_j\) a product of others — excluded. So the \(2^r\) products are the distinct elements of \(S\). Every \(g\in S\) other than \(I\) is \(\pm\) a string \(P\ne I^{\otimes n}\) (it is \(\pm\) a string by P1, and \(-I\notin S\)), and \(\operatorname{tr}P = \prod_j\operatorname{tr}P_j = 0\) since some factor is \(X\), \(Y\) or \(Z\). So \(\operatorname{tr}P_S = 2^{-r}\cdot2^n\), and the trace of a projector is its rank.

2. Existence of \(E\). \(G\) (rows \(v(g_j)\)) has rank \(r\); \(J\) is invertible; so \(GJ\) has rank \(r\) and \(u\mapsto GJu\) maps onto \(\mathbb F_2^r\). Choose \(u\) with \(GJu = e_r\) and let \(E\) be the Pauli string with \(v(E) = u\). Its commutation bits with the generators are the entries of \(GJu\): it commutes with \(g_1..g_{r-1}\) and anticommutes with \(g_r\).

Halving. \(g_r\) commutes with \(S'\), so it maps \(V_{S'}\) into itself; it is Hermitian with eigenvalues \(\pm1\) there, so \(V_{S'} = V_+\oplus V_-\), with \(V_+ = V_S\). \(E\) commutes with \(S'\), so \(E\) maps \(V_{S'}\) into itself. If \(\psi\in V_+\) then \(g_rE\psi = -Eg_r\psi = -E\psi\), so \(E V_+\subseteq V_-\), and likewise \(EV_-\subseteq V_+\). \(E\) is unitary, hence injective, so \(\dim V_+\le\dim V_-\le\dim V_+\): equal. Thus \(\dim V_S = \tfrac12\dim V_{S'}\). Induction on \(r\) from \(\dim V_{\{I\}} = 2^n\) gives \(2^{n-r}\). (Each \(\langle g_1, \dots, g_j\rangle\) is again a stabiliser group with independent generators, so the step applies at every stage.)

3. \(XXXX\) and \(ZZZZ\) differ in four positions: commute. Independent; \(-I\notin S = \{IIII, XXXX, ZZZZ, YYYY\}\) (\(XXXX\cdot ZZZZ = (-iY)^{\otimes4} = YYYY\)). So \(\dim V_S = 2^{4-2} = 4\). \(ZZZZ = +1\) means even weight; \(XXXX = +1\) means symmetric under complementing every bit. Basis, each normalised \(\tfrac12 + \tfrac12 = 1\): \[\tfrac1{\sqrt2}(\ket{0000} + \ket{1111}),\ \tfrac1{\sqrt2}(\ket{0011} + \ket{1100}),\ \tfrac1{\sqrt2}(\ket{0101} + \ket{1010}),\ \tfrac1{\sqrt2}(\ket{0110} + \ket{1001}).\] They have disjoint supports, so they are orthonormal, and the eight even-weight strings are all used.

Check. Trace: \(\tfrac14\operatorname{tr}(IIII + XXXX + ZZZZ + YYYY) = 16/4 = 4\) ✓. For the second proof on this example: \(E = IIIX\) anticommutes with \(ZZZZ\) and commutes with \(XXXX\), and maps \(\ket{0000} + \ket{1111}\) (\(ZZZZ = +1\)) to \(\ket{0001} + \ket{1110}\) (\(ZZZZ = -1\)), as it should.

Steane's code

P3 Steane from Hamming medium

exercises: reading a parity-check matrix twice, commutation from \(MM^{\mathsf T} = 0\), the normaliser, a transversal gate

  1. From \(M\), write Steane's six generators as Pauli strings on qubits 1–7, and prove that they commute and are independent using only \(MM^{\mathsf T} = 0\) over \(\mathbb F_2\) and \(\operatorname{rank}M = 3\).
  2. Show that \(\bar X = X^{\otimes7}\) and \(\bar Z = Z^{\otimes7}\) lie in \(N(S)\setminus\langle S, iI\rangle\) and anticommute. Find a weight-3 operator that acts on the code as \(\bar X\), and one that acts as \(\bar Z\), naming the stabiliser that relates each to its weight-7 form.
  3. Prove that \(H^{\otimes7}\) maps \(V_S\) onto itself and conjugates \(\bar X\) to \(\bar Z\) and back.
  4. With \(\ket{0_L} = \ket{0 + C_2}\) and \(\ket{1_L} = \ket{1111111 + C_2}\) (\(C_2\) the simplex code), compute \(H^{\otimes7}\ket{0_L}\) and \(H^{\otimes7}\ket{1_L}\), and conclude that \(H^{\otimes7}\) is exactly the logical Hadamard on the code.
Hints · 3 rungs
Rung 1

Six strings; two short proofs; two weight-3 strings; a conjugation argument; then two explicit superpositions of sixteen basis states each.

Rung 2

\(X^h\) and \(Z^{h'}\) anticommute exactly at the positions where both \(h\) and \(h'\) are 1, so the sign is \((-1)^{h\cdot h'}\). For part 2, \(N(S)\) is described by "\(a, b\in\) Hamming"; for part 4, use \(\sum_{y\in C_2}(-1)^{y\cdot w} = |C_2|\) if \(w\in C_2^\perp\) and 0 otherwise.

Rung 3

First line of part 4: \(H^{\otimes7}\ket{0_L} = \tfrac1{\sqrt8}\sum_{y\in C_2}2^{-7/2}\sum_{w\in\mathbb F_2^7}(-1)^{y\cdot w}\ket w\).

Worked solution

Idea. Every claim reduces to a fact about \(M\): its rows are mutually orthogonal (the simplex code is inside its dual, Hamming), and \(1111111\) is a Hamming word outside the simplex code.

1. \(g_1 = IIIXXXX\), \(g_2 = IXXIIXX\), \(g_3 = XIXIXIX\), \(g_4 = IIIZZZZ\), \(g_5 = IZZIIZZ\), \(g_6 = ZIZIZIZ\). Two \(X\)-type (or two \(Z\)-type) strings never anticommute. \(X^h\) against \(Z^{h'}\): \(\omega = h\cdot h'\), which is the \((h, h')\) entry of \(MM^{\mathsf T}\), zero. Independence: the check matrix is \(\begin{pmatrix}M & 0\\0 & M\end{pmatrix}\), of rank \(3 + 3 = 6\).

2. \(v(\bar X) = (1111111\,|\,0)\). Against \(g_4, g_5, g_6\): \(\omega = h_i\cdot1111111 = |h_i| \bmod 2 = 4 \bmod 2 = 0\). It commutes with the \(X\)-type ones trivially. So \(\bar X\in N(S)\); likewise \(\bar Z\). Elements of \(S\) are \(X^aZ^b\) with \(a, b\) in the simplex code (row space of \(M\)), whose words have weight 0 or 4; \(1111111\) has weight 7, so \(\bar X, \bar Z\notin\langle S, iI\rangle\). They overlap in 7 positions, odd: anticommute. Weight 3: \(\bar Xg_1 = X^{1111111 + 0001111} = X^{1110000} = X_1X_2X_3\), and \(\bar Zg_4 = Z_1Z_2Z_3\). Since \(g_1, g_4\) act as \(I\) on the code, these act as \(\bar X\), \(\bar Z\).

3. \(HXH = Z\), \(HZH = X\) qubit by qubit, so \(H^{\otimes7}X^hH^{\otimes7} = Z^h\): conjugation swaps \(g_1\leftrightarrow g_4\), \(g_2\leftrightarrow g_5\), \(g_3\leftrightarrow g_6\). If \(\psi\in V_S\) and \(g\in S\), then \(gH^{\otimes7}\psi = H^{\otimes7}(H^{\otimes7}gH^{\otimes7})\psi = H^{\otimes7}\psi\), since \(H^{\otimes7}gH^{\otimes7}\in S\). So \(H^{\otimes7}V_S\subseteq V_S\), and equality holds because \(H^{\otimes7}\) is invertible. And \(X^{\otimes7}\leftrightarrow Z^{\otimes7}\).

4. With \(H^{\otimes7}\ket u = 2^{-7/2}\sum_w(-1)^{u\cdot w}\ket w\): \[H^{\otimes7}\ket{0_L} = \frac{1}{\sqrt8\,\sqrt{128}}\sum_w\Big(\sum_{y\in C_2}(-1)^{y\cdot w}\Big)\ket w = \frac{8}{\sqrt{1024}}\sum_{w\in C_2^\perp}\ket w = \frac14\sum_{w\in\mathrm{Ham}}\ket w.\] The inner sum is 8 on \(C_2^\perp\) = Hamming and 0 elsewhere (a nonzero linear functional on \(C_2\) is 1 on exactly half of it). Hamming is the disjoint union of \(C_2\) and \(1111111 + C_2\), so \(\tfrac14\sum_{\mathrm{Ham}}\ket w = \tfrac{\sqrt8}4(\ket{0_L} + \ket{1_L}) = \tfrac1{\sqrt2}(\ket{0_L} + \ket{1_L})\). For \(\ket{1_L}\), the extra factor is \((-1)^{1111111\cdot w} = (-1)^{|w|}\): \(+1\) on the even-weight words (those of \(\ket{0_L}\), weights 0, 4) and \(-1\) on the odd ones (weights 3, 7): \(H^{\otimes7}\ket{1_L} = \tfrac1{\sqrt2}(\ket{0_L} - \ket{1_L})\). That is the Hadamard matrix in the basis \(\ket{0_L}, \ket{1_L}\), with no extra phase.

Check. Normalisation: sixteen amplitudes \(\tfrac14\), \(16\cdot\tfrac1{16} = 1\) ✓. Applying \(H^{\otimes7}\) twice gives the identity, and the logical Hadamard squared is the identity ✓.

P4 Reading Steane's syndromes routine

exercises: syndromes as \(M\) times a vector, a lookup decoder, logical failure, a failure probability

  1. Give the six-bit syndromes \((g_1g_2g_3\,|\,g_4g_5g_6)\) of \(X_6\), \(Z_3\) and \(Y_7\).
  2. Show that the 21 single-qubit Paulis have 21 distinct nonzero syndromes. How many of the \(2^6\) syndromes does the decoder "undo the unique weight-one error with this syndrome" ever use?
  3. The error \(X_1X_2\) occurs. What does that decoder do, and what is left on the code?
  4. Suppose each qubit suffers an \(X\) independently with probability \(p\), and nothing else. Count, for each weight \(w\), how many \(X\)-error patterns the decoder turns into a logical error, and give the logical failure probability exactly and at \(p = 10^{-3}\). Some weight-3 patterns are harmless: which, and why? For which \(p\) does encoding help?
Hints · 3 rungs
Rung 1

Parts 1–3 are bit strings and one Pauli; part 4 is a polynomial in \(p\), a number, and a threshold.

Rung 2

The \(X\)-type checks read the \(Z\) part of the error, the \(Z\)-type checks its \(X\) part, each as \(M\) times that part. For part 4, the decoder adds one bit to make the pattern a Hamming codeword; the result fails exactly when that codeword is outside the simplex code, i.e. has weight 3 or 7.

Rung 3

First line of part 4: the Hamming code is perfect (every 7-bit word is within distance 1 of exactly one codeword), and its weights are 0 (once), 3 (seven times), 4 (seven times), 7 (once); so a pattern \(e\) fails iff its nearest codeword has weight 3 or 7.

Worked solution

Idea. Syndromes are columns of \(M\); the decoder is Hamming's classical decoder run twice; and a residual error is harmless exactly when it lands in the simplex code.

1. \(X_6\): \(Z\)-checks read column 6 \(= 110\); \(X\)-checks read nothing: \((000\,|\,110)\). \(Z_3\): \((011\,|\,000)\). \(Y_7\): both parts at 7 \(= 111\): \((111\,|\,111)\).

2. \(X_j\mapsto(000\,|\,\mathrm{bin}\,j)\), \(Z_j\mapsto(\mathrm{bin}\,j\,|\,000)\), \(Y_j\mapsto(\mathrm{bin}\,j\,|\,\mathrm{bin}\,j)\). The columns \(\mathrm{bin}\,j\) are the seven distinct nonzero 3-bit strings, so the three families are disjoint and internally distinct: 21 distinct nonzero syndromes. With \(0\) for "no error", the decoder uses 22 of the 64.

3. \(X_1X_2\) has syndrome \((000\,|\,001 + 010) = (000\,|\,011)\), the syndrome of \(X_3\). The decoder applies \(X_3\), leaving \(X_1X_2X_3 = \bar Xg_1\): a logical \(X\), undetected. Two errors beat a distance-3 code.

4. Let \(e\) be the \(X\)-pattern. The decoder flips the bit at position \(Me\) (if nonzero), producing the unique Hamming codeword \(c\) within distance 1 of \(e\); the residual \(X^c\) is harmless iff \(c\in\) simplex (weights 0, 4), and a logical \(\bar X\) iff \(c\) has weight 3 or 7. By weight of \(e\):

  • \(w = 0, 1\): \(c = 0\). No failures.
  • \(w = 2\): \(c\) is at distance 1, so has weight 1 or 3; only 3 exists. All \(\binom72 = 21\) fail.
  • \(w = 3\): the 7 codewords of weight 3 have syndrome 0 and stay: fail. The other 28 are at distance 1 from a codeword of weight 2 or 4, hence 4 — in the simplex code: harmless. The decoder "completes" them to a stabiliser.
  • \(w = 4\): 7 are simplex words (harmless); the other 28 sit next to a weight-3 or weight-5 codeword, hence 3: fail.
  • \(w = 5\): next to weight 4 or 6, hence 4: no failures. \(w = 6\): next to weight 7: all 7 fail. \(w = 7\): \(c = 1111111\): fails.

So \[P_{\rm fail} = 21p^2(1-p)^5 + 7p^3(1-p)^4 + 28p^4(1-p)^3 + 7p^6(1-p) + p^7 = 21p^2 - 98p^3 + 210p^4 - 252p^5 + 168p^6 - 48p^7.\] At \(p = 10^{-3}\): \(P_{\rm fail} = 2.090\times10^{-5}\), about 48 times better than an unencoded qubit's \(10^{-3}\). Encoding helps when \(P_{\rm fail}(p)\lt p\). In the physical range \(0\lt p\le\tfrac12\) (a flip more likely than not would just be relabelled) that holds exactly for \(0\lt p\lt0.0646\) (solved numerically; the curves meet again at \(p = \tfrac12\), where both are \(\tfrac12\)).

Check. Counts: \(21 + 7 + 28 + 7 + 1 = 64\) failing patterns out of 128, and at \(p = \tfrac12\) every pattern is equally likely, so \(P_{\rm fail} = 64/128 = \tfrac12\) ✓ — the polynomial gives \(0.5\) there too. For comparison, unit 22's bit-flip code gives \(3p^2 - 2p^3 = 3.0\times10^{-6}\) at the same \(p\): against bit flips alone it is better, using fewer qubits; Steane's buys protection against \(Z\) and \(Y\) as well.

Logical operators and distance

P5 Proof: 2(n − r) logical operators hard

exercises: symplectic complements over \(\mathbb F_2\), quotient spaces, a symplectic basis, the trace argument for scalars

Let \(S\) be a stabiliser group on \(n\) qubits with \(r\) independent generators, \(k = n - r\).

  1. Prove \(v(N(S)) = v(S)^\omega\) and \(\dim v(S)^\omega = 2n - r\).
  2. Prove that \(\omega\) induces a well-defined, non-degenerate form on the quotient \(v(N(S))/v(S)\), of dimension \(2k\).
  3. Prove that a non-degenerate alternating form on \(\mathbb F_2^{2k}\) has a basis \(a_1, b_1, \dots, a_k, b_k\) with \(\omega(a_i, b_i) = 1\) and all other pairs 0. Conclude that there are logical operators \(\bar X_i, \bar Z_i\) with the commutation relations of \(k\) qubits.
  4. Prove that \(P\in N(S)\) acts on \(V_S\) as a scalar iff \(P\in\langle S, iI\rangle\).
  5. For \(S = \langle XXXX, ZZZZ\rangle\), find \(\bar X_1, \bar Z_1, \bar X_2, \bar Z_2\), each of weight 2, and verify all their commutation relations.
Hints · 3 rungs
Rung 1

Four proofs and an example. The tools are: \(PQ = (-1)^\omega QP\); "\(\dim W^\beta = m - \dim W\)" for a symmetric non-degenerate form (in the deck); induction on \(k\); and the expansion \(P_S = 2^{-r}\sum_{g\in S}g\).

Rung 2

For part 2, the kernel of the induced form is \((v(S)^\omega)^\omega/v(S)\), and \((W^\omega)^\omega = W\). For part 3, pick \(a_1\ne0\), find \(b_1\) with \(\omega(a_1, b_1) = 1\), and split off \(\mathrm{span}(a_1, b_1)\). For part 4, take traces of \(PP_S = cP_S\).

Rung 3

First line of part 3: let \(W = \{u : \omega(u, a_1) = \omega(u, b_1) = 0\}\); these are two independent linear conditions, so \(\dim W = 2k - 2\), and \(W\cap\mathrm{span}(a_1, b_1) = \{0\}\).

Worked solution

Idea. Everything is linear algebra for the form \(\omega\): the normaliser is a complement, the logicals are a quotient, and a non-degenerate alternating form always looks like \(k\) copies of one qubit's \(X\), \(Z\).

1. \(P\in N(S)\) iff \(P\) commutes with every \(g\in S\) iff \(\omega(v(g), v(P)) = 0\) for all \(g\) iff \(v(P)\in v(S)^\omega\). And \(v(S)\) has dimension \(r\) (independence), \(\omega\) is symmetric and non-degenerate on \(\mathbb F_2^{2n}\) (Gram matrix \(J\)), so \(\dim v(S)^\omega = 2n - r\).

2. \(v(S)\subseteq v(S)^\omega\) (abelian). Define \(\bar\omega([u], [w]) = \omega(u, w)\) for \(u, w\in v(S)^\omega\); changing \(u\) by \(s\in v(S)\) changes \(\omega\) by \(\omega(s, w) = 0\) since \(w\in v(S)^\omega\); same for \(w\). Well defined. If \(\bar\omega([u], \cdot) = 0\), then \(u\) is \(\omega\)-orthogonal to all of \(v(S)^\omega\), so \(u\in(v(S)^\omega)^\omega = v(S)\), i.e. \([u] = 0\). Non-degenerate. Dimension \((2n - r) - r = 2k\).

3. Induction on \(k\); \(k = 0\) is empty. Take \(a_1\ne0\); non-degeneracy gives \(b_1\) with \(\omega(a_1, b_1) = 1\) (and \(b_1\ne a_1\) since \(\omega(a_1, a_1) = 0\)). Let \(W\) be as in rung 3. The two functionals \(\omega(\cdot, a_1)\), \(\omega(\cdot, b_1)\) are independent (they differ on \(a_1\) and \(b_1\)), so \(\dim W = 2k - 2\). If \(u = \alpha a_1 + \beta b_1\in W\), then \(\omega(u, b_1) = \alpha = 0\) and \(\omega(u, a_1) = \beta = 0\), so the sum \(\mathrm{span}(a_1, b_1) + W\) is direct and, by dimension, is everything. \(\omega\) is non-degenerate on \(W\): if \(w\in W\) is orthogonal to \(W\), it is also orthogonal to \(a_1, b_1\), hence to everything, so \(w = 0\). Apply induction to \(W\). Then pick Paulis \(\bar X_i, \bar Z_i\) with \(v\) in the cosets \(a_i, b_i\): \(\bar X_i\bar Z_i = -\bar Z_i\bar X_i\), all other pairs commute.

4. If \(P = i^cg\), \(g\in S\), it acts as \(i^c\). Conversely suppose \(PP_S = cP_S\). \(P\) is unitary and \(P_S\ne0\), so \(c\ne0\), and \(\operatorname{tr}(PP_S) = c2^k\ne0\). But \(\operatorname{tr}(PP_S) = 2^{-r}\sum_{g\in S}\operatorname{tr}(Pg)\), and \(Pg\in\mathcal P_n\) has trace 0 unless \(Pg\) is a multiple of \(I\). So for some \(g\), \(Pg = i^{c'}I\), giving \(P = i^{c'}g\in\langle S, iI\rangle\).

5. \(\bar X_1 = XXII\), \(\bar Z_1 = ZIZI\), \(\bar X_2 = XIXI\), \(\bar Z_2 = ZZII\). Each against \(XXXX\) and \(ZZZZ\): every \(X\)-type string commutes with \(XXXX\); \(XXII\) and \(XIXI\) each meet \(ZZZZ\) in two places, commute; similarly for the \(Z\)-type ones against \(XXXX\). Pairs: \(\bar X_1, \bar Z_1\) meet at qubit 0 only (\(X\) vs \(Z\)): anticommute ✓. \(\bar X_2, \bar Z_2\) meet at qubit 0 only: anticommute ✓. \(\bar X_1, \bar Z_2\) at qubits 0, 1: commute ✓. \(\bar X_2, \bar Z_1\) at qubits 0, 2: commute ✓. Same-type pairs commute ✓. None is in \(S = \{IIII, XXXX, ZZZZ, YYYY\}\) up to phase.

Check. Count: \(2k = 2(4 - 2) = 4\) ✓. Steane: \(2(7 - 6) = 2\), the pair \(\bar X, \bar Z\) ✓.

Rung 1

Rung 2

Idea. Inner bit-flip codes give \(ZZ\) checks, the outer phase-flip code gives \(X^{\otimes6}\) checks; the \(ZZ\)'s inside a block are also what make the code degenerate.

1. \(Z_0Z_1, Z_1Z_2, Z_3Z_4, Z_4Z_5, Z_6Z_7, Z_7Z_8\), \(X_0X_1X_2X_3X_4X_5\), \(X_3X_4X_5X_6X_7X_8\). Each \(ZZ\) meets each \(X^{\otimes6}\) in 0 or 2 places: commute. So both code states are fixed; with \(\dim = 2\), \(V_S = \mathrm{span}\{\ket{0_L}, \ket{1_L}\}\).

2. \(Z_0Z_3Z_6\) meets \(X_0\cdots X_5\) at 0, 3 and \(X_3\cdots X_8\) at 3, 6: commutes; it commutes with all \(Z\)'s. \(X_0X_1X_2\) meets \(Z_0Z_1\) and \(Z_1Z_2\) twice each. They meet once (qubit 0): anticommute. \(Z_0\) turns \(\ket{000}+\ket{111}\) into \(\ket{000}-\ket{111}\), so \(Z_0Z_3Z_6\) swaps \(\ket{0_L}\leftrightarrow\ket{1_L}\): it is \(\bar X\). \(X_0X_1X_2\) fixes \(\ket{000}+\ket{111}\) and negates \(\ket{000}-\ket{111}\): it is \(\bar Z\). 3. Let \(E\in N(S)\) have weight \(\le2\), with \(X\) part \(e\) and \(Z\) part \(f\). By rung 3, \(e\) is \(000\) or \(111\) on each block; \(111\) needs three positions, so \(e = 0\) and \(E = \pm Z^f\). \(Z^f\) commutes with \(X_0\cdots X_5\) iff \(f\) has even weight on blocks 1 and 2 together, and with \(X_3\cdots X_8\) iff even on blocks 2 and 3. Writing \(f_b\) for the parity of \(f\) on block \(b\): \(f_1 = f_2 = f_3\). All three odd needs weight \(\ge3\); so all are even, and in each block \(f\) is \(000\) or a pair, which is a product of that block's \(ZZ\) generators (e.g. \(Z_0Z_2 = Z_0Z_1\cdot Z_1Z_2\)). 4. \(X_q\): the two \(ZZ\) checks of its block give \(10, 11, 01\) for its three positions — 9 distinct syndromes. \(Z_q\): only the \(X^{\otimes6}\) checks see it, giving \(10, 11, 01\) for blocks 1, 2, 3 — so the three \(Z\)'s in a block share a syndrome. \(Y_q\): both parts, 9 distinct. Correcting \(Z_1\) by \(Z_0\) leaves a stabiliser, which does nothing. That is degeneracy, harmless.

Check. The same structure on Steane gives 21 distinct syndromes for 21 errors: non-degenerate. Shor's code gets the same 21 from 27 errors by not needing to tell some apart.

P11 Proof: Gottesman–Knill hard

exercises: conjugating a stabiliser, the measurement theorem in both cases, the CNOT sign rule, a running-time bound

  1. Prove: if \(\psi\) is the stabiliser state of \(\langle g_1, \dots, g_n\rangle\) and \(U\) is Clifford, \(U\psi\) is the stabiliser state of \(\langle Ug_1U^\dagger, \dots, Ug_nU^\dagger\rangle\).
  2. Prove the measurement theorem: for a Hermitian Pauli \(P\), (a) if \(P\) commutes with all \(g_j\) the outcome is certain; (b) if it anticommutes with \(g_1\), each outcome has probability \(\tfrac12\), and after outcome \(\lambda\) the state is the stabiliser state of \(\lambda P\) together with \(g_j\) (for \(g_j\) commuting with \(P\)) and \(g_1g_j\) (for \(g_j\), \(j\ge2\), anticommuting).
  3. Derive the CNOT sign rule \(r\mathrel{\oplus}= x_az_b(x_b\oplus z_a\oplus1)\).
  4. Conclude the theorem with a running time, and compare storage at \(n = 1000\): tableau bits against complex amplitudes.
Hints · 3 rungs
Rung 1

Four proofs and two numbers. The heart is part 2(b): a probability from an expectation value, and a check that a list of \(n\) operators is again a valid stabiliser.

Rung 2

2(a): an isotropic subspace of dimension \(n\) equals its own \(\omega\)-complement. 2(b): compute \(\bra\psi P\ket\psi\) by inserting \(g_1\). Part 3: write a two-qubit letter string as \(i^{x_az_a + x_bz_b}X_a^{x_a}Z_a^{z_a}X_b^{x_b}Z_b^{z_b}\) and conjugate.

Rung 3

First line of 2(b): \(\bra\psi P\ket\psi = \bra\psi Pg_1\ket\psi = -\bra\psi g_1P\ket\psi = -\bra\psi P\ket\psi\).

Worked solution

Idea. A stabiliser state is a list of Paulis; Clifford gates map lists to lists; measurements either confirm an element of the list or replace one.

1. \((Ug_jU^\dagger)U\psi = Ug_j\psi = U\psi\). Conjugation \(g\mapsto UgU^\dagger\) is a group isomorphism onto its image, so the images commute, are independent, and exclude \(-I\) (\(UgU^\dagger = -I\) iff \(g = -I\)); they are Pauli strings with signs because \(U\) is Clifford. \(n\) independent generators fix a one-dimensional space, which contains \(U\psi\).

2(a). \(v(S)\) is isotropic of dimension \(n\); \(v(S)^\omega\) has dimension \(2n - n = n\) and contains it; so they are equal. \(P\) commuting with all \(g_j\) means \(v(P)\in v(S)^\omega = v(S)\): \(P = cg\) with \(g\in S\). Both Hermitian, so \(c = \pm1\), and \(P\psi = c\psi\): outcome \(c\), probability 1, state unchanged.

2(b). Rung 3 gives \(\bra\psi P\ket\psi = 0\), using \(g_1\psi = \psi\) and \(\bra\psi g_1 = \bra\psi\). Then \(\Pr(\lambda) = \bra\psi\tfrac{I + \lambda P}{2}\ket\psi = \tfrac12\). The Lüders state is \(\psi_\lambda\propto(I + \lambda P)\psi\), which is nonzero: \(\|(I + \lambda P)\psi\|^2 = 2 + 2\lambda\bra\psi P\ket\psi = 2\). It is fixed by \(\lambda P\) (as \(\lambda P(I + \lambda P) = I + \lambda P\)) and by every \(h\in S\) commuting with \(P\). The listed elements commute with \(P\): \(g_j\) by assumption, and \(g_1g_j\) because both factors anticommute with \(P\). They commute with each other (all in \(S\), or \(\lambda P\) against elements commuting with \(P\)). Independence: \(v(g_2), \dots, v(g_n)\) and \(v(g_1)\) are independent, so the \(n - 1\) vectors \(v(g_j)\) or \(v(g_1) + v(g_j)\), \(j\ge2\), are independent (a dependence among them would express \(v(g_1)\), or 0, as a combination of \(v(g_2), \dots, v(g_n)\) — impossible); and \(v(P)\) is not in their span, since everything in it commutes with \(g_1\) and \(P\) does not. A nonzero common fixed vector \(\psi_\lambda\) rules out \(-I\). So \(\psi_\lambda\) is their stabiliser state.

3. CNOT conjugation: \(X_a\mapsto X_aX_b\), \(Z_a\mapsto Z_a\), \(X_b\mapsto X_b\), \(Z_b\mapsto Z_aZ_b\). Then \(i^{x_az_a + x_bz_b}X_a^{x_a}Z_a^{z_a}X_b^{x_b}Z_b^{z_b}\mapsto i^{x_az_a + x_bz_b}X_a^{x_a}Z_a^{z_a\oplus z_b}X_b^{x_a\oplus x_b}Z_b^{z_b}\) (moving factors on different qubits past each other costs nothing). The new letters' own prefactor is \(i^{x_a(z_a\oplus z_b) + (x_a\oplus x_b)z_b}\), so the sign is \(i^e\), \(e = x_az_a + x_bz_b - x_a(z_a\oplus z_b) - (x_a\oplus x_b)z_b\). If \(x_a = 0\): \(e = x_bz_b - x_bz_b = 0\). If \(z_b = 0\): \(e = x_az_a - x_az_a = 0\). If \(x_a = z_b = 1\): \((z_a, x_b) = (0,0)\) gives \(e = -2\); \((0,1)\): \(0\); \((1,0)\): \(0\); \((1,1)\): \(2\). So the sign flips exactly when \(x_a = z_b = 1\) and \(x_b = z_a\), i.e. \(x_az_b(x_b\oplus z_a\oplus1) = 1\).

4. Initialise \(Z_0, \dots, Z_{n-1}\): \(O(n^2)\) bits. Each gate: two columns and a sign per row, \(O(n)\). Each measurement: commutation checks \(O(n^2)\); case (a) elimination \(O(n^3)\); case (b) up to \(n\) row products \(O(n^2)\) and a fair coin. Total \(O(nm + qn^3)\), exact in distribution. At \(n = 1000\): \(2n^2 + n = 2\,001\,000\) bits, against \(2^{1000}\approx1.07\times10^{301}\) amplitudes.

Check. Part 3 on \(X_aZ_b\): \(x_a = z_b = 1\), \(x_b = z_a = 0\), sign flips; letters become \(Y_aY_b\); and directly \(X_aX_bZ_aZ_b = (X_aZ_a)(X_bZ_b) = (-iY_a)(-iY_b) = -Y_aY_b\) ✓.

P12 T is not Clifford routine

exercises: conjugating by \(T\), one-qubit stabiliser states, why a biased coin breaks the tableau

  1. Compute \(TXT^\dagger\) and \(TZT^\dagger\) for \(T = \mathrm{diag}(1, e^{i\pi/4})\), and show \(T\notin\mathcal C_1\).
  2. List the one-qubit stabiliser states and show \(T\ket+\) is not one of them.
  3. Compute the probability that measuring \(X\) on \(T\ket+\) gives \(+1\). Explain why this number alone proves no tableau can describe \(T\ket+\).
  4. The operator \(A = (X + Y)/\sqrt2\) fixes \(T\ket+\). Show that \(A\) neither commutes nor anticommutes with \(X\), and say which step of the measurement theorem this breaks.
Hints · 3 rungs
Rung 1

Two \(2\times2\) matrices, a list of six states, one probability, and one pair of products.

Rung 2

A one-qubit stabiliser group has one generator, \(\pm X\), \(\pm Y\) or \(\pm Z\). On a stabiliser state every Pauli measurement is certain or fair.

Rung 3

First line of part 1: \((TXT^\dagger)_{01} = 1\cdot1\cdot\overline{e^{i\pi/4}} = e^{-i\pi/4}\) and \((TXT^\dagger)_{10} = e^{i\pi/4}\).

Worked solution

Idea. \(T\) rotates by \(45^\circ\), halfway between the axes the Clifford group permutes.

1. \(TXT^\dagger = \begin{pmatrix}0 & e^{-i\pi/4}\\e^{i\pi/4} & 0\end{pmatrix} = \cos\tfrac\pi4X + \sin\tfrac\pi4Y = \tfrac{X + Y}{\sqrt2}\), since \(\cos\theta X + \sin\theta Y = \begin{pmatrix}0 & e^{-i\theta}\\e^{i\theta} & 0\end{pmatrix}\). \(TZT^\dagger = Z\) (both diagonal). \(\tfrac{X+Y}{\sqrt2}\) is not a phase times a single Pauli (its expansion in the basis \(I, X, Y, Z\) has two nonzero coefficients), so \(T\notin\mathcal C_1\).

2. Generators \(\pm X, \pm Y, \pm Z\) fix \(\ket\pm\), \(\ket{\pm i}\), \(\ket0\), \(\ket1\): six states, Bloch vectors \(\pm\hat x, \pm\hat y, \pm\hat z\). \(T\ket+ = \tfrac1{\sqrt2}(\ket0 + e^{i\pi/4}\ket1)\), normalised, Bloch vector \((\cos45^\circ, \sin45^\circ, 0) = (0.7071, 0.7071, 0)\): not one of the six.

3. \(\bra{T+}X\ket{T+} = \cos\tfrac\pi4 = 0.7071\), so \(\Pr(+1) = \tfrac{1 + 0.7071}{2} = 0.8536 = \cos^2\tfrac\pi8\). On a stabiliser state every Pauli outcome has probability 0, \(\tfrac12\) or 1 (measurement theorem). \(0.8536\) is none of these, so \(T\ket+\) is not a stabiliser state, and no tableau describes it.

4. \(XA = \tfrac1{\sqrt2}(I + iZ)\), \(AX = \tfrac1{\sqrt2}(I - iZ)\): neither equal nor opposite. The measurement theorem's case split — "commutes with every generator, or anticommutes with one" — and the computation \(\bra\psi P\ket\psi = -\bra\psi P\ket\psi\) both rely on \(PQ = \pm QP\), which holds only for Paulis.

Check. \(A\) is Hermitian with \(A^2 = \tfrac12(X^2 + XY + YX + Y^2) = I\) since \(XY + YX = 0\) ✓, and \(A\,T\ket+ = TXT^\dagger T\ket+ = TX\ket+ = T\ket+\) ✓.
